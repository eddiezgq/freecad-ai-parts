# AI 设计协作机器人 J2 输出空心轴（ADR-0100 42.5）

`requirement.txt` 是需求原话（示意数据：结构与节拍取自《机械设计》33.10，臂长与质量取自公开的 UR5e 资料）。
`python -m assist.joint_design -o out/result.json --model-dir out` 回放录制（`tests/recordings/joint_design/`，CI 上 Claude 生成）：
AI 列条件、选轴承、内孔与法兰圆角；载荷由代码从机器人动力学算；刚度、强度、花键、疲劳、轴承寿命由代码校核。
改到合格最多 4 轮，通过后再减重最多 3 轮，采用通过且最轻的一轮。

| 文件 | 内容 |
| --- | --- |
| `out/result.json` | 条件（每个数带原话引用）、AI 的问题、每一轮的方案与校核结论 |
| `out/shaft.step` | 三维模型：法兰、轴承位、隔套段、花键段（按大径圆柱，齿不建）、螺纹段（按公称直径），贯通内孔 |
| `out/readback.json` | 测量回读：外圆逐段与内孔都与设计一致 |
| `out/drawing.svg` | 外形轮廓、内孔（虚线）、尺寸，花键与螺纹的注 |
| `out/bom.json` | 自制件（质量取回读，花键齿槽未去除）+ 两个轴承；圆螺母、隔套不在零件库，不列 |

在问渠 CAD 里：“AI 设计零件”面板，零件类型选“关节空心轴”，“载入示例”后“开始设计”。
