# 示范缝纫机企业（虚构）：用 AI 快速建自己的零件库

ADR-0099 第 41.6 步的示范。**企业、物料表、自制件图号都是虚构的**；外购件的参数来自厂商公开目录（安川、NSK，
按 ADR-0040 抽取入公共库，每个值注明出处），自制件的尺寸从三维模型由代码测量。

## 输入

| 文件 | 内容 |
| --- | --- |
| `bom.csv` | 示范平缝机 WQ-LS 的物料表：41 行（含一行重复录入），自制件、电机驱动器、轴承、同步带、电磁铁、紧固件、杂项；有单价列（不发给 AI） |
| `models/LS-101.step` | 上轴（《机械设计》33.11 的 LS-101：Ø10×22、Ø12×10、Ø16×215、Ø12×10、Ø10×40） |
| `models/LS-HS.step` | 控制箱散热器（铝，120×80） |
| `confirm.yaml` | 企业工程师（虚构）确认的事项：自制件的零件类型与材料、厂商写法不同的对应关系、主轴选型的需求 |

## 怎么建

```bash
python examples/enterprise-lockstitch/build.py            # 回放录制（不联网）
python examples/enterprise-lockstitch/build.py --record   # 在 CI 上用真实模型录制（.github/workflows/enterprise-demo.yml）
```

产出：`library/`（企业库文件夹：自制件组件、登记的模型文件、写入记录）与 `out/`：

- `bom-result.xlsx / .json`：每条物料的品类、对应的组件、待人确认的事项、待补清单
- `completeness.xlsx / .json`：物料表用到的组件缺哪些数据、缺了哪些校验会待确认、去哪找、先补哪个
- `selection.json`：物料表里的电机 SGM7J-04A + 驱动器 SGD7S-2R8A 按 confirm.yaml 的需求做的 C1–C11 校验
- `summary.json`：上面的汇总

## 三条通道各做了什么

1. **三维模型（通道 C）**：代码量出上轴的五段（与 33.11 一致）、按 45 钢调质的密度算质量；散热器没给材料，只给体积。
   AI 只提议零件类型，以企业确认的为准。
2. **物料表（通道 B）**：AI 认列、提议品类；代码查重（两行 SGM7J-04A、两行 6201 各合并成一条）、对应公共库与企业库
   （“安川”与 Yaskawa Electric Corporation 写法不同，列为候选、由人确认）、按型号特征核对品类、列待补清单
   （6202、6000ZZ 库里没有；其余自制件没有三维模型）。
3. **产品目录（通道 A）**：外购件直接用公共库里已经从公开目录抽取、两次独立抽取一致的组件。

## 在问渠 CAD 里看

把 `library/` 设为企业库文件夹（零件库窗口 → 企业库），可以看到两个自制件；选中组件看“缺的数据”，
“完整度报告…”导出 Excel。
