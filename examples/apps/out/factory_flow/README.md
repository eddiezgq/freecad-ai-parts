# 典型应用的工厂一侧：ERP、MRP、MES、工厂计算、厂情中枢

## 依据

- [问渠数字工厂（本仓库 factory/digital）](http://localhost:8100)：本机原生启动的整座工厂：枢纽、假 ERPNext、桥接、车间仿真、计算服务

## 假设（不是零件库数据，按需改）

- 订货客户“示例·绿谷输送设备 GreenValley Conveyor (Demo)”、每种产品 2 台、交期 2026-11-21：演练假设
- 采购件交期、单价、成品售价零件库里没有，本脚本不填：工厂按“交期待确认”排程
- 车间仿真 120 倍速；采购到货由脚本代替供应商送货
- 自制件工艺规程以方案带来的工艺路线为起点，第一道机加工工序的粗基准与装夹（回转件外圆 / 三爪卡盘，板件毛坯底面 / 平口钳）由脚本按工艺员的常规写法补上；工艺计算书没有，AI 评审会提醒
