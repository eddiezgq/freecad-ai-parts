# 工业直驱平缝机（JUKI DDL-9000C 一类）

## 依据

- [JUKI DDL-9000C 系列样本（经销商发布的 PDF）](https://www.sewingmachinesplus.com/media/products/juki/juki-9000c/brochure.pdf)：最高缝速 5000 针/分（半干式）；针杆行程 35.0 mm（厚料）/ 30.7 mm（薄料）；400 W 小型交流伺服电机直联主轴（直驱）
- [问渠《机械设计》第 33.11 节案例：平缝机上轴 LS-101](https://github.com/eddiezgq/freecad-ai-parts/blob/main/factory/digital/hub/case_parts.py)：上轴各段直径、长度：Ø10×22（针杆曲柄座）、Ø12×10、Ø16×215、Ø12×10、Ø10×40

## 假设（不是零件库数据，按需改）

- 针杆机构按曲柄滑块：曲柄半径 17.5 mm（行程 35 mm）、连杆 60 mm、杆宽 8 mm、厚 5 mm、45 钢；针杆（滑块）质量按模型方块取，是示意值；不计挑线、旋梭、送布机构。平衡块只平衡机座振动，恒速下不改变驱动扭矩，所以不建
- 缝制阻力、摩擦零件库与样本都没有：连续扭矩的下限不含它们，结论待确认
- 起停加速时间 0.05 / 0.1 / 0.2 s（样本没有，设计假设）；转速不均匀系数取 0.05 只为说明手轮大小，不是标准值
- 供电按缝纫车间 200 V 三相（零件库的 SGD7S 驱动器要求三相；只有单相 220 V 时要换驱动器）
- 上轴两个轴承位按径向支承；表面系数 β = 0.92、尺寸系数 ε = 0.85（问渠数字工厂实验 8 的示例值）
- 控制箱散热器：铝底板 120×80×6 mm、8 片直翅高 30 mm；风扇风速 2 m/s、空气 35 °C、散热器 60 °C

## 各步结果

| 步骤 | 结论 | 摘要 |
| --- | --- | --- |
| 动力学：针杆机构 | 完成 | 主轴恒速 5000 rpm：惯性力矩峰值 2.82 N·m、均方根 1.60 N·m，一转平均 -0.060 N·m（往复质量的动能有增有减，一转做功约为零）；最大盈亏功 ΔE = 2.23 J，教材近似 ½·m·(rω)²·max(sinθ + λ/2·sin2θ)² = 2.07 J（往复质量取滑块 + 连杆一半）；机构最大等效惯量 4.89e-05 kg·m²。针杆质量按杆宽、杆厚取的示意值，不是实物数据 |
| 选型（上限：刚性速度环） | 失败 | 连续 = 惯性力矩均方根 1.60 N·m、峰值 3.08 N·m（惯性力矩峰值 + 0.1 s 起停的机构加速 0.26）；引擎逐对校验 28 组：没有全部通过的：扭矩、转速够的电机有 SGM7J-08A，但库里最大的驱动器 SGD7S-2R8A（2.8 A）带不动（C9），要补更大驱动器的数据 |
| 选型（下限：惯量吸收） | 待确认 | 连续 = 机构一转平均扭矩 0.060 N·m（不含缝制阻力，零件库与样本都没有 → 待确认）、峰值同上；引擎逐对校验 28 组，取功率最小的 SGM7J-04A、SGD7S-2R8A（总体 pass）——与 JUKI 实机的 400 W 一致。转子惯量 4.86e-05 + 机构 4.89e-05 kg·m²：转速不均匀系数 δ = ΔE/(J·ω²) = 0.083；要降到 δ = 0.05（示例值）需再加约 6.5e-05 kg·m²（手轮）。起停加速 0 → 5000 rpm：转子本身要 0.05 s 时 0.51 N·m、0.1 s 时 0.25 N·m、0.2 s 时 0.13 N·m，机构 0.05 s 时 0.51 N·m、0.1 s 时 0.26 N·m、0.2 s 时 0.13 N·m（加速时间是假设） |

| 固有频率：上轴 LS-101 | 完成 | 两轴承位径向支承、电机端固定：一阶 1184.69 Hz（71081.0 rpm），工作 5000 rpm = 83.3 Hz，比值 14.2——远离共振（不计装在轴上的曲柄、带轮、转子的质量） |
