# 工业直驱平缝机（JUKI DDL-9000C 一类）

## 依据

- [JUKI DDL-9000C 系列样本（经销商发布的 PDF）](https://www.sewingmachinesplus.com/media/products/juki/juki-9000c/brochure.pdf)：最高缝速 5000 针/分（半干式）；针杆行程 35.0 mm（厚料）/ 30.7 mm（薄料）；400 W 小型交流伺服电机直联主轴（直驱）
- [问渠《机械设计》第 33.11 节案例：平缝机上轴 LS-101](https://github.com/eddiezgq/freecad-ai-parts/blob/main/factory/digital/hub/case_parts.py)：上轴各段直径、长度：Ø10×22（针杆曲柄座）、Ø12×10、Ø16×215、Ø12×10、Ø10×40

## 假设（不是零件库数据，按需改）

- 针杆机构按曲柄滑块：曲柄半径 17.5 mm（行程 35 mm）、连杆 60 mm、杆宽 8 mm、厚 5 mm、45 钢；不计挑线、旋梭、送布机构，未加平衡块
- 主轴恒速 5000 rpm；缝制阻力、摩擦零件库与样本都没有，未计（实际扭矩会更大）
- 供电按缝纫车间 200 V 三相（零件库的 SGD7S 驱动器要求三相；只有单相 220 V 时要换驱动器）
- 上轴两个轴承位按径向支承；表面系数 β = 0.92、尺寸系数 ε = 0.85（问渠数字工厂实验 8 的示例值）
- 控制箱散热器：铝底板 120×80×6 mm、8 片直翅高 30 mm；风扇风速 2 m/s、空气 35 °C、散热器 60 °C

## 各步结果

| 步骤 | 结论 | 摘要 |
| --- | --- | --- |
| 动力学：针杆机构 | 完成 | 主轴 5000 rpm：驱动扭矩峰值 2.50 N·m、均方根 1.58 N·m（主要是针杆往复惯性力，未加平衡块）；最大等效惯量 4.89e-05 kg·m² |
| 选型：主轴直驱电机 | 失败 | 直驱（无减速器）：引擎逐对校验 28 组电机 + 驱动器，没有全部通过的。电机扭矩、转速够的有 SGM7J-06A、SGM7J-08A；但零件库里最大的驱动器 SGD7S-2R8A 额定电流 2.8 A，带不动这些电机（C9）——要补更大驱动器的数据。另：针杆机构未加平衡块、扭矩偏大；JUKI 实机用 400 W，差距可能来自平衡块等这里没建模的因素 |
| BOM | 完成 | （按最接近的组合，驱动器待换）外购件：Yaskawa Electric Corporation SGM7J-06A、Yaskawa America, Inc. SGD7S-2R8A；总质量 2.7 kg |
| 布局与干涉 | 不适用 | 直驱电机直接装在机头上，没有电机—减速器的端口配合要摆（V1 的布局针对关节模组） |
| 固有频率：上轴 LS-101 | 完成 | 两轴承位径向支承、电机端固定：一阶 1184.69 Hz（71081.0 rpm），工作 5000 rpm = 83.3 Hz，比值 14.2——远离共振（不计装在轴上的曲柄、带轮、转子的质量） |
| 有限元：上轴扭转 | 完成 | 针杆端加峰值扭矩 2.50 N·m：最大 Von Mises 33.4 MPa、安全系数 10.6；Ø10 段手算 τ = 16T/πd³ = 12.7 MPa（等效 22.1） |
| 疲劳：上轴 | 完成 | 5000 rpm 下每转一个扭矩循环（0.3 s 记录 10 个循环）：无限寿命 |
| 数控编程：上轴 | 完成 | Ø20 棒料、两次装夹 2 个程序、约 1.5 min；检查：没有发现问题（细长轴 L/d ≈ 30，实际要顶尖、跟刀架，仿真不计让刀） |
| 流体：控制箱散热器 | 完成 | 风速 2 m/s、散热器比空气高 25 K：散热 23.2 W、平均散热系数 13.6 W/(m²·K)、压降对应阻力 0.003 N；驱动器损耗零件库无数据，待确认够不够 |
| 拓扑优化：电机支架 | 完成 | 支架构形（左边固定、右下角受力）、材料用量 40%：柔度 403 → 50，45 次迭代；板面积 2124 mm² |
| 热分析 / 数字孪生 | 不适用 | 直驱没有减速器、零件库也没有轴承，孪生无可算的零件；电机温升需要电机损耗数据 |
