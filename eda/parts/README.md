# 器件电气参数（问渠电子，第 104 轮）

每个器件一个 YAML（`format: wqeda.part/1`）。**每个数都要有出处**：厂家规格书名称、版本、网址、页码或章节（`where`）。

- `checked: false`：录了但没逐页对照规格书 PDF 核对。用到它的判定显示“待核对”，**不算通过**。
- 核对过的人把 `checked` 改成 `true`（最好在提交说明里写谁核对、对照的哪一版 PDF）。
- 没有文件、或文件里没有这一项：用到它的判定是“未知”。
- 不写估计值、不写“典型应用”里的数；规格书里查不到就不写。

第 104 轮录入的五个器件，数值是从厂家官网规格书经网页工具读取的，全部 `checked: false`。IR2101S、AMS1117、MCP2562 的官方规格书当时打不开，没有录（相关判定为“未知”）。
