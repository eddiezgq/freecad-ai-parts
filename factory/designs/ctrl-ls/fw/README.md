# 平缝机控制器 CTRL-LS · 示例固件（第 159 轮 159f）

MCU STM32G431（与驱动板 B 版同一颗）。主轴伺服沿用 B 版的磁场定向控制写法，换成本板：功率模块 STGIPS14K60T（16 kHz、死区 1 µs、SD 低有效）、
三相下桥 25 mΩ 采样 + 片内运放 8 倍、2500 线编码器（TIM4 编码器模式）。上面加缝纫状态机：

待机 → 脚踏前踩：起缝加固（正 4 针、倒 4 针，倒缝电磁铁）→ 缝纫（转速跟脚踏，最高 5000 r/min）→ 脚踏回中：停下针位 180° →
脚踏后踩：减到 300 r/min 转一针剪线（剪线电磁铁在 200°–330° 吸合）→ 停上针位 70° → 拨线 → 抬压脚（后踩不松就抬着）。

开机：量电流零点 → d 轴通电对零（加阻尼、等停稳）→ 低速找编码器 Z 相（针杆最高点 = 主轴 0°）→ 停上针位 → 就绪。
保护：过流（7.5 A，本周期关断）、欠压（300 V）、堵转（电流顶到上限、转速 < 30 r/min 连续 200 ms）；故障时关输出（MOE 关、SD 拉低）、电磁铁全部释放。

板上的调试口只有 SWD：遥测区 `mc`（电机）、`sw`（缝纫）、面板设置 `cfg`（仿真里由 Renode 读写内存）。
没做的（留了引脚）：针距步进电机、操作面板串口、联网、校正关断。

示例固件，仿真验证；电机未选型（极对数、电阻、电感是示例值），不能直接用于产品。

## 和 159c 的复算对照（`out/sim_sew.json` 场景 ①）

159c 用第 138 轮 `tools/wqls/gc_sim.py` 的模型（力矩上限 3.0 N·m）算了一个工作周期；这里是真固件在 Renode 里接同一张 G2 一转负载表跑同一个周期。
起动时间、稳速波动、减速时间、停针误差、剪线时转速逐项对照，见网页“电路板设计 → 平缝机控制器 → 固件”或 `out/sim_sew.json`。

## 文件

| 文件 | 内容 |
|---|---|
| `src/motor.c`、`motor.h` | 16 kHz 电流环（Clarke / Park、PI、SVPWM、死区补偿）、三阶速度观测器、2 kHz 速度环（带宽 40 Hz + 加速度前馈）、停针位置环、对零、找 Z 相、保护 |
| `src/sew.c`、`sew.h` | 缝纫状态机、脚踏、四个电磁铁（剪线 PA5、拨线 PA11、倒缝 PA12、抬压脚 PA15，低电平吸合） |
| `src/regs.h` | 用到的寄存器（对照 ST 官方 CMSIS 头文件；运放接 ADC 的内部通道对照 LL 驱动） |
| `renode/WqSew.cs` | 功率级与被控对象：TIM1 + 功率模块 + 永磁同步电机 + 主轴一转负载 + Z 相 + 电磁铁记录、TIM4 编码器、ADC1/ADC2 |
| `renode/load_table.txt` | 第 138 轮 G2 一转负载表（`gen_load.py` 用 `tools/wqls/dyn.py` 生成，与 159c 同一张） |
| `run_sew.py` | 四个场景：① 与 159c 同一个工作周期 ② 缝一段 ③ 针卡住（过流）④ 阻力太大（堵转），写 `out/sim_sew.json` |
| `ref_159c.py` | 从 159c 的模型多取两个对照量（剪线时转速、减速时间），写 `out/ref_159c.json` |
| `pack.py` | 写 `out/fw.json`（网页用）、打包 `out/ctrl-ls-fw.zip` |

## 自己跑

需要 `arm-none-eabi-gcc`（Ubuntu：`apt install gcc-arm-none-eabi`）和 Renode 1.15（Linux 便携版解压即可）。

```
make
python3 run_sew.py --renode <Renode 目录>/renode
python3 pack.py
```
