# 计算书：DRV-JOINT（B 版）

关节伺服驱动板 DRV-JOINT B 版（放上编码器接口芯片 WQ-ENCIF、加抱闸驱动；设计对照，不投产）

> 示例设计，未经硬件验证，不能直接投产。器件为示例选型（KiCad 官方库里有的器件，引脚取自库）。
> 由问渠电子功能块计算器生成（第 104 轮）。判定：通过 / 不通过 / 未知（缺数据）/ 待核对（用到的器件数据还没人对照规格书核对，不算通过）。

## 相对底稿改了什么

- U10：引脚 12：未用 → ENC_CS_N
- U10：引脚 13：未用 → ENC_SCK
- U10：引脚 14：ENC_A_F → ENC_MISO
- U10：引脚 15：ENC_B_F → ENC_MOSI
- U10：引脚 16：ENC_Z_F → BRK_ISEN
- U10：引脚 17：未用 → ENC_RST_N
- U10：引脚 43：未用 → BRK_PWM
- U14：新增：编码器接口芯片 WQ-ENCIF（第 92 轮设计，未流片）：滤波、4 倍频计数、SPI 从机
- Y2：新增：芯片时钟 50 MHz 有源晶振（示例选型）
- U15：新增：芯片核心电源 1.8 V（示例选型）
- C57：新增：U14 VDDIO 去耦
- C58：新增：U14 VCCD 去耦
- C59：新增：U15 输入
- C60：新增：U15 输出
- C61：新增：Y2 去耦
- U16：新增：抱闸栅极驱动（示例选型，第 110 轮）：12 V 供电，输入兼容 3.3 V
- Q7：新增：抱闸低边开关（同三相桥的 MOSFET）：PWM 20 kHz，松闸先 100% 50 ms，再保持平均 24 V（示例）
- D5：新增：抱闸线圈续流
- R36：新增：抱闸 MOSFET 栅极电阻
- R37：新增：栅源下拉：驱动没电时 MOSFET 关断
- R38：新增：抱闸输入下拉：MCU 复位、没输出时线圈断电 → 抱住（失效安全）
- C62：新增：U16 去耦
- J6：新增：抱闸线圈（失电制动，24 V 0.42 A，示例）：1 = 母线 +、2 = 线圈 −
- R39：新增：抱闸线圈电流采样（第 114 轮）：0.5 Ω 在 Q7 源极，导通时电压 = 线圈电流 × 0.5 Ω（示例）
- R40：新增：采样滤波（与 C63 约 160 Hz）
- C63：新增：采样滤波：读到的是“线圈电流 × 占空比 × 0.5 Ω”的平均值
- 铺铜：新增 VBUS 铺铜（F.Cu）
