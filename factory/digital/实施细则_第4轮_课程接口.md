# 问渠数字工厂 · 实施细则 · 第 4 轮：课程接口

2026-09-30 · 承接：第 3 轮（已上线）；《docs/方案/数字工厂资源接口约定》第三节（学习平台一侧起草，本轮定下路径与字段后写回为 v0.2）

> 状态：**已完成（2026-09-30）**。C5 随第 3 轮补丁上线；第 2–7 步在零件库第一期之后完成并上线，见第七节。

## 一、目标

学习平台（AI 建课、讲义、插图、动画、虚拟实验）从数字工厂取**真实案例和生产数据**：产品结构、工艺、质检方案、成本、设计版本、测量值、设备事件、AGV 轨迹、订单与指标、车间平面，以及可嵌入的只读 3D 车间。

学生和老师不直接调用这些接口；学习平台的网关用一把只读钥匙，服务器对服务器地取数据，课件生成时复制进课程。

## 二、决定

| 编号 | 决定 | 说明 |
|---|---|---|
| C1 | 接口放在枢纽（hub），路径前缀 `/api/course/`，只读 | 约定 3.2 的路径原样采用 |
| C2 | **认证**：请求头 `Authorization: Bearer <WQ_FACTORY_READ_KEY>`；钥匙由数字工厂 `install.sh` 生成，存在服务器 `/opt/wenquest/factory/.env`；学习平台的部署脚本从这个文件读取，写进学习平台的 `.env`（同一台服务器）；换钥匙：删掉该行后运行 `deploy/update.sh`，再重启学习平台 | 只读、可随时更换；不给浏览器 |
| C3 | **走公网地址** `https://factory.wenquestrobotics.com/api/course/...`（经 Caddy）；以后分开部署也不用改 | 学习平台网关不必接入数字工厂的内部网络 |
| C4 | **不含个人信息**：课程接口返回的数据里，操作人只写**角色**（计划员、工艺员、操作工、质检员、厂长、系统、仿真）；不返回姓名、账号编号 | 约定第三节要求 1 |

| C6 | 每次返回带 `as_of`（数据截至时间，UTC）、`source`（`factory-data`＝工厂设计数据，`erpnext`，`historian`＝总线历史库，`freecad`） | 课件注明“数据来自问渠数字工厂，截至 …” |
| C7 | 列表型接口一页最多 10 000 行，`page` 从 1 开始，返回 `next`（下一页页码，没有则为 `null`） | |
| C8 | **嵌入式 3D 车间**：实时画面不用登录（它显示的设备状态、AGV 位置本来就可以匿名只读，且 C5 之后不含姓名）；回放某段历史需要一个 30 分钟有效的**嵌入凭证**，由学习平台网关用只读钥匙向 `/api/course/embed-token` 申请，放在网址参数 `token` 里 | 约定第六节待定 3 的答复；浏览器里拿不到只读钥匙 |
| C9 | 产品结构里的物料若在零件库有对应条目，带上 `library_ref`（如 `A-BRG-DG/6207`）；枢纽每天读一次零件库的 `latest.json` 和 `index.json` 里的 `erp_items` 建对照；库还没发布时为 `null` | 与第 2 轮 L11 衔接 |
| C10 | 教学情景 `case` 目前只有一个：`lab7`（实验 7，对应教学模式的数据）；生产模式的数据不对课程接口开放 | 生产模式将来是企业的真实数据 |

## 三、上线后发现的问题：总线上的姓名（C5）

第 3 轮 D5 让浏览器匿名只读总线（`wss://factory.wenquestrobotics.com/mqtt`）。但总线消息里有操作人的姓名：`source` 写成 `workbench/<姓名（编号）>`、`mes/<姓名>`，提议的 `confirmed_by`、不合格品的 `decided_by` 也是姓名。任何人连上总线都能看到正在做实验的学生姓名。

**改法**：枢纽发到总线的消息，操作人一律写“角色·匿名编号”。匿名编号 = 问渠账号编号的 HMAC 前 4 位（同一个人始终相同，看不出是谁）。枢纽数据库里照旧存姓名，页面上本人和老师看得到姓名；总线、课程接口、3D 车间都只见匿名。本地版（填名字登录）不变。

**建议作为第 3 轮的补丁先做**（不必等课程接口），推送后自动上线。

## 四、接口

路径均在 `https://factory.wenquestrobotics.com` 下；除 `/embed/workshop` 外都要带只读钥匙。

| 接口 | 返回 |
|---|---|
| `GET /api/course/products` | `{"as_of", "source", "items": [{"code", "name": {"zh","en"}, "summary", "image", "specs": {...}}]}`。`image` 为产品示意图地址（暂无时 `null`）；`specs` 是主要参数，WQR-105 为传动比、输入转速、输出转速、中心距 |
| `GET /api/course/products/{code}` | 见 4.1 |
| `GET /api/course/designs/{item}` | 设计版本列表，见 4.2 |
| `GET /api/course/cases` | `{"items": [{"id": "lab7", "name": {"zh","en"}, "summary", "mode": "teach", "guide_url"}]}` |
| `GET /api/course/data?case=lab7&kind=…&from=…&to=…&page=1` | 生产数据，见 4.3；`from`、`to` 为 ISO 时间（UTC），不给则为最近 7 天 |
| `GET /api/course/layout` | 车间平面：`{"floor": {"w_m","d_m"}, "units": [{"unit","name":{"zh","en"},"x_m","y_m","w_m","d_m","area","operations":[...]}], "aisles": [...], "agv_home": {...}}` |
| `GET /api/course/embed-token?ttl=1800` | `{"token", "expires"}`，用于回放 |
| `GET /embed/workshop?view=overview&device=&mode=live&t0=&speed=&token=` | 可嵌入的只读 3D 车间页面：`view` 为 `overview`（全车间）或 `device`（对准某台设备，`device` 为设备单元号，如 `grd-01`）；`mode=live` 实时，`mode=replay` 从 `t0` 开始按 `speed` 倍速回放（要 `token`）；页面上没有任何操作按钮 |

### 4.1 产品详情（数值为示例）

```json
{"as_of": "2026-10-05T14:00:00Z", "source": ["factory-data", "erpnext"],
 "code": "WQR-105", "name": {"zh": "二级圆柱齿轮减速器 i=10.5", "en": "Two-stage gear reducer"},
 "bom": {"item_code": "WQR-105", "name": {...}, "kind": "fg", "qty": 1, "uom": "Nos", "library_ref": null,
         "children": [{"item_code": "SA-300", "kind": "sub", "qty": 1, "children": [
             {"item_code": "BRG-6207", "kind": "buy", "qty": 2, "uom": "Nos", "library_ref": "A-BRG-DG/6207"}]}]},
 "routings": {"SH-301": [{"seq": 1, "operation": {"zh": "下料", "en": "Sawing"}, "workstation": "saw-01", "minutes": 3}]},
 "workstations": [{"unit": "saw-01", "name": {...}, "rate_per_hour": 38.0, "capacity": 1}],
 "quality_plans": [{"template": "零件检验-输出轴", "item_code": "SH-301", "characteristics": [
     {"name": {"zh": "轴承位直径 Ø35 k6", "en": "Bearing seat Ø35 k6"}, "numeric": true, "unit": "mm",
      "min": 35.002, "max": 35.018, "gauge": "三坐标"}]}],
 "std_cost": {"SH-301": {"material": 4.48, "operations": 57.9, "total": 62.38, "currency": "USD"}}}
```

`kind` 取 `raw`（原材料）、`buy`（外购件）、`make`（自制零件）、`sub`（组件）、`fg`（成品）。

### 4.2 设计版本（数值为示例）

```json
{"as_of", "source": ["freecad", "historian"], "item": "SH-301",
 "revisions": [{"revision": 2, "released_at": "…", "author_role": "engineer", "change_note": "键槽长 45 → 42 mm",
   "params": {...},
   "files": [{"kind": "step", "name": "SH-301_r2.step", "url": "https://factory…/api/files/<sha256>", "sha256": "…"},
             {"kind": "svg", "name": "SH-301_r2.svg", "url": "…"}, {"kind": "gcode", "name": "…", "url": "…"}],
   "gcode": {"operation": "…", "machine": "key-01", "est_time_s": 540, "lines": 23}}]}
```

### 4.3 生产数据

`{"as_of", "source": "historian", "case", "kind", "from", "to", "rows": [...], "page", "next"}`；每种 `kind` 一行的字段：

| `kind` | 字段 |
|---|---|
| `measurement` | `ts`、`part_serial`、`item`、`work_order`、`characteristic`、`name`、`nominal_mm`、`lower_tol_mm`、`upper_tol_mm`、`value_mm`、`result` |
| `event` | `ts`、`unit`、`event`（`cycle_start`/`cycle_end`/`op_complete`/`alarm`/`fault`/`recover`/`tool_change`/`state`）、`state`、`work_order`、`operation`、`code`、`message`、`cycle_time_s`、`actor_role` |
| `agv` | `ts`、`unit`、`x_m`、`y_m`、`heading_deg`、`load`、`task` |
| `order` | `ts`、`doctype`、`name`、`action`、`status`、`customer`、`item_code`、`qty`、`delivery_date`、`produced_qty` |
| `kpi` | 每天一行：`date`、`otd`（准时交付率）、`oee`、`fpy`（一次合格率）、`wip`、`output`、`cost_variance_pct` |
