# 数字工厂课程接口（给学习平台开发者）

学习平台的网关用一把只读钥匙，从数字工厂取真实案例和生产数据，放进课件。学生和老师不直接调用这些接口。字段的完整说明见《docs/方案/数字工厂资源接口约定》第三节（3.2 接口表、3.3 实现说明）。

## 一、钥匙和地址

- 地址：`https://factory.wenquestrobotics.com`（网关环境变量 `WQ_FACTORY_URL`）。
- 钥匙：请求头 `Authorization: Bearer <WQ_FACTORY_READ_KEY>`（网关环境变量同名）。
- 钥匙由数字工厂部署时生成，学习平台部署时（`deploy/update.sh`）自动复制，不用手工配置。
- **换钥匙**：登录服务器，删掉 `/opt/wenquest/factory/.env` 里 `WQ_FACTORY_READ_KEY` 这一行，运行 `/opt/wenquest/factory/deploy/update.sh`（生成新钥匙并重启枢纽），再运行 `/opt/wenquest/deploy/update.sh`（学习平台复制新钥匙并重启网关）。

在服务器上试一下（`jq` 只是为了看得清楚）：

```bash
KEY=$(grep ^WQ_FACTORY_READ_KEY= /opt/wenquest/factory/.env | cut -d= -f2)
curl -s -H "Authorization: Bearer $KEY" https://factory.wenquestrobotics.com/api/course/products | jq .
curl -s -H "Authorization: Bearer $KEY" "https://factory.wenquestrobotics.com/api/course/data?case=lab7&kind=measurement" | jq '.rows[:3]'
```

## 二、接口一览

| 接口 | 用途 |
|---|---|
| `GET /api/course/products` | 产品清单（目前是 WQR-105 减速器：传动比、输入输出转速、中心距、两级齿轮） |
| `GET /api/course/products/WQR-105` | 物料清单树（带零件库编号 `library_ref`）、工艺路线、工位与费率、检验方案、标准成本 |
| `GET /api/course/designs/SH-301` | 输出轴的设计版本：参数、变更说明、STEP、零件图 SVG、G 代码 |
| `GET /api/course/cases` | 教学情景（目前只有 `lab7`） |
| `GET /api/course/layout` | 车间平面：设备位置尺寸、通道、AGV 停靠点 |
| `GET /api/course/data?case=lab7&kind=…&from=…&to=…&page=1` | 生产数据：`measurement` 测量值、`event` 设备事件与状态变化、`agv` 小车轨迹、`order` 订单与工单、`kpi` 每日指标 |
| `GET /api/course/embed-token?ttl=1800` | 3D 车间回放用的嵌入凭证（最长 30 分钟） |
| `/embed/workshop?…` | 可嵌入的只读 3D 车间页面 |

每次返回都带 `as_of`（数据截至时间）和 `source`（数据来源），课件里注明“数据来自问渠数字工厂，截至 …”。列表一页最多 10 000 行，`next` 不为空就用 `page=next` 取下一页。数据里没有姓名，操作人只写角色。

## 三、嵌入 3D 车间

```html
<!-- 实时，全车间 -->
<iframe src="https://factory.wenquestrobotics.com/embed/workshop?view=overview&mode=live" width="960" height="540"></iframe>
<!-- 回放：对准外圆磨床，从 t0 开始 60 倍速；token 由网关用只读钥匙申请 -->
<iframe src="https://factory.wenquestrobotics.com/embed/workshop?view=device&device=grd-01&mode=replay&t0=2026-10-20T12:00:00Z&speed=60&token=…"></iframe>
```

- `view`：`overview` 全车间，`device` 对准一台设备（`device` 用设备单元号，见 `layout` 接口的 `units[].unit`）。
- `mode=live` 不用登录；`mode=replay` 要 `token` 和 `t0`，`speed` 为倍速（默认 1）。
- 页面没有操作按钮，只能拖动旋转、滚轮缩放。
- 只允许从 `learn.`、`factory.` 和本机开发地址嵌入。

## 四、注意

- 只开放教学情景（实验 7）的数据，生产模式的数据不开放。
- 数值会随实验进行而变化：课件生成时把用到的数据复制进课程，不要每次上课都实时取。
- 零件库对照 `library_ref` 每天更新一次；零件库还没对上的物料为 `null`。
