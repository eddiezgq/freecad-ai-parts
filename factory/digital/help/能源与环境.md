# 能源与环境

数字工厂工作台左侧“保障 → **能源与环境**”（第 18 轮 E6 上线）。

它把能源接进工厂主线：**设备状态 → 功率 → 计量读数 → 单件能耗 → 电费（峰平谷）→ 碳排放**，再加车间环境的两项监测（油雾、噪声）。机床开着没活（空转）、热处理炉在电价最贵的时候开炉、设备劣化每件多用电，都会在这里看到，也会在厂情中枢报出来。

- 数据都在平台自己的表，不进 ERPNext；维修、整改仍走 ERPNext（设备维护的维修工单、安全环保的整改工单）。
- **教学模式**由仿真车间按设备状态和功率每 15 分钟（工厂时间）发一个读数，和真实电表的抄表间隔一样；计量只记数，不改车间节拍。
- **生产模式**默认不计量：以后接电表网关（MQTT / Modbus）或导入读数，写进同一张表。

**谁能用：**
- 看：所有角色；
- 改电价、排放因子、合同需量、环境限值：厂长；
- 节能设定、错峰：计划员、维修工或厂长发起，厂长批准（改变车间的运行方式）；
- 老师（教学模式）可以开关能源模拟器、注入问题。

页面上方六个数：用电、电费（峰 / 平 / 谷电量）、峰时占比、空转电量、碳排放、本月需量 / 合同需量。默认看最近一天（刚过半夜不到 6 小时时看前一天），总览里可以翻前一天、后一天。

## 一、计量点

16 个计量点 + 2 个环境监测点：

| 编号 | 是什么 |
| --- | --- |
| E-SAW-01 … E-TEST-01 | 12 台设备各一块电表（kWh） |
| E-AIR | 空压机电表 |
| E-TOTAL | 车间总表（各设备 + 空压机 + 照明空调） |
| F-AIR | 压缩空气流量计（m³） |
| W-MAIN | 自来水总表（m³） |
| ENV-MIST、ENV-NOISE | 机加区油雾（mg/m³）、车间噪声（dB(A)） |

每台设备四档功率（kW）：

| 设备 | 运行 | 空转 | 待机 |
| --- | --- | --- | --- |
| 带锯床 SAW-01 | 7.5 | 2.0 | 0.3 |
| 数控车床 A / B | 15 / 11 | 5.5 / 4.5 | 0.6 / 0.5 |
| 立式 / 卧式加工中心 | 15 / 18 | 5.0 / 6.0 | 0.6 / 0.7 |
| 键槽铣床 / 滚齿机 | 5.5 / 7.5 | 2.0 / 2.5 | 0.3 / 0.4 |
| 热处理炉 HT-01 | 110（升温） | 35（保温） | 不待机 |
| 外圆磨床 GRD-01 | 11 | 4.0 | 0.5 |
| 检验站 / 装配工位 / 跑合试验台 | 1.5 / 3 / 15 | 0.8 / 1 / 1.5 | 0.2 / 0.2 / 0.3 |

- **空转**：开着没活。
- **关机**：这一班没人的设备（按班次下班，或排班里这台这一班没人），下班的人顺手关掉；**忘了关**就一直空转。检验站、试验台是自动设备，不按班次关。
- **待机**：设了“空闲 N 分钟自动待机”，空闲到时自己转待机；再开要**预热 3 分钟**（算调整时间）。
- **空压机** = 卸载 2 kW + 按开着的用气设备用气；漏气时多出一截。

在“计量点”一栏选一个计量点看曲线（24 小时 / 3 天 / 7 天）。

## 二、总览

- **总表曲线**：每 15 分钟的平均功率，红色峰时（8–11、18–21 点，$0.15/度）、黄色平时（$0.10/度）、蓝色谷时（23–7 点，$0.05/度）；虚线是合同需量。
- **每台设备的电量条**：运行、调整、空转、待机、停机、关机分色。灰色（空转）多的设备，可以考虑自动待机。
- **节能设定**：车间正在用的自动待机、错峰、隔声罩。

## 三、单耗

- **单件运行电量**：每台设备每个物料最近 3 件的每件电量，对比基线（之前近 7 天；不到 5 件就用“运行功率 × 标准工时 × 1.08”）。高 25% 以上厂情中枢报“单耗突增”——多半是主轴轴承、刀具 / 砂轮在劣化。
- **近 12 小时空转**：每台设备的空转电量、空转小时、占比。
- **公用**：空压机比按开着的用气设备该用的多多少（多 3 kW 以上可能漏气）；近 24 小时峰时占比、其中热处理炉多少。

## 四、碳与环境

- **碳核算**（范围 2：外购电力）：本月电量 × 电网排放因子（默认 0.5306 kg CO2/度，生态环境部、国家统计局公布的 2023 年度全国电力平均二氧化碳排放因子，可按地区和新公布的值改）。
- **每件产品的碳足迹（全口径）**：各工序设备本月的电量 ÷ 件数，加上空压机、照明按件分摊。开工率低时每件分摊的保温、空转很多，会比“运行功率 × 工时”大得多。
- **车间环境**：油雾（按开着的湿式加工设备数推算，限值 5 mg/m³）、噪声（运行设备声级叠加，限值 85 dB(A)）。
- **参数**：电价、排放因子、合同需量、环境限值，只有厂长能改。

## 五、厂情中枢的异常

| 规则 | 什么时候报 |
| --- | --- |
| N1 单耗突增 | 某台设备某物料最近几件的单件电量比基线高 25% 以上 |
| N2 空转能耗高 | 近 12 小时某台设备空转电量占 30% 以上（至少 1 小时、10 度）；只报最多的 3 台，热处理炉保温不算 |
| N3 峰时用电占比高 | 近 24 小时峰时电量占 30% 以上 |
| N4 压缩空气基荷高（可能漏气） | 近 4 小时空压机比该用的多 3 kW 以上 |
| N5 需量接近合同需量 | 本月最大 15 分钟平均功率超过合同需量的 90%（超过合同为严重） |
| N6 车间环境指标超限 | 近 1 小时油雾或噪声平均超过限值 |

读数停了 3 小时以上（车间没在跑）不判。

**处理方案**（指挥台右栏）：

| 异常 | 方案 |
| --- | --- |
| N2 空转 | 不处理（对照）/ 这台空闲 10 分钟自动待机 / 30 分钟 / 全部机加设备 10 分钟；车间推演算未来 24 小时的电量、电费、碳和交期 |
| N3 峰时、N5 需量 | 热处理错峰（峰时不开新炉，工件攒着峰后一起进炉）/ 不处理 |
| N1 单耗突增 | 开维修工单（设备维护）/ 暂不处理 |
| N4 漏气 | 整改工单：管路查漏 / 暂不处理 |
| N6 环境超限 | 整改工单：油雾收集器检修，或给锯床、磨床加隔声罩 / 暂不处理 |

推荐顺序：交期不变的方案里电费最省的。错峰省的是**钱**（电换了时段），电量和碳排放不变；待机省的是**电**，钱和碳一起省。

## 六、AI 助手

可以直接问：
- “昨天用了多少电、电费多少？峰时占多少？”
- “磨床的单耗为什么升高了？”“空压机是不是漏气了？”
- “这个月的碳排放是多少？每件输出轴多少？”

AI 用三个新工具回答：能耗总览、单耗与空转、碳核算。

## 七、教学模式

- **计量一直开**（只记数，不改车间）。
- **能源模拟器（会出问题）**：教学模式默认打开，大约每 30 分钟（真实时间）可能出一个问题——下班忘关（晚班没岗位的卧加、滚齿机、键槽铣床、立加）、压缩空气泄漏、设备劣化（单耗慢慢升高）、油雾收集器故障。**重载实验 7 情景后关闭**，生产模式不模拟。
- **问题怎么消失**：劣化——这台设备的维修单修好；漏气、油雾——对应的整改工单批准执行；没人处理的，模拟器 2 小时后“修好”；忘关、峰时开炉到时自己结束。
- **老师注入**：总览最下面“老师：能源模拟器”，选问题和设备注入，也可以清除。实验 21 页上“注入：卧加下班忘关 + 峰时开炉”。

**两周情景**：第 7 幕“空转与峰时”用到这一页，见[两周情景](两周情景.md)。

## 九、常见问题

- **页面上一直“还没有计量读数”？**教学模式要车间在跑（倍速 20 时 45 秒一个读数）；平台每 5 分钟把计量开关发给车间一次，车间重启后最多等 5 分钟。
- **为什么热处理炉空闲也有 35 kW？**炉子保温，不待机、不关机。降低它的办法是集中开炉、错峰。
- **全口径的每件碳排放为什么这么大？**开工率低时，空转和保温的电摊到很少的件上。多做件、少空转，每件就降下来。
