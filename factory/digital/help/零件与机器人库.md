**怎么用**

- **检索**：输入名称、编号、标准号、规格或工厂物料号，比如 `6207`、`GB/T 1096`、`M8x25`、`UR5e`、`BRG-6207`。输入的恰好是某个规格时，详情直接打开这个规格。
- **筛选**：类别、来源；勾“WQR-105 用到”只显示减速器用到的标准件。
- **厂商参数**：Universal Robots 的 6 个型号有“参数”页（官方技术参数、DH 参数、出处）。UR5e、UR10e 用开源的可动模型，其余按 DH 参数生成示意模型（关节位置和连杆长度准确，外形简化）。
- **自建机器人**：SCARA、Delta 并联机器人、差速小车、直角坐标（龙门）、两连杆平面臂、倒立摆小车、Stewart 六自由度平台（问渠自建，参数化）。串联的和小车可下载 URDF；Delta、Stewart 是闭链，拖单个关节不能保持闭合，点“播放运动”看动平台运动，也可下载运动表（CSV）。倒立摆小车的“关节”数据里带动力学方程和线性化模型，可直接做控制实验。
- **工装夹具（E 部分）**：总成的“零件表”页列出每个零件的序号和作用；点三维窗口右上角“拆开”，各零件沿爆炸方向分开，再点“装回”。SH-301 的毛坯和五个工序状态在一个模型里并排，橙色是该工序加工的面。书中的三维实验页用的就是这些模型。条目由 `library/tools/import_fixtures.py` 按一张表生成，改表后重新运行即可。
- **机构（C 部分）**：10 个常用机构，播放运动、下载运动表。WQR-105 减速器在 ERPNext 的成品物料上也会显示零件库编号，点开就是这个传动机构。
- **详情**：三维模型可拖动旋转、滚轮缩放。标准件点规格表的一行换规格；机器人拖关节滑块看运动；“零位”复位，有初始姿态的（如人形、四足的站立姿态）可点“初始姿态”。“来源”页有原仓库、许可和署名。
- **复制编号**：课件、作业里引用零件时用编号，比如 `A-BRG-DG/6207`。
- **从 ERPNext 过来**：减速器的标准外购件（轴承、键、螺栓、垫圈、销、油封、螺塞等）在 ERPNext 物料页上有“零件库编号”和“零件库页面”，点链接直接打开这个规格。

## 二、怎么更新（给维护者）

零件库的程序和条目在仓库 `library/`，模型文件不进仓库，由 GitHub 自动生成。

1. 改 `library/` 下的条目或程序，本地跑 `python3 library/tools/validate.py` 和 `cd library && python3 -m pytest -q tests`。
2. 推送到 main。工作流“Parts library 零件库发布”会依次：取来源仓库固定版本 → 校验 → 测试 → 生成全部模型（约 20～30 分钟）→ 发布到 GitHub Releases（`library-v年.月.序号`）→ 解包到数字工厂服务器。
3. 发布完成后，工作台页面自动读新版本（`https://factory.wenquestrobotics.com/library/latest.json`）。服务器保留最近 3 个版本。

**来源仓库**：`python3 library/tools/fetch_sources.py` 按固定提交取 Menagerie、FreeCAD-library、robot_descriptions 及其各模型仓库、ROS-Industrial 仓库到 `library/vendor_src/`。工业机械臂的 xacro 用 PyPI 的 xacro 包展开（不用装 ROS），页面上可下载展开后的 URDF；平衡缸一类的从动关节跟着主动关节动，不单独出滑块。

**更换来源版本**：改 `library/vendor/menagerie.yaml` 或 `library/vendor/freecad_library.yaml` 里的 `commit`；Menagerie 换版本后运行 `python3 library/tools/import_menagerie.py` 重新生成机器人条目，看许可有无变化。

**本地生成**（需要先把两个来源仓库克隆到 `library/vendor_src/`，或用环境变量 `WQ_MENAGERIE`、`WQ_FCLIB` 指向它们）：

```bash
pip install -r library/requirements.txt
python3 library/tools/build.py --only A-BRG-DG --limit 5   # 只试一个族的 5 个规格
python3 library/tools/build.py --version 2026.10.0         # 全部，输出在 library/build/
```

## 三、给学习平台（接口）

- 库地址 `WQ_LIBRARY_URL` 第一期为 `https://factory.wenquestrobotics.com`，文件都在 `/library/` 下，允许 `learn.`、`factory.` 和本机开发地址跨域读取（GET、HEAD）。
- `library/latest.json`：当前版本和 `index.json` 的位置（不缓存）。
- `library/<版本>/index.json`：每个规格一行（编号、名称、类别、标准、主参数、许可、工厂物料号、文件）；`collections` 列出只收索引的外部库（FreeCAD 零件库，文件 `freecad-library.json`）；`categories` 是类别代号的中英文名称。
- `library/<版本>/<条目>/entry.json`：条目全部信息、每个规格的参数和文件；机器人另有 `robot`（连杆、关节表，约定 R4）。
- 带版本号的文件内容不再改变，可长期缓存。格式细节见《docs/方案/数字工厂资源接口约定》第二节。

## 四、许可

- 标准件：Apache-2.0（问渠零件库；造型程序 bd_warehouse，© gumyr）。
- 机器人：以 Menagerie 每个模型文件夹里的许可为准（Apache-2.0、BSD、MIT 等），条目“来源”页逐个写明。GPL、CC BY-SA、非商用的不收。
- FreeCAD 零件库：CC BY 3.0，每个零件的作者见原仓库；我们只放索引和缩略图。

**二维图**：每个规格都有一张二维图（详情的“图纸”页，点图在新窗口打开、可缩放打印；“二维图 SVG”按钮下载）。标准件是主视图加俯视/侧视图（轴承、油封、带轮、联轴器画成剖视），标总体尺寸，主要尺寸列在标题栏上方；机器人是关节示意图；机构是机构运动简图。可直接插进课件和作业。

**AI 选型**：库页面检索框下面的“AI 选型”，用一句话说需求（如“35 mm 轴、1450 r/min、径向载荷为主用什么轴承”），AI 只从零件库里挑，答案写出“编号/规格”、依据的规格表那一行和出处；编号下面的按钮点开就是详情。答案里的编号逐个和库核对，库里没有的会被去掉并注明；库里没有合适的就直接说没有。模型和数字工厂的 AI 助手是同一个通道（国内部署用 DeepSeek，Claude 只在美国用）；没配模型时按规则匹配（关键词定族、句子里的尺寸定规格）。每人每小时的次数和 AI 助手合计。

**FreeCAD 插入宏**：`factory/digital/freecad/wq_library.py`。在 FreeCAD 里：宏 → 宏… → 选这个文件 → 执行。
1. 对话框里输入编号、名称、标准号、规格或工厂物料号（如 6207、GB/T 1096、M8x25、BRG-6207）搜索；
2. 选族、选规格，点“插入”。宏会下载这个族的 STEP 压缩包（只第一次下载，缓存在 `~/.wenquest/library/<版本>/`），把这个规格插到当前文档；
3. 改规格：在模型树里选中插入过的零件，再执行宏，对话框直接打开这个族，选新规格点“替换”，位置不变。
插入的零件带属性 `WQ_LibraryRef`（编号/规格）和 `WQ_LibraryVersion`（零件库版本）。标准件（A）和机器人零部件（D，外形示意）有 STEP；机器人和机构只有网页模型。零件库地址默认 https://factory.wenquestrobotics.com ，可用环境变量 `WQ_LIBRARY_URL` 改。不开 FreeCAD 也能用：`python wq_library.py search 6207`、`python wq_library.py fetch A-BRG-DG/6207`。
