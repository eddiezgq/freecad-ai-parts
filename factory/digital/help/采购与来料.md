# 采购与来料

数字工厂工作台左侧“从订单到回款 → **采购与来料**”（第 18 轮 E5 上线）。

它把料的一生接进工厂主线：**请购 → 采购单（选供应商）→ 供应商发货 → 到货 → 来料检验 → 合格入库 / 不合格 → 用到哪些零件 → 供应商评分**。一批轴承来料不合格，装配就要等；一家供应商老是晚，生产计划就不稳。

- 采购单、收货单、来料检验单以 **ERPNext** 为准；
- 每次到货是一个**批次**（批号 L + 日期 + 编号，记在 ERPNext 收货单上）；
- 车间每做一件，平台按先进先出记下它用了哪个批次的料，所以能从批次查到零件、工单、现场设备，也能从设备查回批次和供应商；
- 供应商评分卡、备选供应商、教学模拟器在平台。

**谁能用：**
- 看：所有角色；
- 转采购单、退货：计划员、质量或厂长发起；
- 来料检验、判定可疑批次：质量或厂长；
- 登记到货：计划员、质量或厂长；
- 批准：采购单、开发备选供应商花钱，厂长批；退货计划员、质量或厂长批；让步接收要质量或厂长批（都不能批自己发起的）；
- 老师（教学模式）可以开关供应商模拟器、注入问题。

页面上方五个数：在途批次、到货待检、不合格待处理、近 30 天准时率 / 来料合格率、供应商模拟器开没开。

## 一、采购单与在途

- **还没下采购单的请购**：每行选供应商（默认或在用的备选，标出提前期和贵多少），点“转采购单”，生成“采购单”动作，厂长批准后进 ERPNext。
- **批次表**：批号、采购单、物料、数量、供应商、承诺到货日（晚到的标红）、状态。

状态：已下单 → 在途 → 到货待检 → 合格入库 / 不合格 → 已退货（或让步接收后入库）；事后发现问题的批次可以判为“可疑”。

## 二、到货与来料检验

1. 点一批“到货待检”的“检验”，看**抽样数据**：每件每一项的量具读数，上面写着检验模板的上下限。
2. 自己逐件对照，判定：
   - **合格**：收货单提交，ERPNext 入库，库存增加；
   - **不合格**：ERPNext 生成来料检验单（不合格），收货单留草稿，货进不了库，厂情中枢出“来料检验不合格”。
3. 没有检验模板的物料（钢材、标准件）直接收货。

检验模板（轴承）：外观与转动（无锈蚀、转动灵活）；内径偏差 −10～0 μm。任何一件、任何一项超差，整批判不合格。铸件、锻坯看外观和硬度。

## 三、批次

输入批号（L……）或零件 / 设备序列号，点“追溯”：
- 批号 → 这批料用到了哪些零件、工单，装进了哪些现场设备；
- 序列号 → 用了哪些批次、哪家供应商。

情景开始时库里的料记为“期初”。事后发现某批有问题（例如复验不合格），质量可以把它判为**可疑批次**，厂情中枢出“可疑批次已用到零件上”。

## 四、供应商

评分卡：每家的物料类别、默认还是备选、价格指数、提前期、准时率、合格率（近 30 天；括号里是过去一年的历史）、在途。

- 轴承、钢材各有一家**已经在用的备选**（贵 10–20%，快）；
- 铸件、锻坯的备选还要“开发”（采纳“单一来源”异常的方案，厂长批）；
- 油封、润滑油只有一家（单一来源的反面例子）。

**总拥有成本**（每件）= 单价 × 价格指数 +（1 − 合格率）× $4 +（1 − 准时率）× $3。便宜的供应商算上晚到和不合格，不一定便宜。

## 五、厂情中枢的异常

| 规则 | 什么时候报 |
| --- | --- |
| W1 缺料 / 低于安全库存 | 原有 |
| W2 采购单逾期到货 | 原有 |
| W3 来料检验不合格未处理 | 一批判不合格，还没退货或让步接收（轴承为严重） |
| W4 供应商准时率低 | 近 30 天到货至少 3 批，准时率低于 80% |
| W5 供应商来料合格率低 | 近 30 天检验至少 3 批，合格率低于 95%（让步接收不算合格） |
| W6 单一来源 | 一类物料只有一家在用的供应商 |
| W7 可疑批次已用到零件上 | 判为可疑的批次已经用到了零件上 |

**来料不合格（W3）的处理方案**（指挥台右栏，推演按每个方案的到料日下达等料的工单）：

| 方案 | 做什么 |
| --- | --- |
| A 不处理（对照） | 这批料不能用，等料的订单一直等 |
| B 退货，等原供应商补发 | 不花钱，按原提前期补发 |
| C 向备选供应商下急单 | 加价（轴承 20%），快；这一批退货；备选还没启用时先开发 |
| D 让步接收，全检挑用 | 全检一天（每件 3 分钟，$40/小时），能用的件先入库，不能用的退回；要质量批 |

推荐顺序：交期保得住的方案里花钱最少的；一样时先到的。

**单一来源（W6）、准时率低（W4）**：开发备选供应商 / 暂不处理。

## 六、AI 助手

可以直接问：
- “各家供应商的准时率和合格率怎么样？”
- “批次 L…… 用到哪里去了？”
- “现在有哪些采购在途、到货待检？”

AI 用三个新工具回答：供应商评分卡、批次追溯、采购在途与风险。

## 七、教学模式

- **时间压缩**：供应商的 1 天 = 真实 2 分钟（轴承 7 天约 14 分钟到）。
- **供应商会出问题**：教学模式默认打开，各家按自己的准时率、合格率晚到、送来不合格的一批（东岳铸造常晚；五大湖轴承偶尔一批不合格）；**重载实验 7 情景后关闭**（关闭时供应商准时、不出问题，也不自动下单）。生产模式不模拟。
- **教学模拟器**（打开时）：
  - 请购单 3 分钟没人转，采购员（模拟器）按默认供应商下单；
  - 到货 3 分钟没人检验，质检员（模拟器）按抽样判定；
  - 不合格 10 分钟没人处理，采购员（模拟器）退货，供应商补发。
- **老师注入**：某家下一批晚 N 天 / 不合格；实验 20 页上“注入一批不合格的轴承”会马上下单，到货后留给学生检验。

**两周情景**：第 2、3 幕“缺料、来料不合格”用到这一页，见[两周情景](两周情景.md)。

## 八、实验 20

左侧“**实验与任务 → 实验 20**”：供应链——来料不合格与供应商选择。五个任务自动评 60 分，报告 40 分由老师批改；沿用比对模式（提交任务 3 之前，指挥台和 AI 不显示建议）。指导书和报告模板在页面右上角。

## 九、常见问题

- **采购单一直是“已下单”？**要等 ERPNext 建好采购单（桥接执行提议），通常几秒到一分钟；“厂情中枢 → AI 运行记录”里能看到提议有没有出错。
- **为什么不用 ERPNext 的批次管理？**启用后每次完工入库都要逐批指定原料批次，会牵动已有的生产流程；批号记在收货单上，用料记录在平台里。
- **不合格的批次 ERPNext 里有收货单吗？**有一张草稿（没提交、没入库）和一张不合格的检验单；退货不再另开退货单（货没入账）。
