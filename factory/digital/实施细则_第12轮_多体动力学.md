## 一、目标

在“仿真与分析”里加第二个工具 **“运动与动力分析”**（多体动力学，功能对标 ADAMS 的教学常用部分）。教学平台先用，演示工厂可演示：

- **机构**：在零件库的机构和机器人上加驱动、重力、负载、摩擦，算出运动和受力。
- **结果**：动画回放；位置、速度、加速度曲线；关节反力和力矩；驱动力矩和功率；任意点的轨迹（如连杆曲线）。
- **和第 11 轮接上**：动力学算出的受力，一键送去有限元做强度校核、送去疲劳算寿命。这样“运动 → 受力 → 强度 → 寿命”在一个平台里走通。

## 二、决定（待确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| D1 | **求解器用 MuJoCo**（Apache-2.0，零件库已在用）。闭环机构（四杆、曲柄滑块）用 MuJoCo 的等式约束闭合。Project Chrono 暂不引入，等以后需要齿轮啮合、柔性体时再议 | 许可干净、快、零件库 167 台机器人已经是 MJCF |
| D2 | **计算放在第 11 轮的 `cae` 容器**，同一个队列（一次算一个，每次最多 5 分钟），任务种类多一个“动力学”。仿真时长上限 60 秒，结果按不超过 200 Hz 采样 | 不再多开容器；8 GB 服务器够用 |
| D3 | **模型来源（第一期）**：① 零件库 C 部分机构：曲柄摇杆、曲柄滑块、凸轮、槽轮、齿轮系、蜗轮蜗杆、带传动、棘轮、丝杠、WQR-105 减速器。给生成程序加“出 MJCF”：构件按材料密度算质量和惯量。② 零件库 B 部分机器人（直接用它们的 MJCF）。③ 上传 MJCF / URDF（zip）。从 STEP 装配体自动建机构**不做**，以后另议 | 先把库里现成的用起来；装配体自动识别运动副难度大、容易错 |
| D4 | **设置**：驱动有匀速、给定转角 / 位移曲线（如梯形速度、正弦）、给定力矩 / 力三种，可加在任意关节；另有重力、末端负载（质量）、外力、关节摩擦和阻尼、仿真时长。也可以**一句话设置**，例如“曲柄 60 rpm 匀速转，滑块上有 200 N 阻力”“UR5e 两秒内把 3 kg 工件从 A 搬到 B”。和第 11 轮一样，AI 只填表，人确认后才算 | 与第 11 轮一致的 AI 原生方式 |
| D5 | **结果**：三维动画回放（可调速、拖进度，构件可按受力着色）；曲线（任选构件、关节、点：位置 / 速度 / 加速度、反力、力矩、功率），可对比两次计算；CSV 导出；Word 报告（设置、曲线、峰值表、结论）；AI 解释（峰值出现在哪一刻、为什么、怎么改，例如加平衡配重、换电机、改轨迹） | 教学写报告，企业存档 |
| D6 | **送到有限元和疲劳**：选一个构件，取它在整个运动过程中受力最大的时刻，把各铰点的力带入第 11 轮做强度计算。同一构件的受力时间序列可以作为载荷谱算疲劳。为此给零件库的机构生成程序加“出 STEP” | 走通“运动 → 受力 → 强度 → 寿命” |
| D7 | **电机选型助手**（机器人方向）：根据关节力矩、转速曲线，算峰值力矩、均方根力矩、峰值功率；和电机 + 减速器的额定值对比，给出是否够用、裕量多少。第一期用一张常用伺服电机 + 谐波 / 行星减速器参数表，逐条注明出处 | 机器人课最常见的实际问题 |
| D8 | **标准题（进自动测试）**：① 单摆周期与理论值对比；② 曲柄滑块驱动力矩与虚功原理手算对比；③ 四杆机构位置与零件库已有的解析解对比；④ 机械臂静止时的重力矩与 Σ m·g·r 手算对比。前三项误差 < 1%，第 ④ 项 < 2% | 有限元那一轮的做法：先证明算得对 |
| D9 | **教学**：实验 9“机械臂关节力矩与电机选型”（主例，机器人），另附生活例子“缝纫机 / 发动机的曲柄滑块机构”。指导书、报告模板、挂课程接口，做法同实验 8 | 课程标准：实际问题以机器人为主，保留一个生活例子 |
| D10 | **合规**：AI 走现有通道（国内 DeepSeek，Claude 只在美国） | 总规矩 |

## 四、施工顺序

1. 求解与标准题：在 `cae` 容器里装 MuJoCo，加动力学任务种类，做单摆、机械臂重力矩两道题。

4. 送到有限元 / 疲劳；电机选型助手；报告。
5. 一句话设置、AI 解释。
6. 实验 9、帮助、验收。

每步完成即上线。

## 七、实施记录

- 第 1 步（求解与标准题，2026-10-02）：
  - `cae/mbd.py`：
    - 载入 MJCF / URDF，去掉模型自带的执行器，按设置加驱动、负载、外力、摩擦和阻尼、重力；默认不算碰撞。
    - 驱动五种：匀速、梯形速度点到点、正弦、保持、给定力矩 / 力。
    - 给定运动的驱动用“刚性伺服 + 前馈”：先跑一遍取得所需力矩，第二遍作为前馈；跟踪误差约 0.006°。
    - 记录各关节的位置、速度、加速度，驱动力矩，每个构件的关节反力和力矩（世界坐标，力矩对关节中心），指定点的轨迹，以及动画帧（50 帧 / 秒）。
    - 另有“手算”重力矩（几何算法，不经过动力学求解），测试用。
  - `cae/mbd_models.py`：
    - 零件库机器人第一期 UR5e、UR10e、Franka FR3：镜像构建时按零件库同一个 Menagerie 提交取模型（`deploy/fetch_menagerie.sh`）；
    - 上传 MJCF / URDF（单个文件或带网格的 zip，检查不安全路径）；
    - 网页动画用的模型（每个构件一个节点）。
  - 计算服务：多一种任务“动力学”，和有限元共用队列和限时。有限元页的记录只列有限元任务。
  - 枢纽接口：`/api/mbd/robots|models/load|models/upload|models/{编号}/model.glb|jobs|jobs/{编号}/series.bin|anim.bin`。
  - 镜像加 MuJoCo 3.14.0 和三台机械臂模型；CI 测试前也取模型。
  - **标准题**：
    - 单摆周期与理论值误差 < 10⁻⁷。✓
    - UR5e 带 3 kg 负载的重力矩与几何手算误差 < 10⁻⁷。✓
    - UR5e 两关节同时点到点搬运，驱动力矩与按实际运动做逆动力学（mj_inverse）的结果最大差 < 2% 峰值。✓
  - 测试 `test_mbd.py` 6 项；部署前演练加“UR5e 保持姿态”一题。
- 第 2 步（零件库机构出 MJCF 和 STEP）：`cae/mech_mjcf.py`
  - 10 种机构按参数生成 MJCF，坐标与零件库一致；构件按钢的密度算质量和惯量。
  - 闭环方式：
    - 四杆、曲柄滑块：两点重合约束（connect，用 site 定义，与模型零位无关）；
    - 齿轮系、WQR-105、蜗杆蜗轮、带传动、丝杠：关节比例约束（传动比）；
    - 凸轮、槽轮、棘轮：**函数耦合**，关节比例约束每一步按当前位置重新线性化（斜率 = df/dθ），由约束求解器隐式处理。
  - 运动学公式与零件库 `generators/c_mech.py` 逐点一致（测试互核）；参数默认值与零件库条目一致（测试核对）。
  - 开始时按主动件的初值、初速度把闭环各关节摆好，避免约束在起步时猛拉。
  - **驱动的做法改了（与第 1 步不同）**：给定运动的驱动由“刚性伺服 + 前馈、跑两遍”改为**单关节等式约束**，每一步更新目标值，软约束的稳态滞后用 2τ·q̇ 超前补偿；驱动力矩 = 这个约束的约束力（按约束行分出来，不含闭环约束的力）。原因：槽轮、棘轮啮合冲击时伺服拉不住（误差 0.2 rad）。改后所有机构跟踪误差 < 0.01 rad，第 1 步的标准题照样通过，代码也更简单。
  - **连杆类构件出 STEP**（曲柄、连杆、摇杆）：两端半圆头扁杆，两端销孔；构件坐标与动力学模型一致（A 孔在原点、B 孔在 +X、厚度沿 Y），第 4 步把铰点受力直接加到孔面上。
  - **标准题**：
    - 曲柄滑块准静态、滑块受 200 N 阻力：驱动力矩与虚功原理手算误差 0.04%（要求 < 1%）。✓
    - 四杆位置与零件库解析解一致（摇杆角误差 4×10⁻⁵ rad）。✓
    - 另加 WQR-105 传动链：输出轴 350 N·m，输入力矩 = 350 / 10.5，误差 < 1%。✓
  - 测试 `test_mbd.py` 共 21 项（含 10 种机构各跑一遍、闭环不散开）。

- 第 3 步（网页）：工作台“专业软件”加“运动与动力”（`/mbd`）。
  - **左边设置**：

    - 驱动：
      - 机构只有主动件一行；从动件可加工作阻力 / 负载力矩。
      - 机械臂每个关节一行：初值、自由 / 保持 / 匀速 / 点到点 / 正弦 / 给定力矩。
      - 单位按人习惯：度、r/min、mm，提交时换算。
    - 负载：重力开关、末端负载（质量）、外力。
    - 记录点：例如四杆的连杆中点、机械臂末端。
    - 仿真时长。
    - 各模型有示范默认值：曲柄滑块带 200 N 阻力；四杆记录连杆中点；UR5e 肩、肘在 1.3 秒内点到点、带 3 kg。

- 第 4 步（送到有限元 / 疲劳、电机选型、报告）：
  - **送到有限元**：
    - 动力学结果页对连杆类构件（曲柄、连杆、摇杆）给出“送去有限元”按钮。计算服务取 B 端受力最大的时刻，按构件当时的姿态换算到构件坐标，生成杆件 STEP，读成零件。
    - 有限元页打开时已填好：A 端销孔固定、B 端销孔受这个力（二力杆近似，略去惯性力和自重，页面上写明）、名称、材料。
    - 曲柄 B 端的力取“下一根杆从曲柄受的力”的反作用。
  - **送到疲劳**：从动力学送来的有限元任务，疲劳多一种载荷谱“动力学受力记录”：这根杆沿所加力方向的受力随时间变化，整段运动当作一块不断重复。
  - **电机选型**（`cae/motors.py`）：
    - 参数表：7 档交流伺服（100 W–2 kW），6 个规格的谐波减速器（传动比 50–160），通用典型值，注明量级参照的厂家目录，提示以厂家目录为准。
    - 校核：电机峰值 / 均方根力矩（含转子惯量的加速项）、转速；减速器重复峰值 / 额定力矩、输入转速；可选安全系数。
    - 选法：够用的组合里电机功率最小、减速器最小、传动比最接近 100；都不够时说明卡在哪里。
    - 机构只给主动件选电机，从动件上的是工作阻力。
  - **报告**（`cae/mbd_report.py`）：Word 包含设置、驱动汇总、各构件受力峰值和时刻、动画截图、当前显示的曲线（SVG 转图片）、电机选型、AI 解释。

    - 疲劳寿命超过 100 万年时显示“实际上无限”。

    - UR5e 搬运题每个关节给出推荐组合和裕量；选型与手算一致。✓
    - 浏览器走通：动力学 → 电机选型 → 报告 → 连杆送有限元 → 疲劳。

- 第 5 步（一句话设置、AI 解释）：`hub/mbd_ai.py`
  - **一句话设置**：配了模型由模型填表（只能调用“填表”工具，不存在的关节、构件会被丢掉）；没配或出错时用规则：
    - 机构：转速（rpm、r/min、rad/s）、阻力（N、kN，加在滑块等从动件上，与运动相反）、负载力矩（N·m，默认加在输出端）、负载质量。
    - 机械臂：关节可以用 J1–J6、“关节 n”或中文叫法（底座 / 腰、大臂 / 肩、小臂 / 肘、腕 1–3），“转 / 抬 X°”按相对现在、“转到 X°”按绝对，“不动”= 保持；没说角度的“搬过去”用示范动作。
    - 全句：时长（含“两秒”这类中文数字）、不计重力。
    - 没看懂的部分列出来请人补。填好表给人看，确认后才计算。
  - **AI 解释**：
    - 驱动力矩最大的关节和时刻；峰值远大于均方根时说明是惯性力为主，建议放慢 / 平缓加减速，带“运动时间放长到 1.5 倍重算”一键执行；
    - 平均功率为负时说明电机在发电，驱动器要能吸收回馈能量；
