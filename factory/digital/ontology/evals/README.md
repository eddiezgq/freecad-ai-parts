# AI 代理评测集（第 17 轮 D 期 D4）

每个文件一个领域，每题一项：

| 字段 | 意思 |
|---|---|
| `id` | 题号，全局唯一 |
| `q` | 问题；`{grd_anomaly}` 这类占位符按当时的数据填（见 `hub/ont/evals.py` 的 `slots`） |
| `as` | 谁来问：`teacher`（默认，完整回答）、`student`（教学模式学生，只给提示）、`prod_manager`（生产模式厂长） |
| `tools` | 必须调用的工具 |
| `contains` | 回答里必须出现的文字（可用占位符） |
| `any_of` | 回答里至少出现其中一个 |
| `not_contains` | 回答里不能出现的文字（教学模式不能直接说出答案） |
| `drafts` | `true`：必须起草出动作草稿；`false`（默认）：不能起草 |
| `cite` | 默认 `true`：至少一个引用 [n]，且引用编号都有效 |
| `verified` | 默认 `true`：回答里的数字全部能在工具结果里找到 |

情景：实验 7 闭环情景（`sim/scenario.py`），GRD-01 正在换砂轮停机，BRG-6207 低于安全库存，Ø35 k6 上移。

规则版每次推送都在测试里跑（`tests/test_evals.py`），要求全过；模型版在服务器上从“AI 运行记录 → 评测”页手动跑，分数存档，目标 ≥ 90%。
改提示词、工具或规则版之后，先跑评测。
