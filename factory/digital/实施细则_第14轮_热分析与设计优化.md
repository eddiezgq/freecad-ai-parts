## 一、目标

第 11–13 轮把“设计 → 强度 / 寿命 → 运动 → 工艺 → 程序”接起来了，但都是**人改一次、算一次**。这一轮补两件企业最常问、教学也最常讲的事：

1. **热**：零件、箱体热到多少度？热了会不会变形、胀坏？（减速器热平衡、电机和电子散热）
2. **优化**：在满足强度、寿命、温度要求下，**让电脑自己找**最轻、最凉、最省料的尺寸，人只定目标和约束——这正是“AI 原生”：说一句“输出轴越轻越好，安全系数不小于 2、寿命无限”，平台自己跑几十次有限元，给出最好的几组尺寸，一键送回设计台发布。

## 二、决定（待确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| H1 | **热分析**放进现有“仿真与分析”页，多一种分析类型：稳态 / 瞬态温度场（发热功率、面热流、对流换热、固定温度），以及**热—结构耦合**（先算温度，再算热应力和热变形）。求解器仍是 CalculiX（`*HEAT TRANSFER`、`*FILM`、`*DFLUX`；耦合时温度作为下一步载荷） | 同一个计算服务、同一套网格和点面方式，零新增依赖 |
| H2 | **材料库补热物性**：导热系数、比热、线膨胀系数（12 种材料，每个数值注明出处，和第 11 轮一样）；对流换热系数给参考表（自然对流 5–25、风冷 25–250 W/m²·K，按表面朝向和风速）并注明出处 | 热分析的结果几乎全由这几个数决定，出处必须可查 |
| H3 | **教学主例：WQR-105 减速器箱体热平衡**。平台按减速器尺寸生成**参数化简化箱体**（长宽高、壁厚、散热筋数量和高度），齿轮和轴承损耗 P·(1−η) 取第 12 轮传动链的效率；结果与教材公式 t_油 = t₀ + 1000·P·(1−η)/(K·A) 对比，讨论加散热筋、加风扇（换对流系数）的效果。**生活例子：电脑 CPU 散热片**（零件库加一个散热片，比较片数、片厚、有无风扇） | 机械设计课程设计里“减速器热平衡计算”是必做项；散热片人人见过 |
| H4 | **设计优化**：新页“设计优化”（专业软件里新增一项）。选一个参数化零件（SH-301 设计台参数、简化箱体、零件库参数件）→ 选要变的尺寸和范围 → 定目标（最轻 / 最小最高温度 / 最大安全系数）和约束（安全系数 ≥、疲劳寿命 ≥、最高温度 ≤、几何校核通过）→ 平台自动跑 20–60 次分析。算法用 **Optuna**（MIT 许可，贝叶斯 / TPE，支持约束和多目标），每次评估就是一次第 11 轮有限元（或热分析），整个优化作为**一个排队任务**，限时 15 分钟 | 不自己写优化算法；评估次数有上限，教学服务器扛得住 |
| H5 | **优化结果**：每次评估一行（尺寸、质量、安全系数、寿命、温度、是否满足约束），收敛曲线、两目标时画帕累托前沿，最优几组可以打开看云图；**“送到设计台”**一键带参数和改动说明（沿用第 11 轮的建议动作），之后照常校核、发布、审批，工艺和数控程序跟着走 | 优化结果不直接改设计，必须经设计台和审批，符合现有流程 |
| H6 | **拓扑优化（平面件）**：一个简单的 2D 拓扑优化（SIMP 方法，numpy 自写约 100 行，经典教学算法），给定板件外形、支承和载荷、目标体积比，看材料“长”成什么样；结果可拉伸成 STEP 再做有限元校核。只做平面件，三维拓扑优化不做 | 拓扑优化是“AI 设计”最直观的展示；平面件几秒算完，学生看得懂 |
| H7 | **一句话与 AI 解释**：热（“箱体里齿轮损耗 300 W，外面空气 25 ℃，自然对流”）、优化（“输出轴越轻越好，安全系数不小于 2，寿命无限，直径只能取整毫米”）都能一句话填表；结果由 AI 解释（热从哪里散掉、瓶颈在哪；优化为什么停在这组尺寸、哪个约束卡住了）。走现有 AI 通道（国内 DeepSeek，Claude 只在美国） | AI 原生 |
| H8 | **教学**：实验 11“减速器热平衡与输出轴轻量化”：箱体热平衡（手算对比、加散热筋）→ 热应力 → 输出轴优化（约束强度、寿命）→ 送设计台发布；选做 CPU 散热片、拓扑优化。指导书、报告模板，挂课程接口 | 每个工具都要能进课 |
| H9 | **合规与许可**：CalculiX（GPL）作为独立程序调用（同第 11 轮）；Optuna（MIT）；拓扑优化自写 | 总规矩 |

## 七、实施记录

### 第 1 步 热分析核心（2026-10-02，完成）

- 材料库补热物性（导热系数、比热、线膨胀系数，12 种，出处统一注明：钢、不锈钢、铝按 ASM 对应牌号典型值，铸铁按 GB/T 9439、GB/T 1348 附录，塑料按厂商物性表）；新增表面散热系数参考表（濮良贵《机械设计》蜗杆传动热平衡的 K_s：通风差 8.15、通风良好 17.45、风扇冷却 31 / 38 W/(m²·℃)，以及强制风冷、油、水的参考值）。计算服务 `/materials` 一并返回。
- `cae/thermal.py`：同第 11 轮的二阶四面体网格，CalculiX 求解。热载荷：固定温度、对流换热（可选“其余所有面”）、面上总发热功率、体积均匀发热；分析：稳态、瞬态（后向欧拉，每次 200–400 步，输出温度—时间曲线）、热—结构耦合（`*COUPLED TEMPERATURE-DISPLACEMENT`，参考温度可设，支承和机械载荷同第 11 轮）。结果：最高 / 最低温度和位置、表面平均温度、输入功率与对流散走的热量（核对热平衡）、各对流面组的平均温度和散热量；耦合时另有应力、变形、安全系数。
- 计算服务：热分析也走原来的 `/jobs` 排队（setup.analysis = thermal / thermo_mech），表面结果文件多一段节点温度（旧读法不受影响）。
- 测试 `tests/test_thermal.py` 7 项，全部通过：
  - 平壁一维导热：T_max 与 20 + qL/k 差 < 0.01%；
  - 圆柱肋片（端部对流）：散热量 3.951 W，公式 3.974 W，差 0.6%；
  - 集总参数冷却（铝块，Bi ≈ 0.003）：一个时间常数处差 < 3%，全程偏差 < 1% 初始温差；
  - 热应力：两端固定的 300 mm 杆升温 100 ℃，中段 σ 与 E·α·ΔT 差 < 2%；热伸长：中段到端部的伸长与 α·L·ΔT 差 < 1%；
  - 计算服务的热分析任务：体积发热、一端定温，T_max 与 20 + qL²/(2k) 差 < 2%。
- 偏差：
  - 计划写“两端固定杆的热应力”：用 100 mm 杆时中段比 E·α·ΔT 高 2.9%——两端面被“固定”同时限制了横向膨胀，端部区域轴向膨胀更多、整根杆的压力更大（物理上正确）。验收改用 300 mm 长杆，端部影响降到 2% 以内。
  - 瞬态用后向欧拉，时间常数附近误差约 1–2%，越到后面相对误差越大（温差本身已很小），验收按“初始温差的 1%”和“一个时间常数处 3%”两条。

### 第 2 步 热分析进网页、示例零件（2026-10-02，完成）

- “仿真与分析”页第 3 步加“算什么”：**强度 / 温度 / 温度 + 热应力**。温度时填热边界（固定温度、对流散热〔散热系数从参考表选或自己填，可勾“其余所有面”〕、面发热、整体发热），可选瞬态（时长、初温）；热应力时另填约束和机械载荷（可只加约束）、无应力参考温度。材料行显示导热、比热、线膨胀系数。
- 结果：温度云图（耦合时另有热应力、热变形云图），最高温度点标红；卡片：最高温度（有限值时超限标红）、最低 / 表面平均、热平衡（进来的热量与对流散走的热量）、耦合时热应力和安全系数；各对流面的面积、平均温度、散热量；瞬态画最高、平均温度随时间的曲线；Word 报告（温度场 / 热—结构耦合两种版式：材料热物性及出处、热边界、结果、与教材公式对比、云图、AI 解释）。
- 参数化示例零件（`cae/thermal_parts.py`，零件下拉框里“示例 · …”，参数可改后重新生成）：
  - **WQR-105 简化箱体**：外形 410×150×300、壁厚 10，可加每侧散热筋（数量、高、厚），可调负载率。发热 = 输入功率 ×（1 − η），η = 0.97²（两级闭式齿轮）× 0.99³（三对轴承）= 0.913，额定时 482.6 W；读入后自动分出箱内壁、外表面、底面，“填入示范题”：内壁发热、外表面 K_s = 17.45、底面装在机座上不散热，HT200。教材公式 t_油 = t₀ + P(1−η)/(K_s·A)。
  - **CPU 散热片**（生活例子）：底板、片数、片高、片厚、CPU 接触面、功率 65 W，6061 铝，接触面发热、其余表面风冷 h = 50；附粗估 t = t₀ + P/(hA)。
- 结果：无散热筋的箱体外表面平均 **89.6 ℃，与公式 89.6 ℃ 一致**；最高 106.9 ℃（底部角落），超过油温限值约 80 ℃——实验里加散热筋或风扇的理由。加 8 条 / 侧散热筋后外表面平均降到约 64 ℃。
- AI 解释（`hub/thermal_ai.py`，规则先写、有模型时改写）：热平衡、主要散热面、与公式差在哪、是否超限；超限时给出可一键执行的建议（“加 8 条散热筋重算”“片数加到 13 片重算”：按新参数重新生成示例零件、自动填表并提交）。
- 测试新增 2 项（箱体热平衡与公式一致、面分组和参数校核）；演练脚本加箱体热平衡（与公式差 < 0.5 ℃、报告能生成）。本地浏览器走了一遍：读入箱体示例 → 计算 → 公式对比 → AI 解释 → 加散热筋重算。
- 偏差：
  - 热分析不在发热面附近加密网格（温度场平滑，加密只会让箱体内壁网格超过 20 万单元上限）。
  - 演练脚本里数控程序下发的检查放宽为“这一版挂着的程序至少 2 个、粗车的是 O1201、O1202”，重复演练时上一次挂的精车程序也会随新版下发。

### 第 3、4 步 设计优化核心与网页（2026-10-02，完成）

- `cae/optimize.py`：Optuna 5.0（MIT）TPE 贝叶斯优化，单目标或两个目标（帕累托前沿），约束用 Optuna 的约束机制（每项 ≤ 0 为满足）；**第 1 次评估固定是现行设计**；同一组尺寸只算一次；最多 60 次、15 分钟。每次评估是一次真实分析：
  - **输出轴 SH-301**：变量齿轮位直径（36–46，每档 0.5）、两端轴伸直径（26–33）；轴承位 Ø35 由轴承定死不参加。每组尺寸先过设计台校核（不过的直接不可行），再按“示范题”自动选面（两处轴承、轴伸限制转动、键槽侧面 350 N·m）做有限元，算安全系数，并按 0 → 350 N·m 脉动算疲劳寿命（避开约束面奇异点，同静强度评估）；质量按尺寸算（扣键槽、倒角）。
  - **WQR-105 箱体**：散热筋数、筋高、壁厚；温度场按第 2 步示例自动设置，目标质量 / 最高温度 / 两者。
  - **CPU 散热片**：片数、片高、片厚；目标质量，约束最高温度。
  - **悬臂梁**（标准题，网页不列）：截面高。
- 计算服务：`/opt/problems`、`/opt/jobs`（kind = opt，进同一个排队，独立进程、限时）、`/opt/jobs/{id}/trials`（进行中逐行返回、完成后给最好的几组和帕累托前沿）。
- 枢纽 `hub/opt_api.py`：`/api/opt/problems|jobs|jobs/{id}|jobs/{id}/trials|jobs/{id}/use`；SH-301 总以设计台现行参数为起点；“用这组”：SH-301 → 设计台（参数填好、改动说明写好，还没发布）；箱体、散热片 → “仿真与分析”按这组参数重新生成零件并填好热边界。
- 网页 `/opt`“设计优化”（专业软件新增一项）：选问题 → 一句话或勾选可以改的尺寸和范围 → 目标（最轻 / 最凉 / 又轻又凉）→ 要求（安全系数、疲劳寿命、最高温度）→ 次数；结果逐行出来：最好的一组、现行设计、比现行变化，单目标画每次的值和“到这次为止最好的”，两目标画质量—温度散点和帕累托前沿；表格标出满足 / 不满足及原因；“送到设计台”/“到仿真与分析”；AI 解释；我的优化记录。
- 一句话和 AI 解释（`hub/opt_ai.py`）也在这一步做了（原计划第 6 步）：规则能认“越轻越好 / 最凉”“安全系数不小于 x”“寿命无限 / 至少 x 小时”“不超过 x 度”“齿轮位 / 筋高 / 片厚 … 在 a 到 b 之间”“算 n 次”；解释说明比现行好多少、哪个要求卡住了最优解、两个目标怎么取舍、下一步。
- 结果：
  - 悬臂梁（L 200、宽 20、1000 N、安全系数 ≥ 2）：找到 h = 18.3 mm，解析 18.39 mm，差 0.5%；
  - SH-301（安全系数 ≥ 1.3、无限寿命，8 次）：齿轮位 Ø39、轴伸 Ø27.5，质量 1.147 kg，比现行 1.238 kg 轻 7.4%，安全系数 1.36；送设计台后校核通过；
  - 箱体（又轻又凉，6–12 次）：帕累托前沿上筋数多、筋高大的更凉更重，例如 7 条 / 侧 × 40 mm 最高 71.8 ℃；
  - 测试 `tests/test_optimize.py` 5 项：悬臂梁与解析解差 < 3%、SH-301 比现行轻且满足约束、参数校验、计算服务的优化任务、一句话与解释规则。
- 偏差：
  - 计划的轴“输出轴最轻、安全系数不小于 2”在现有键槽尖角下做不到（现行设计安全系数约 1.4–1.5），默认要求改为 ≥ 1.3，网页上可改；AI 解释会提醒键槽尖角使最大应力随网格变化（几个百分点的“噪声”），选定方案后要用细网格复核。
  - 优化里的有限元网格取包围盒对角线 / 32（同“仿真与分析”的“中”），安全系数与在“仿真与分析”页手动算的可能差几个百分点（加密区域不同）。

### 第 5 步 拓扑优化（平面件）（2026-10-02，完成）

- `cae/topo.py`：SIMP（材料插值 E = E_min + x^p·E₀），按 Andreassen 等 2011《88 行 MATLAB 拓扑优化程序》的经典算法用 numpy / scipy 重写（自写，不引外部库）：平面应力四节点单元、灵敏度过滤（半径 r_min）、最优准则法更新（每步变化 ≤ 0.2），收敛条件“每格密度的最大变化 < 0.01”，最多 200 次。四个算例：**MBB 梁**（经典）、悬臂梁、桥 / 简支梁、支架；网格上限 6000 格，一般几秒算完。
- 结果：每格密度（0–1）、柔度和体积比随迭代的记录、约 24 帧“生长过程”；**拉伸成板件**：按密度 0.5 取轮廓（shapely 合并、去碎块、简化），在支承和载荷处加一小块垫块（让约束和力落在独立的面上，避免点载荷的奇异应力），build123d 拉伸成 STEP，读入后按位置自动填好约束、载荷行。MBB 梁按对称面镜像成整根简支梁再校核。
- 计算服务：`/topo/presets`、`/topo/jobs`（kind = topo，进同一个排队，独立进程、限时 3 分钟）、`/topo/jobs/{id}/result`、`/topo/jobs/{id}/to-fea`。枢纽：`/api/opt/topo/presets|jobs`、`/api/opt/topo`、`/api/opt/topo/{id}/result`（附规则解释：柔度降了多少、形状为什么是桁架 / 拱、灰色单元多不多、下一步）、`/api/opt/topo/{id}/to-fea`。
- 网页：“设计优化”页顶部分两块——**参数优化（改尺寸）/ 拓扑优化（平面件：材料该放在哪）**（`/opt?mode=topo`）。拓扑优化：选板件（附支承与载荷示意图）→ 材料用量滑块、网格 → 实际尺寸（长、板厚、载荷、材料）→ 开始；结果是黑白密度图（MBB 梁同时画出镜像的另一半），可播放“生长过程”、拖动看某一次迭代；柔度、迭代次数、灰色单元三张卡片；柔度—迭代曲线；解释；“拉伸成板件，去有限元校核 →”跳到“仿真与分析”，零件、约束、载荷、材料、网格都已填好，直接点“开始计算”。
- 验收：**MBB 梁 60×20、体积比 0.5、p = 3、r_min = 1.5：94 次收敛，柔度 1007.0 → 203.2**（文献同一算例约 203），上下弦连续、中间挖空、腹杆成“W”形桁架，灰色单元 21%；柔度单调下降后走平。拉伸成 300 × 50 × 10 mm 的 6061 板、2000 N：有限元最大应力 182.9 MPa（在垫块尖角处）、安全系数 1.51、最大位移 0.19 mm。
- 测试 `tests/test_topo.py` 5 项全部通过：MBB 经典算例（柔度差 < 2%、收敛、体积比守住、上下弦连续、中间挖空、腹杆 3–8 段）、其他算例与参数校验、拉伸成板件后是一个实体且垫块面找得到、计算服务任务和 to-fea、解释。演练脚本加 MBB 梁（柔度 203 ± 5、拉伸成板件）。本地浏览器走了一遍：拓扑优化 → 播放 → 拉伸成板件 → 有限元计算。
- 偏差：
  - 有限元校核时简支梁两端的垫块都按“固定”（“仿真与分析”还没有“只限制一个方向”的滚动支座），比真正的简支略刚，下弦拉力偏小；网页说明里写明。
  - 支架、悬臂梁到 200 次才收敛或接近收敛（比 MBB 慢），最多次数从计划的约 100 次放到 200 次。
