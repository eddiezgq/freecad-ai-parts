## 一、目标

建一个开放的**问渠零件与机器人库**，同时服务两处：
- **课程**：机器人课程和物理课需要现成的模型、案例和动画（移动机器人、直角坐标机器人、机械臂、人形机器人、并联机器人等），做课件和虚拟实验时直接从库里取，不再临时找模型；
- **数字工厂**：标准件和机构带参数、带三维模型，能挂到 ERPNext 物料上，FreeCAD 能直接插入，AI 能按需求选型并注明来源。

原则：教育要广，第一批就按“铺开”做，覆盖课程需要的典型对象；每个条目都记清来源和许可。

## 四、每个条目包含什么

- **身份**：编号、中英文名称、类别、适用标准（如 ISO 15、DIN 6885）
- **参数**：参数表与规格表（例：6207 → d=35, D=72, B=17），单位写在字段名里
- **模型**：STEP（CAD 用）、STL（打印用）、glTF（网页 3D 用）；机器人另有 URDF 或 MJCF 和关节、连杆参数
- **来源与许可**：原仓库、版本、许可、署名文字；自建的写“问渠”
- **教学信息**：一句话原理、典型用途、可引用的课程章节、建议的虚拟实验或动画
- **工厂信息**：可对应的 ERPNext 物料编码、常见供应商字段（先留空）

## 五、接入平台

1. **零件库服务**：统一的检索接口（按类别、标准、参数、关键词），返回条目和模型下载地址。
2. **工作台“零件库”页面**：浏览、按参数筛选、网页三维预览（机器人可拖动关节）、下载。
3. **FreeCAD 插入宏**：在 FreeCAD 里搜索并插入库中零件，参数可改。
4. **ERPNext 关联**：物料可链接到库条目；减速器 WQR-105 的标准外购件全部对上。
5. **AI 选型**：按自然语言需求给候选（如“35 mm 轴、1450 r/min 用什么轴承”），每个建议注明库条目与标准来源。
6. **课件与虚拟实验**：课件生成和 Manim 动画可按编号取模型；浏览器虚拟实验可直接载入 glTF / MJCF。

### B.3 条目字段（`entry.yaml`）

| 组 | 字段 | 说明 |
|---|---|---|
| 身份 | `schema` | 恒为 `1`；格式只增字段不改版本，删改字段时加一 |

### B.4 规格表（`specs.csv`）

1. 第一列固定为 `size`（规格代号），其余列名 = `params[].key`，与参数定义一一对应；
2. 数值一律国际单位，单位写在列名里（`d_mm`、`C_kN`、`n_lim_rpm`）；空缺留空，不写 0；
3. 每族附 `note` 列可选，写标准里的说明（如 “-2RS 两面接触密封”）；
4. 测试逐行检查：生成的模型外形尺寸与表中主尺寸一致（误差 ≤ 0.01 mm），且该规格的 STEP 能被重新读入。

### B.5 模型文件约定

| 项目 | 约定 |
|---|---|
| 文件名 | `<条目>/<规格代号>.<格式>`，规格代号中的 `/`、`×` 换成 `_`、`x` |
| 单位 | STEP、STL：毫米；glTF、URDF、MJCF：米（各自格式的惯例），构建统一换算 |
| 坐标 | CAD：Z 向上，回转件轴线沿 Z；glTF 按规范 Y 向上，构建自动转换 |
| 精度 | STL / glTF 弦高误差 0.02 mm；glTF 每个规格 ≤ 2 MB（网页预览） |
| 缩略图 | 每个规格一张 PNG（512×512），构建时渲染 |
| 机器人 | 保留原仓库的 URDF/MJCF 与网格原样（只换算路径），另出一份合并的 glTF 供网页预览 |

### B.6 许可规则

1. **可收**：`Apache-2.0`、`BSD-2-Clause`、`BSD-3-Clause`、`MIT`、`Zlib`、`ISC`、`CC0-1.0`、`CC-BY-3.0`、`CC-BY-4.0`；
2. **不收**：GPL / LGPL / AGPL 各版本、`CC-BY-SA`、`CC-BY-NC` 及其他非商用或传染性许可、没有许可声明的；
3. 第三方条目逐个核对：以原仓库该模型文件夹里的 LICENSE 为准，没有单独 LICENSE 的以仓库总许可为准；核对人、日期写进 `source.checked`；
4. `CC-BY` 条目必须带 `attribution`，页面详情、下载包 `LICENSE-ATTRIBUTION.txt` 里都显示；
5. FreeCAD-library 只收索引和缩略图，模型由用户点击时从原仓库下载，页面注明来源与许可。

### B.7 发布与索引

1. 推送 `library/` 到 main → 工作流 `library.yml`：校验全部条目 → 生成模型 → 跑测试 → 打包；
2. 打标签 `library-vYYYY.MM.N` 时发布到 GitHub Releases：每个条目一个压缩包（`A-BRG-DG.zip`，含全部规格、许可文件），加 `index.json`；
3. 同时把网页要用的 glTF、缩略图和 `index.json` 同步到 DigitalOcean Spaces：`library/<版本>/<条目>/<规格>.glb`；
4. `index.json` 每个规格一行：编号、名称、类别、标准、主参数、许可、各格式下载地址（Releases）、预览地址（Spaces），检索接口和工作台页面只读它。

### B.10 发布目录、`latest.json` 与 `index.json`（R1、R6）

库地址 `<库地址>` = Spaces CDN 公开地址（L12）；**第一期为 `https://factory.wenquestrobotics.com`，由枢纽提供（L14）**。下面的路径都相对于它。

```
library/latest.json                         # 最新版本指针（R1）
library/<版本>/index.json                   # 全部规格一览
library/<版本>/<条目>/entry.json            # 条目详情（R2，B.11）
library/<版本>/<条目>/<规格>.glb            # 网页三维（米，Y 向上）

library/<版本>/freecad-library/thumbs/*.png # 外部库缩略图
```

- **版本** `YYYY.MM.N`（如 `2026.10.1`），与 Releases 标签 `library-v2026.10.1` 对应；已发布的版本目录不再改动。
- **规格代号**：`family` 用规格表的 `size`（文件名里 `/` 换 `_`、`×` 换 `x`，B.5）；`robot`、`mechanism`、`case` 只有一种，规格代号固定为 `default`。

- **缓存**：`latest.json` 不缓存；带版本号的文件长期缓存（内容不再改变）。

`latest.json`：

```json
{"schema": 1, "version": "2026.10.1", "released": "2026-10-12T15:00:00Z",
 "index": "library/2026.10.1/index.json",
 "release_url": "https://github.com/eddiezgq/WenQuest/releases/tag/library-v2026.10.1"}
```

`index.json`：每个规格一行（`items`），路径相对于该版本目录。

```json
{"schema": 1, "version": "2026.10.1", "released": "2026-10-12T15:00:00Z",
 "count": {"entries": 64, "items": 520},
 "items": [
  {"ref": "A-BRG-DG/6207", "id": "A-BRG-DG", "size": "6207", "part": "A", "kind": "family", "category": "BRG",
   "name": {"zh": "深沟球轴承 6207", "en": "Deep groove ball bearing 6207"},
   "tags": ["滚动轴承", "62系列"], "standards": ["GB/T 276-2013", "ISO 15:2017"],
   "params": {"d_mm": 35, "D_mm": 72, "B_mm": 17},
   "license": "Apache-2.0", "erp_items": ["BRG-6207"],
   "files": {"glb": "A-BRG-DG/6207.glb", "png": "A-BRG-DG/6207.png", "svg": "A-BRG-DG/6207.svg"},
   "entry": "A-BRG-DG/entry.json",
   "family": {"zh": "深沟球轴承", "en": "Deep groove ball bearing"}, "origin": "wenquest", "default": true}
 ],
 "collections": [{"id": "freecad-library", "name": {"zh": "FreeCAD 零件库", "en": "FreeCAD Parts Library"},
                  "url": "freecad-library.json", "count": 2901, "thumbs": 516, "license": "CC-BY-3.0"}],
 "categories": {"A": {"BRG": {"zh": "滚动轴承", "en": "Rolling bearings"}}, "B": {}, "C": {}}}
```

`params` 只放 `role: key` 的主参数（检索和筛选用）；完整参数在 `entry.json`。`family` 是条目（族）名称，`origin` 是来源（`source.origin`），`default` 标出条目的默认规格（网页卡片用它的缩略图）；机器人另有 `dof`。`categories` 是类别代号的中英文名（B.2）。

`freecad-library.json`：`{"schema", "collection", "name", "repo", "commit", "license", "attribution", "note", "count", "items"}`，每个零件一行 `{"id": "F-<10 位>", "name", "path": [分类…], "top": {"zh","en"}, "formats": {"fcstd","step","stl"}（原仓库固定提交的下载地址）, "thumb"（相对版本目录，没有为 null）, "source_url"}`。

### B.11 `entry.json`（R2）

= `entry.yaml` 原样转成 JSON（字段同 B.3），另加构建时生成的几项：

| 字段 | 内容 |
|---|---|
| `version` | 所在库版本 |
| `sizes[]` | 每个规格：`size`、`params`（该规格全部参数，键同 `params[].key`）、`files`（`glb`、`png`、`svg`，相对路径）；`robot`/`mechanism` 只有一项 `default`，`params` 为默认参数 |
| `package` | Releases 里该条目压缩包的地址（STEP、STL、URDF/MJCF 在包里） |
| `robot.links[]`、`robot.joints[]` | 机器人，见 B.13 |
| `mechanism.members[]`、`mechanism.input`、`mechanism.motion` | 机构，见 B.13 |

仓库里的 `specs.csv` 不直接发布，内容已在 `sizes[]` 里。

### B.12 二维图 SVG（R3）

| 部分 | 内容 |
|---|---|
| A 标准件 | 主视图 + 侧视图（回转件：沿轴线的投影 + 端面投影，剖开显示内部），标注 `role: key` 的主尺寸，单位 mm |
| B 机器人 | 关节示意图：零位姿态侧视，连杆画成线段，关节画圆并编号 J1…Jn，标出基座坐标系 X/Y/Z；不画外形 |
| C 机构 | 机构运动简图：按默认参数，用标准符号（转动副、移动副、机架）画各构件，标构件名和主要尺寸 |

共同要求：白底黑线、线宽随比例；右下角中英文标题栏（名称、编号/规格、标准、比例、单位、来源与许可）；`viewBox` 以毫米为单位；文字用系统字体（不嵌字体文件），课件可直接缩放插入。

### B.13 三维节点、关节表与机构运动表（R4、R5）

**glTF 节点**：根节点 `root` 负责把 Z 向上（CAD、URDF 惯例）转成 glTF 的 Y 向上；它下面的节点坐标与 URDF / 机构坐标系一致。

- 机器人：每个连杆一个节点，**节点名 = URDF 连杆名**（只有 MJCF 的模型用 body 名），节点层级 = 运动链；
- 机构：每个构件一个节点，节点名 = `mechanism.members[].node`；
- 标准件：一个节点即可，多零件的（如轴承的内圈、外圈、滚动体）按零件分节点，名称写在 `entry.json` 的 `model.nodes`。

**机器人关节表** `robot.joints[]`（长度用米，角度用弧度）：

```json
{"name": "shoulder_pan_joint", "type": "revolute", "parent": "base_link", "child": "shoulder_link",
 "axis": [0, 0, 1], "origin": {"xyz": [0, 0, 0.1625], "rpy": [0, 0, 0]},
 "limit": {"lower": -6.2832, "upper": 6.2832, "velocity": 3.1416, "effort": 150}}
```

`type` 取 `revolute`、`continuous`、`prismatic`、`fixed`；`robot.links[]` 每项 `{"name", "node", "mass_kg"}`。

**机构** `mechanism`：

```json
{"dof": 1,
 "members": [{"id": "ground", "name": {"zh": "机架", "en": "Ground"}, "node": "ground", "ground": true},
             {"id": "crank", "name": {"zh": "曲柄", "en": "Crank"}, "node": "crank"}],
 "input": {"member": "crank", "type": "rotation", "unit": "deg", "range": [0, 360], "step": 1},
 "motion": "motion.csv"}
```

`motion.csv`：每个输入值一行；第一列 `input`（单位同 `input.unit`），之后每个活动构件 7 列：`<id>.x_m, <id>.y_m, <id>.z_m, <id>.qx, <id>.qy, <id>.qz, <id>.qw`（相对机构坐标系；机架不列）。按默认参数采样；机构锁死、无解的输入值不出行。
