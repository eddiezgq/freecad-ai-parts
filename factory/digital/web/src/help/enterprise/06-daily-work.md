# 各岗位的日常

> 计划、生产、质量、经营：每个岗位一个工作台，单据都在 ERPNext 里，数据都在统一数据总线上。

## 计划员：接单与计划

```anim
name: mrp
```

接单 → 算料 → 提交 → 确认 → 下达车间。算料用 ERPNext 的库存、在途和其他订单的占用；采购件没填提前期的标“交期待确认”。

```goto
tour: planner-order
label: 带我接一张订单
```

## 操作工：派工与开工

工单下达后按工艺路线逐道派给设备，操作工在车间终端对派来的工序点“开工”，停机处理完点“复位”。
真实设备经现场网关接入后，状态从设备来；没接入的设备没有状态。

```goto
tour: operator-start
label: 带我在车间终端开工
```

## 质检员：检验与 8D

看控制图和测量值；对不合格品选返修、报废或让步接收；发现异常开质量异常单，按 D1–D8 处理。

```goto
tour: quality-chart
label: 带我看控制图
```
