# 厂情中枢与提醒

> 规则每 20 秒看一遍全厂：异常、原因、影响；处理办法先推演；日报周报自动写。

```anim
name: causal
```

| 地方 | 做什么 |
| --- | --- |
| 全厂态势 | 各领域的指标和异常数，可以回看过去某个时刻 |
| 异常处理 | 异常列表、因果链、处理 |
| 推演工作台 | 在快进副本里比较几种办法（加班、换设备、改顺序） |
| 动作收件箱 | 起草的动作，审批后执行 |
| 日报与周报 | 自动生成 |
| 通知设置 | 订阅哪些领域、什么严重程度；站内铃铛总能收到，生产模式下还可以发邮件和群消息 |

邮件提醒要在 `.env` 里配 SMTP（`WQ_SMTP_HOST` 等）。

```goto
tour: ont-anomaly
label: 带我追一个异常
```

```ask
q: 现在最严重的异常是什么，原因是什么？
```
