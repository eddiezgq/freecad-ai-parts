# 新产品进工厂

> 工程师在 FreeCAD 里选型、校验、发布；工厂把方案转为 ERPNext 的物料、工艺路线和 BOM，就能接单生产。

## 一个产品的路

```anim
name: flow
caption: 设计 → ERP → MRP → MES → 车间 → 质量 → 厂情中枢
```

1. **FreeCAD 里发布**：AI Parts 工作台选型、校验，点“发布到工厂”，填工厂地址、用户名和密码，选“生产”模式；
2. **工厂里看方案**：“CAD 方案”里有 BOM（每个零件带资料出处）、自制件、总装工艺和校验结论；
3. **转为生产物料**：填外购件的采购提前期和单价（不知道就空着，系统标“交期待确认”，不会替你估），点“转为生产物料”，确认后在 ERPNext 建供应商、物料、工艺路线和 BOM；
4. **起草工艺规程**：自制件的粗基准和装夹从方案里带过来，工艺员补全后交 AI 预检、技术负责人批准；
5. **接单**：计划员在“订单与计划”选这个产品下单。

自制件的工序只能用工厂清单里已有的工序；方案里用了工厂没有的工序，转为生产物料时会说出是哪一道。
