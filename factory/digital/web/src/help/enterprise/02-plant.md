# 工厂清单：把你的车间搬进来

> 交一份 Excel：公司、工作站、每台设备的位置、工序、班次、指标。数字工厂、ERPNext、3D 车间都按它建。

## 三步

```anim
name: terminal
title: 你的电脑或服务器
$ python -m factory.plant template 工厂清单.xlsx
已生成模板：工厂清单.xlsx
$ python -m factory.plant import 工厂清单.xlsx plant.yaml
工厂清单有 2 处错：
  - 设备表第 6 行“x / y / 宽 / 深”：这一组要填全（4 项）
  - 工序表第 3 行“可用设备”：没有这台设备：lathe-3
$ python -m factory.plant import 工厂清单.xlsx plant.yaml
已导入：工厂清单.xlsx → plant.yaml（8 个工作站、13 台设备、12 道工序）
$ python -m factory.plant check plant.yaml
清单无误：示例缝纫机厂，8 个工作站、13 台设备、12 道工序
```

1. **生成模板**：模板已经按演示工厂填好，作样例；
2. **照着改成你的车间**：哪里填错了，导入时会说清是哪张表、第几行、哪一列；
3. **安装时带上**：`install.sh --plant plant.yaml`；已经装好的用 `upgrade.sh --plant plant.yaml` 换清单。

## 每张表填什么

| 表 | 每行是 | 要点 |
| --- | --- | --- |
| 工厂 | 一个项目 | 公司名称、缩写、国家（英文）、币种、时区；原材料库、成品库（设备编号）；车间长宽、通道；班次、工作日、加班上限；三项指标目标 |
| 工作站 | 一组同类设备 | 名称（就是 ERPNext 的工作站名）、台数、每小时折旧 / 人工 / 能耗费率 |
| 设备 | 一台设备 | 编号、区域、中英文名、所属工作站；中心 x、y 和宽、深（米，原点在车间左下角）；看板顺序；物流小车填停靠点 |
| 工序 | 一道工序 | 工序名（与工艺路线一致）、工作站、可用设备（编号，逗号分开）、阶段、是否检验 |
| 供应商、客户 | 一家 | 可空 |

不知道的格子留空，不要写 0 代替。仿真参数（换型、刀具磨损等）留空时用缺省。
