# 账号与角色

> 管理员开账号、分角色；每个人只看到自己岗位的工作台。

## 登录方式

企业版用用户名加密码登录。第一个管理员在安装时建（`install.sh --admin`），其他人由管理员在“账号与角色”里开。

| 安全规则 | 说明 |
| --- | --- |
| 密码 | 至少 10 位，字母加数字；库里只存加盐慢哈希，不存明文 |
| 锁定 | 连续输错 5 次，锁 10 分钟 |
| 停用、重置密码 | 对方已登录的地方立即失效 |
| 管理员 | 可用全部角色；普通账号只能用分给他的角色 |

## 角色

| 角色 | 工作台 |
| --- | --- |
| 厂长 | 经营与成本、厂情中枢，AI 模型设置 |
| 计划员 | 订单与计划 |
| 工艺员 | 设计与工艺、工艺规程与 AI 评审、CAD 方案 |
| 操作工 | 车间执行 |
| 质检员 | 质量 |
| 审批人 | 设计发布与审批 |
| 销售 | 参数配置器 |

## 忘了管理员密码

在服务器上再建一个管理员（密码从标准输入读，不留在命令历史里）：

```anim
name: terminal
title: 服务器 · /opt/fap
$ read -s PW; printf '%s\n' "$PW" | docker compose -p fap exec -T hub python -m hub.accounts create-admin admin2
完成： create-admin admin2
```
