# AI 设置

> 国内自动用 DeepSeek，其他地方用 Claude；一家出错自动换另一家。

## 怎么选

| 设置 | 说明 |
| --- | --- |
| 自动（缺省） | 按服务器时区判断地区：中国时区用 DeepSeek，其他用 Claude |
| 固定 Claude / DeepSeek | 管理员在“厂情中枢 · AI 运行记录”里改 |
| 出错换另一家 | 两家都配了密钥时，首选出错（网络、额度）自动换另一家，运行记录里注明 |
| 都没配 | AI 助手改用规则回答，其他功能照常 |

密钥写在服务器安装目录的 `.env` 里（`WQ_CLAUDE_KEY`、`WQ_DEEPSEEK_KEY`），只给服务器，不经过任何人的电脑。改完重启：
