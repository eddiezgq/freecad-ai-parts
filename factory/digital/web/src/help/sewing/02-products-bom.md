# 产品、物料与工艺路线

## 两种整机

| 产品 | 编号 | 示例售价 | 自制件 |
|---|---|---|---|
| 工业直驱平缝机 | WQ-LS | $520 | 平缝机壳 HSG-LS、上轴 LS-101、下轴 LS-102、针杆 LS-201、旋梭 LS-301、送布 / 抬牙偏心 LS-401 ×2 |
| 工业直驱四线包缝机 | WQ-OL | $640 | 包缝机壳 HSG-OL、主轴 OL-101、针杆 OL-201、弯针 / 差动偏心 OL-401 ×3 |

机壳用自己铸的铸件：平缝机壳铸件 CAST-LS（HT250，约 14 kg）、包缝机壳铸件 CAST-OL（约 6 kg，一型两件）。

外购件写通用名称 +“型号待确认”：直驱伺服电机与电控箱、机针、弯针、梭壳、送布牙针板压脚、轴承、同步带、盖板、油盘、标准件、包装。
电控箱出厂测试时烧录本厂固件。

## 接一张单会建几张工单

接 1 台 WQ-LS，算料后建 8 张工单：铸件 → 机壳，上轴、下轴、针杆、旋梭、偏心，最后是整机。
每张工单按自己的工艺路线逐工序派到车间，前一级完工入库，后一级才能领料。

## 工艺路线（工时为示例值）

| 路线 | 工序 |
|---|---|
| 铸件 | 配料 → 熔炼 → 炉前分析 → 混砂 → 型砂检测 → 制芯 → 砂芯检验 → 造型下芯合型 → 孕育浇注 → 冷却 60 min → 落砂 → 旧砂处理 → 去浇冒口 → 抛丸 → 清内腔芯砂 → 打磨 → 第一次时效 480 min → 刮腻子 → 喷底漆 → 理化检验 → 铸件检验 |
| 平缝机壳 | 毛坯检验 → 粗铣底面（立加）→ 粗加工、粗镗（卧加）→ 第二次时效 → 精铣底面、铰销孔、打刻序列号（立加）→ 钻攻、油路孔（钻攻中心）→ 精镗孔系（卧加，一次装夹）→ 去毛刺 → 清洗吹干 → 三坐标 → 机壳终检 → 面漆 → 烘干 |
| 包缝机壳 | 同上，多一道渗漏试验（油池） |
| 轴 | 下料 → 粗车 → 调质 → 校直 → 精车 → 铣扁钻孔 → 轴颈高频淬火 → 校直 → 磨外圆 → 清洗 → 零件检验 |
| 针杆 | 下料 → 无心粗磨 → 车、钻针夹孔 → 淬火回火 → 校直 → 无心精磨 → 清洗 → 检验 |
| 旋梭 | 车削 → 铣梭尖梭道 → 渗碳淬火 → 磨梭道 → 研磨梭尖 → 清洗 → 检验 |
| 偏心 | 下料 → 车削 → 铣键槽 → 渗碳淬火 → 磨内孔端面 → 磨偏心外圆 → 偏心测量 → 清洗 → 检验 |
| 平缝机总装 | 4 个分装 → A01–A12 总装线 → 调试 → 跑合 30 min → 出厂测试 → 清洗包装 |
| 包缝机总装 | 2 个分装 → B01–B06 总装线 → 调试 → 跑合 → 出厂测试 → 包装 |

ERPNext 一种物料一张检验模板，所以一种物料的全部测量都记在它最后一道检验工序上，名称里写明是在哪台设备测的。

## 实验 34：一台平缝机从订单到交付

左侧“实验与任务 → 实验 34”：自己接 1 台 WQ-LS，算料，按层下达（铸件和关键零件 → 机壳 → 整机），判一台平缝机出厂检验合不合格，入库开票，看整台的标准成本与实际成本，最后复盘。平台自动评 60 分，实验报告 40 分。
