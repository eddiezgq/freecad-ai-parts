# 机壳：铸造与加工

## 铸造

铸件检验时每件记录：
- 布氏硬度（180–240 HB）；
- 本炉单铸试棒抗拉强度（≥ 250 MPa）；
- 关键壁厚；
- 关键部位气孔、砂眼数（要求 0）；
- 浇注这一型时的型砂含水（3.0–3.8 %）。

两个常见毛病：

- **型砂含水高 → 气孔**。混砂机加水控制失灵，型砂里的水在浇注时变成气，留在铸件里。气孔常藏在表皮下，加工后才露出来，所以铸件检验要看轴承座凸台。
- **孕育不够 → 硬度高、加工崩刀**。孕育剂受潮，或孕育后拖太久才浇（孕育衰退），石墨长不好，铸件发硬，三角试片白口变宽。

## 机壳加工的几条规矩（教材 25.4）

1. 第一道工序以上下轴孔的铸孔为**粗基准**（锥销插进孔里找中心），保证最重要的孔余量均匀；粗基准只用一次。
2. 以后都用**一面两销**定位：底面 A + 两个工艺销孔（基准统一）。
3. **粗精分开**，粗加工后做**第二次时效**，把加工释放出来的应力再去一次。
4. 同一轴线的孔用长镗杆**一次镗通**，夹具上的导向套支承镗杆，不调头；镗前用测头量底板上平面，修正镗孔坐标（教材 25.4.6 的工序尺寸换算）。
5. 交叉孔去毛刺，清洗后测清洁度；包缝机壳做油池渗漏试验。
6. 全部机加工完、终检合格后才喷面漆：先遮蔽孔和加工面，再低温烘干。

## 机壳终检记什么

| 平缝机壳 | 要求（示例） |
|---|---|
| 上轴立柱孔 Ø26 J7 | 25.991–26.012 mm |
| 上轴孔三处同轴度、下轴孔三处同轴度 | ⌀0.010 |
| 上下轴孔平行度 | ≤ 0.015 |
| 上下轴孔中心距偏差 | ± 0.020 |
| 针杆孔对上轴孔垂直度 | 0.010 |
| 针杆孔到下轴孔位置度 | ⌀0.030 |
| 下轴孔轴线到底板上平面 | 32 ± 0.03 |
| 底面 A 平面度 | ≤ 0.020 |
| 清洁度 | ≤ 15 mg |

每条测量记录带着“精镗用的哪台卧加”，可以按卧加分层看。

## 两个机壳毛病

- **一台卧加的定位销磨了**：只有那台镗的机壳针杆孔位置度、中心距慢慢变大，别的卧加照常。返镗只能救一件；要换那台夹具的定位销和衬套。
- **时效炉热电偶漂移**：仪表显示温度够了，实际炉温偏低，残余应力没去掉，机壳同轴度、平面度变差。出厂时可能还合格，到用户手里几个月后机臂慢慢变形，梭尖间隙就变了（教材 25.1 问题一）。
