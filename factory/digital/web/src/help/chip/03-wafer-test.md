# 晶圆测试与晶圆图

> 探针台一次扎 8 颗芯片，测试机给每颗分档；一片约 3.8 万颗的结果画成晶圆图。看图形就能分出是芯片坏了，还是测试没扎好。

## CP 每片记什么

| 特性 | 名义（范围） | 怎么来 |
|---|---|---|
| CP 良率 % | 92（85–100） | 由晶圆图数出来——图和良率是同一份数据 |
| 探针接触电阻 Ω | 1.0（0–3.0） | 8 个测试位的平均 |
| 静态电流 IDDQ µA | 1.0（0–10） | 中位数 |
| 施密特上 / 下阈值 V | 1.254 / 0.607 | 名义取第 93 轮晶体管级仿真 |

## 晶圆图怎么看

[晶圆图](/wafer-map) 页：每颗芯片一个小格，绿色合格，其余按失效分档上色：

| 分档 | 图上的样子 | 多半是 |
|---|---|---|
| 功能失效（红） | 散点，偶尔一小簇 | 工艺里的随机缺陷、颗粒——找代工厂 |
| 静态电流超标（橙） | 靠边一圈多 | 晶圆边缘工艺不均 |
| 开路 / 接触不良（紫） | **每隔 4 列、每隔 1 行**规律地出现 | 不是芯片坏——是探针卡某个测试位接触不好 |

探针卡一次扎 **2 行 × 4 列**：测试位 1–4 在上一行、5–8 在下一行。右边的柱状图按测试位分开数失效率——
芯片不会按“测试位”坏，某一位特别高，一定是测试的问题。下面一行是各测试位的接触电阻。

## 误判的代价

接触不良的那一位扎到的芯片其实是好的，但在 CP 被判失效、打上标记，后面不封装——**白白扔掉好芯片**。
FT 的良率不受影响（坏的都在 CP 挡掉了），所以只看 FT 发现不了这个问题。
