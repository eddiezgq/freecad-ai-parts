# 封装与成品测试

> 划片、装片、键合、塑封……每一步都有抽检；结果按批次在 FT 工位一起记，进控制图。

## 每批成品记什么

| 特性 | 名义（范围，示例） | 抽检在哪一步 |
|---|---|---|
| 划片崩边 µm | 10（0–25） | 划片后抽检，取最大值 |
| 键合拉力 gf | 6.0（≥ 3.0） | 键合后拉线试验，取最小值；**记下是哪台键合机** |
| 焊球推力 gf | 25（15–40） | 键合后推球试验 |
| 塑封空洞率 % | 1.0（0–3.0） | 塑封后 X 光抽检 |
| FT 良率 % | 98（95–100） | 成品测试 |
| 工作电流 mA | 0.67（0.4–1.0） | 名义取第 92 轮版图功耗 |
| 施密特回差 V | 0.648（0.45–0.85） | 名义取第 93 轮晶体管级仿真 |

一种物料在 ERPNext 里只有一张检验模板，所以键合、塑封、划片的抽检结果按批追溯、一起记在 FT 这一道。

## 老师可以注入的四种问题

| 问题 | 数据上的表现 | 对症的措施 |
|---|---|---|
| 探针卡磨损 | 第 6 个测试位接触电阻逐片升高，晶圆图上那一位规律地变紫，CP 良率下降；FT 不受影响 | 清洁探针、超寿命换探针卡 |
| 划片刀磨损 | 崩边逐批增大，FT 良率略降 | 换划片刀 |
| 键合机 wb-2 劈刀磨损 | **只有 wb-2 键合的批次**拉力、推力下降，wb-1 的照常 | 换 wb-2 的劈刀 |
| 塑封料受潮 | 空洞率升高 | 隔离受潮批次、按规程回温、限时用完 |

“看起来有道理但不对症”的措施也在列：CP 失效全部复测、加大键合功率、FT 判定加严……学生在质量异常单上做 8D，只有对症的措施能让后面的批次恢复。
