# 这座厂：问渠数字工业园 · 电路板厂

> 工业园的第三座厂：把光板和元器件做成三种电路板；机器人厂关节里的驱动板、AGV 里的控制板都从这里买。

## 造什么

| 产品 | 编号 | 示例售价 | 用在哪里 |
|---|---|---|---|
| 关节伺服驱动板（48 V、三相、电流采样 + 编码器接口） | DRV-JOINT | $160 | A 版；第 118 轮前机器人厂的关节模组用它 |
| 关节伺服驱动板 B 版（编码器接口芯片、抱闸驱动与线圈电流检测、输出端编码器） | DRV-JOINT-B | $165 | 第 118 轮起机器人厂的每个关节模组一块 |
| AGV 控制板（双路电机控制 + CAN + 安全 IO） | CTRL-AGV | $700 | 机器人厂的每台 AGV 一块 |
| 编码器读头板（正余弦输出） | ENC-RD | $60 | 以后卖给传感器厂 |

售价、工时、名义值都是**示例值**。驱动板有一份 KiCad 设计（[电路板设计](/pcb-design)，示例设计、未经硬件验证），
它用到的芯片是示例选型；其余外购件写通用名称并标“型号待确认”，不编厂商型号。

## 车间

一条 **SMT 线**（板子依次经过）加一段**后段**：

- SMT 线：锡膏印刷 → 锡膏检测 SPI → 高速贴片（片式元件）→ 多功能贴片（IC、MOSFET）→ 回流焊 → 自动光学检测 AOI；
- 后段：选择焊（插件端子）→ 在线测试 ICT → 程序烧录 → 三防涂覆 → 老化 → 功能测试 FCT → 包装。

回流焊炉一次能过 8 块板，老化房一次 40 块；其余设备一块一块做。

## 设备一览

| 工作站 | 设备 | 做什么 |
|---|---|---|
| 锡膏印刷机 | 1 台 | 用钢网把锡膏印到焊盘上 |
| 锡膏检测仪 SPI | 1 台 | 量每个焊盘的锡膏体积、高度 |
| 贴片机 | 2 台 | 高速贴片机贴电阻电容，多功能贴片机贴 MCU、驱动芯片、MOSFET |
| 回流焊炉 | 1 台（10 温区） | 锡膏熔化成焊点；炉温记录峰值温度、液相线以上时间 |
| 自动光学检测 AOI | 1 台 | 拍照找立碑、桥连、少锡、偏移、错件、反向 |
| 选择焊 | 1 台 | 焊插件的功率端子、连接器 |
| 在线测试仪 ICT | 1 台 | 针床量每个元件：采样电阻阻值等 |
| 烧录工位 | 1 个 | 写固件 |
| 三防涂覆机 | 1 台 | 喷三防漆 |
| 老化房 | 1 间 | 带电高温老化 |
| 功能测试台 FCT | 1 台 | 上电测母线电压、电流采样、死区、编码器接口 |
| 包装台 | 1 个 | 装防静电袋 |
| 元器件库、成品库、物流小车 | 2 + 2 | 元器件库带防潮柜 |
