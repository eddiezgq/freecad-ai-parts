# SMT 车间与检验

> 每块贴片板在 AOI 工位记下它的锡膏检测、炉温记录和光学检测结果；每块成品板在功能测试工位记下在线测试和功能测试结果。数据进控制图。

## 每块板记什么

| 物料 | 在哪道工序记 | 特性（名义值和范围是示例值） |
|---|---|---|
| 贴片板 SMT-DRV / SMT-AGV / SMT-ENC | 自动光学检测 AOI | 锡膏体积 %（100，70–130）、锡膏高度 μm、回流峰值温度 ℃（245，235–255）、液相线以上时间 s、片式元件偏移 μm、IC 与 MOSFET 偏移 μm、AOI 缺陷数（计数型，0 才合格） |
| 驱动板 DRV-JOINT | 功能测试 FCT | 采样电阻阻值 mΩ（ICT，2.00 ± 0.02）、母线电压读数误差 %、相电流采样误差 %、栅极死区 ns、编码器接口读数误差、老化后电流零点漂移 |
| AGV 控制板 CTRL-AGV | 功能测试 FCT | 母线电压读数误差、5 V 与 3.3 V 电源、安全 IO 响应时间 |
| 读头板 ENC-RD | 功能测试 FCT | 正余弦幅值、直流偏置、A/B 相位差、细分误差 |

一种物料在 ERPNext 里只有一张检验模板，所以 SPI、炉温、AOI 的结果按板追溯、一起记在 AOI 这一道。
驱动板在线测试时还认出它用的是**哪一卷采样电阻**，质量页可以按卷号分层。

## 老师可以注入的四种问题

| 问题 | 数据上的表现 | 对症的措施 |
|---|---|---|
| 钢网堵孔 | 锡膏体积逐块下降，AOI 少锡缺陷增多 | 清洗钢网、加大擦网频次 |
| 回流炉温漂 | 峰值温度、液相线以上时间逐渐下降，出工艺窗口（冷焊风险） | 测炉温曲线、校正温区 |
| 多功能贴片机 PP-2 吸嘴磨损 | 只有 IC 与 MOSFET 偏移变大，片式元件正常 | 换吸嘴、校吸嘴中心 |
| 采样电阻来料批次超差 | 从某一卷起 ICT 阻值、相电流采样误差偏大，母线电压正常 | 隔离这一卷、退回供应商 |

学生在质量异常单上做 8D：只有对症的措施能让问题消失，后面的板子数据恢复。
