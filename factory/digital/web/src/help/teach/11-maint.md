# 设备维护

> 一台设备拖着不保养，坏的可能越来越大；坏了要停机、挂牌上锁、等备件，进而影响工单和订单。保养做不做、什么时候做，用失效率和推演算清楚。

## 这一页有什么

左栏“保障 → 设备维护”（维修工常用）。上方五个数：保养逾期的设备、开着的维修单、近 7 天故障停机分钟、平均故障间隔（MTBF）、点检异常待处理。

| 标签 | 做什么 |
| --- | --- |
| 设备台账 | 每台设备一行：资产号、自上次保养运行了多少小时、保养周期、未来一段运行时间内坏的概率、预期损失；点“详情”看失效率曲线和参数 |
| 保养 | 保养单：状态、时长、做的人和验收人；“保养完成”“验收解锁” |
| 点检 | 选设备（或扫设备上的二维码），逐项点“正常 / 异常”，提交 |
| 维修与备件 | 备件库存、维修单；“维修完成”“验收解锁” |

资产台账、保养计划、保养记录、维修单以 ERPNext 资产维护模块为准，第一次打开时自动建好。

## 失效率怎么算

设备坏不坏按威布尔分布：

- 运行 t 小时内坏掉的概率 F(t) = 1 − exp(−(t/η)^β)；
- 已运行 t 小时没坏，再运行 H 小时内坏掉的概率 P = 1 − exp(−[((t+H)/η)^β − (t/η)^β])；
- 预期损失 = P ×（修理费 + 平均修复时间 × 停机每小时损失）；
- 保养把 t 拨回 0。

β、η、保养周期、修理费都在“详情”里。平台算的、你手算的、仿真车间里实际“抽签”坏不坏的，是同一套参数。

## 保养：从异常到验收解锁

1. 厂情中枢报“保养逾期”（M2）或“故障风险高”（M4）。
2. 右栏三个方案：**不做**（对照，花费是预期故障损失）/ **现在保养** / **下班后保养**（24 小时运转时 4 小时后）。推荐交期都保得住的方案里“确定花费 + 预期损失”最小的。
3. 采纳，生成“保养工单”动作。维修工或厂长发起，厂长批准。
4. 到时间，车间里这台设备**挂牌上锁**停下，显示 🔒。挂着锁时车间终端不能复位。
5. 维修工做完点“保养完成”。
6. **另一个人**点“验收解锁”：做活的人、申请这把锁的人都不能自己解锁。
7. 设备的“自上次保养”回到 0，ERPNext 多一条保养记录。

## 维修与备件

- 设备故障停机，平台自动记故障、开维修单；点检异常可以采纳“开维修单”；维修工也能手动开。
- 开维修单同时开挂牌上锁许可，ERPNext 开资产维修单。
- 备件不够时维修单变“等备件”，厂情中枢报“维修等备件”，方案是紧急采购或等正常采购。

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| M1 设备反复停机 | 同一台设备 24 小时内报警 3 次以上 |
| M2 保养逾期 | 自上次保养运行的小时数超过保养周期 |
| M3 点检异常 | 点检有不合格项，还没处理 |
| M4 故障风险高 | 未来一段运行时间内坏的概率超过 20%（超过 40% 为严重） |
| M5 维修等备件 | 维修单要用的备件库存不够 |
| M6 维修超时 | 超过平均修复时间 2 倍还没修好 |
| M7 平均故障间隔下降 | 近 30 天的 MTBF 比之前 30 天低 30% 以上 |

M2–M6 的因果链连到这台设备 → 排在它上面的工序 → 工单 → 订单。

## 教学模式

- **车间会坏**：老师在“设备台账”上方的“老师：车间可靠性”选 关（不会坏）/ 正常 / 加速 ×5。重载实验 7 情景后回到“关”。
- 模拟的维修工按时做完维修和保养，等你验收；故障停机的维修单做完一会儿没人验收，模拟的班组长替你验收，车间不会一直锁着。
- **实验 18** 设备维护策略：保养时机的决策：“实验与任务 → 实验 18”。老师在实验页把一台设备的运行小时拨到逾期。
