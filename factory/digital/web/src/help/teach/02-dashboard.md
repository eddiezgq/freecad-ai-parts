## 首页上有什么

| 区域 | 看什么 |
| --- | --- |
| AI 今日简报 | 现在最该关注的三四件事；每条下面写着来源。教学模式只提示方向 |
| 关键指标 | 准时交付率、在制品、设备综合效率（OEE）、一次合格率、本周完工、成本偏差；彩色小字说明离目标多远 |
| 车间实况 | 每台设备此刻的状态；“瓶颈”标签是本周负荷最满的设备；点设备卡片弹出状态和帮助 |
| 订单与交期 | 在手订单按交期排；标签是系统预测的延期风险 |
| 本周计划与实际 | 空心柱是计划，实心柱是实际完工 |
| 质量 | 关键尺寸的控制图：红虚线是公差上下限 |
| 关键物料 | 库存、在途、可用天数；红色是低于安全库存或不够本批需求 |
| 提醒与待办 | 按你的角色列出要处理的事；教学模式下是实验任务 |

## 设备的状态

| 颜色或标记 | 状态 | 意思 |
| --- | --- | --- |
| 绿 | 运行 | 正在加工 |
| 灰 | 空闲 | 没活，或者等料 |
| 黄 | 调整 | 换型、换刀、修整砂轮、待机后预热 |
| 红 | 停机 | 故障；处理完在车间终端点“处理完毕，复位” |
| 🔒 | 挂牌上锁 | 正在整改、保养或维修；要另一个人验收解锁，复位没有用 |
| 👤 | 缺人 | 这一班没人能开这台设备（见“人员与排班”） |

## 顶上的提醒条

有严重异常，或者有带处理方案的警告（停机、缺料、交期），首页顶上会出现一条“厂情中枢”提醒，点“去处理”进指挥台。
教学模式下学生看不到这条提醒：实验 7 要你自己从看板里找问题。

## 首页的数字不动？

- 看左栏下方“统一数据总线”是不是“已连接”；
- 倍速是 1× 时变化很慢，属正常。倍速由老师在“情景导演”的教师控制台里设。
