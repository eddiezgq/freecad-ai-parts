# 看懂首页

> 首页是全厂的一张脸：简报、指标、设备、订单、质量，一屏看完。

## 首页上有什么

| 区域 | 看什么 |
| --- | --- |
| AI 今日简报 | 现在最该关注的三四件事；每条下面写着数据来源 |
| 关键指标 | 准时交付率、在制品、设备综合效率（OEE）、一次合格率、本周完工、成本偏差；彩色小字说明离目标多远 |
| 车间实况 | 每台设备的状态；“瓶颈”标签是本周负荷最满的设备 |
| 订单与交期 | 在手订单按交期排；标签是系统预测的延期风险 |
| 本周计划与实际 | 空心柱是计划，实心柱是实际完工 |
| 质量 | 关键尺寸的控制图：红虚线是公差上下限 |
| 关键物料 | 库存、在途、还够几天；红色是低于安全库存或不够本批需求 |
| 提醒与待办 | 按你的角色列出要处理的事，点按钮直接去处理 |

## 设备的四种颜色

| 颜色 | 状态 | 意思 |
| --- | --- | --- |
| 绿 | 运行 | 正在加工 |
| 灰 | 空闲 | 没活或者等料 |
| 黄 | 调整 | 换型、换刀、修整砂轮 |
| 红 | 停机 | 故障；处理完要在车间终端点“复位” |
