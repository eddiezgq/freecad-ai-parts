# 角色与分工

> 同一座工厂，五个岗位各看各的工作台；顶栏随时换角色。

## 五个岗位

| 角色 | 工作台 | 主要做什么 |
| --- | --- | --- |
| 计划员 | 订单与计划 | 新建订单 → 算料 → 提交 → 确认；把工单“下达车间” |
| 工艺员 | 设计与工艺、工艺规程与 AI 评审 | 改零件设计、发布新版本；写工艺规程交 AI 预检和审批 |
| 操作工 | 车间执行（车间终端） | 选工位，对派来的工序点“开工”；设备停机处理完点“复位” |
| 质检员 | 质量 | 看控制图和测量值；对不合格品选返修、报废或让步接收；开质量异常单（8D） |
| 厂长 | 经营与成本 | 看各设备效率、工单成本、本月交付；教学模式下是老师的控制台 |

厂长只给老师。生产模式里还有“审批人”和“销售”两个岗位（销售用参数配置器给客户报价）。

左栏里标着“我的”的就是你当前角色的工作台。厂情中枢、3D 车间、零件库所有角色都能看。
