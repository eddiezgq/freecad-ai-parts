# 老师专用

> 控制仿真车间、注入问题、重置情景、看学生的提交。

## 教师控制台（经营与成本页，教学模式）

| 功能 | 用法 |
| --- | --- |
| 仿真倍速 | 1×–300×；上课演示用 20×–60× |
| 制造一次故障 | 选设备、停机分钟数和原因，注入 |
| 车间班次 | 24 小时连续，或按班次（周一至周五）；按班次时可以在厂情中枢推演和批准加班 |
| 重置实验 7 情景 | 清空教学模式的历史、重新载入情景；可以同时清空学生得分 |

```goto
tour: teacher-console
label: 打开教师控制台
```

## 问题情景（质量页右侧，学生看不到）

注入一个隐藏的加工问题：磨床尾座偏移（锥度）、砂轮修整间隔过长（漂移加快）、磨床未预热（开机后逐件变小）、
键槽夹具定位元件磨损（对称度超差）、中心孔质量差（圆跳动超差）。注入后车间照常生产，问题只在数据里表现出来。
学生开 8D、提交纠正措施，老师批准后措施才下发。

## 学生与评分

- 学生用名字登录，名字就是成绩账号；
- 实验 7、实验 15 的得分由系统按总线记录计算；
- “我的任务”里的工程任务单由老师审阅；
- 企业成员：老师可以授权某些账号在生产模式使用指定角色。
