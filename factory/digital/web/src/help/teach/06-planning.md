# 接单与计划（MRP）

> 一张订单进来：按 BOM 展开，扣掉库存和在途，算出要请购什么、要下哪些工单。

## 算料是怎么算的

拖动下面的订单数量，看每一行怎么跟着变：

```anim
name: mrp
```

工作台里算料用的是真数据：库存取自 ERPNext 最新的库存快照，在途取自采购单和请购单，占用取自其他在手订单和没开工的工单。

## 在工作台里接一张订单

1. 计划员在“订单与计划”填客户、产品、数量、交期，点“算料”——这一步不写任何东西；
2. 看清楚后“提交”，生成一条待确认的提议；
3. 确认后，ERPNext 里有了销售订单、工单和请购单；
4. 在工单表里点“下达车间”，工单按工艺路线逐道派给设备。
