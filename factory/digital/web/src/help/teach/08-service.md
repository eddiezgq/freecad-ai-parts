## 这一页有什么

左栏“从订单到回款 → 客户与服务”。上方五个数：满意度（近 30 天）、开着的投诉（平均响应小时）、待上门的服务（一次修复率）、保修成本、漏斗金额（本月成交）。

| 标签 | 做什么 |
| --- | --- |
| 销售漏斗 | 加线索 → 转成商机 → 出报价 → 签合同（违约金、响应时限、保修期三项条款）→ 转订单 |
| 投诉 | 登记投诉：设备序列号、现象、严重度、渠道、联系人；同时在 ERPNext 开投诉单 |
| 服务与排班 | 服务工程师未来 14 天的排班、服务工单、完工 |
| 回访与满意度 | 完工后的回访打分（1–5 分） |
| 客户 360 | 一个客户的合同、订单、现场设备、投诉、服务单、满意度，一页看全 |

线索、商机、报价、合同、服务单都写进 ERPNext；投诉、派工排班、回访在平台里做。

## 谁做什么

| 角色 | 能做 |
| --- | --- |
| 所有角色 | 看 |
| 售后 | 登记投诉、“已联系客户”、派工、完工、回访；批准客户通知 |
| 销售（生产模式）、厂长 | 销售漏斗、转订单；也能做售后的事 |
| 厂长 | 批准花钱的派工和备件出库 |

## 合同条款用在哪里

- **违约金**：推演和复盘里订单的延期违约金，按客户合同算。
- **响应时限**：超过时限还没人联系客户，报“投诉超时”。
- **保修期**：服务费用分“保修内由工厂承担”和“向客户收”。

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| C1 客户投诉 | 开着的投诉都是异常；紧急的、或客户合同有违约金的为严重 |
| C2 满意度下降 | 某客户最近 3 次回访平均低于 3.5 分 |
| C3 投诉超时 | 超过合同的响应时限还没联系客户 |
| C4 同批多台投诉 | 两台以上投诉设备的输出轴出自同一片砂轮或同一张工单 |
| C5 报价快到期 | 报价 3 天内到期 |
| R3 延期会触发违约金 | 订单可能延期，而合同有违约金 |

**追溯**：投诉有序列号的，因果链一路追到出厂数据：设备 → 出厂总成 → 输出轴 → 磨它的砂轮 → 同一片砂轮磨的其他轴 → 装在哪些设备、哪些客户。这就是**排查范围**。

## 处理方案（派工）

| 方案 | 做什么 |
| --- | --- |
| A 只修出问题的 | 只上门修投诉的那台 |
| B 修 + 高风险点检 | 再加上排查范围里的高风险设备 |
| C 整批排查 | 排查范围全部上门点检 |

每个方案算好：派哪几位工程师、几天做完、几件备件、花多少钱（保修内 / 向客户收）、涉及几个客户、有没有漏掉高风险设备。
推荐的是“不漏高风险设备里最便宜的”。

采纳后生成三种动作：**服务派工**（ERPNext 服务单）、**备件出库**（ERPNext 出库单）、**客户通知**（B、C 才有；教学模式只记录、不发出）。

## 教学模式

- 模拟器：现场设备健康度变差会来电投诉；工程师按排的日子完工；回访自动打分；隔一阵来一条新线索。
- **实验 16** 客户投诉的追溯、召回与服务决策：“实验与任务 → 实验 16”。老师在实验页注入批次投诉。
- **两周情景**第 1 幕“客户下急单”从这里的销售漏斗走到下单。
