## 三条发布的路

| 从哪里设计 | 适合 | 怎么进工厂 |
| --- | --- | --- |
| “设计与工艺”页的在线设计 | 演示零件输出轴 SH-301，改参数就行 | 填改动说明，点“发布新版本” |
| 桌面 CAD 宏包（FreeCAD 1.1 或 SolidWorks，选做） | 想学真 CAD 的同学 | 同一页下载“我的 CAD 宏包”，在 CAD 里执行发布宏 |
| “设计发布与审批”页 | 任何 CAD 画的零件 | 上传 STEP（可带图纸、加工程序） |

教学模式提交即生效。生产模式要审批人看图、批注、批准后才生效（按钮变成“提交审批”）。

## 在线设计

1. 打开“设计与工艺”（工艺员）。
2. 在“在线设计 · 输出轴 SH-301”里改轴段直径与长度、倒角、台阶圆角、键槽。右边三维模型马上跟着变，下面显示校核结果。
3. 填改动说明，点“发布新版本”。服务器生成 STEP、零件图和键槽 G 代码，ERPNext 里的设计版本加一。
4. 新的 G 代码在下达工单时，随“铣键槽”工序派给键槽铣床。

校核没通过时“发布新版本”是灰的：看红字（例如键槽长超过了所在轴段）。黄字是和国标推荐值不同的提示，可以点“用推荐值”，不改也能发布。
宏包里的登录凭证 7 天有效。过期了回“设计与工艺”页重新下载。

## 工艺规程的两步

1. **AI 预检**：自动核算定位误差、夹紧力、工时。超差的标“必须改”，有余量的给“建议”。
2. **技术负责人批注、批准**：批准后成为生效版本，车间按它派工。

批准后的工艺规程可以生成全套工艺文件：工艺过程卡片、工序卡片、检验卡片、刀具卡片。

## 电路分析

[电路分析](/circuit)（第 79 轮）用 ngspice 算机器人关节伺服驱动板 DRV-JOINT 上的电路。每道例题有原理图（点带参数的元件就跳到它的输入框）、可调参数、曲线，
每个读数都和手算公式放在一张表里对照，写明允许差多少；公式是近似的，表下说明为什么差。

| 例题 | 算什么 | 用到的分析 |
| --- | --- | --- |
| 1 相电流采样放大 | 采样电阻和放大倍数让峰值电流落进 ADC 量程；带宽；电阻 1% 偏差下的增益误差 | 直流扫描、交流、蒙特卡洛 |
| 2 栅极驱动与开关时间 | 驱动电阻与开关快慢、米勒平台、关断延时（定死区） | 瞬态；栅电荷法 |
| 3 母线电容与输入滤波 | 母线纹波、电缆电感与母线电容的谐振 | 瞬态、交流 |
| 4 编码器信号接收与滤波 | RC 滤波会不会吃掉高速脉冲、比较器延时 | 瞬态、交流 |
| 5 24 V → 5 V 降压电源 | 电感电流纹波、输出纹波、效率 | 瞬态 |
| 6 电机电流环 | 电气时间常数、PI 调节的上升时间与带宽、电压够不够 | 瞬态、交流 |

“在哪儿算”选**浏览器**：ngspice 编译成 WebAssembly 在你自己的电脑里跑（第一次下载约 5 MB，之后很快）；选**服务器**：交给服务器上的 ngspice。两边用同一张网表，读数相同。
容差分析、网表模式在服务器上跑。网表模式不支持读写文件和 `.control` 段。“下载计算书”生成 Word：参数、对照表、曲线、容差结果和网表。

参数都是示例值（48 V 母线、力矩常数 0.15 N·m/A、伺服 400 W 电机），器件用通用模型，不代表任何厂商的产品。

## 虚拟仪器

[虚拟仪器](/instruments)（第 82 轮）照实验桌的样子测量：被测对象和接线已经摆好，调仪器、读数、点“记录”，最后把算出的结果“交平台核对”，逐项打 ✓ 或 ✗（不显示正确值）。
每个人的传感器参数在名义值附近散布（按登录的人固定），数不能互相抄。参数都是示例值。

| 任务 | 仪器 | 要算出 |
| --- | --- | --- |
| 1 力矩传感器标定 | 万用表（供桥电源 10 V） | 灵敏度（mV/V）、零点、非线性、迟滞（%FS） |
| 2 编码器测速与解码 | 示波器、逻辑分析仪 | 转向、转速、每转计数、Z 脉冲间隔 |
| 3 IMU 静置零偏与 Allan 方差 | 数据记录仪（静置 2 小时） | 零偏、角度随机游走、零偏不稳定性 |
| 4 霍尔电流传感器 | 电流源、万用表、信号源、示波器 | 灵敏度、零点、−3 dB 带宽 |
| 5 热敏电阻测温曲线 | 恒温槽、万用表 | B 值、R25 |
| 6 激光测距的噪声与平均 | 数据记录仪 | 1 m、5 m 处的标准差，平均 16 次后的标准差 |

仪器按真仪器建模：示波器有带宽、8 位量化和本底噪声；万用表有量程、分辨率和精度等级，读数旁给出 B 类（精度 ÷ √3）、A 类（最近 10 次读数）和合成不确定度。
几个窍门：示波器量正弦幅值时用“交流有效值 × √2”比用峰峰值准；Allan 曲线在短 τ 段（斜率 −1/2）读 ARW；零偏不稳定性的估计本身有 ±30% 左右的散布，平台的允许误差放宽了。
电路分析页的瞬态曲线点“送到示波器”，在这里用示波器看仿真波形。每个任务能导出 CSV 和 Word 实验记录。

## 电路板设计

[电路板设计](/pcb-design)（第 88 轮）是关节伺服驱动板 DRV-JOINT 的一份 KiCad 设计。**示例设计，未经硬件验证，不能直接投产**；
芯片用 KiCad 官方库里有的器件做示例选型（引脚取自官方库），电阻电容的数值由电路公式算，和“电路分析”的例题是同一组数。

| 标签 | 看什么 |
| --- | --- |
| 原理图 | 7 页：48 V 输入与母线、辅助电源、三相桥、栅极驱动、相电流采样、MCU、编码器与 CAN；每页有说明，四页能跳到电路分析的同名例题 |
| PCB | 4 层板 100 × 70 mm，各层可开关；半桥中点、母线走铺铜，地走内层平面 |
| 三维 | 器件外形取自 KiCad 官方三维模型库，可以下载 STEP 放进 FreeCAD |
| BOM | 一行一种物料，物料编号就是电路板厂清单里的编号（贴片板、成品板的物料清单按这份设计的数量写） |
| 可制造性检查 | 按一份示例板厂工艺能力查：线宽线距、孔与孔环、阻焊桥、元件到板边、元件间距、极性元件方向、ICT 测试点覆盖率、大电流走线宽度；每项写“为什么板厂在乎”，点一下在 PCB 上标出位置 |
| 下载 | KiCad 工程、Gerber 与钻孔、BOM、贴片坐标、STEP |

设计怎么来的：一份设计描述（器件、数值、每个引脚接哪个网络）→ 脚本写出 KiCad 原理图和 PCB → 开源自动布线器 Freerouting 布线 →
KiCad 设计规则检查与导出。每次推送，自动测试都会用 KiCad 重新导出一遍，必须和仓库里的一字不差（三维除外）。

页面顶上可以切换 **A 版 / B 版**（第 98 轮）。A 版是电路板厂在生产的那一版，MCU 直接数编码器脉冲；
B 版把下面“芯片设计”里的编码器接口芯片 WQ-ENCIF 放上了板：编码器 A/B/Z 经原来的滤波进芯片，芯片计数，MCU 用 SPI 读，另加 50 MHz 晶振和 1.8 V 稳压。
B 版的“A→B 改了什么”列出新增器件、MCU 改了哪几只引脚、多出的物料和固件要改的配置。**B 版只作设计对照，不投产**——芯片没有流片，买不到。

B 版还有“**固件（Renode 仿真）**”一栏（第 100 轮）：MCU 读这颗芯片的示例固件（C 语言，不用厂商库，寄存器地址都注明手册出处），
编译出来的真固件在开源单片机仿真器 Renode 里跑，芯片和电机是仿真出来的。六个场景——上电、正转 600 rpm、反转过零、Z 相、芯片报错、芯片不响应——
每个都把“固件读到的”和“电机实际的”画在一起、逐项判对错。板上没有调试串口，固件把结果放在内存里一块“遥测区”，相当于用调试器经 SWD 看变量。
源码可以逐文件看，也可以下载整包（含 fw.elf 和仿真脚本），本机装 Renode 就能复现。本轮只做编码器这一路，电机控制和 CAN 以后再做。

## 芯片设计

[芯片设计](/chip-design)（第 92 轮）是一颗为驱动板设计的小芯片：**编码器接口芯片 WQ-ENCIF**，从 Verilog 一直做到版图（GDS）。
**示例设计，未流片，未经硅验证**；工艺用开源的 SKY130（130 nm）。

它做的事：编码器的 A、B、Z 三路脉冲 → 同步器 → 数字滤波（去掉短于 N+1 个时钟的毛刺）→ 4 倍频解码（每个边沿计一步，A、B 同时跳变报“丢步”）
→ 32 位计数、Z 相锁存 → SPI 交给 MCU 读。时钟 50 MHz。

| 标签 | 看什么 |
| --- | --- |
| 规格 | 内部五块怎么连、引脚、寄存器表、SPI 帧格式 |
| Verilog | 芯片的源代码；仿真、综合、版图都由这一份生成 |
| 仿真 | 9 个用例（正反转、高速、毛刺、丢步、Z 相、溢出、SPI 读写、复位、随机）：RTL 和 Python 参考模型**逐拍**比对，每个都能看波形 |
| 综合 | 变成多少个标准单元（触发器、加法器、与或门……）、面积、功耗估计 |
| 版图 | 整颗芯片，按器件层和各层金属开关；放大能看到一个个标准单元 |
| 检查 | 设计规则（DRC）、版图对原理图（LVS）、建立和保持时间、天线效应：全过才能出 GDS |
| 晶体管级 | 输入端的施密特触发器（第 93 轮）：SKY130 器件模型 + ngspice 算出上下两个门限和回差；同一段带 ±0.3 V 干扰的慢边沿，普通反相器来回翻很多次，施密特触发器只翻一次（《数字集成电路设计》第 1 章“编码器信号的抗干扰”那道题的答案之一） |
| 接上编码器 | 调转速、毛刺多少和宽度、滤波长度 N，逻辑分析仪看原始 A/B、滤波后的 A/B、计数和 SPI 读数帧；N 太小毛刺就穿过去，计数一来一回 |
| 下载 | Verilog、测试平台、参考模型、流程配置；GDS、门级网表、全部报告 |

可以试试：在“接上编码器”里把滤波长度调成 0，毛刺加多——看“穿过滤波的”和“计数多跳了几下”；再调回 3，看它们变成 0。
