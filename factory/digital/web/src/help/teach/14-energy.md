# 能源与环境

> 设备状态 → 功率 → 计量读数 → 单件能耗 → 电费（峰平谷）→ 碳排放。机床开着没活、在电价最贵的时候开炉，都会在这里看到，也会在厂情中枢报出来。

## 这一页有什么

左栏“保障 → 能源与环境”。上方六个数：用电、电费（峰 / 平 / 谷电量）、峰时占比、空转电量、碳排放、本月需量 / 合同需量。

| 标签 | 做什么 |
| --- | --- |
| 总览 | 车间总表曲线（红峰、黄平、蓝谷，虚线是合同需量）；每台设备的电量条，灰色是空转；正在用的节能设定 |
| 计量点 | 选一块电表、流量计或环境监测点看曲线 |
| 单耗 | 每台设备每件的运行电量，对比基线；近 12 小时空转；空压机和峰时 |
| 碳与环境 | 本月碳排放、每件产品的碳足迹、油雾和噪声、参数（电价、排放因子、合同需量、限值） |

数据在平台自己的表，不进 ERPNext。教学模式由仿真车间每 15 分钟（工厂时间）发一个读数，和真实电表的抄表间隔一样。

## 几个叫法

| 叫法 | 意思 |
| --- | --- |
| 空转 | 设备开着，没活 |
| 待机 | 设了“空闲 N 分钟自动待机”，空闲到时自己转待机；再开要预热几分钟 |
| 关机 | 这一班没人的设备，下班的人顺手关掉；忘了关就一直空转 |
| 错峰 | 峰时不开新炉，工件攒着峰后一起进炉 |
| 碳足迹 | 电量 × 电网排放因子 |

错峰省的是**钱**（电换了时段），电量和碳不变；待机省的是**电**，钱和碳一起省。

## 谁做什么

| 角色 | 能做 |
| --- | --- |
| 所有角色 | 看 |
| 计划员、维修工、厂长 | 发起节能设定、错峰 |
| 厂长 | 改电价、排放因子、合同需量、环境限值；批准节能设定、错峰 |

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| N1 单耗突增 | 某台设备最近几件的单件电量比基线高 25% 以上（多半在劣化） |
| N2 空转能耗高 | 近 12 小时某台设备空转电量占 30% 以上；热处理炉保温不算 |
| N3 峰时用电占比高 | 近 24 小时峰时电量占 30% 以上 |
| N4 压缩空气基荷高 | 空压机比该用的多出一截，可能漏气 |
| N5 需量接近合同需量 | 本月最大 15 分钟平均功率超过合同需量的 90% |
| N6 车间环境指标超限 | 近 1 小时油雾或噪声平均超过限值 |

## 处理方案

| 异常 | 方案 |
| --- | --- |
| N2 空转 | 不处理（对照）/ 这台空闲 10 分钟自动待机 / 30 分钟 / 全部机加设备 10 分钟 |
| N3 峰时、N5 需量 | 热处理错峰 / 不处理 |
| N1 单耗突增 | 开维修工单 / 暂不处理 |
| N4 漏气、N6 环境超限 | 整改工单 / 暂不处理 |

空转、错峰的方案用车间推演算未来 24 小时的电量、电费、碳和交期。推荐交期不变的方案里电费最省的。

## 教学模式

- 能源模拟器（“总览”最下面“老师：能源模拟器”）：会出下班忘关、漏气、设备劣化、油雾收集器故障；老师可以注入，也可以清除。
- **实验 21** 能源：空转、错峰与单件碳足迹：“实验与任务 → 实验 21”。
- **两周情景**第 7 幕：带锯床空转、热处理排在峰时段开炉。

```ask
q: 昨天用了多少电？峰时占多少？
```
