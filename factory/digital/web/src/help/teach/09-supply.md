# 采购与来料

> 料的一生：请购 → 采购单（选供应商）→ 到货 → 来料检验 → 合格入库或不合格 → 用到哪些零件 → 供应商评分。一批料不合格，装配就要等。

## 这一页有什么

左栏“从订单到回款 → 采购与来料”。上方五个数：在途批次、到货待检、不合格待处理、近 30 天准时率 / 合格率、供应商模拟器开没开。

| 标签 | 做什么 |
| --- | --- |
| 采购单与在途 | 还没下采购单的请购：每行选供应商，点“转采购单”；批次表看每批的状态 |
| 到货与检验 | 点一批的“检验”，看抽样数据，自己逐件对照上下限，判合格或不合格 |
| 批次 | 输入批号或零件、设备序列号，点“追溯”：这批料用到了哪些零件、装进了哪些设备 |
| 供应商 | 评分卡：价格指数、提前期、准时率、合格率、在途；默认和备选供应商 |

采购单、收货单、来料检验单以 ERPNext 为准。每次到货是一个批次，车间每做一件都记下用了哪个批次的料。

## 谁做什么

| 角色 | 能做 |
| --- | --- |
| 所有角色 | 看 |
| 计划员 | 转采购单、退货、登记到货 |
| 质检员 | 来料检验、判可疑批次、退货、让步接收 |
| 厂长 | 批准采购单、开发备选供应商（花钱）；批准让步接收 |

不能批准自己发起的动作。

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| W1 缺料 / 低于安全库存 | 库存不够订单或安全库存 |
| W2 采购单逾期到货 | 过了承诺到货日还没到 |
| W3 来料检验不合格未处理 | 一批判不合格，还没退货或让步接收 |
| W4 供应商准时率低 | 近 30 天至少 3 批，准时率低于 80% |
| W5 供应商来料合格率低 | 近 30 天至少 3 批，合格率低于 95% |
| W6 单一来源 | 一类物料只有一家在用的供应商 |
| W7 可疑批次已用到零件上 | 判为可疑的批次已经用到零件上 |

## 处理方案（来料不合格）

| 方案 | 做什么 |
| --- | --- |
| A 不处理（对照） | 这批料不能用，等料的订单一直等 |
| B 退货，等原供应商补发 | 不花钱，按原提前期补发 |
| C 向备选供应商下急单 | 加价，快 |
| D 让步接收，全检挑用 | 全检一天，能用的先入库；要质量批 |

推演按每个方案的到料日下达等料的工单，算出订单晚几天。推荐交期保得住的方案里花钱最少的。

**总拥有成本**：便宜的供应商算上晚到和不合格，不一定便宜。实验 20 任务 5 要你算。

## 教学模式

- 时间压缩：供应商的 1 天 = 真实 2 分钟（账期日）。
- 供应商模拟器（老师可在上方开关）：供应商会晚到、会送来不合格的一批。没人处理时，模拟的采购员、质检员会替你做（都给你留了时间先做）。
- **实验 20** 供应链：来料不合格与供应商选择：“实验与任务 → 实验 20”。
- **两周情景**第 2、3 幕：缺料、来料不合格。
