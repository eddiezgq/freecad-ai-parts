# 进入工厂

> 填名字、选角色、选模式：三步就进到{{厂名}}里。

## 一座正在运转的工厂

你登录进去的是一座按真实工厂做的数字工厂：订单、物料、工单、设备、检验、成本都在跑。车间里的机床由仿真器驱动，
每台设备的开工、加工、换刀、停机都会发到“统一数据总线”上，看板、3D 车间、ERPNext 看到的是同一份数据。

## 登录

浏览器打开老师给的地址（在自己电脑上是 `http://localhost:8100`），填你的名字，选角色和模式。
名字就是你的成绩账号，每次用同一个名字登录。顶栏可以随时换角色、换模式。

```video
name: teach-login
caption: 登录、选角色、两种模式
```

| 模式 | 用来做什么 | AI 工厂助手 |
| --- | --- | --- |
| 教学模式 | 有实验任务、提示和评分，机床是仿真的 | 只提示方向，不替你做 |
| 生产模式 | 工厂日常工作台，没有任务和评分 | 可以帮你起草单据，你确认后才生效 |
