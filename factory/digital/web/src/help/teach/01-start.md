## 一座正在运转的工厂

订单、物料、工单、设备、检验、成本都在跑；还有客户与服务、采购、人员、安全、设备维护、能源、财务七个领域。
车间里的机床由仿真器驱动，每台设备的开工、加工、换刀、停机，都会发到“统一数据总线”上。看板、3D 车间、厂情中枢、ERPNext 看到的是同一份数据。

## 登录

浏览器打开老师给的地址（在自己电脑上是 `http://localhost:8100`）。

| 从哪里进 | 怎么登录 |
| --- | --- |
| 问渠学习平台的课程里点进来（线上） | 点“用问渠账号登录”，不用另外注册 |
| 学校机房、自己电脑（本地版） | 填姓名。名字就是你的成绩账号，每次用同一个名字 |

| 模式 | 用来做什么 | AI 工厂助手 |
| --- | --- | --- |
| 教学模式 | 有实验、提示和评分；机床是仿真的；老师可以注入问题 | 只提示方向，不替你做 |
| 生产模式 | 工厂日常工作台，没有实验和评分；只对老师和企业成员开放 | 可以帮你起草单据，你确认后才生效 |

## 角色

同一座工厂，每个岗位看各自的工作台。左栏标着“我的”的，就是你当前角色常用的页面。顶栏的“角色”下拉框随时可以换。

| 角色 | 主要在哪一页 | 做什么 |
| --- | --- | --- |
| 计划员 | 订单与计划、采购与来料 | 接单、算料、下达工单；转采购单；发起推演里的动作 |
| 工艺员 | 设计与工艺 | 改零件设计、发布新版本；写工艺规程 |
| 操作工 | 车间执行（车间终端） | 对派来的工序点“开工”；停机处理完点“处理完毕，复位” |
| 质检员 | 质量 | 看控制图；处置不合格品；开质量异常单（8D）；来料检验 |
| 售后 | 客户与服务 | 登记投诉、派工、回访 |
| 维修工 | 设备维护 | 保养、点检、维修，挂牌上锁 |
| 班组长 | 人员 | 排班、记出勤、调班 |
| 安全员 | 安全环保 | 隐患、作业许可、培训、验收解锁 |
| 厂长 | 经营与财务 | 只给老师。批准花钱的动作；教学模式下老师用它演情景 |

生产模式里还有“审批人”和“销售”两个岗位。

## 左栏怎么分组

| 分组 | 里面有 |
| --- | --- |
| 总览 | 首页 · 运营总览、厂情中枢、我的任务、AI 工厂助手 |
| 从订单到回款 | 客户与服务、订单与计划、采购与来料、车间执行、质量、经营与财务 |
| 保障 | 设备维护、人员、安全环保、能源与环境 |
| 设计与工艺 | 设计与工艺、工艺规程与 AI 评审、设计发布与审批、参数配置器、3D 车间 |
| 教学（只在教学模式） | 情景导演（只给老师）、实验与任务 |
| 资源 | 零件与机器人库、企业成员、帮助 |

下面还有“专业软件”（ERPNext、仿真、数控编程、数字孪生、虚拟 PLC……）和“统一数据总线”的连接状态。每一页右上角都有“帮助”，打开这一页的说明。
