## 在车间终端开工

左栏“车间执行”打开车间终端（操作工）。

1. 先选你的工位。圆点颜色就是设备此刻的状态。
2. 看“派到本工位的工序”，点“开工”。
3. 设备停机，处理完点“处理完毕，复位”。

只有派了工的设备才有“开工”按钮，要先由计划员下达工单。点了开工零件没动？上一道工序还没把零件送来，或者上一道还没人开工。

## 车间为什么停

| 看到什么 | 原因 | 怎么办 |
| --- | --- | --- |
| 红色、停机 | 故障。教学模式下设备会按失效率随机坏（老师可以关） | 维修单做完、验收后复位；见“设备维护” |
| 🔒 挂牌上锁 | 正在整改隐患、保养或维修 | 做完由另一个人验收解锁；复位没有用 |
| 👤 这一班没人能开 | 排班里这台设备这一班没人（车间“要有人”打开时） | 到“人员 → 排班”换人，或看指挥台的“排班缺口” |
| 学徒带着开 | 只有学徒在岗 | 速度只有六成，交期会受影响 |
| 灰色、等料 | 缺料或来料不合格 | 看“采购与来料” |

每一种都会在厂情中枢变成异常，并能推演怎么处理。

## 统一数据总线和虚拟 PLC

每台设备的状态、事件、测量值都是总线上的一条消息，主题形如 `wq/gearbox/machining/设备编号/status`。
[统一数据总线](/bus) 页能看到实时的消息流。压装工位和分拣线由 [虚拟 PLC](/plc) 控制，可以下载自己写的程序。
