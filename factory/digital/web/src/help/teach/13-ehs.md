# 安全环保

> 一条隐患不是孤立的一张单子：它可能让一台设备停下来，进而影响工单、订单和客户。重大隐患先停机挂牌整改，整改完由另一个人验收解锁。

## 这一页有什么

左栏“保障 → 安全环保”（安全员常用）。上方五个数：开着的隐患（重大、逾期各几条）、整改按期率、挂牌上锁的设备、培训 30 天内到期、未遂（近 30 天）。

| 标签 | 做什么 |
| --- | --- |
| 隐患 | “随手拍”：选设备或区域、种类、等级，写一句话，拍照，提交；下面有危险源清单 |
| 作业许可 | 动火、高处、受限空间、挂牌上锁；申请时自动核对作业人的培训是否有效 |
| 事故与未遂 | 谁都能报；详情只有厂长和老师看得到 |
| 培训与资质 | 每人每类培训一格：红已过期，黄 30 天内到期 |
| 化学品与废弃物 | 切削液、淬火油、润滑油的存量；危险废物暂存和处置 |

整改工单经桥接进 ERPNext。挂牌上锁批准后，车间里这台设备真的停下。

## 隐患怎么走

待指派 → 整改中（安全员指派整改人）→ 待验收（整改人点“整改完成”）→ 已关闭（安全员验收）。

- 重大隐患 1 天内整改，一般隐患 7 天；
- 整改人不能验收自己的整改；
- 挂着锁的隐患，验收时同时解锁。

## 谁做什么

| 角色 | 能做 |
| --- | --- |
| 所有角色 | 随手拍隐患、报告未遂 |
| 安全员 | 指派整改、验收、批准作业许可、登记培训、危废处置；验收解锁、安排培训 |
| 厂长 | 同安全员；批准停机挂牌整改、整改工单（花钱） |

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| E1 重大隐患未关闭 | 有重大隐患开着（严重） |
| E2 隐患整改逾期 | 过了整改期限 |
| E3 作业许可缺资质 | 作业人的培训不在有效期内（严重） |
| E4 安全培训到期 | 30 天内到期或已过期 |
| E5 挂牌上锁期间设备在运转 | 有人没走许可就把锁拆了（严重） |
| E6 化学品存量异常 | 低于安全库存或超过现场限额 |
| E7 危险废物暂存超期 | 危险废物暂存超过 90 天 |

重大隐患的因果链连到设备 → 排在它上面的工序 → 工单 → 订单，和停机一样。

## 处理方案（重大隐患）

| 方案 | 做什么 |
| --- | --- |
| A 不处理（对照） | 带着重大隐患继续生产：安全规定不允许，校验不通过，只用来对比 |
| B 立即停机挂牌整改 | 现在就停，整改按标准工时，验收后解锁 |
| C 限时整改 | 先加临时防护、降速、专人看守，晚些再停 |
| D 停机整改 + 改派 / 加班 | 有同类设备可以改派，或按班次可以加班时才出现 |

推荐先排除校验不通过的，再比交期；交期一样时立即停机优先，最后比钱。

## 教学模式

- 模拟器隔一阵在设备附近来一条一般隐患，偶尔来一起未遂；按车间运转消耗切削液、产生钢屑。
- 挂着锁的整改，持证的维修工会在一段时间后做完，等你验收。
- **实验 17** 安全隐患的识别、评估与停机决策：“实验与任务 → 实验 17”。老师在实验页注入重大隐患，也可以“模拟违规拆锁”。
- **两周情景**第 5 幕：赶工时磨床防护门联锁被短接。
