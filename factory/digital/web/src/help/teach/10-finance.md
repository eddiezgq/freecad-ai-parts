## 这一页有什么

左栏“从订单到回款 → 经营与财务”（厂长常用）。上方五个数：毛利率（做完的订单）、应收与逾期、应收周转天数、现金、本月预算已用。

| 标签 | 做什么 |
| --- | --- |
| 经营目标 | 七个目标的指标树：准时交付、毛利率、一次合格率、OEE、空转电量占比、重大隐患、应收周转天数；绿达标、黄差一点、红偏离 |
| 订单毛利 | 每张做完的订单：收入 − 料 − 工 − 电 − 废品 − 急单加班外协加急 − 保修；点“分解”看每一项的来源 |
| 应收应付 | 应收账龄、客户信用、未来 8 周现金流预测、应付 |
| 预算 | 七个成本中心按月对预算，竖线是月度进度 |
| 生产与成本 | 各设备 OEE、本月交付、工单成本分解（原来是一个独立页面） |

发票、收付款以 ERPNext 为准。教学模式：订单的工单全部完工就自动开票。生产模式只起草提议，由会计确认。

## 谁做什么

| 角色 | 能做 |
| --- | --- |
| 所有角色 | 看 |
| 厂长 | 改经营目标、预算；批准催款、信用冻结、调预算、付款（催款销售也能批） |
| 计划员、销售、厂长 | 发起催款、信用冻结、付款、调整预算 |

## 厂情中枢会报什么

| 规则 | 什么时候报 |
| --- | --- |
| F1 工单成本差异超标 | 工单实际成本偏离标准太多 |
| F2 应收逾期 | 发票过了到期日还没付 |
| F3 客户信用超限 | 应收 + 在做没开票的订单 > 信用额度 |
| F4 现金不够付到期的账 | 未来两周现金预测降到 0 以下 |
| F5 订单毛利低于目标 | 做完的订单毛利率比目标低 5 个百分点以上 |
| F6 预算超支 | 某成本中心本月实际 > 预算 × 进度 × 1.1 |
| F7 经营指标偏离目标 | 某指标现在是红的，并且近 7 天至少 5 天是红的 |

**钱的因果链**：应收逾期、毛利低的因果链是 发票 → 订单 → 记到订单上的动作费用 → 动作来自哪个异常，跨领域一路追回源头。

## 处理方案

| 异常 | 方案 |
| --- | --- |
| F2 应收逾期 | 不处理 / 发催款函 / 信用冻结；每个写预计几天收到钱、现金最低在哪一周 |
| F3 信用超限 | 不处理 / 信用冻结 / 临时提额 |
| F4 现金不够 | 不处理 / 推迟付款 / 加快催收 |
| F6 预算超支 | 不处理 / 调整预算 |
| F5、F7 | 给分解和去处，不推演 |

## 教学模式

- **账期日**：1 天 = 真实 2 分钟，30 天账期约 1 小时。
- 财务模拟器（“应收应付”最下面，老师开关）：客户按各自的习惯晚付，催款后通常 3 天内付；老师可以注入“某客户一笔发票不付”。
- 这里的毛利是经营口径（工时、电、废品、动作费用、保修都算），和 ERPNext 的会计口径不一样。
- **实验 22** 经营：订单毛利、应收与现金：“实验与任务 → 实验 22”。
- **两周情景**第 8 幕：交付开票、应收逾期；复盘看这张订单的毛利。
