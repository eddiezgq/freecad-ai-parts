# 产品与物料

## 物料清单（一台份，示例）

| 部分 | 物料 | 说明 |
|---|---|---|
| 定子 | 硅钢冲片（60 / 80 机座）、漆包线、绝缘套件、绝缘漆 | 冲片外协，漆包线和绝缘漆按 kg 领 |
| 转子 | 钕铁硼磁钢一套（10 块，未充磁到货）、转子铁芯与轴、磁钢胶 | 磁钢在厂里贴好后再充磁 |
| 总装 | 轴承 ×2、失电制动器（伺服电机才有）、机壳与端盖、动力线与抱闸线、螺钉、包装盒 | |

外购件都写通用名称 +“型号待确认”，单价是示例值。在 [设计与工艺](/work/engineer) 能看到四张物料清单和两条工艺路线。

## 工艺路线

| 路线 | 工序（分钟，示例） |
|---|---|
| 伺服电机 | 来料检验 5 → 铁芯叠压 6 → 绕线 25 → 嵌线整形 15 → 浸漆烘干 180 → 定子测试 8 → 磁钢粘贴 20 → 充磁 3 → 动平衡 8 → 电机总装 25 → 抱闸测试 6 → 电机终检 12 → 包装 4 |
| AGV 电机 | 同上，绕线、嵌线时间长一些，没有抱闸测试 |

浸漆烘干最长：一炉 24 个定子一起烘。

## 测量项

ERPNext 里一种物料一张检验模板，所以一台电机的全部测量都记在“电机终检”这道工序上，名称里写着是哪台设备测的：

| 测量 | 在哪测 | 规格（示例） |
|---|---|---|
| 三相电阻不平衡 | 定子测试台 | ≤ 1.5 % |
| 匝间冲击波形面积差 | 定子测试台 | ≤ 5 % |
| 耐压漏电流（1500 V，1 s） | 定子测试台 | ≤ 1.0 mA |
| 转子剩余不平衡量 | 动平衡机 | ≤ 20 g·mm |
| 抱闸静态保持力矩 | 抱闸测试台 | 按型号 |
| 反电势常数、三相不平衡、谐波畸变、齿槽转矩 | 电机终检台 | 见下一章 |
| 空载电流 | 电机终检台 | 按型号 |

## 实验 42：一台伺服电机从订单到交付

左侧“实验与任务 → 实验 42”：自己接 1 台 WQ-SM200，算料（物料清单只有一层，只开一张工单），看工艺路线找瓶颈——浸漆烘干单件最长，但一炉 24 个摊下来很短，真正卡产能的是一次只能装一台的工序；判这台电机出厂检验合不合格，入库开票，看这张单的标准成本与实际成本，最后复盘。平台自动评 60 分，实验报告 40 分。
