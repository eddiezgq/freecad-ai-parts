# 这座厂：问渠数字工业园 · 电机厂

> 工业园的第六座厂：做协作机器人关节和 AGV 驱动轮用的**永磁同步伺服电机**。
> 四种电机都卖给工业园的机器人厂——它原来向“示例·伺服电机商”买，第 131 轮起改向这里买。

## 工业园的链条

```
芯片厂（WQ-ENCIF）→ 电路板厂（驱动板 B 版、读头板）→ 传感器厂（关节编码器）→ 机器人厂（关节模组、整机） ← 电机厂（伺服电机、AGV 电机）
```

机器人厂的物料 MTR-SV-100/200/400、MTR-AGV-750 向这里下单（对方物料号 WQ-SM100/200/400、WQ-AM750）。
采购单送过去成为这里的销售订单，这里做完发货、机器人厂到货检验入库——和其他几座厂之间买卖是同一套办法。

## 车间

三条线、14 台设备（布局、尺寸、费率都是示例值）：

- **定子线**：来料检验台、铁芯叠压机、绕线机 ×2（wd-1、wd-2）、嵌线整形台、浸漆烘箱、定子测试台；
- **转子线**：磁钢粘贴台、充磁机、动平衡机；
- **总装线**：电机总装台、抱闸测试台、电机终检台（测功台）、包装台；
- 原材料库、成品库和两台物流小车。
