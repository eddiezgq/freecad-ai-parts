# 定子与转子

## 定子：冲片 → 线圈 → 浸漆

1. **铁芯叠压**：一片片硅钢冲片叠起来压紧、扣片，叠高要对。
2. **绕线**：针式绕线机把漆包线绕进 12 个槽。**张力**要稳——张力忽大忽小，线被拉细、匝数漂，三相电阻就不一样，匝间也容易刮破漆。
3. **嵌线整形**：插槽楔、绑扎、整形端部。
4. **浸漆烘干**：真空浸绝缘漆，再进烘箱烘透。**炉温不够，漆没固化透**，绝缘就差，耐压时漏电流大。
5. **定子测试**：测三相电阻（看是否平衡）、匝间冲击（两个线圈的冲击波形比面积差）、耐压（加 1500 V 看漏电流）。

两台绕线机 wd-1、wd-2 绕的定子都记着“绕线机”（测量记录的分层字段），在 [质量](/work/quality) 和 [电机终检波形](/motor-wave) 都能按绕线机分开看。

## 转子：贴磁钢 → 充磁 → 动平衡

1. **磁钢粘贴**：10 块钕铁硼磁钢靠定位工装贴到转子铁芯上。**工装磨损，磁钢就贴歪**——位置差零点几度，齿槽转矩就变大。
2. **充磁**：电容放电，一下子把磁钢充饱。**电容老化、充磁电压不够**，磁钢充不饱，反电势常数整体低，同样出力要更大电流。
3. **动平衡**：测转子不平衡量，去重或加重。

磁钢先贴后充：没充磁的磁钢不吸铁件，好贴、安全。
