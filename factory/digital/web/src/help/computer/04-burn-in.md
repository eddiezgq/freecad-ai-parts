# 整机老化与老化曲线

老化房里每台整机跑**满载压力测试**：每小时满载 50 分钟、空闲 10 分钟，每分钟记一次 CPU 温度、风扇转速、整机功耗。
**CPU 满载温度、老化平均功耗这两个数是从曲线算出来的**，所以曲线和测量记录一定对得上。

## “整机老化曲线”页怎么看

打开 [整机老化曲线](/burn-in)，左边是最近测完的整机，可以按型号、按点胶机筛；点一台看它的三条曲线（浅色底是满载段）：

| 看哪里 | 正常 | 不正常说明什么 |
|---|---|---|
| CPU 温度 | 满载段很快到一个平台，平台在上限（红虚线）下面有余量 | 平台高、升温快 → 热量出不去：先查导热硅脂那一层（点胶量） |
| 风扇转速 | 满载时升到七八成，空闲时降下来 | 一上来就转到顶、温度还是高 → 不是风扇的问题，是热阻大 |
| 整机功耗 | 满载、空闲两档，平稳 | 抖动大 → 查电源 |
| 总热阻 | 页面上方给出每颗 CPU 的总热阻和其中硅脂层那一份 | 硅脂层比同型号的大一截 → 点胶量少 |

左边列表上方给出**每台点胶机点过的整机，满载温度离上限的平均余量**——只有一台的余量小，问题就在那台点胶机。

## 为什么“老化时间加长”“风扇调高”都不对症

硅脂少是**导热路径**的问题：老化再久，热阻也不会变小；风扇调高能把温度压下去一点，但噪声变大、到了用户手里环境一热照样过热——这是“掩盖”，不是“纠正”。
对症的是清洗点胶机针头、称重校点胶量，已经装好的整机拆开补涂硅脂复测。
