# 这座厂：问渠数字工业园 · 计算机厂

> 工业园的第八座厂：做**台式机、14 英寸笔记本、2U 双路服务器、42U 整机柜和工控机**。
> 主板、内存条、机箱、笔记本铝壳自己做；CPU、内存颗粒、硬盘、屏幕、电池、电源外购——CPU 和内存颗粒要晶圆厂才能做，工业园的芯片封测厂做不了。

## 工业园的链条

```
计算机厂（工控机 WQ-IPC）→ 机器人厂（装进机器人控制柜）
```

机器人厂的物料 IPC 向这里下单（对方物料号 WQ-IPC，第 166 轮起从控制柜里拆出来单独买）。整机柜 WQ-RACK42 卖给算力中心、数据中心（示例客户）。

## 车间

五条线、29 台设备（布局、尺寸、费率都是示例值）：

- **主板与内存条（SMT）**：来料检验、锡膏印刷、锡膏检测、贴片 ×2、回流焊、光学检测、**X 光检测**（BGA 焊点空洞）、选择焊、在线测试、BIOS 烧录、**内存测试机**（8 个测试座）；
- **结构件**：激光切割、数控折弯、压铆、喷粉线；加工中心 ×2、阳极氧化线（笔记本壳）；
- **整机**：导热硅脂点胶机 ×2（dp-1、dp-2）、台式 / 笔记本 / 服务器三个装配工位、开机自检与系统灌装、**老化房**、整机功能测试；
- **整机柜联调台**、包装台、原材料库、成品库和两台物流小车。
