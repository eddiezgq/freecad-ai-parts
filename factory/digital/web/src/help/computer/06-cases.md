# 设计案例：主板供电、服务器散热、算力中心

> 左栏“设计案例”：计算机厂三个从任务书做到车间的案例。A 的主板在台式机里，B 的服务器装进 C 的整机柜。数字都由程序算出，是示例设计，没有实物试制。

| 案例 | 做什么 | 值得看的地方 |
|---|---|---|
| A 台式机主板的 CPU 核心供电 | 12 V 降到约 1.1 V、最大 140 A：6 相降压、负载线、输出电容、电压公差叠加 | ngspice 开关仿真和公式对上（纹波、导通损耗）；电容只数扫一遍，少于 5 只就冲出负载线；**公差叠加算出的电压散布写进了工厂数据**，上电测试的合格率是设计决定的 |
| B 2U 服务器的 CPU 散热 | 两颗 270 W CPU、进风 35 ℃、坏一只风扇也不过 85 ℃ | 鳍片不是越多越好（风扇和风道一起定风量）；有限元算铜底板的扩散热阻，和公式差 0.1 ℃；设计热阻放进[整机老化曲线](/burn-in)的同一个模型 |
| C 20 柜算力中心 | 20 台整机柜：供配电、制冷、布置、年 PUE、可用性 | 全年 8760 小时逐时仿真：背门换热器 + 温水 + 自然冷却年 PUE 约 1.17，房间空调约 1.38；N+1 冗余的可用性公式和蒙特卡洛对上；整柜联调台是交付瓶颈 |

每个案例走八步：任务书、方案、计算、仿真、三维与图纸、工艺、制造、总结；每一步上面有“打开软件”的按钮（电路分析、仿真与分析、整机老化曲线、能源与环境……），可以拿案例里的数自己再算一遍。

## 和工厂的关系

- 案例 A 之后，主板“核心供电电压偏差”的散布按设计取 2.2 mV（原来按经验 3 mV）。
- 案例 B 的散热器热阻和老化曲线模型里服务器的热阻相差 4 %（模型略保守）。
- 案例 C 第 7 步在整机柜联调台上联调 20 柜，量整柜功率、换热器温差、链路误码。

