# 主板、内存条、结构件与整机柜

## 主板：一条 SMT 线

和电路板厂同一套做法（锡膏印刷 → 锡膏检测 → 贴片 → 回流焊 → 光学检测），多了一道 **X 光检测**：CPU 插座、芯片组、内存颗粒都是 BGA，焊点在芯片下面，光学看不到，只能用 X 光看焊点里的**空洞**。
主板在在线测试工位记三项：锡膏厚度、BGA 最大空洞率、上电后的 CPU 核心供电电压。

## 内存条：同一条 SMT 线 + 内存测试机

贴好的内存条上内存测试机做读写测试，量**时序余量**（信号离出错还有多远，ps）。测试机有 8 个测试座，内存条按顺序轮流插——记下每条在哪个座上测，是追“测试座接触不良”这类假不良的关键。

## 结构件

- **台式与服务器机箱**：激光切割 → 数控折弯 → 压铆螺母柱 → 喷粉。量折弯角度、安装孔位置、涂层厚度——孔位偏了，主板、电源装不上。
- **笔记本铝壳**：加工中心铣出 A 面、C 面 → 阳极氧化。量平面度和阳极膜厚。

## 整机

涂导热硅脂（点胶机，记下是 dp-1 还是 dp-2）→ 装配 → 开机自检与系统灌装 → 老化（台式、笔记本 4 小时，服务器 12 小时）→ 整机功能测试。见 [整机老化曲线](/burn-in)。

## 整机柜（算力中心 / 数据中心交付）

16 台服务器上架、接电源与网络 → 整柜满载联调：量整柜功率、背门换热器进出风温差、交换机链路误码 → 整柜装运输木箱出货。
算力中心本身怎么设计（机柜数、供电、制冷、PUE）放在计算机厂的设计案例里。
