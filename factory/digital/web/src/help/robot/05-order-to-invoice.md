# 怎么接单：从订单到开票

> 接单、算料、提议确认写进 ERPNext、按层下达、车间完工、测试标定、入库，最后自动开销售发票。

## 一张订单走过的路

和减速器厂一样，AI 和系统只起草，人确认才写进 ERPNext；不一样的是一张单有一串工单，要按物料清单从下往上做。

## 一步一步

1. **接单、算料**（计划员）：在“订单与计划”里选产品、数量、交期，点“算料”，看要下哪些工单、请购什么；
2. **提交、确认**：生成一条提议，确认后桥接把销售订单、全部工单、请购单写进 ERPNext；
3. **按层下达**（计划员）：先下达自制件（壳体、空心轴、臂管、底座），等它们**完工入库**，再下达关节模组，最后整机；
4. **开工**（操作工）：车间终端里对派来的工序点“开工”；
5. **测试、标定**：关节测试台、整机标定工位、AGV 调试场地出测量值，进质量页；检验单到了作业卡才能提交；
6. **完工入库**：最后一道工序做完，按合格数入库；
7. **开票**：订单的工单全部完成，系统自动在 ERPNext 里开销售发票（教学版自动确认），金额 = 售价 × 数量。

## 和减速器厂的区别

| | 减速器厂（教学版） | 机器人厂 |
|---|---|---|
| 一张订单下几张工单 | 一张（输出轴，教学只做这一件） | 整机所有自制件、部件，加整机本身 |
| 测量数据 | 三坐标量输出轴 | 三坐标、关节测试台、整机标定工位、AGV 调试场地 |
| 采购到货 | 供应链领域：下采购单、来料检验、收货 | 这一期没有：用期初库存，请购单只是记录 |
| 开票之后 | 经营与财务：收款、催款、应收账龄 | 这一期只到开票 |
