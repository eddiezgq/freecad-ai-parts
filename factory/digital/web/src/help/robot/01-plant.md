# 这座厂：问渠数字工业园 · 机器人厂

> 工业园的第二座厂：造六轴协作机器人、搬运 AGV 和三种关节模组；减速器厂造的 WQR-105 是这里的外购件。

## 造什么

| 产品 | 编号 | 示例售价 | 怎么来的 |
|---|---|---|---|
| 六轴协作机器人（负载 5 kg 一类） | WQ-CR5 | $18,000 | 三种关节模组 + 大臂、小臂、底座 + 外购的控制柜 |
| 搬运 AGV（载重 300 kg 一类） | WQ-AGV300 | $9,500 | 车架 + 两个驱动单元（每个里有一台减速器厂的 WQR-105）+ 电池、激光雷达 |
| 关节模组 大 / 中 / 小 | WQJ-L / WQJ-M / WQJ-S | $1,800 / $1,300 / $900 | 壳体、空心轴自己做，谐波减速器、伺服电机、编码器外购 |

售价、工时、尺寸都是**示例值**。外购件的型号从零件库选（谐波减速器 CSF-32/25/17、轴承 6010/6007/6004、激光雷达 TiM781）；
库里没有的（伺服电机、驱动板、控制柜、电池）标“型号待确认”，不编参数。

|---|---|---|
| 带锯床 | 1 台 | 下料：铝棒、40Cr 棒料、铝管 |
| 数控车床 | 2 台 | 关节壳体、空心轴的粗车、精车 |
| 立式加工中心 | 2 台 | 臂管、底座、壳体的铣削和钻孔 |

| 三坐标 | 1 台 | 零件检验 |
| 关节装配工位 | 2 个 | 装关节模组 |
| 关节测试台 | 1 台 | 背隙、空载摩擦力矩、编码器零位标定 |
| 整机装配单元 | 1 个 | 整机装配、包装 |
| 整机标定工位 | 1 个 | 几何参数标定、出厂检验 |
| 负载跑合台 | 1 台 | 带载跑合 |

## 这一期能用什么

订单到开票的主线、3D 车间、质量（含关节测试数据）、成本、厂情中枢的生产类异常、帮助。
减速器厂的七个领域（客户与服务、安全环保、设备维护、人员、供应链、能源、经营与财务）、实验 15–23、两周情景这一期只在减速器厂。
