# 采购到货与减速器厂供货

> 缺料 → 请购 → 采购单 → 供应商发货 → 到货 → 来料检验 → 入库。WQR-105 的采购单送到问渠减速器厂，在那边成为一张销售订单，做完发货回来。

## 外购件怎么到货

机器人厂的“采购与来料”和减速器厂用的是同一套：

1. 接单算料，缺的外购件、原材料写成**请购单**；
2. 请购单 3 分钟没人转，采购员（教学模拟器）按默认供应商转成**采购单**，写进 ERPNext；
3. 供应商发货（在途）。教学模式里供应商的 1 天 = 真实 2 分钟，谐波减速器提前期 20 天 ≈ 40 分钟；
4. 到货后做**来料检验**：谐波减速器测背隙、伺服电机测空载电流和绝缘电阻、铝棒查材质证明和硬度、WQR-105 查噪声和渗漏；
5. 合格的收货入库（ERPNext 收货单 + 来料检验单），批号记下来；不合格的退货或让步接收。

供应商的准时率、合格率、提前期、备选供应商都是**示例值**，写在机器人厂的工厂清单里。

## WQR-105：两座厂真正连起来

WQR-105 的供应商是问渠减速器厂——工业园里的另一座厂。它的采购单不会停在纸上：

1. 机器人厂的采购单进 ERPNext 后，平台把它**送到减速器厂**（教学模式），那边多一张“工业园订单”；
2. 减速器厂的计划员在“订单与计划”里**接单**：算料、订单和工单写进减速器厂的 ERPNext、下达车间。
   老师可以打开“自动接单”（缺省打开）：3 分钟没人接，平台代接、下达、开工；
3. 减速器厂这张订单的工单都做完，就**发货**：批号、每台的出厂编号传回机器人厂；
4. 机器人厂这一批变成“在途”，运输 1 天（≈ 2 分钟）后到货，照常来料检验、入库。

减速器厂连不上，或者不接这种物料时，这张采购单按普通外部供应商处理（提前期 10 天，示例），页面写明原因。
两座厂之间只传“订单”和“发货”两种消息，对方的库存、成本、客户资料都看不到。

## 批次一路追到供应商

装关节时，谐波减速器按到货批次**先进先出**用掉：质量页的“按减速器批次分层”和实验 25 里看到的批号，就是来料检验时的批号。
在“采购与来料 → 批次”里输批号，能查到这批用在了哪些关节上；反过来输关节编号，查到它用的哪一批、哪家供应商、哪张采购单。
实验 25 的措施“隔离问题批次”会把在用的那一批判不合格、退回供应商，供应商补发新的一批。

## 两厂互发订单：谁做什么

| 步骤 | 机器人厂 | 问渠减速器厂 |
|---|---|---|
| 下单 | 请购 → 采购单（ERPNext） → 送到减速器厂 | 多一张“工业园订单”（待接单） |
| 接单 | — | 计划员接单或平台自动接单：算料、订单和工单进 ERPNext、下达 |
| 生产 | 等货（采购单“已送到兄弟厂，生产中”） | 车间做 WQR-105 订单的工单 |
| 发货 | 收到批号和出厂编号，这一批“在途” | 工单都做完 → 发货回传；订单照常开票 |
| 收货 | 到货 → 来料检验 → 收货入库 | — |
