## 接单到开票

和其他厂一样：在 [订单与计划](/work/planner) 接一张 WQ-ENC17 或 WQ-TS 的订单 → 算料（缺的自动请购；读头板向电路板厂下单）→ 工单进 ERPNext →
车间按工序做 → 终检记测量值 → 入库 → 发货开票。

## 卖给机器人厂

机器人厂的关节模组 WQJ-L / M / S 每台用一个编码器。机器人厂把编码器的安全库存设得和期初一样，用一个就补一个，
所以它一开工，这边就会收到采购单——在 [订单与计划](/work/planner) 的工业园订单里能看到。
