# 这座厂：问渠数字工业园 · 传感器厂

> 工业园的第五座厂：做协作机器人每个关节里都有的两种传感器——测角度的**绝对值编码器**、测力矩的**关节扭矩传感器**。
> 编码器卖给工业园的机器人厂，读头板向工业园的电路板厂买。

## 工业园的链条

```
芯片厂（WQ-ENCIF 编码器接口芯片）→ 电路板厂（驱动板 B 版、编码器读头板 ENC-RD）→ 传感器厂（关节编码器 WQ-ENC17）→ 机器人厂（关节模组、整机）
```

机器人厂的物料“关节绝对值编码器 ENC-ABS”向这里下单（对方物料号 WQ-ENC17）；这里的读头板 ENC-RD 向电路板厂下单。
采购单送过去成为对方的销售订单，对方做完发货、这边到货检验入库——和机器人厂向减速器厂、电路板厂买东西是同一套办法。

## 造什么

| 产品 | 编号 | 示例售价 | 主要工序 |
|---|---|---|---|
| 关节绝对值编码器（光电、17 位单圈） | WQ-ENC17 | $120 | 码盘清洗 → 粘接对心 → 读头装调 → 精度标定 → 温度循环 → 终检 |
| 关节扭矩传感器（应变片全桥，±200 N·m） | WQ-TS | $320 | 应变片粘贴 → 胶固化 → 组桥焊线 → 温度补偿 → 砝码标定 → 终检 |

## 车间

两条线、15 台设备（布局、尺寸、费率都是示例值）：

- **编码器线（洁净间）**：来料检验台、码盘清洗台、码盘粘接对心机 ×2（cb-1、cb-2）、读头装调台、编码器标定台、温度循环箱、编码器终检台；
- **扭矩传感器线**：应变片粘贴台、固化炉、组桥焊线台、温度补偿箱、砝码标定台、扭矩终检台；
- 共用的包装台、原材料库、成品库和两台物流小车。
