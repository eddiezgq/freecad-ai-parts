# 扭矩传感器线

> 关节扭矩传感器是一个弹性体：受力矩时轻微变形，贴在上面的 4 片应变片组成全桥，把变形变成毫伏级的电压。
> 协作机器人靠它做碰撞检测和拖动示教。

## 工序

| 工序 | 做什么 | 要点 |
|---|---|---|
| 应变片粘贴 | 弹性体表面打磨清洁，显微镜下对位贴 4 片，压块加压 | 位置、方向贴准；胶层薄而均匀 |
| 胶固化 | 固化炉按曲线升温保温 | **温度要够**：没固化透的胶会慢慢“爬”，读数随时间漂 |
| 组桥焊线 | 4 片连成全桥，焊到线缆 | 桥路电阻复测 |
| 温度补偿 | 温度箱里测零点随温度的漂移，配补偿电阻 | — |
| 砝码标定 | 杠杆加砝码，加载、卸载各 5 级 | 算灵敏度、非线性、滞后 |
| 终检 | 复测零点、满量程保持 30 min 看蠕变 | 按规格判合格 |

## 终检记什么（都按满量程 FS 的百分数）

| 特性 | 名义 | 上限（示例） |
|---|---|---|
| 非线性 | 0.10 % | 0.30 % |
| 滞后（加载和卸载读数差） | 0.08 % | 0.25 % |
| 零点输出 | 0 | ±0.5 % |
| 蠕变（满量程保持 30 min） | 0.03 % | 0.10 % |
| 零点温漂（每 10 K） | 0.05 % | 0.15 % |

## 蠕变、滞后、温漂一起变大

三项一起变大，多半不是应变片坏了，而是**胶没固化透**——胶层还软，受力后慢慢变形。去查固化炉的炉温曲线，校温控；没固化透的补固化。
