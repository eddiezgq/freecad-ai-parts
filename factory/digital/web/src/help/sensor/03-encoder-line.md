# 编码器线与误差曲线

> 编码器好不好，看的是“转到哪个角度、读数差多少”。终检时把编码器和更准的基准编码器同轴连起来转一圈，记下每个角度的误差，就是整圈误差曲线。

## 工序

| 工序 | 做什么 | 做不好会怎样 |
|---|---|---|
| 码盘清洗 | 超声清洗、风淋，洁净间里拿边缘 | 码盘上的污点挡光，那个角度信号变弱 |
| 粘接对心 | 码盘粘到轴套上，显微相机看着把码道中心对到转轴上，紫外灯固化 | 偏心 1 µm，整圈误差就多约 16″ 的一次谐波 |
| 读头装调 | 用塞规调读头到码盘的间隙，看正余弦信号的幅值 | 间隙偏大，信号幅值低、细分误差大 |
| 精度标定 | 对照基准编码器测整圈误差，写补偿表 | 补偿表能把可重复的误差减小，但偏心本身还在 |
| 温度循环 | −20 ~ 85 ℃ 循环几次，让胶和机械应力稳定 | — |
| 终检 | 复测整圈误差曲线、信号幅值 | 按规格判合格 |

## 终检记什么

| 特性 | 名义 | 规格（示例） |
|---|---|---|
| 精度（整圈误差峰峰值） | 约 50″ | ≤ 100″ |
| 一次谐波（偏心） | 约 12″ | ≤ 30″ |
| 细分误差 | 约 8″ | ≤ 20″ |
| 信号幅值（平均） | 100 % | 80 ~ 120 % |
| 信号幅值（整圈最低） | 约 95 % | ≥ 70 % |

17 位单圈 = 一圈 131 072 个数，一个数约 9.9″；精度 100″ 约等于 10 个数。

## 看曲线找原因

打开 [编码器误差曲线](/enc-curve)：

| 曲线上看到的 | 说明 | 去查 |
|---|---|---|
| 每圈一个大起伏，谐波分解里 1 次特别高 | 码盘偏心 | 粘接对心机——按 cb-1 / cb-2 分开看，只有一台高就是那台的夹具 |
| 幅值整体低、细分误差大 | 读头间隙偏大 | 读头装调台的间隙塞规 |
| 某个角度一个尖峰，同一角度幅值掉坑 | 码盘上有污点 | 洁净间（压差、粒子计数、过滤器）、码盘清洗 |

**一个常见的坑**：偏心大了，重做补偿表能把终检的整圈误差“补平”——可偏心还在，装到关节里换一种安装状态、温度一变，误差就回来了。
要找的是为什么偏心，而不是把它藏起来。
