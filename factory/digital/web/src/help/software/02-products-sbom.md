# 软件物料清单与合规

## 软件物料清单（SBOM）

| 版本 | 用到的组件 |
|---|---|
| 实时操作系统 REL-RTOS | 实时内核与驱动的开源组件包（BSD / Apache）、功能安全认证编译器授权、代码签名 |
| 操作系统 REL-OS | Linux 内核与用户态组件包（GPL / LGPL / MIT）、代码签名 |
| 云平台 REL-CLOUD | Linux 组件包、云原生组件包（Apache-2.0）、代码签名 |
| 数字工厂 REL-MES | 前后端框架与数据库组件包、商业数据库中间件授权、代码签名 |
| 机器人软件 REL-ROBOT | 实时内核组件、机器人中间件与视觉库、安全编译器、代码签名 |

开源组件单价 0，但不是没有成本：每个组件进库前要做**许可证审查**和**漏洞审查**——这就是软件公司的“进货检验”。开源社区这个“供应商”的“合格率”约 97 %：
大约三十个组件里有一个许可证不合适（比如 GPL 组件要链接进闭源程序）或带着没修的高危漏洞，退回去换版本。

## 授权和订阅

授权（实时 OS、操作系统、机器人软件）每台设备一份，在授权服务器上签发；订阅（云平台、数字工厂）先在宿主机上开通，再由监控平台验收 24 小时。
它们在系统里是“不占实物库存的成品”：签发消耗一份授权密钥配额。

## 国内产品还要做的（写在这里，不做申报）

- **等保 2.0**：云平台按第三级做——身份鉴别、访问控制、安全审计、入侵防范、数据备份；每年测评。
- **软件著作权登记**：每个产品、每个大版本登记一次。
- **开源许可证合规**：发布时附上开源组件清单和许可证原文。
- **数据出境**：国内客户的数据留在国内机房。
