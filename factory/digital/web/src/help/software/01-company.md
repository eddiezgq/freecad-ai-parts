# 这家公司：问渠数字工业园 · 软件公司

> 工业园的第九家：做**实时操作系统、服务器 / 桌面操作系统、云平台、数字工厂（工业软件）、机器人软件**。
> 软件没有毛坯和机床，但“生产”照样有一条线——**发布流水线**；所以数字工厂那一套全都用得上，只是换个说法。

## 工厂里 → 软件公司里

| 工厂里 | 软件公司里 |
|---|---|
| 物料清单 BOM | **软件物料清单 SBOM**：用了哪些开源组件和商业组件 |
| 进货检验 | 开源组件进来先查**许可证**（GPL 会不会“传染”）和**已知漏洞**（CVE） |
| 工艺路线 | **发布流水线**：合并与评审 → 编译与单元测试 → 集成测试 → 硬件在环测试 / 长稳压测 → 安全扫描 → 发布门禁 → 签名发布 |
| 工单 | 一次构建（一个版本） |
| 设备 | 构建服务器、测试机群、硬件在环测试台、长稳压测平台、云平台宿主机 |
| 出厂测试 | **发布门禁**：测试通过率、中断延迟、内存增长速率不过就不发 |
| 售后 | 云平台开通后的**服务验收**（24 小时延迟、错误率、可用性）、值班、在线升级 |
