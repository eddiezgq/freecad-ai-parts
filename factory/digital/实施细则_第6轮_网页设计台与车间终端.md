# 问渠数字工厂 · 实施细则 · 第 6 轮：网页设计台与车间终端

2026-10-01 · 承接：第 3 轮（上线）、第 5 轮 P10①（FreeCAD 插入宏）

> 状态：**已确认（2026-10-01）；施工完成、已上线、已验收（见第八节；两项待 Eddie 实测）**

## 一、起因

Eddie 反映：工作台左侧“专业软件”里的 **FreeCAD** 和 **车间终端（MES）** 点了“没反应”。

查明的原因：

1. 这两项**不是独立软件**，只是跳到“设计与工艺”“车间执行”两个页面的快捷方式；如果已经在那个页面上，点了确实什么都不变。
2. “设计与工艺”页面本身**要求在自己电脑上装 FreeCAD**、拿到仓库里的宏、用 VS Code 改参数、再运行发布宏。线上学生没有这些，所以在网页上什么也做不了。
3. “车间终端”的数据来自统一数据总线（`wss://factory.<域名>/mqtt`）和服务器上的仿真程序。总线没连上时，设备列表是空的，看起来也像“没反应”。线上的连接情况本会话访问不到，要在施工第 1 步实测。

## 二、决定（待确认）

| 编号 | 决定 | 理由 |
|---|---|---|
| W1 | **两样都走网页，不要求下载安装**。桌面 FreeCAD 保留为“进阶（选做）” | 学生零安装、手机平板也能用；出问题只需在服务器上修一次。符合“负担在平台，不在老师和学生” |
| W2 | **网页设计台**：“设计与工艺”页加一块“在线设计”。用表单改输出轴参数：各轴段直径与长度、倒角，键槽的所在段、键宽、槽深、槽长。改的同时，页面上实时显示三维模型和校核结果（键槽是否超出轴段、键宽是否符合 GB/T 1095 推荐） | 现有的建模、校核、图纸、G 代码程序都是纯 Python，可以直接搬到服务器上用 |
| W3 | **在线发布**：点“发布新版本”，由服务器生成以下内容，经总线发布 `design.release` 和 `design.gcode`，与桌面宏的效果完全一样（版本号加一、ERPNext 设计版本加一、工单派工带新 G 代码）：<br>① STEP（用 build123d，零件库已在用）；② 零件图 SVG；③ 键槽 G 代码；④ BOM | 复用 `wq_publish.publish()`，只把“出 STEP”这一步从 FreeCAD 换成 build123d |
| W4 | **三维显示**：模型在浏览器里按参数生成（three.js 旋转体加键槽），不等服务器；发布后显示服务器生成的 glTF | 拖动参数即时看到变化 |
| W5 | **进阶：桌面 FreeCAD**。页面上提供“下载 FreeCAD 宏包”（`wq_shaft.py`、`wq_publish.py`、`wq_library.py`，已填好线上地址）和一页图文安装步骤。不再要求 VS Code 和仓库目录 | 想学真 CAD 的学生照样能用；不强制 |
| W6 | **左侧“专业软件”改名、改链接**：“FreeCAD”改成“设计台（CAD/CAM）”，“车间终端（MES）”不变。点击时总是打开对应页，并滚动到在线设计或工位区；与上面“设计与工艺”“车间执行”重复的部分合并，避免两个入口指向同一页又像没反应 | 消除“点了没反应”的感觉 |
| W7 | **车间终端排错与提示**：<br>① 线上实测总线（WebSocket 是否连上、仿真是否在发状态），修好；<br>② 页面加连接状态提示：未连接时显示“正在连接数据总线…/连接失败，点此重试”和原因，不再是空白；<br>③ 没有设备数据时提示“仿真未运行”，并给老师一个“启动仿真”按钮（教学模式） | 网页本来就是 MES，问题在连接和提示 |
| W8 | **合规**：本轮不新增 AI 调用；如在设计台加“AI 帮我检查设计”，走现有 AI 通道（国内 DeepSeek，Claude 只在美国） | 总规矩 |

## 三、规则

1. 在线发布与桌面宏发布**结果格式完全一致**（同一个 `design.release`/`design.gcode` 消息结构），3D 车间、车间终端、ERPNext 无需改动。
2. 发布时记录来源：`tool` 字段写“问渠网页设计台”或“FreeCAD 1.1 + wq_publish.py”。
3. 教学模式下每个学生的发布进自己的教学空间（沿用现有 mode 隔离），不影响生产模式数据。
4. 参数校核不通过时不能发布，页面写明哪一项不合格、按什么标准。

## 七、实施记录

### 第 1 步：车间终端排错（2026-10-01）

- 本会话的网络访问不到 factory 子域名，所以在“数字工厂部署”的最后加一步**线上车间检查**（`factory/deploy/online_check.py`）：在 GitHub 的机器上像浏览器一样连接 `wss://factory.<域名>/mqtt`，收 30 秒消息，按教学/生产模式统计设备数；再经 SSH 读容器状态和仿真日志。结果写成部署记录里的注释，以后每次部署都会自动检查（也是第四节“车间终端可用”的验收手段）。
- 读代码发现的一个原因：**仿真只在教学模式发数据**（`sim` 的 `WQ_MODE` 默认 teach），网页只显示当前模式的消息。老师账号切到“生产模式”时，没有真设备接入，车间终端就是空的，按钮也没有对象。处理办法放进第 2 步的提示里（生产模式下没有设备时写明“生产模式只显示真实设备；要练习请切换到教学模式”）。

- **线上检查结果（部署 7031c43）**：总线连接正常；教学模式 12 台仿真设备都在发状态，但**全部空闲**（仿真 `自动开工 False`，教学情景里还没有派工）。所以线上车间终端的“没反应”是：① 左侧“FreeCAD”“车间终端”只是跳到同一页；② 默认打开的 SAW-01 没有派工，页面上就没有“开工”按钮；③ 切到生产模式时没有真实设备。**总线和仿真本身没有故障。**

### 第 2 步：连接提示与左侧入口（2026-10-01）

- 新增 `BusNotice` 提示条（车间终端页顶部）：连接中 / 连不上（显示原因、“重试”按钮）/ 生产模式没有设备（“切换到教学模式”按钮）/ 教学模式 10 秒内没有设备数据（请管理员检查仿真）。
- 没有派工时，说明为什么没有“开工”按钮，并链接到“订单与计划”。
- 没指定工位时，自动打开有派工或正在运行的设备（不再总是打开空闲的 SAW-01）。
- 左侧“专业软件”的“FreeCAD”改名“设计台（CAD/CAM）”；已在该页时点击会回到页首。
- **与细则的偏差**：W7③ 原定的老师“启动仿真”按钮不做——线上检查证明仿真一直在运行，没有需要启动的情况；改为上面的派工说明和自动选工位。
- 本地完整环境（Postgres + 总线 + 仿真 + 枢纽）用老师账号实测教学、生产两种模式，截图核对通过。

### 第 3 步：服务器端在线发布接口（2026-10-01）

- 新增 `hub/design.py` 和三个接口：`GET /api/design/SH-301/params`（现行参数与校核）、`POST …/check`（校核）、`POST …/publish`（发布）。
- 校核分两级：**不合格**（轴段数、直径不超过棒料 Ø50、长度、倒角、键槽超出轴段等）不能发布；**GB/T 1095 推荐键宽、槽深不同**只提示，不拦（学生可以试不同方案）。
- 发布复用桌面宏的零件图、键槽 G 代码、BOM 程序，STEP 改用 build123d 生成；消息字段与桌面宏完全一致，只有 `tool` 写“问渠网页设计台”、`source` 为 `web-cad`。教学模式任务 3 照常按作者计分。
- 工厂镜像加入 build123d 和它要的系统库，`freecad/` 目录一起打进镜像。
- 测试：新增 `tests/test_design_web.py`（4 项）；完整闭环 `closed_loop.py` 增加“4b 网页设计台在线发布”（读现行参数、超长校核不通过、在线发布带 STEP、ERPNext 设计版本随之加一）。本地完整环境（Postgres、总线、仿真、枢纽、Node-RED 桥接、模拟 ERPNext）闭环全部通过、实验 7 得 100 分。
- **与细则的偏差**：W4 的“发布后显示服务器生成的 glTF”不做——三维一律在浏览器里按参数生成，发布前后看到的是同一个模型，省一次服务器建模。

### 第 4 步：网页设计台页面（2026-10-01）

- “设计与工艺”页顶部新增“在线设计”：轴段表（直径、长度，可加减段，最多 8 段）、两端倒角、平键槽（所在段、b、t、L）；改动 0.3 秒后自动校核，红字为不合格、黄字为 GB/T 1095 提示（“用推荐值”按钮）、绿字显示总长和下料重量；改动说明 + “发布新版本”（校核不通过时不可点）+ “恢复现行版”。
- 右侧三维（`ShaftView.vue`）：three.js 旋转体（含两端倒角）+ 长圆形键槽，按总长自动调整视距，可拖动旋转。
- 本地完整环境用学生账号实测：改第 3 段长度、键槽长、键宽 → 三维即时变化、提示正确 → 发布 rev 4，版本表、零件图、G 代码、AI 改版提醒都出现。

### 第 5 步：桌面 FreeCAD 宏包（2026-10-01）

- 新接口 `GET /api/freecad/pack.zip`：打包 5 个宏和《使用说明.txt》，`wq_publish.py` 里预填工作台地址、本人（匿名）名字、模式和登录凭证（7 天有效）；`wq_library.py` 预填零件库地址。`wq_publish.py` 增加 `token` 配置（环境变量 `WQ_TOKEN`），有凭证时不再走本地登录——线上用问渠账号登录也能从桌面发布。
