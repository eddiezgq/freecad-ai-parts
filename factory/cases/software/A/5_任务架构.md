# 图纸：任务、优先级与共享数据

软件没有三维零件，这一步出的是**任务架构图**和**调度表**（写进 REL-RTOS 的板级配置，构建时生成任务控制块）：

| 优先级 | 任务 | 启动方式 | 周期 / μs | 栈 / 字节 | 用共享缓冲 |
|---|---|---|---|---|---|
| P1 | 电流环（FOC） | ADC 中断 | 50 | 512 | 否（无锁双缓冲） |
| P2 | 速度环 | 电流环每 5 次 | 250 | 768 | 是 |
| P3 | EtherCAT 过程数据 | SYNC0 中断 | 1000 | 2048 | 是 |
| P4 | 位置环与插补 | SYNC0 后 | 1000 | 1536 | 是 |
| P5 | 诊断（编码器、温度、过流） | 系统节拍 | 10000 | 2048 | 是 |
| P6 | 日志与参数服务 | 系统节拍 | 100000 | 4096 | 否 |

- 电流环、速度环之间：**无锁双缓冲**（两份电流指令，速度环写备用的一份，写完原子地换指针）；
- 其余共享：互斥锁 + 优先级天花板（天花板 = 速度环 P2），临界区代码走查限 6 μs；
- 中断里只做最少的事（记时间戳、放信号），算法都在任务里，中断延迟才能压在 8 μs 内。
