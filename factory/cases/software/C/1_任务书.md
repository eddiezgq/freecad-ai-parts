# 设计任务书：20 柜云平台的容量规划

**用在哪**　软件公司向计算机厂买了 20 台整机柜 WQ-RACK42（计算机厂案例 C 的机房，每柜 16 台 WQ-SV2U），建云平台 WQ-Cloud：
16 柜计算（256 台服务器）、4 柜存储（本厂案例 B）。两个可用区，各一半，供电、网络分开。
卖的是订阅 SUB-CLOUD：**一份 = 100 vCPU·月，2,400 美元**（软件公司价目）。

| 项目 | 要求 | 出处 |
|---|---|---|
| 三年订阅预测 | 逻辑斯谛增长，上限 400 份，第 36 个月约 367 份 | 市场预测（示例） |
| 容量 | 第 36 个月的订阅装得下，**每个可用区留一整柜**（坏一柜虚拟机有地方重启） | 运维规程 |
| 高峰物理 CPU | 高峰小时 ≤ 85 %（超分后不能挤爆） | 运维规程 |
| 服务延迟 p99 | ≤ 50 ms（软件公司清单 cl_p99）；其中网关 ≤ 20 ms，一个可用区全断时也满足 | 服务验收 |
| 月可用性 | ≥ 99.9 %（软件公司清单 cl_avail 的日指标 ≥ 99.9 %） | 订阅合同 |
| 回本 | 36 个月内 | 投资要求 |

服务器配置、虚拟机规格分布、请求量、故障率、电价、人工都是示例值。整机柜价格 172,000 美元取计算机厂价目，PUE 1.17 取计算机厂案例 C。
