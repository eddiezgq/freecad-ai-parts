# 仿真：大臂有限元、整机变形与固有频率

## 大臂有限元（数字工厂“仿真与分析”的结构示例“WQ-CR5 大臂”，CalculiX）

大臂 = 6061-T6 铝管 Ø90×3 + 两端法兰（厚 10，线缆孔 Ø50），长 400 mm。J2 端固定，J3 端加伸直、5 kg 时 J3 以外部分的重力（`wqcr5.upper_arm_end_loads`）。

| 量 | 有限元 | 梁理论 |
|---|---|---|
| 最大冯·米塞斯应力 | 5.54 MPa | 5.17 MPa（根部名义） |
| 端部位移 | 0.115 mm | 0.10913 mm |
| 单元 / 网格 | 20080 / 8.0 mm | — |

有限元在法兰与管连接的转角处应力比名义值高（应力集中），但仍然很低；端部位移和梁理论相差不大——**这根管本身很硬**。

## 整机的末端变形（《机器人学》31.2 节）

| 来源 | 末端位移 mm |
|---|---|
| J2 | 1.200 |
| J3 | 0.659 |
| J4 | 0.140 |
| J5 | 0.048 |
| upper_bend | 0.350 |
| upper_tors | 0.014 |
| fore_bend | 0.105 |
| fore_tors | 0.022 |

合计约 **2.43 mm**；关节（谐波减速器扭转）占 81%，臂管只占 19%。
重力变形是有规律的，标定和重力补偿能补掉大部分；重复精度看的是每次回到同一点的散布。

## 固有频率（关节刚度 K₁ + MuJoCo 质量矩阵）

前三阶 11.8 / 14.6 / 38.2 Hz。只算大臂这一根管一端固定，一阶有 447.7 Hz——**整机的低频来自关节，不来自臂管**。
