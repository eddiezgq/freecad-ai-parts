# 三维、DH 参数与物料清单

整机三维（初始位姿 (0, -90, 90, -90, -90, 0)）由 `wqcr5.link_parts()` 生成，与 MuJoCo 模型、零件库 B-ARM-WQCR5 同一份数据。

**名义 DH 参数**（标准 DH；与整机标定 `sim/calib.NOMINAL` 一致）：

| 关节 | a mm | α | d mm | 模组 |
|---|---|---|---|---|
| J1 | 0 | 90° | 150 | WQJ-L |
| J2 | -400 | 0° | 0 | WQJ-L |
| J3 | -360 | 0° | 0 | WQJ-M |
| J4 | 0 | 90° | 120 | WQJ-S |
| J5 | 0 | -90° | 100 | WQJ-S |
| J6 | 0 | 0° | 90 | WQJ-S |

**物料清单**（机器人厂清单，一层）：

| 物料 | 名称 | 用量 |
|---|---|---|
| WQJ-L | 关节模组（大） Joint module L | 2 |
| WQJ-M | 关节模组（中） Joint module M | 1 |
| WQJ-S | 关节模组（小） Joint module S | 3 |
| ARM-UP | 大臂 Upper arm | 1 |
| ARM-FO | 小臂 Forearm | 1 |
| BASE-CR5 | 底座 Robot base | 1 |
| CTRL-CAB | 机器人控制柜（型号待确认） Robot controller cabinet | 1 |
| CABLE-ARM | 臂内线束 Arm cable harness | 1 |
| SCR-M5x16 | 内六角螺钉 M5×16 Socket screw | 24 |

整机 17.4 kg，运动部分 11.895 kg。案例 B 发现 WQJ-L 的实际长度比模型长，模型数据更新后整机质量、惯量要复算。
