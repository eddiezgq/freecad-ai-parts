# 仿真：MuJoCo 跑一遍跑合台的标准动作

带 5 kg 标准负载，从初始位姿经过三个位姿再回来（每段五次多项式 1.2 s，段间停 0.3 s），
MuJoCo 逆动力学（含关节摩擦、转子惯量）算每个关节的力矩。红色虚线是模组的力矩上限。

再把关节力矩换到电机侧（τ_m = τ/(iη) + J_m α i），按电机选型助手的规则逐项核对（电机峰值 / 额定、转速）：

| 关节 | 关节峰值 N·m | 关节均方根 | 电机峰值 / 允许 | 电机均方根 / 额定 | 电机转速 / 允许 r/min | 最紧的一项 |  |
|---|---|---|---|---|---|---|---|
| J1 | 51.2 | 16.2 | 0.73 / 4.46 | 0.23 / 1.27 | 3906 / 4800 | 转速 | ✓ |
| J2 | 88.6 | 53.6 | 1.20 / 4.46 | 0.72 / 1.27 | 1693 / 4800 | 电机连续（均方根）力矩 | ✓ |
| J3 | 45.0 | 39.1 | 0.60 / 2.23 | 0.52 / 0.637 | 1562 / 5600 | 电机连续（均方根）力矩 | ✓ |
| J4 | 8.3 | 5.8 | 0.11 / 1.11 | 0.08 / 0.318 | 391 / 6000 | 电机连续（均方根）力矩 | ✓ |
| J5 | 7.7 | 3.8 | 0.10 / 1.11 | 0.05 / 0.318 | 781 / 6000 | 减速器额定（均方根）力矩 | ✓ |
| J6 | 1.8 | 0.8 | 0.03 / 1.11 | 0.01 / 0.318 | 2344 / 6000 | 转速 | ✓ |

这一段动作不带 1.2 倍的安全系数，所以比第 3 步的需求低；第 3 步的选型留够了余量。
