# 方案：每个关节专门选，还是统一几种

## 只按每个关节自己的需求选

| 关节 | 自己够用的最小模组 | 通用化后 |
|---|---|---|
| J1 | WQJ-M | WQJ-L |
| J2 | WQJ-L | WQJ-L |
| J3 | WQJ-M | WQJ-M |
| J4 | WQJ-S | WQJ-S |
| J5 | WQJ-S | WQJ-S |
| J6 | WQJ-S | WQJ-S |

J1 自己用 WQJ-M 就够（它只转动、不抬重），但和 J2 统一成 WQJ-L：底座和肩部一种模组，备件、装配工装都少一种。腕部三个关节本来就是同一种。

## 改需求会怎样（同一段选型程序）

| 需求 | J1–J6 模组 | 整机质量 | 最紧的连续利用率 |
|---|---|---|---|
| 标准：5 kg、860 mm、标准速度 | L、L、M、S、S、S | 17.4 kg | 0.97 |
| 快速：5 kg、860 mm、快速 | L、L、M、S、S、S | 17.4 kg | 0.96 |
| 长臂：5 kg、1000 mm | L、L、L、S、S、S | 18.7 kg | 0.83 |
| 重载：7 kg、860 mm | L、L、L、S、S、S | 18.4 kg | 0.82 |
| 轻载：3 kg、860 mm | L、L、M、S、S、S | 17.4 kg | 0.76 |

- 快速、长臂、重载都会让模组不够或升级；轻载可以省成本，但会多出一种整机型号。
- **选定标准方案**：J1、J2 用 L，J3 用 M，J4–J6 用 S（与机器人厂清单一致）。
