# 仿真：扭转刚度对整机的影响

谐波减速器不是刚体：CSF-32-100 的扭转刚度分三段 K₁ / K₂ / K₃ = 67,000 / 110,000 / 120,000 N·m/rad（零件库厂商数据）。
用《机器人学》31.2 节的方法，把每个柔性的地方（六个关节、大臂和小臂的弯曲、扭转）在重力下转的小角度乘力臂，叠出末端位移：

| 来源 | 末端位移 |
|---|---|
| J2 | 1.200 mm |
| J3 | 0.659 mm |
| J4 | 0.140 mm |
| J5 | 0.048 mm |
| upper_bend | 0.350 mm |
| upper_tors | 0.014 mm |
| fore_bend | 0.105 mm |
| fore_tors | 0.022 mm |

合计约 **2.43 mm**，其中 **J2 一项占 47%**——大臂铝管弯曲只占 14%。
想让机器人更“硬”，先换刚度更大的减速器，加粗铝管用处不大。

用关节刚度 K₁ 和 MuJoCo 的质量矩阵求固有频率（31.5 节）：一阶 **11.8 Hz**、二阶 14.6 Hz。
位置环带宽要避开这几个频率，否则一动就抖。
