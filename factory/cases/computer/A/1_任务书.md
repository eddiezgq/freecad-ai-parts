# 设计任务书：台式机主板 CPU 核心供电

**用在哪**　计算机厂自制的台式机主板 MB-PC（台式机 WQ-PC1、工控机 WQ-IPC 用同一块板）。CPU 满载约 125 W，核心电压约 1.1 V——
电压低、电流大：**最大 140 A**。ATX 电源只给 12 V，要在主板上 CPU 插座旁边降压，这块电路叫 VRM（电压调节模块）。

| 项目 | 要求 | 出处 |
|---|---|---|
| 输入 | 12 V（ATX 电源 8 针 CPU 供电） | 整机设计 |
| 空载电压（VID） | 1.25 V（CPU 通过串行总线告诉 VRM） | CPU 规格（示例值） |
| 负载线（AVP） | 1.1 mΩ：电流每大 1 A，电压低 1.1 mV | CPU 规格（示例值） |
| 最大电流 / 持续电流 | 140 A / 100 A | CPU 规格（示例值） |
| 负载阶跃 | 30 → 130 A，100 A/μs | CPU 从空闲突然满载 |
| 电压偏离负载线 | ±15 mV（静态公差 + 动态过冲合计） | CPU 规格；工厂上电测试 mb_vcore |
| 效率（100 A） | ≥ 88 % | 整机功耗、散热 |
| 板上位置 | 插座左侧和上方一条，宽不超过 30 mm | 主板布局 |

外购件（智能功率级、多相控制器、电感、聚合物电容）写通用名称和示例参数；输入电容、去耦电容从问渠零件库选。
