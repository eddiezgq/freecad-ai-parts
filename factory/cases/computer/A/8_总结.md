# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 6 相 100 A 效率 | 92.4 % | >= 88 | 任务书 |
| ✓ | 输出电容（ζ ≥ 0.7 所需） | 3.76 mF | >= 3.54 | 第 3 节 |
| ✓ | 140 A 时每颗功率级发热 | 2.25 W | <= 3 | 功率级封装加铜皮散热（示例） |
| ✓ | 预计核心电压 Cpk | 2.3  | >= 1.33 | 常用要求 |
| ✓ | 开关仿真与公式：纹波最大相差 | 3.9 % | <= 5 | 核对公式 |
| ✓ | 开关仿真与公式：导通损耗相差 | 0.2 % | <= 5 | 核对公式 |
| ✓ | 负载阶跃偏离负载线（电容少 20 %） | 0 mV | <= 8.5 | 第 3 步动态允许 |
| ✓ | 工厂数据 mb_vcore 的 σ = 公差叠加结果（向上取 0.1 mV） | 2.2 mV | == 2.2 | 第 3 步 |
| ✓ | 不合格项 | 0  | == 0 | 在线测试 |
| ✓ | 最低 Cpk | 1.34  | >= 1.33 | 常用要求 |

1. **低电压大电流靠多相**：6 相把每相电流降到 23 A 以内，交错把输出纹波电流降到每相的 48 %。
2. **负载线让电容少一半**：AVP 下要的电容由“控制环带宽 + 负载线”决定（ζ 公式），仿真扫电容只数对上了公式。
3. **电压准不准是公差叠加出来的**：最大一项是基准 ±0.5 %；电流测量从电感 DCR 换成功率级内部测量，电压散布才进得了 ±15 mV、Cpk 过 1.33——
   这个 σ 写进了工厂数据，工厂的合格率是设计决定的。
