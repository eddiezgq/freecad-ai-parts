# 计算书 Calculation

## 1 占空比与纹波 Duty and ripple（100 A，Vo = 1.140 V）

| 量 Quantity | 公式 Formula | 结果 Result |
|---|---|---|
| 占空比 D | (Vo + I_ph·(R_LS + DCR)) / (Vin − I_ph·(R_HS − R_LS)) | 0.0975 |
| 每相纹波 ΔI_ph | (Vin − Vo)·D / (L·f) | 14.11 A |
| 输出纹波电流 ΔI_out（D < 1/N，同一时刻只有一相开） | (Vin − N·Vo)·D / (L·f) | 6.71 A |
| 纹波频率 | N·f | 3.0 MHz |
| 输出纹波电压 | ΔI_out × \|Z_电容组(N·f)\| | 0.62 mV |

六相交错，输出纹波电流只有每相的 48 %。

## 2 损耗与效率 Losses and efficiency（100 A，W）

| 损耗 Loss | W |
|---|---|
| 上管导通 | 0.86 |
| 下管导通 | 1.91 |
| 电感直流电阻 | 0.35 |
| 开关交叠 | 2.40 |
| 栅极驱动 | 0.38 |
| 死区体二极管 | 1.05 |
| 电感铁损 | 1.80 |
| 控制器 | 0.60 |
| **合计** | **9.35** |

导通损耗 = 相数 × I_rms² × R，I_rms² = I_ph² + ΔI_ph²/12；开关交叠 = ½·Vin·I_ph·t·f；栅极 = Q_g·V_drv·f；死区 = 2·V_F·I_ph·t_dead·f。
效率 **92.4 %**（100 A），91.9 %（140 A）；140 A 时每颗功率级 2.25 W。

## 3 输出电容：负载线 + 控制环 Output capacitance

AVP 下输出看进去像一个 1.1 mΩ 的电阻，控制环（带宽 f_i = 80 kHz，时间常数 τ = 1/(2π·f_i) = 1.99 μs）
和输出电容 C 组成二阶系统：τ·C·s² + C·s + 1/LL = 0，阻尼 ζ = ½·√(C·LL/τ)。不过冲要 ζ ≥ 0.7：

C ≥ 1.96·τ / LL = **3.54 mF**

选 6 只 560 μF 聚合物电容 + 40 只 22 μF 陶瓷（直流偏压下按 10 μF 算）= 3.76 mF，ζ = 0.72。
电流上升最快 N·(Vin − Vo)/L = 434 A/μs，比负载阶跃 100 A/μs 快；下降最快 N·Vo/L = 46 A/μs，比阶跃慢——卸载时多出来的电流先进电容。

## 4 电压公差叠加 Tolerance stack（上电测试，10 A）

| 来源 Source | 规格 Spec | 3σ / mV |
|---|---|---|
| VID 基准（DAC） | ±0.5 % × 1.25 V | 6.25 |
| 误差放大器失调 | ±1.0 mV | 1.00 |
| 电流测量增益 | ±3 % × 1.1 mΩ × 10 A | 0.33 |
| 上电测试表与夹具 | ±1.5 mV | 1.50 |

方和根 3σ = **6.51 mV**，σ = 2.17 mV。±15 mV 公差下预计 Cpk = 15 / 6.51 = **2.30**；
留给负载阶跃的动态偏差 15 − 6.51 = **8.5 mV**。
这个 σ 写进计算机厂清单 mb_vcore（原来按经验取 3 mV，Cpk 只有约 1.3；用测电流更准的智能功率级以后按 2.2 mV）。
