# 设计任务书：2U 服务器 CPU 散热

**用在哪**　计算机厂的 2U 双路服务器 WQ-SV2U，16 台装一个整机柜（案例 C）卖给算力中心。两颗 CPU 并排，各 270 W；
2U 机箱高 88.9 mm，散热器只能 68 mm 高；机房按 A2 级进风，最高 35 ℃。

| 项目 | 要求 | 出处 |
|---|---|---|
| CPU 功耗 | 270 W × 2（满载） | CPU 规格（示例），和老化曲线模型一致 |
| 进风温度 | ≤ 35 ℃（前面硬盘、内存再预热约 2 ℃） | 数据中心 A2 级 |
| CPU 温度 | ≤ 85 ℃ | 计算机厂整机测试 pc_tmax 上限 |
| 风扇冗余 | 坏一只风扇（6 → 5）仍满足 | 服务器常规（N+1） |
| 散热器外形 | 108 × 100 mm、高 68 mm | 2U 机箱、内存插槽之间 |
| 风扇 | 6 只 60 mm 高速风扇，机箱前部一排 | 机箱设计 |

CPU、风扇、散热器外购（通用名称、示例参数）；固定螺钉从问渠零件库选。
