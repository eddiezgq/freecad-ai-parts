# 方案：散热器底板、鳍片、风扇

## 热量的路：芯片 → 顶盖 → 硅脂 → 散热器底板 → 鳍片 → 空气

总热阻预算：(85 − 35 − 2) / 270 = 0.1778 K/W；
减去芯片到顶盖 0.023 K/W（CPU 规格）和硅脂层 0.0017 K/W，**散热器（底面到进风）≤ 0.1531 K/W**，坏一只风扇时也要满足。

## 方案比较（44 片鳍片、5 只风扇时）

| 方案 | 散热器热阻 | 说明 | |
|---|---|---|---|
| 全铝挤压（底板 6061） | 0.1611 K/W | 底板导热差，热量从 CPU 中间散不开（扩散热阻 0.0225） | ✗ |
| **紫铜底板 + 铝鳍片（钎焊）** | 0.1465 K/W | 铜导热是铝的 2.3 倍，扩散热阻 0.0103 | ✓ |
| 均温板 + 热管 | 更低 | 贵一倍多；350 W 以上的 CPU 再用 | 留给下一代 |

鳍片做薄（0.5 mm）、做高（62 mm，2U 能放的最高），片数下一步算。风扇六只一排，导风罩把每颗 CPU 的风道隔开（分到总风量的 20 %）。
