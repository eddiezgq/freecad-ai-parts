# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | CPU 温度（6 只风扇、进风 35 ℃） | 81.2 ℃ | <= 85 | 任务书 |
| ✓ | CPU 温度（坏一只风扇） | 83.2 ℃ | <= 85 | 任务书 N+1 |
| ✓ | 有限元与公式：CPU 接触面温度相差 | 0.1 K | <= 2 | 核对公式 |
| ✓ | 老化曲线：进风 37 ℃ 满载最高温度 | 82.3 ℃ | <= 85 | 任务书 |
| ✓ | 设计热阻与工厂老化模型相差 | 4.1 % | <= 5 | 细则规则 2 |
| ✓ | 不合格项 | 0  | == 0 | 整机功能测试 |
| ✓ | 最低 Cpk | 1.34  | >= 1.33 | 常用要求 |

1. **散热是一串热阻**：芯片、硅脂、底板扩散、鳍片、空气温升，每一段都要算；最容易忽略的是**扩散**（铝底板多 4 ℃）。
2. **鳍片不是越多越好**：风扇和风道一起决定风量，片数有最优；按“坏一只风扇也够”取最少片数，间距大、不积灰。
3. **设计和工厂用同一个模型**：老化曲线模型里的热阻就是这个散热器的设计值；老化房里 CPU 偏热，先查硅脂（点胶量），不是先加风扇。
