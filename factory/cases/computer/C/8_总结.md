# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 背门换热器换热量（每柜设计功率） | 18.2 kW | >= 13 | 第 1 节 |
| ✓ | 换热后回机房空气温度 | 22.2 ℃ | <= 25 | 不额外加热机房 |
| ✓ | UPS 去掉一块后的容量 | 300 kW | >= 260 | N+1 |
| ✓ | 年 PUE（方案 C） | 1.17  | <= 1.3 | 任务书 |
| ✓ | 年可用性 | 100 % | >= 100 | 任务书 |
| ✓ | 可用性：蒙特卡洛与公式相差 | 0.9 % | <= 5 | 核对公式 |
| ✓ | 不合格项 | 0  | == 0 | 整机柜联调 |
| ✓ | 最低 Cpk | 1.51  | >= 1.33 | 常用要求 |
| ✓ | 实测整柜功率最大值 | 11.3 kW | <= 13 | 第 3 步按设计功率 |

1. **产品决定机房**：每柜 13 kW、服务器风量（案例 B）决定了背门换热器够不够、水温能多高；水温高，自然冷却小时就多，PUE 才下得来。
2. **PUE 主要看冷机开多久**：方案 C 一年有 3,450 小时冷机不开；剩下的非 IT 用电里 UPS 损耗是大头——UPS 负载率、效率曲线值得算。
3. **冗余靠算，不靠感觉**：N+1 把年停机从 33 小时降到 2.2 分钟；公式和蒙特卡洛对上了。
4. **整柜在工厂联调**：现场只接水接电，交付快；但联调台是瓶颈。

## 留给学生的问题

1. 温水从 18/24 ℃ 提到 22/28 ℃：自然冷却小时、PUE 怎么变？服务器进风还能保持 25 ℃ 吗（第 3 步换热器公式）？
2. 把这个算力中心搬到西北（年均温 8 ℃、空气干）：哪个方案最好？
3. 每柜功率升到 40 kW（新一代加速卡）：背门换热器还够吗？要改成什么（提示：冷板液冷）？
