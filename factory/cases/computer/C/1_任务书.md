# 设计任务书：20 柜算力中心

**用在哪**　计算机厂把 20 台 42U 整机柜 WQ-RACK42（每柜 16 台 2U 服务器 WQ-SV2U，案例 B）交付给一个算力中心（示例客户），
机房、供电、制冷由同一个设计组一起做——**整机柜的功率和散热决定机房怎么建**。

| 项目 | 要求 | 出处 |
|---|---|---|
| 机柜 | 20 柜 × 16 台 = 320 台服务器 | 客户订单 |
| 每柜功率 | 设计 13 kW，满载实测约 10.8 kW | 计算机厂整机柜联调 rk_power |
| IT 负荷 | 设计 260 kW；长时间满载约 216 kW | 算力中心训练、计算任务 |
| 服务器进风 | 25 ℃（A1 推荐区间 18–27 ℃） | 案例 B 按最高 35 ℃ 设计，留余量 |
| 年 PUE | ≤ 1.3 | 国内新建大型数据中心常见要求 |
| 可用性 | ≥ 99.98 %（关键设备 N+1，一台坏了不停机） | 客户要求 |
| 停电 | 电池撑 15 分钟，柴油发电机接上 | 常规 |
| 场地 | 华东沿海城市（气候示例），一层厂房改造，室外设备场 | 客户提供 |

PUE = 全年总用电 / 全年 IT 用电。冷机、UPS、水泵、冷却塔、照明都是外购设备，写通用名称和示例参数。
