# 方案比较

中心距 135 mm（箱体已合镗）和传动比 3.5（总传动比 10.5）不能变。比较四个方案（齿面接触最小安全系数 S_H、齿根弯曲最小安全系数 S_F 用第 3 步同一个函数算）：

| 方案 | 传动比 | 总重合度 | S_H | S_F | 轴向力 |  |
|---|---|---|---|---|---|---|
| 直齿 m3、20/70、b = 40 | 3.500 | 1.68 | 1.05 | 5.18 | 0 N |  |
| 直齿 m3、20/70、b = 45 | 3.500 | 1.68 | 1.12 | 5.83 | 0 N | ✓ 选定 |
| 直齿 m3、20/70、b = 50 | 3.500 | 1.68 | 1.18 | 6.48 | 0 N |  |
| 斜齿 mn2.5、23/81、β = 15.6°、b = 45 | 3.522 | 3.16 | 1.31 | 5.71 | 971 N |  |

- **接触强度是这对齿轮的关键**：弯曲安全系数都在 4 以上，接触只略大于 1——大齿轮 40Cr 调质的齿面硬度低，许用接触应力只有小齿轮的一半左右。
- **斜齿**接触强度高约 15%、更平稳；但齿数只能取 23/81，传动比变成 3.522，总传动比偏离 10.5；还要多出约 971 N 轴向力，两根轴的深沟球轴承、箱体都要重新校核；滚刀也要换成 m2.5。输出端只有 138 r/min，节线速度 1.5 m/s，噪声不是问题。
- **直齿 b = 40** 接触不够；**b = 50** 余量更大，但 GR-302 的轮缘宽是 45（案例 A 的结构），加宽要改锻坯和轴的长度。

**选定：直齿 m3、20/70，大齿轮宽 45、小齿轮宽 50**（现行齿数和中心距不变）。接触余量不大（S_H = 1.12），第 7 步要盯住齿面质量。
