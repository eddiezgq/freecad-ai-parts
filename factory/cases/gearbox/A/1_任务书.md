# 设计任务书：WQR-105 输出轴 SH-301

**用途**　二级圆柱齿轮减速器 WQR-105 的输出轴：低速级大齿轮 GR-302 装在轴上，外伸端经联轴器带动输送机、搅拌机一类连续运转的设备。

| 项目 | 要求 | 出处 |
|---|---|---|
| 额定输出转矩 | 350 N·m（已含工况系数 K_A） | 数字工厂参数配置器 T_RATED |
| 输出转速 | 138.1 r/min（输入 1450 r/min ÷ 传动比 10.5） | 工厂设计；齿数 72/24 × 70/20 |
| 起动冲击 | 跑合试验台转矩记录的峰值是额定的 1.66 倍，每 25 s 一次起停 | 数字工厂跑合台 test-01（仿真车间同一个函数） |
| 齿轮 | GR-302：模数 3、70 齿、直齿、α = 20°，分度圆 Ø210，带毂锻件（毂宽 55） | 第 33.2 节 B 版 |
| 轴承 | 两端深沟球轴承 6207（Ø35 × Ø72 × 17，C = 25.5 kN） | BOM：BRG-6207；GB/T 276 |
| 联轴器 | 外伸段 Ø30，轮毂长 70 | 第 33.2 节 |
| 要求寿命 | 10,000 h（频繁起停） | 参数配置器默认值；任务单 TS-33-1 |
| 毛坯 | 热轧圆钢 Ø50（物料 RM-45-D50），最大直径不超过 Ø48 | 工厂物料；工艺规程 GY-SH301 |
| 安全系数 | 静强度、疲劳都不小于 1.5 | 《机械设计》33.5.5 节 |
| 刚度 | 轴承处转角不超过 1 mrad | [SHI] 轴一章 |
| 临界转速 | 工作转速不超过一阶临界的 0.7 倍 | 33.7.2 节 |

**交付物**　计算书、有限元与疲劳报告、三维模型（STEP）、零件图、工艺路线与数控程序、首批 20 根的检验与成本记录。
