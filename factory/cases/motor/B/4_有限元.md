# 仿真：二维静磁场有限元

**模型**：定子（12 齿、齿靴、轭）、气隙、10 块表贴磁钢、转子铁心，Gmsh 二维三角形网格 15,900 个（气隙里加密到 0.12 mm），scikit-fem 解矢量磁位 A。
铁心按线性材料（μ_r = 2000），磁钢 μ_r ≈ 1、B_r = 1.2 T。转子转动 = 磁钢的磁化跟着转，一个电周期算 37 个位置。

| 量 | 有限元 | 手算 | 相差 |
|---|---|---|---|
| 气隙磁密（磁钢下平顶 / 基波） | 基波 1.034 T | 平顶 0.992 T | 波形不同，量级一致 |
| 转矩（额定电流 12.17 A，q 轴） | 0.6242 N·m | 0.637 N·m（K_t × I） | -2.0 % |
| 转矩脉动（一个齿距内 7 个位置） | 4.6 % | — | — |
| 线反电势谐波畸变 THD | 2.99 % | — | 终检公差 ≤ 5 % |
| 线反电势常数 | 6.24 V/krpm（峰值） | — | — |
| 额定电流时定子铁心磁密（99 % 分位） | 1.58 T | — | ≤ 1.6 T，线性假设成立 |

有限元的转矩与“K_t × I”相差 2.0 %：K_t 由空载磁链算出，有限元里还有电流本身的磁场和齿槽效应。
**齿槽转矩**比额定转矩小两个数量级，这套线性、固定网格的二维模型分辨不出来（磁钢边缘在网格里跳格造成的数值噪声和它同一个量级）；
齿槽转矩以终检台实测为准（案例 A 第 4 步、电机厂“电机终检波形”页）。
