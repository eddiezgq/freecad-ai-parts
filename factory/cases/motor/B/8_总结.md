# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 最高转速线反电势峰值 / 母线 | 0.791  | <= 0.8 | 任务书 |
| ✓ | 额定电流密度 | 7.04 A/mm² | <= 8 | 自然冷却小电机常用上限 |
| ✓ | 有限元转矩与手算相差 | 2.01 % | <= 5 | 核对有限元 |
| ✓ | 线反电势 THD（有限元） | 2.99 % | <= 5 | 终检公差 |
| ✓ | 额定电流时定子铁心磁密 | 1.58 T | <= 1.6 | 线性铁心的前提 |
| ✓ | 终检不合格数 | 0  | == 0 | 终检台 |
| ✓ | 终检最低 Cpk | 2.54  | >= 1.33 | 常用要求 |

1. 磁钢 2.5 mm；每线圈 7 匝（由 48 V 母线和最高转速定）；K_t = 0.0524 N·m/A，额定相电流 8.6 A 有效值。
2. 有限元与手算对得上（转矩差 2.0 %），铁心不饱和，线性假设成立。
3. 齿槽转矩太小，这套模型算不准，以终检实测为准——知道模型能算什么、不能算什么，和算出数一样重要。
