# 计算书：WQ-SM200 电磁设计

## 气隙磁密（磁路法）

磁钢厚 h_m = 2.5 mm、气隙 g = 0.5 mm、回复磁导率 μ_r ≈ 1.05：B_g ≈ B_r·(h_m/μ_r)/(g + h_m/μ_r) = **0.992 T**（磁钢下的平顶值）；
有限元（第 4 步）气隙磁密基波幅值 1.034 T（平顶波的基波约为平顶值 × 4/π × sin(极弧 π/2) 量级）。

## 匝数：由母线电压定

有限元得每相每匝磁链幅值 λ₁ = 0.9974 mWb（4 个线圈串联、叠厚 45 mm）。
6000 r/min 时电角速度 ω_e = 3142 rad/s，每匝线反电势峰值 √3·ω_e·λ₁ = 5.43 V。
线反电势峰值 ≤ 0.8 × 48 V ⇒ 每个线圈匝数 N_c ≤ 7.08，**取 N_c = 7**。

## 转矩常数、额定电流

K_t = 1.5·p·λ₁·N_c = 1.5 × 5 × 0.9974e-3 × 7 = **0.0524 N·m/A**（相电流峰值）；
额定 0.637 N·m 要相电流峰值 I = 12.17 A（有效值 8.60 A）。

## 绕组铜

每半槽面积 21.4 mm²，槽满率 0.4：每匝导线截面 1.223 mm²（线径约 Ø1.25，可用多股并绕）；
额定电流密度 **7.0 A/mm²**；平均匝长约 112 mm，相电阻（100 ℃）57.7 mΩ，额定铜耗 **12.8 W**（案例 C 的热计算用）。
