# 计算：特性、效率、轴承、抱闸

## 电参数（由案例 B 的有限元）

每相磁链幅值 ψ = 6.98 mWb（每线圈 7 匝），K_t = 1.5 p ψ = 0.0523 N·m/A；相电阻（100 ℃）58 mΩ；同步电感（有限元，磁钢置零、通三相电流）83 μH（不含端部漏感）。

## 转矩—转速特性（48 V 母线，q 轴电流、不弱磁）

相电压峰值上限 V_dc/√3 = 27.7 V；峰值电流 42.6 A（峰值转矩 2.23 N·m）。转速升高后反电势吃掉电压，电流被电压限住：
6000 r/min 时还能出 **2.23 N·m**（额定 0.637），满足最高转速下带额定转矩。

## 效率（额定点，只计铜耗）

铜耗 1.5 I² R = **12.8 W**，η ≈ 200 / (200 + 12.8) = 94.0%。铁耗、机械损耗还要加几瓦，这台示例设计没有硅钢片的损耗曲线，**铁耗没有算**（实测在终检台的空载电流里）。

## 轴承（零件库 `A-BRG-DG/608`，d 8 × D 22 × B 7，C = 3.45 kN，零件库数据来源 SKF）

转子质量约 0.19 kg；电机直连谐波减速器，没有皮带拉力；每只轴承径向载荷 ≈ 21 N（含预紧）。L₁₀ ≈ **14,347,867 h**。

## 抱闸

静态保持力矩下限 0.64 N·m ≥ 额定转矩 0.637 N·m（断电时能抱住额定负载）。
