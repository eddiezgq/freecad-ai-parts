# 计算：槽电势星形图与绕组排布

**槽距电角** α = p·360°/Q = 5·360°/12 = 150°。第 k 个线圈的电势相位 = k·α；把 12 个线圈归到最近的六个相轴（+A、−C、+B、−A、+C、−B），三相各 4 个。

**绕组排布**（齿 1–12，“−”表示反绕）：

`A −A −B B C −C −A A B −B −C C`

**基波绕组系数** k_w1 = k_p · k_d：
- 节距系数 k_p = sin(α/2) = sin(75°) = 0.966（线圈跨一个齿）；
- 分布系数 k_d = |每相线圈相量之和| / 线圈数 = 0.966；
- k_w1 = **0.933**。

各次谐波：ν = 1：0.933, ν = 3：0.500, ν = 5：0.067, ν = 7：0.067, ν = 9：0.500, ν = 11：0.933, ν = 13：0.933, ν = 15：0.500, ν = 17：0.067, ν = 19：0.067。5、7 次被压到 0.067，11、13 次又回到 0.933——它们是“齿谐波”（ν = Q/p ± 1），由磁钢形状和斜极去削弱。
