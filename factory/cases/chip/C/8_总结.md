# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 与参考模型逐拍一致的场景 | 9  | == 9 | Icarus 逐拍对照 |
| ✓ | 建立时间余量 | 5.06 ns | >= 0 | 静态时序分析 |
| ✓ | 保持时间余量 | 0.12 ns | >= 0 | 静态时序分析 |
| ✓ | 设计规则 + LVS 错误 | 0  | == 0 | LibreLane |
| ✓ | 晶圆测试 + 成品测试不合格项 | 0  | == 0 | 芯片厂测试公差 |

1. **芯片设计 = 写 RTL + 证明它对**：参考模型、逐拍对照、坏情况场景，比 RTL 本身花的功夫多。
2. **开源工具链能走到 GDS**：SKY130 + LibreLane，时序、设计规则、LVS 都过；还剩转换时间违例要优化——工具诚实地列出来。
3. **一片晶圆就是一批货**：37,748 颗 → 34,403 只成品；良率由晶圆图解释，瓶颈在键合。
4. **芯片、电路板、机器人接上了**：这颗芯片装在驱动板 B 版上（电路板厂案例 C），驱动板装在机器人关节里（机器人厂案例 B）。
