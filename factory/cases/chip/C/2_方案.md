# 方案：功能块与寄存器

| 功能块 | 做什么 |
|---|---|
| 同步器 | 每路输入过两级触发器，避免外部信号和芯片时钟不同步造成亚稳态 |
| 数字滤波 | 输入与当前值不同、并且连续 N+1 拍都不同才改：短于 N+1 拍（N=3 时 80 ns）的毛刺被滤掉 |
| 4 倍频解码 | A、B 每个边沿都计一步：A 超前 B 为正转 +1；A、B 同时跳变说明漏了边沿，报“丢步” |
| 计数与 Z 锁存 | 32 位计数；Z 相上升沿把当时的计数存进 INDEX（可选同时清零），用来找零位 |
| SPI 从机 | 模式 0：8 位命令（最高位 1 = 写，低 7 位地址）+ 32 位数据，高位先出；读的值在命令收齐那一拍取快照，读计数不会读到一半变了的数 |

| 地址 | 寄存器 | 读写 | 复位值 | 位 |
|---|---|---|---|---|
| 0x00 | ID | 只读 | 0x454E4331 | 31:0：芯片标识 “ENC1” |
| 0x01 | CTRL | 读写 | 0x00000031 | 0：计数使能；1：方向取反；2：Z 相上升沿清零计数；7:4：滤波长度 N（0–15）：输入要连续 N+1 拍与当前不同才认 |
| 0x02 | STATUS | 读 / 写 1 清除 | 0x00000001 | 0：最近方向（1 = 正转）；1：丢步：A、B 同时跳变（粘住，写 1 清除）；2：已锁存 Z 位置（粘住，写 1 清除）；3：A（滤波后）；4：B（滤波后）； |
| 0x03 | COUNT | 读写 | 0x00000000 | 31:0：32 位有符号计数（4 倍频：每个边沿 ±1）；写入 = 置数 |
| 0x04 | INDEX | 只读 | 0x00000000 | 31:0：Z 相上升沿那一拍的计数 |

输入 A、B、Z 用施密特缓冲（案例 A）进同步器；SPI 模式 0、SCLK ≤ 时钟 / 10。
