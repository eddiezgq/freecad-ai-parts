# 计算：RTL 与时序要点

- RTL `rtl/wq_encif.v` 137 行；参考模型 `model/encif.py`（Python，逐拍同样的行为）。
- **滤波**：输入要连续 N+1 拍与当前值不同才认；复位值 N = 3 → 短于 80 ns 的毛刺被滤掉。
- **最高计数频率**：每个边沿要等同步 2 拍 + 滤波 N+1 拍才被认，A、B 两相边沿间隔至少约 6 拍 → A 相最高约 2.1 MHz；
  电机 6000 r/min、2500 线编码器 A 相 250 kHz，余量很大。
- **SPI**：SCLK 由芯片时钟过采样，要求 SCLK ≤ 5 MHz；驱动板固件用 ≤ 5 MHz（电路板厂案例 C 的固件说明）。
