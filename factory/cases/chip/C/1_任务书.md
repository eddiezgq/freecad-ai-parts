# 设计任务书：编码器接口芯片 WQ-ENCIF

**为什么要做芯片**　关节驱动板读电机端增量编码器（A、B、Z），原来用 MCU 定时器的编码器模式：滤波弱、丢步查不出、Z 相要软件处理。
做一颗小芯片：滤波、4 倍频解码、32 位计数、丢步检测、Z 相锁存，MCU 通过 SPI 读——驱动板 B 版用它（电路板厂案例 C）。

| 项目 | 值 | 出处 |
|---|---|---|
| 工艺 | SKY130（开源工艺库，130 nm） | 开源工艺库 |
| 时钟 | 50 MHz | 设计 |
| 引脚 | 9 个信号脚（clk, rst_n, enc_a, enc_b, enc_z, sclk, cs_n, mosi, miso） | `out/design.json` |
| 寄存器 | 5 个（0x00 ID, 0x01 CTRL, 0x02 STATUS, 0x03 COUNT, 0x04 INDEX） | 同上 |
| 封装 | QFN-16 3×3 mm | 芯片厂清单 |
| 量 | 一片晶圆一批，约 34 000 只（电路板厂整批买） | 芯片厂清单 |

> 示例设计，未流片，未经硅验证
