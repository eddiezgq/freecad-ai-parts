# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 七个工艺角的最小回差 | 0.602 V | >= 0.6 | 任务书 |
| ✓ | 工艺角 VT+ 最大值 | 1.33 V | <= 1.4 | 晶圆测试公差 |
| ✓ | 工艺角 VT− 最小值 | 0.533 V | >= 0.45 | 晶圆测试公差 |
| ✓ | 干扰下施密特翻转次数 | 2  | == 2 | 一上一下 |
| ✓ | 晶圆测试不合格 | 0  | == 0 | 晶圆测试 |
| ✓ | 最低 Cpk | 2.1  | >= 1.33 | 常用要求 |

1. **手算给规律，模型给数**：平方律公式说清楚“反馈越强、回差越大”，VT− 算得很准、VT+ 差 0.06 V（体效应）。
2. **一个设计要在所有工艺角下都成立**：典型值 0.648 V，最差 0.602 V 也要过线。
3. **测试公差来自工艺角**：晶圆测试的 VT+、VT− 公差就是仿真的工艺角范围放宽一点。
