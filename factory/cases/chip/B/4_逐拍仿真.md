# 仿真：Icarus Verilog 逐拍 + Python 参考模型

测试平台 `tb_ssi.v`：编码器（SSI 从机）行为模型 + 一段可调的线缆往返延迟；Python 生成位置、跑 Icarus Verilog version 12.0、逐帧和参考模型比。

## 功能：64 个位置（含 0、1、全 1、最高位、交替位和随机），延迟 0

读对 **64 / 64** 帧，校验错 0。

- 延迟到 **450 ns** 全对，500 ns 开始出错——和第 3 步预算的 440 ns 吻合（仿真步长 50 ns）。
- **偶校验抓不住移位错**：延迟超了以后，每一位都晚采一位，整帧错位；157 个错帧里有 49 个校验照样“通过”——
  错位的数据里 1 的个数是偶数的概率约一半。所以光靠校验不行：**要么保证时序预算，要么连读两次比对、或者加循环冗余校验（CRC）**。
