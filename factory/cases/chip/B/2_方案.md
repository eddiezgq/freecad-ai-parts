# 方案：状态机 + 移位寄存器

| 部分 | 做法 |
|---|---|
| 状态机 | 空闲 → 移位（发 18 个时钟、采 18 位）→ 等待（20 μs）→ 空闲 |
| 时钟发生 | 计数器数 25 拍翻一次：50 MHz / 50 = 1 MHz |
| 采样时刻 | 时钟高电平的最后一拍（编码器在上升沿换数，等了半个周期，数据最稳） |
| 输入同步 | 数据线过两级触发器（编码器和芯片不同时钟，防亚稳态）——代价是采样晚 2 拍 |
| 格雷码 → 二进制 | b[n−1] = g[n−1]，b[i] = b[i+1] ⊕ g[i]：一串异或 |
| 校验 | 18 位全部异或，应为 0 |

RTL：`wq_ssi.v`（参数 BITS、HALF、TM，71 行）。
