# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 最高帧率 | 26.3 kHz | >= 1 | 任务书 |
| ✓ | 与参考模型一致的帧 | 64  | == 64 | 逐帧对照 |
| ✓ | 仿真延迟上限与预算相差 | 10 ns | <= 50 | 仿真步长 50 ns |
| ✓ | 工程样片成品测试不合格 | 0  | == 0 | 成品测试 |

1. **硬件模块 = 状态机 + 计数器 + 移位寄存器**：64 个触发器就把 MCU 软件做的事搬进了芯片。
2. **仿真要有参考模型**：Python 写一份“应该是什么”，逐帧对照，才知道 RTL 对不对。
3. **时序预算先算、再仿真验证**：440 ns 的预算和仿真的 450 ns 对上；超了以后错得悄无声息——**偶校验抓不住移位**。

3. 编码器换成 CRC-6 校验，状态机要改哪里？
