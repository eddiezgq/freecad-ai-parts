# 制造：一批工程样片（一片晶圆）

芯片封测厂仿真车间按工程样片路线走一批（37 小时，键合、老化最长）。成品测试（一批记一条：抽检值、良率、中位数）：

| 特性 | 公差 | 这一批 |
|---|---|---|
| 划片崩边（抽检最大值） | ≤ 25 | 10.4061 |
| 键合拉力（抽检最小值） | 3–12 | 5.7059 |
| 焊球推力（抽检平均） | 15–40 | 25.6094 |
| 塑封空洞率（X 光抽检） | ≤ 3 | 1.2151 |
| FT 良率 | 95–100 | 97.7259 |
| 工作电流（50 MHz，中位数；第 92 轮版图约 0.67 mA） | 0.4–1 | 0.6527 |
| 施密特回差（中位数；第 93 轮仿真 0.648 V） | 0.45–0.85 | 0.6516 |

不合格 0。（一批只有一条记录，算不了 Cpk；量产后按批积累。）真正的 SSI 功能要等这一版流片后才能在样片上测——现在的样片是现有 WQ-ENCIF，这一步演示路线和测试项。
