# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 最危险截面疲劳安全系数 | 3.62  | >= 1.5 | 教材第 33 章 |
| ✓ | 前轴承寿命 L10h | 27,198 h | >= 20,000 | G2 计算书 |
| ✓ | 一阶临界转速 / 最高转速 | 2.32  | >= 1.5 | G2 计算书 |
| ✓ | MuJoCo 与设计软件驱动力矩相差（占峰值） | 0.16 % | <= 1 | 核对模型 |
| ✓ | 不合格项 | 0  | == 0 | 零件检验 |
| ✓ | 最低 Cpk（件数 ≥ 10 的特性） | 1.61  | >= 1.33 | 常用要求 |

1. **高速机的轴由惯性决定**：缝纫功率只有 66 W，一转里的力矩却起伏 ±5 N·m。
2. **设计跟着整机走**：教材的轴放不进这台机器，机壳、挑线机构一改，轴就跟着改了三版——每一版都重算一遍，程序化计算才跟得上。
3. **刚度好不等于更好**：加中间支承挠度减半，前轴承寿命却不够了。
