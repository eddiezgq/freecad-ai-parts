# 工艺

## 机壳精加工：精度预算（G5）

每个关键形位要求，把机床、刀具、夹具、热漂移的误差一项项加起来（系统误差直接加，随机误差方和根），看占公差多少：

| 要求 | 误差合计 / mm | 公差 / mm | 占公差 |  |
|---|---|---|---|---|
| 压脚杆孔对针杆孔平行度 0.03/100 | 0.0123 | 0.03 | 41 % | ✓ |
| 针杆孔对旋梭轴孔 位置度 Ø0.05 | 0.0148 | 0.05 | 30 % | ✓ |
| 针杆孔对上轴孔 B 位置度 Ø0.05 | 0.0118 | 0.05 | 24 % | ✓ |
| 送布摆轴两孔同轴度 Ø0.04 | 0.0234 | 0.04 | 58 % | ✓ |
| 抬牙摆轴两孔同轴度 Ø0.03 | 0.0180 | 0.03 | 60 % | ✓ |
| 上轴两孔同轴度 Ø0.02 | 0.0147 | 0.02 | 73 % | ✓ |
| 下轴两孔同轴度 Ø0.02 | 0.0137 | 0.02 | 68 % | ✓ |
| 齿轮中心距 31.058 ± 0.015 | 0.0181 | 0.03 | 60 % | ✓ |
| 上轴中心高 262 ± 0.05（对 A） | 0.0325 | 0.1 | 33 % | ✓ |
| 上轴对下轴平行度 0.03/300 | 0.0124 | 0.03 | 41 % | ✓ |
