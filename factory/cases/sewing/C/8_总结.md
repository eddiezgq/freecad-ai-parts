# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | G1 机构项不通过 | 0  | == 0 | G1 校核 |
| ✓ | 机壳前两阶固有频率（较低者） | 221 Hz | >= 210 | G3 目标 |
| ✓ | 一转最小间隙 | 1 mm | >= 1 | G4 干涉检查 |
| ✓ | 太近的零件对 | 0  | == 0 | G4 干涉检查 |
| ✓ | 精度预算超公差项 | 0  | == 0 | G5 精度分析 |
| ✓ | 不合格项 | 0  | == 0 | 出厂测试 |
| ✓ | 最低 Cpk | 1.62  | >= 1.33 | 常用要求 |

1. **一台机器是一串互相牵动的决定**：机壳一改，上轴改版（案例 A）；挑线机构装不下，曲柄改共用销；每一步都重算。
2. **刚度、重量、成本要一起看**：机壳频率由“机头前后摆”卡住，灰铸铁下不了 22 kg，定案时说清楚了代价。
3. **工艺在设计阶段就算**：铸造凝固、精度预算、三坐标计划都在出图前做完。
