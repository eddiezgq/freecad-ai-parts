# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 量程 / 峰值电流 | 1.39  | >= 1.05 | 设计描述 sense_headroom |
| ✓ | ngspice 与公式最大相差 | 0.51 % | <= 3 | 例题 1 的核对规则 |
| ✓ | −3 dB 带宽 | 474 kHz | >= 20 | 任务书 |
| ✓ | 不合格项 | 0  | == 0 | 在线测试、功能测试 |
| ✓ | 最低 Cpk | 1.63  | >= 1.33 | 常用要求 |

1. **采样电阻是“信号大小 ↔ 发热、量程”的折中**：2 mΩ 是量程够的里面分辨率最好的。
2. **几毫欧的电阻，布局决定精度**：开尔文接法、散热过孔。
3. **比例误差标定掉，零点每次上电扣掉**：分立电路的 ±3.8 % 散布也能用，但标定是必须的工序。
