# 仿真：数字工厂“电路分析”例题 1（同一张网表、同一个蒙特卡洛）

例题 1 用通用运放 + 四个电阻搭差分放大器（参数 rs_mohm = 2、gain = 20），用来核对公式；实际板子上换成固定增益的专用放大器。

| 读数 | ngspice | 公式 | 相差 |  |
|---|---|---|---|---|
| 峰值电流时的输出 | 0.4606 V | 0.4607 V | 0.02 % | ✓ |
| 零电流时的输出 | 1.65 V | 1.65 V | 0.02 % | ✓ |
| −3 dB 带宽 | 4.737e+05 Hz | 4.762e+05 Hz | 0.51 % | ✓ |

**元件容差**：采样电阻、四个增益电阻都按 ±1 % 随机取 200 次，峰值电流时输出的散布 ±3.8 %（3σ，相对摆幅）——
比任务书 ±2 % 还大。**分立方案必须逐块标定**；专用放大器的增益误差是器件规格里的一个小数（待核对），加上采样电阻 ±1 %，功能测试时标定一次就进 ±2 %。
带宽 474 kHz 远高于 20 kHz；实际还要在 ADC 前加 RC（1N 电容，零件库）滤掉开关尖峰。
