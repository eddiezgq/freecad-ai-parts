# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 最高信号频率时幅值下降 | 0.008 % | <= 1 | 任务书 |
| ✓ | 读头板公差全取上限的细分误差 | 10.1 ″ | <= 40 | 功能测试公差 |
| ✓ | 差分幅值：ngspice 与公式相差 | 0 % | <= 1 | 公式核对 |
| ✓ | 功能测试不合格项 | 0  | == 0 | 功能测试台 |
| ✓ | 最低 Cpk | 1.42  | >= 1.33 | 常用要求 |

1. **微安级信号先看对称**：正反相相减抵消了直流，但抵消不完——偏置要在出厂时调。
2. **误差要换算到用户关心的单位**：20 mV 偏置、3° 相位，到编码器就是几角秒；2048 线把电气角缩小了 2048 倍。
3. **一块板只管自己那一份**：细分误差的大头在码盘和光学（传感器厂），读头板的公差设计让它只占一小部分。
