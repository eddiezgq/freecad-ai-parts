# 工艺：两层物料清单、两条路线

电路板厂的物料清单是两层：贴片板 SMT-DRV-B（光板 + 全部贴片元件 + 锡膏）→ 成品板 DRV-JOINT-B（贴片板 + 插座 + 三防漆 + 防静电袋）。
贴片元件数量和 KiCad 物料清单一致（测试核对，第 88 轮）。

| 线 | 工序 | 设备 | 工时 / min |
|---|---|---|---|
| 贴片线 | 锡膏印刷 Stencil printing | 锡膏印刷机 SP | 1.0 |
| 贴片线 | 锡膏检测 SPI | 锡膏检测仪 SPI | 0.5 |
| 贴片线 | 高速贴片 Chip placement | 贴片机 PP | 2.0 |
| 贴片线 | 多功能贴片 IC placement | 贴片机 PP | 1.5 |
| 贴片线 | 回流焊 Reflow soldering | 回流焊炉 RF | 6.0 |
| 贴片线 | 自动光学检测 AOI | 自动光学检测 AOI | 0.8 |
| 后段 | 选择焊 Selective soldering | 选择焊 SW | 2.0 |
| 后段 | 在线测试 ICT | 在线测试仪 ICT | 1.5 |
| 后段 | 程序烧录 Programming | 烧录工位 PG | 1.0 |
| 后段 | 三防涂覆 Conformal coating | 三防涂覆机 CC | 1.5 |
| 后段 | 老化 Burn-in | 老化房 BI | 120 |
| 后段 | 功能测试 FCT | 功能测试台 FCT | 3.0 |
| 后段 | 包装 Packing | 包装台 PK | 0.5 |

- 贴片程序直接用 KiCad 导出的坐标文件 `pos.csv`；钢网由 Gerber 的锡膏层出。
- 芯片 WQ-ENCIF 向工业园芯片厂整批买（一批 34 000 只，第 106 轮）。
- 老化 120 分钟是整炉走；功能测试台按板写入相电流标定值（案例 A）。
