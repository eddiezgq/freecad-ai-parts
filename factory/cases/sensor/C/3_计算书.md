# 计算：误差预算、调零电阻、标定砝码

## 误差预算（%FS）

| 来源 | %FS | 依据 |
|---|---|---|
| 非线性 | 0.300 | 终检公差（弹性体 + 应变片） |
| 滞后 | 0.250 | 终检公差（胶层、结合面） |
| 零点（调零后残差） | 0.500 | 终检公差 |
| 零点温漂 × 2.5（±25 K 工作范围） | 0.375 | 终检公差 × 温差 |
| 蠕变 | 0.100 | 终检公差 |
| 噪声（峰峰值） | 0.035 | 案例 A |
| 标定不确定度 | 0.050 | 砝码 + 力臂（下面计算） |

每项都按终检公差的**上限**取（实际产品大多远小于上限，见第 7 步），各项独立，按方和根合成：**0.75 %FS**（最坏情况直接相加 1.61 %FS）——
满足任务书的 ±1 %FS，对外标“综合精度 ±0.8 %FS（0–50 ℃）”。
最大的两项是**零点温漂**和**零点残差**：这两项靠下面的补偿和工艺，不靠弹性体。

## 调零电阻（RES-COMP）

组桥后测到的零点 z₀（mV/V）近似等于 ΔR/(4R)，在电阻偏低的那一个桥臂里串一个 ΔR = 4·R·z₀ 的电阻就能调平（R = 700 Ω）：

| 组桥后零点 | 串联电阻 | 串在 |
|---|---|---|
| +0.2 mV/V（16 %FS） | 0.56 Ω | 电阻低的那一臂 |
| +0.6 mV/V（47 %FS） | 1.68 Ω | 电阻低的那一臂 |
| +1.2 mV/V（94 %FS） | 3.36 Ω | 电阻低的那一臂 |

几欧姆的电阻用低温漂锰铜丝或箔电阻：它自己的温度系数要远小于应变片，否则调平了零点、又引进了温漂。调完零点残差 ≤ ±0.5 %FS 交终检。

## 零点温漂补偿（两步）

1. **电桥里**：温度补偿箱测 0、25、50 ℃ 三点零点，算出零点温漂斜率，在相应桥臂串一段铜电阻（铜的温度系数大，几十毫欧就能抵掉）——粗补。
2. **调理板里**：MCU 读板上温度，按三点表做二次插值修正——细补（第 4 步仿真）。

## 砝码标定

力臂 500 mm 的标定杠杆，每级 40 N·m → 砝码 40 / (0.5 × 9.80665) = **8.158 kg**，5 级共 40.79 kg（正、反向各一套）。
不确定度：力臂 ±0.05 mm → 0.010 %，砝码 ±0.005 %（示例），重力加速度按当地值修正——合计远小于预算里的 0.05 %FS。
