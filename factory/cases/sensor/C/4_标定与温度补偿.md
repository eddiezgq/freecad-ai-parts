# 仿真：砝码标定与温度补偿

## 一台传感器的砝码标定（“虚拟仪器”力矩传感器同一个模型）

模型 y = x + 4·nl·x(1−x)（加载），卸载再加 4·hys·x(1−x)，噪声取案例 A 的 0.035 %FS 峰峰值。这一台的“真值”（示例）：灵敏度比设计高 0.4 %、非线性 0.11 %、滞后 0.09 %、零点 +0.12 %FS。
0、40 … 200 N·m 六级，加载、卸载各一遍，做 3 个循环：

| 标定结果 | 值 | 终检公差 |
|---|---|---|
| 灵敏度 | 1.2751 mV/V（设计 1.2700） | —（写进证书，调理板按它换算） |
| 非线性（最佳直线） | 0.081 %FS | ≤ 0.3 |
| 滞后 | 0.090 %FS | ≤ 0.25 |
| 零点 | +0.202 %FS | ±0.5 |

标定把灵敏度的 0.4 % 偏差和零点修掉（写进调理板）；**非线性、滞后修不掉**，只能靠弹性体、粘片和固化。

## 零点温漂：200 台的统计（示例模型）

每台的零点温漂 = 斜率 + 二次 + 三次项（应变片温度系数不匹配、胶层，系数随机）。

|  | 未补偿 | 粗补（铜电阻，斜率剩 ±20 %） | 细补（MCU 三点二次插值） |
|---|---|---|---|
| 零点温漂中位数 %FS/10K | 0.679 | 0.368 | 0.016 |
| 最大 %FS/10K | 2.487 | 1.374 | 0.063 |
| ≤ 0.15 的比例 | 2 % | 14 % | **100 %** |

只靠铜电阻粗补，86 % 的传感器温漂超差；加上 MCU 的三点修正，剩下的只有三次项和测量噪声。这就是温度补偿工序要 240 分钟（三个温度点、每点等热平衡）的原因。
