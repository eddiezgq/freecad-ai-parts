# 设计任务书：关节扭矩传感器 WQ-TS

**卖给谁**　协作机器人厂、伺服电机厂、自动化设备厂（传感器厂清单里的三家示例客户）：装在关节减速器输出端，做力控、碰撞检测、拖动示教。

| 指标 | 要求 | 出处 |
|---|---|---|
| 量程 / 过载 | ±200 N·m / 300 N·m | 清单；案例 B |
| 额定输出（调理前） | 1.27 mV/V | 案例 B 有限元 |
| 输出 | CAN，1 kHz，24 位 | 案例 A |
| 非线性 / 滞后 | ≤ 0.3 / ≤ 0.25 %FS | 终检公差 |
| 零点输出 | ±0.5 %FS | 终检公差 |
| 蠕变（满量程 30 min） | ≤ 0.1 %FS | 终检公差 |
| 零点温漂 | ≤ 0.15 %FS / 10 K（0–50 ℃） | 终检公差 |
| 扭转刚度 | 3e+05 N·m/rad | 案例 B |
| 外形 | Ø90 × 14，中空 Ø20 | 案例 B |
| 综合精度 | ≤ ±1 %FS（0–50 ℃，各项按公差上限合成） | 本案例设定（关节力矩传感器常见档次） |
| 售价 | 320 美元 | 传感器厂清单 |

**这个案例要做的**：把 A、B 两个案例的结果合成一个产品——误差怎么分配、零点和温漂怎么补、出厂怎么标定、批量做出来是不是都合格。
