# 三维、装配与物料清单

`WQ-TS.step`：弹性体（案例 B）+ 正面盖板（铝 1 mm，盖住凹槽和应变片，4 × M3×8 拧在外圈内侧）+ 背面环形调理板（SIG-TS，2 × M3×8）。

**物料清单**（传感器厂清单，一层）：

| 物料 | 名称 | 用量 |
|---|---|---|
| BODY-TS | 扭矩传感器弹性体（17-4PH 不锈钢，外协机加，型号待确认） Torque sensor flexure | 1 |
| SG-350 | 应变片 350 Ω（剪切型双栅，型号待确认） Strain gauge 350 Ω | 4 |
| GLUE-SG | 应变胶（热固化环氧，型号待确认） Gauge adhesive | 0.0003 |
| RES-COMP | 补偿电阻套件（零点、温漂，型号待确认） Compensation resistor kit | 1 |
| SIG-TS | 信号调理板（仪表放大 + ADC，型号待确认） Signal conditioning board | 1 |
| CABLE-TS | 扭矩传感器线缆（屏蔽，型号待确认） Torque sensor cable | 1 |
| SCR-M3 | 内六角螺钉 M3×8 Socket screw M3×8 | 6 |
| BOX-S | 防静电包装盒 ESD box | 1 |
