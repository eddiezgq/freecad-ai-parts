# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 过载时 ADC 量程占用 | 64 % | <= 90 | 留 10 % 余量放零点 |
| ✓ | 噪声峰峰值 | 0.035 %FS | <= 0.05 | 任务书 |
| ✓ | 增益：ngspice 与公式相差 | 0.02 % | <= 0.5 | 公式核对 |
| ✓ | −3 dB 带宽 | 748 Hz | >= 500 | 任务书 |
| ✓ | 选定方案：供桥 ±5 % 时零点变化（1 % 电阻） | 1.3e-07 %FS | <= 0.01 | 蒙特卡洛 |
| ✓ | 终检不合格项 | 0  | == 0 | 扭矩终检台 |
| ✓ | 零点输出 Cpk | 1.5  | >= 1.33 | 常用要求 |

1. **小信号先看噪声和零点，不看位数**：24 位 ADC 的最低位折到电桥只有 1.78 nV，真正的限制是前置级噪声（0.035 %FS 峰峰值）。
2. **共模抑制不能靠分立电阻**：方案 ② 的差分级用 1 % 电阻，供桥一漂零点就跟着变（最大 0.34 %FS，比终检零点公差的一半还多）；方案 ③ 让共模原样通过、交给差分 ADC。
3. **应变片的公差和信号一样大**：不调零的电桥零点标准差 50 %FS——调零必须在放大之前、在电桥里做。
4. 增益误差（±1.4 %）是比例误差，标定修掉；**零点、噪声修不掉**，要在设计时压住。
