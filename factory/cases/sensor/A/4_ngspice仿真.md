# 仿真：ngspice（数字工厂“电路分析”同一个接口、同一个通用运放模型）

电桥用戴维南等效（两个输出端各 350 Ω，电压随力矩线性变化）；运放开环 120 dB、增益带宽积 1 MHz（通用模型，示例参数）。网表：`4_信号链_dc.cir`、`4_信号链_ac.cir`，可以贴进“电路分析”页的网表框直接跑。

## 增益、线性、带宽

| 量 | ngspice | 公式 |
|---|---|---|
| 额定 200 N·m 输出 | 1.0645 V | 1.0647 V（差 0.02 %，运放有限开环增益） |
| 过载 300 N·m 输出 | 1.5968 V | 1.5970 V |
| 零力矩输出 / 共模 | 0.00 μV / 2.500 V | 0 / 2.5 V |
| 偏离直线（−300…+300 N·m） | 1.1e-07 %FS | — |
| −3 dB 带宽 | **748 Hz** | 758 Hz（RC；运放闭环带宽 ≈ 1 MHz / 168 = 6.0 kHz 也参与） |

电路部分是线性的——传感器的非线性只来自弹性体和应变片（案例 B、C）。

## 元件容差（蒙特卡洛，零件库电阻 ±1 %）

- **增益**：R_F、R_G 各 ±1 %，60 次，满量程输出散布 ±1.41 %——是固定的比例误差，案例 C 的砝码标定一次修掉。
- **共模变化漏成零点漂移**：方案 ② 的差分级参考端接独立的 2.5 V 基准、用四个 1 % 电阻；供桥电压漂 ±5 %（共模漂 ±125 mV）时，
  零力矩输出变化 -0.32 … +0.34 %FS（标准差 0.14 %FS）——共模恰好等于参考电压时看不出来，一漂就露馅；
  方案 ③（选定）在同样 1 % 电阻下变化最大 1.3e-07 %FS（共模原样通过，交给差分 ADC）。**这就是第 2 步选 ③ 的原因，仿真把它量出来了。**

## 应变片阻值公差 → 电桥零点

8 个栅各 ±0.3 %（示例），真实电阻电桥 200 次：零点标准差 **50 %FS**，最大 148 %FS。
应变片阻值的微小差别（0.3 % = 1 Ω）和满量程信号（1.27 mV/V 相当于阻值变化 0.13 %）是一个量级——**不调零根本不能用**：
3σ 零点放大后 1.59 V，ADC 量程 ±2.5 V，会挤掉过载余量甚至削顶。所以零点必须在电桥里（放大之前）用补偿电阻调平（清单 RES-COMP，案例 C 的“温度补偿”工序）。
