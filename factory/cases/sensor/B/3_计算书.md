# 计算：第一版尺寸（手算）

**几何**（mm）：外圈 R45/R34，内毂 R22，中孔 Ø20，厚 14；轮辐宽 14、长 12；
凹槽 8（径向）× 8（切向），腹板厚 t_w = 1.5。

**轮辐的剪力**：把轮辐看成两端固定、可以相对平移的短梁（内毂转、外圈不动），反弯点在中点。对内毂取矩：

  T = 4·(V·R_ho + V·L/2) = 4·V·R_mid　→　V = T / (4·R_mid) = 200×10³ / (4 × 28) = **1786 N**

**腹板中心的剪应力**（工字截面，绕轴线方向弯曲）：

  I = 2668 mm⁴，中性轴以外面积矩 Q = 243 mm³
  τ = V·Q / (I·t_w) = 1786 × 243 / (2668 × 1.5) = **108 MPa**
  γ = τ / G = 108 / 77437 = **1400 μ**（G = E / 2(1+ν)，17-4PH：E 197 GPa、ν 0.272）

**电桥输出**：±45° 栅的应变 = ±γ/2，四个臂 → Vout/Vex = GF·γ/2 = 2.0 × 1400×10⁻⁶ / 2 = **1.40 mV/V**

**轮辐根部弯曲**：M = V·L/2 = 10.7 N·m，σ = M·(B/2)/I = 28 MPa——厚壁让弯曲应力很小。
