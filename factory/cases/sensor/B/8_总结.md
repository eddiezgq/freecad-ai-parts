# 总结

|  | 项目 | 结果 | 要求 | 出处 |
|---|---|---|---|---|
| ✓ | 第一版有限元输出（不满足，改版） | 0.763 mV/V | < 1 | 有限元：说明为什么改版 |
| ✓ | 定稿额定输出 | 1.27 mV/V | >= 1 | 任务书 |
| ✓ | 扭转刚度 | 300,191 N·m/rad | >= 228,000 | 4 × K3（零件库） |
| ✓ | 过载 300 N·m 对屈服的安全系数 | 3.67  | >= 2 | 任务书 |
| ✓ | 径向力 1 kN 串扰 | 0.006 %FS | <= 0.5 | 任务书 |
| ✓ | 倾覆力矩 20 N·m 串扰 | 0.004 %FS | <= 0.5 | 任务书 |
| ✓ | 网格 2 mm 与 1.6 mm 输出相差 | 0.7 % | <= 2 | 网格收敛 |
| ✓ | 外圈螺钉摩擦能传的力矩 | 518 N·m | >= 360 | 过载 × 1.2 |
| ✓ | 内毂螺钉摩擦能传的力矩 | 223 N·m | >= 188 | 重复峰值 × 1.2（零件库） |
| ✓ | 过载时内毂锥销剪应力 | 85 MPa | <= 100 | 不淬火锥销许用值（示例取值） |
| ✓ | 终检不合格项 | 0  | == 0 | 扭矩终检台 |
| ✓ | 终检最低 Cpk | 1.41  | >= 1.33 | 常用要求 |

（第一项“第一版输出 < 1.0”是记录第一版不行、需要改版，不是要求。）

1. **短而粗的零件，手算定方向，有限元定数**：工字截面剪应力公式高估了 1.8 倍。
2. **一个零件里的矛盾**：输出要大（腹板薄）、刚度要高（侧壁厚）、过载要扛（应力低）——轮辐 + 剪切腹板把三者分给不同的部位。
3. **抵消靠对称**：径向力在单根轮辐上有 3.8 %FS 的串扰，相对轮辐串联后 0.006 %FS；对称要靠加工（四个腹板一样厚）和粘片（贴在正中）保证。
4. **小直径的结合面要算摩擦**：内毂 M5 不够，改 M6 加锥销。

## 留给学生的问题

1. 在“仿真与分析”里把腹板改成 0.8 mm，输出、刚度、过载安全系数怎么变？有没有上限？
2. 把四根轮辐改成三根：串联抵消还成立吗？
3. 倾覆力矩让正、反两面的腹板应变反号——只在正面贴片，为什么有限元算出的串扰仍然很小？
