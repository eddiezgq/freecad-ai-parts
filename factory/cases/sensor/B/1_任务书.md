# 设计任务书：关节扭矩传感器的弹性体

**用在哪**　传感器厂的 WQ-TS（应变片全桥，量程 ±200 N·m）。目标客户是协作机器人厂的中关节（和问渠 WQJ-M 同级：谐波减速器 25 号、减速比 100），
传感器装在减速器输出和关节输出法兰之间，直接测关节力矩，用于力控、碰撞检测。

| 项目 | 要求 | 出处 |
|---|---|---|
| 量程 | ±200 N·m（覆盖减速器重复峰值 157 N·m） | 零件库 `D-RDC-HD-CSF/25-100`（厂商目录） |
| 过载 | 300 N·m（150 %FS，覆盖瞬时最大 284 N·m）不屈服，安全系数 ≥ 2 | 同上 |
| 额定输出 | ≥ 1.0 mV/V（全桥，灵敏系数 2.0） | 案例 A 信号调理板的设计输入 |
| 扭转刚度 | ≥ 4 × K3 = 2.28e+05 N·m/rad（与减速器串联后关节刚度下降 ≤ 20 %） | 零件库 K3 = 5.7e+04 N·m/rad |
| 串扰 | 径向力 1000 N、倾覆力矩 20 N·m 引起的输出 ≤ 0.5 %FS | 本案例设定 |
| 外形 | 外径 ≤ 90 mm（减速器外径 85 mm）、中空 ≥ Ø20（走线） | 关节结构 |
| 材料 | 17-4PH 不锈钢（清单 BODY-TS） | 传感器厂清单 |

**要定的**：弹性体结构、轮辐和腹板尺寸、应变片位置、安装螺钉；外协加工要求。
