# 问渠CAM 试用说明

谢谢你来试用问渠CAM。试用的目的是找出问题：哪里算错、哪里卡住、哪里不好用、哪里和车间的做法不一样。**你遇到的每一个问题对我们都有用**，不用担心问得太简单。

## 1. 安装

1. 运行 `WenQuest-CAM-Setup-<版本>.exe`，按提示装（Windows 10 / 11，64 位；安装包自带 FreeCAD 和需要的组件）。
2. 从开始菜单打开“问渠CAM”，第一次启动直接进入问渠CAM 工作台。
3. 开始菜单里有用户手册、验证手册和入门例子。

## 2. 先做两个入门例子（半小时）

照用户手册“第一次用”两节做一遍：

- 例子 1：车一根阶梯轴（两次装夹、切槽、车螺纹）；
- 例子 2：铣一个带型腔和孔的块。

每个例子做到：起草 → 确认工序 → 计算并检查 → 回放 → 保存程序与工艺卡。做完把你的程序和入门例子文件夹里的样张对一下。

## 3. 按角色试用

**培训班学员**（重点：会不会用、看不看得懂）

- [ ] 拿一个自己画的回转体零件，从模型走到程序；
- [ ] 拿一个自己画的 2.5 轴铣削零件（型腔、外轮廓、孔、螺纹孔），从模型走到程序；
- [ ] 回放：拖动进度条，看刀具怎么走、程序窗口是不是跟着走；
- [ ] 打开工艺卡：零件图、装夹图、刀具图看不看得懂，表里的数是不是你设的；
- [ ] 检查清单里的红、黄、灰几条，每条你知道该怎么办吗？

**合作厂工艺员**（重点：结果对不对、能不能直接用）

- [ ] 在“机床”窗口里建你们的机床（行程、最高转速、功率、换刀时间），在“刀具库”窗口里建你们常用的刀；
- [ ] 按你们的程序写法写一份后处理配置（用户手册“后处理配置”一节），或者把你们的一个程序发给我们，由我们来写；
- [ ] 拿车间正在做的零件出程序，用作业面板的“程序对比…”和车间现在的程序比：刀具、转速、进给、时间差在哪；
- [ ] 工艺卡能不能直接下发到车间？缺什么、多什么；
- [ ] 上机：**首件一律空运行、单段试切**。记下实际时间与软件算的时间。

## 4. 出了问题怎么办

1. 在问渠CAM 菜单里点“问题反馈…”；
2. 写几句：做了什么、哪里不对、本来应该是什么样（有截图更好，另外发）；
3. 点“生成反馈包…”，选一个文件夹，会生成 `wenquest-cam-feedback-日期-时间.zip`；
4. 把这个 zip 发给我们（微信或邮件）。

反馈包里有：你写的话、软件和系统版本、当前文档的副本、你的刀具库 / 机床 / 后处理配置、报错文字。**不含授权文件。**
零件模型如果是保密的，请先说一声，我们另商量（比如换一个相似的零件复现）。

我们收到后登记进问题清单，改好后告诉你在哪个版本里。
