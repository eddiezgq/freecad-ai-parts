# 企业上线清单（ADR-0063）

问渠数字工厂企业安装版上线前，企业要准备好下面这些。我们据此远程部署（`factory/enterprise/deploy.sh`），装好后与企业一起按第三节验收。

## 一、企业要准备的

| 项目 | 要求 | 备注 |
| --- | --- | --- |
| 服务器 | 4 核、16 GB 内存、100 GB 磁盘起；Ubuntu 22.04 或 24.04；x86-64 | 云服务器或内网机器都行。有限元、流体计算多时加到 8 核 32 GB |
| Docker | Docker Engine 与 compose 插件 | 没装时运行 `curl -fsSL https://get.docker.com \| sh` |
| 域名 | 两个：工作台（如 `factory.企业.com`）与 ERPNext（缺省 `erp.` 加工作台域名），都解析到服务器 | 国内云服务器上的域名要先备案 |
| 端口 | 对外开放 80、443（网页）、8883（现场网关）；SSH 只对部署人员开放 | 其他端口不要开 |
| SSH 账号 | 给我们一个能 sudo、用 SSH 密钥登录的账号 | 部署完可以收回 |
| 管理员 | 指定数字工厂管理员一人（建第一个账号）、ERPNext 管理员一人 | 管理员再给其他人开账号、分角色 |
| AI 密钥 | 国内：DeepSeek 密钥；其他地方：Claude 密钥。两家都给更好（一家出错换另一家） | 不给也能用，AI 助手改用规则回答 |
| 邮件（可选） | SMTP 服务器、账号 | 厂情提醒发邮件用 |
| 现场网关 | 工厂里一台小工控机：Ubuntu、Docker，能访问云端 8883 | 车间设备与采集器连它 |
| 设备清单 | 每台设备的名称、型号、所在工序、通讯方式（OPC UA、Modbus、PLC 型号与地址表）、要采的数据点 | 用来配置设备接入 |
| 主数据 | 物料、BOM、工艺路线、客户、供应商、期初库存（按我们给的 Excel 模板） | 导入 ERPNext 与数字工厂 |
| 产品方案 | 用 FreeCAD AI Parts 发布到工厂，或提供图纸与工艺路线 | 新产品经“转为生产物料”进入 ERP、MRP、MES |

## 二、我们做的

1. 远程部署：`deploy.sh 用户@服务器 --domain … --email … --admin …`（自动 HTTPS、真 ERPNext、首次备份）
2. 按地区设 AI：国内 DeepSeek、其他地方 Claude（`--region`，或按服务器时区推断）
3. 设定时备份：每天一次（`/etc/cron.d/fap-backup`），备份包复制到企业指定的另一处存储
4. 把现场网关连接包（`gateway-bundle/`）交给企业网关管理员，指导装好网关
5. 导入主数据；把企业产品经“转为生产物料”建进 ERPNext
6. 培训：管理员开账号、分角色；各岗位在工作台上的日常操作

## 三、上线验收

| 检查 | 怎么看 |
| --- | --- |
| HTTPS | 浏览器打开工作台与 ERPNext 两个域名，证书有效，没有警告 |
| 账号 | 管理员能登录、能开账号；普通账号只能用分给他的角色；输错 5 次会锁 |
| AI | 厂情中枢 → AI 运行记录：显示的模型与地区相符；问 AI 助手一个问题能回答 |
| ERP | 发布一个产品方案，经“转为生产物料”在 ERPNext 里看到物料与 BOM |
| MRP、MES | 下一张订单，看到工单与请购；工单下达到车间 |
| 现场网关 | 车间设备的状态在看板上实时显示；断开网关网络几分钟再恢复，数据补上 |
| 备份 | `status.sh` 显示最近备份；在别的机器上用 `restore.sh` 恢复演练一次 |

## 四、目前的限制（下一阶段解决）

- 车间设备、工作站、工序表还是问渠减速器厂那一套；企业自己的车间布局需要导入工具
- ERPNext 的公司按演示公司建（币种美元），企业的公司名称、币种、会计科目要手动调整
