# 企业上线清单（ADR-0063）

问渠数字工厂企业安装版上线前，企业要准备好下面这些。我们据此远程部署（`factory/enterprise/deploy.sh`），装好后与企业一起按第三节验收。

## 一、企业要准备的

| 项目 | 要求 | 备注 |
| --- | --- | --- |
| 服务器 | 4 核、16 GB 内存、100 GB 磁盘起；Ubuntu 22.04 或 24.04；x86-64 | 云服务器或内网机器都行。有限元、流体计算多时加到 8 核 32 GB |
| Docker | Docker Engine 与 compose 插件 | 没装时运行 `curl -fsSL https://get.docker.com \| sh` |
| 域名 | 两个：工作台（如 `factory.企业.com`）与 ERPNext（缺省 `erp.` 加工作台域名），都解析到服务器 | 国内云服务器上的域名要先备案 |
| 端口 | 对外开放 80、443（网页）、8883（现场网关）；SSH 只对部署人员开放 | 其他端口不要开 |
| SSH 账号 | 给我们一个能 sudo、用 SSH 密钥登录的账号 | 部署完可以收回 |
| 管理员 | 指定数字工厂管理员一人（建第一个账号）、ERPNext 管理员一人 | 管理员再给其他人开账号、分角色 |
| AI 密钥 | 国内：DeepSeek 密钥；其他地方：Claude 密钥。两家都给更好（一家出错换另一家） | 不给也能用，AI 助手改用规则回答 |
| 邮件（可选） | SMTP 服务器、账号 | 厂情提醒发邮件用 |
| 现场网关 | 工厂里一台小工控机：Ubuntu、Docker，能访问云端 8883 | 车间设备与采集器连它 |
| 工厂清单 | 按 Excel 模板填：公司、工作站、每台设备（位置、尺寸）、工序、班次、指标目标（见第五节） | 数字工厂按它建车间 |
| 设备接入 | 每台设备的型号、通讯方式（OPC UA、Modbus、PLC 型号与地址表）、要采的数据点 | 用来配置设备接入 |
| 主数据 | 物料、BOM、工艺路线、客户、供应商、期初库存（按我们给的 Excel 模板） | 导入 ERPNext 与数字工厂 |
| 产品方案 | 用 FreeCAD AI Parts 发布到工厂，或提供图纸与工艺路线 | 新产品经“转为生产物料”进入 ERP、MRP、MES |

## 二、我们做的

1. 远程部署：`deploy.sh 用户@服务器 --domain … --email … --admin … --plant plant.yaml`（自动 HTTPS、真 ERPNext、按企业的工厂清单建公司与车间、首次备份）
2. 按地区设 AI：国内 DeepSeek、其他地方 Claude（`--region`，或按服务器时区推断）
3. 设定时备份：每天一次（`/etc/cron.d/fap-backup`），备份包复制到企业指定的另一处存储
4. 把现场网关连接包（`gateway-bundle/`）交给企业网关管理员，指导装好网关
5. 导入主数据；把企业产品经“转为生产物料”建进 ERPNext
6. 培训：管理员开账号、分角色；各岗位在工作台上的日常操作

## 三、上线验收

| 检查 | 怎么看 |
| --- | --- |
| HTTPS | 浏览器打开工作台与 ERPNext 两个域名，证书有效，没有警告 |
| 账号 | 管理员能登录、能开账号；普通账号只能用分给他的角色；输错 5 次会锁 |
| AI | 厂情中枢 → AI 运行记录：显示的模型与地区相符；问 AI 助手一个问题能回答 |
| ERP | 发布一个产品方案，经“转为生产物料”在 ERPNext 里看到物料与 BOM |
| MRP、MES | 下一张订单，看到工单与请购；工单下达到车间 |
| 现场网关 | 车间设备的状态在看板上实时显示；断开网关网络几分钟再恢复，数据补上 |
| 备份 | `status.sh` 显示最近备份；在别的机器上用 `restore.sh` 恢复演练一次 |

## 四、目前的限制（下一阶段解决）

- 企业的车间按工厂清单建（第五节，`install.sh --plant`）；ERPNext 的公司、国家、币种、时区按清单。会计科目用 ERPNext 的标准科目表，企业按需调整
- 工作日历只排了清单里的休息日，法定节假日要在 ERPNext 里补
- 换工厂清单（`upgrade.sh --plant`）只补建新的工作站与工序，公司不随之改
- 只服务教学的页面（输出轴设计台、实验 15、虚拟 PLC 示例）只在演示工厂里显示

## 五、工厂清单（ADR-0064）

企业的车间用一份工厂清单（`plant.yaml`）描述。企业填 Excel，我们转成清单：

```bash
python -m factory.plant template 工厂清单.xlsx         # 模板，按演示工厂填好作样例
python -m factory.plant import 工厂清单.xlsx plant.yaml # 转成清单并校验；有错列出“哪张表第几行哪一列”
python -m factory.plant check plant.yaml              # 只校验
```

（在服务器上可用 `docker compose exec factory python -m factory.plant …`。）

| 表 | 每行是 | 要点 |
| --- | --- | --- |
| 工厂 | 一个项目 | 公司名称、缩写、国家（英文）、币种、时区；原材料库、成品库（设备编号）；车间长宽、横向主通道 y、纵向通道 x；班次时段、工作日、加班上限；准时交付、设备综合效率、一次合格率目标；是否装演示数据 |
| 工作站 | 一组同类设备 | 名称（ERPNext 工作站名）、台数、每小时折旧 / 人工 / 能耗费率；可选主电机功率与传动效率 |
| 设备 | 一台设备 | 编号（小写字母、数字、-）、区域、中文 / 英文名、所属工作站；平面位置：中心 x、y 与宽、深（米，原点在车间左下角）、高；可选上下料点、看板顺序、仿真参数（同时加工件数、换型、刀具磨损、换刀、主轴转速与进给）；物流小车要填停靠点 |
| 工序 | 一道工序 | 工序名（与工艺路线一致）、工作站、可用设备（编号，逗号分开）、阶段、是否检验 |
| 供应商、客户 | 一家 | 可空 |

规则：

- 不知道的格子留空，不要写 0 代替；仿真参数留空时用缺省（每次 1 件、不计换型与磨损）
- 工序用到的工作站、设备必须在表里；每个工作站至少一台设备；设备编号不重复；位置在车间内；至少一台物流小车
- 总线主题根（`wq/gearbox`）与五类仓库（原材料、外购件、半成品、在制品、成品）固定，不在清单里配；仓库名后缀是公司缩写
- 演示工厂的清单在 `factory/plants/wenquest-gearbox.yaml`

### 设备的维护、能耗与经营财务（ADR-0073，可选）

清单写了产品的厂（第 2 版）打开“设备维护、能源、经营财务”三页。每台设备按编号前缀认类别（`saw` 锯床、`cnc` 车床、`vmc`/`hmc` 加工中心、
`grd` 磨床、`cmm`/`qc` 测量、`ja`/`asm`/`ra`/`aa` 装配、`jt`/`test` 测试台、`cal` 标定、`run` 跑合台、`at` 调试场地，其余通用），
取一组**示例缺省值**（`factory/factory/equip.py`）。要用企业自己的数，在 YAML 清单里给这台设备写：

```yaml
- id: cnc-r1
  ...
  maint: {value: 65000, bought: 2022, pm_text: 换主轴润滑脂, pm_min: 120, repair_usd: 700, lost_per_h: 80,
          beta: 2.5, eta_h: 1400, mttr_min: 240, pm_h: 600, init_h: 0}   # 不知道的不写
  power_kw: [15, 5, 0.6]                                               # 运行、空转、待机
```

客户的信用额度、付款习惯、月度预算、期初现金写在顶层 `finance`（`credit`、`late_days`、`budget`、`opening_cash`、`weekly_expense`），不写按缺省。
Excel 版清单暂不带这几项。
