# ADR-0101：多体动力学里的大变形柔性梁（几何精确梁，对标 ADAMS FE Part）

- 状态：已接受
- 日期：2026-11-18

## 背景

ADR-0097 D6 的柔性构件是“浮动坐标系 + 模态”，只能算**线性小变形**。ADR-0098 E2 碰到了它算不了的情况：细长铝杆受压超过欧拉临界载荷后
屈曲，梁元件链（几何非线性）算出来了，柔性构件算不出来。ADAMS 用 **FE Part**（几何精确梁）补这一块，用来算：

- 大挠度：悬臂梁端部受大力矩卷成圆，受大横向力的“弹性线”。
- 失稳：受压屈曲。
- 离心刚化：旋转梁升速时，线性模态法会算出虚假的发散（Kane 1987 的经典反例）。

这些在机器人里常见：细长连杆、柔性臂、线缆、弹簧片、传送带。这是 ADR-0098 收尾时写明的最后一个主要差距。

现在的梁元件链（刚体段 + `beam` 力元）虽然几何非线性，但有几个问题：

- 要手工建几十个构件。
- 力元在 i 构件系里列式，不对称，相邻段相对转角大时不准。
- 没有截面内力和应力输出。

## 决策

`bodies[].flex` 加一种 `type: "nonlinear_beam"`（大变形梁），程序自动展开成节点构件和几何精确梁单元。

1. **离散**：
   - 直梁从 `from_mm` 到 `to_mm` 分 `elements` 段，`elements + 1` 个节点。每个节点是一个内部构件（位置 + 欧拉参数），id 为 `梁id.n0 … 梁id.nN`。
   - 节点质量：相邻单元各分一半质量（ρAL/2）和转动惯量（ρI·L/2，按截面轴）。
   - 这就是离散 Cosserat 杆，单元数趋于无穷时收敛到 Simo–Reissner 几何精确梁。
2. **单元**（内部力元，不写进 schema）：
   - 用两节点相对转动的“中间构架”Rₘ = Rᵢ·exp(θ/2) 列式，θ 是 Rᵢᵀ Rⱼ 的转动向量。
   - 应变：Γ = Rₘᵀ(pⱼ − pᵢ)/L₀ − e₁（轴向、剪切）；曲率 K = θ/L₀（扭转、弯曲）。都在梁截面系里。
   - 内力：n = diag(EA, κGA, κGA)·Γ，m = diag(GJ, EIy, EIz)·K，κ 缺省 5/6。
   - 节点力：fⱼ = Rₘn，fᵢ = −fⱼ。节点力矩：Mⱼ = Rₘm − ½ d×fⱼ，Mᵢ = −Rₘm − ½ d×fⱼ（d = pⱼ − pᵢ）。合力、合力矩为零。
   - 列式对整体刚体转动不变：整体转动时没有内力。
   - 阻尼：刚度比例，系数 `stiffness_damping_s`（s），作用在应变速度上。字段名直接写单位，避免和阻尼比混淆（ADR-0098 补充二）。
3. **运动副、力**：
   - 模型里 `body: 梁id` 加 `point_mm` 的运动副和力，挂到离这个点最近的节点上；离节点超过 `FLEX_SNAP_MM` 就报错。
   - 梁两端和任一节点都可以挂。
4. **静力大变形**：`analysis` 加 `load_steps`（静平衡分几步加载，缺省 1）。外力和重力按 k/N 逐步加，每步用上一步的解起步。
   悬臂梁卷成圆这类强非线性问题，一步解不出来。
5. **输出**：`flex[梁id]` 给每帧、每个单元的：
   - 轴力、两个剪力、扭矩、两个弯矩。
   - 节点位置。
   - 给了截面外缘距离（`fiber_y_mm`、`fiber_z_mm`）时，加上最大正应力 σ = |N|/A + |My|·z/Iy + |Mz|·y/Iz（MPa）。
   节点构件照常出现在 `bodies` 里。
6. **积分器**：有大变形梁时，`advise` 建议用 HHT，rtol 1e-7（同梁元件链）。

## 分步

| 步 | 内容 | 验收（解析解 / 经典标准题） |
| --- | --- | --- |
| F1 | `nonlinear_beam` 展开、几何精确梁单元、内力与应力输出、静平衡分步加载 | 小挠度悬臂 PL³/3EI（含剪切）误差 < 1%；端部力矩 M = πEI/L 卷成半圆，端点 (0, 2L/π)，误差 < 1%；大挠度弹性线 PL²/EI = 1：端点 w/L = 0.30172、u/L = 0.05643（Mattiasson 1981），误差 < 1%；整体刚体转动无内力 |
| F2 | 动力学：屈曲、离心刚化；HHT 建议；与线性柔性体对比 | 受压线性化：一阶弯曲频率平方随压力线性下降，外推到零得临界载荷，对欧拉公式误差 < 2%；旋转梁升速（Kane 1987）：大变形梁端部挠度有界、稳态 < 1 mm 级，线性模态柔性体（D6）发散 |
| F3 | FreeCAD：细长零件选“大变形梁”（截面由零件自动量出），变形和应力显示，帮助，计算报告事实 | 窗口走一遍；截面面积、惯性矩与解析值一致；帮助写清三种柔性怎么选 |

## 理由

- **为什么用离散 Cosserat**：
  - 节点就是构件，现有的约束、力元、积分器（HHT 分组差分，链只要 3 组）、输出全部直接复用。
  - 物理上就是几何精确梁的有限差分，每个量都有明确的力学含义，验收题都有解析解或经典数值。
- **没选的方案**：
  - ANCF（绝对节点坐标法）：要另一套坐标和质量阵，与现有刚体欧拉参数框架接不上；剪切闭锁要特殊处理。
  - 实体非线性有限元联合仿真（CalculiX 非线性）：重，而且绝大部分机器人场景的大变形件是细长件，梁够用。以后有需要另议。
  - 只改进现有 `beam` 力元：仍然要手工建一串构件，也没有截面内力。

## 影响

- `schema/mbd-model.schema.json`：
  - `flex` 加 `nonlinear_beam` 一支：几何、材料、截面、`elements`、`shear_factor`、`stiffness_damping_s`、`fiber_y_mm`、`fiber_z_mm`。
  - `analysis` 加 `load_steps`。
  - schema 改动单独成 PR（本 ADR 的 PR）。
- 线性柔性构件（`beam`、`modal`）不变。帮助里写清：
  - 小变形、高频、实体零件用模态柔性体；
  - 细长件、大变形、屈曲、旋转刚化用大变形梁。
