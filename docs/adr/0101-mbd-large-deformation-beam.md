# ADR-0101：多体动力学里的大变形柔性梁（几何精确梁，对标 ADAMS FE Part）

- 状态：已接受
- 日期：2026-11-18

## 背景

ADR-0097 D6 的柔性构件是“浮动坐标系 + 模态”，只能算**线性小变形**。ADR-0098 E2 碰到了它算不了的情况：细长铝杆受压超过欧拉临界载荷后
屈曲，梁元件链（几何非线性）算出来了，柔性构件算不出来。ADAMS 用 **FE Part**（几何精确梁）补这一块，用来算：

- 大挠度：悬臂梁端部受大力矩卷成圆，受大横向力的“弹性线”。
- 失稳：受压屈曲。
- 离心刚化：旋转梁升速时，线性模态法会算出虚假的发散（Kane 1987 的经典反例）。

这些在机器人里常见：细长连杆、柔性臂、线缆、弹簧片、传送带。这是 ADR-0098 收尾时写明的最后一个主要差距。

现在的梁元件链（刚体段 + `beam` 力元）虽然几何非线性，但有几个问题：

- 要手工建几十个构件。
- 力元在 i 构件系里列式，不对称，相邻段相对转角大时不准。
- 没有截面内力和应力输出。

## 决策

`bodies[].flex` 加一种 `type: "nonlinear_beam"`（大变形梁），程序自动展开成节点构件和几何精确梁单元。

1. **离散**：
   - 直梁从 `from_mm` 到 `to_mm` 分 `elements` 段，`elements + 1` 个节点。每个节点是一个内部构件（位置 + 欧拉参数），id 为 `梁id.n0 … 梁id.nN`。
   - 节点质量：相邻单元各分一半质量（ρAL/2）和转动惯量（ρI·L/2，按截面轴）。
   - 这就是离散 Cosserat 杆，单元数趋于无穷时收敛到 Simo–Reissner 几何精确梁。
2. **单元**（内部力元，不写进 schema）：
   - 用两节点相对转动的“中间构架”Rₘ = Rᵢ·exp(θ/2) 列式，θ 是 Rᵢᵀ Rⱼ 的转动向量。
   - 应变：Γ = Rₘᵀ(pⱼ − pᵢ)/L₀ − e₁（轴向、剪切）；曲率 K = θ/L₀（扭转、弯曲）。都在梁截面系里。
   - 内力：n = diag(EA, κGA, κGA)·Γ，m = diag(GJ, EIy, EIz)·K，κ 缺省 5/6。
   - 节点力：fⱼ = Rₘn，fᵢ = −fⱼ。节点力矩：Mⱼ = Rₘm − ½ d×fⱼ，Mᵢ = −Rₘm − ½ d×fⱼ（d = pⱼ − pᵢ）。合力、合力矩为零。
   - 列式对整体刚体转动不变：整体转动时没有内力。
   - 阻尼：刚度比例，系数 `stiffness_damping_s`（s），作用在应变速度上。字段名直接写单位，避免和阻尼比混淆（ADR-0098 补充二）。
3. **运动副、力**：
   - 模型里 `body: 梁id` 加 `point_mm` 的运动副和力，挂到离这个点最近的节点上；离节点超过 `FLEX_SNAP_MM` 就报错。
   - 梁两端和任一节点都可以挂。
4. **静力大变形**：`analysis` 加 `load_steps`（静平衡分几步加载，缺省 1）。外力和重力按 k/N 逐步加，每步用上一步的解起步。
   悬臂梁卷成圆这类强非线性问题，一步解不出来。
5. **输出**：`flex[梁id]` 给每帧、每个单元的：
   - 轴力、两个剪力、扭矩、两个弯矩。
   - 节点位置。
   - 给了截面外缘距离（`fiber_y_mm`、`fiber_z_mm`）时，加上最大正应力 σ = |N|/A + |My|·z/Iy + |Mz|·y/Iz（MPa）。
   节点构件照常出现在 `bodies` 里。
6. **积分器**：有大变形梁时，`advise` 建议用 HHT，rtol 1e-7（同梁元件链）。

## 分步

| 步 | 内容 | 验收（解析解 / 经典标准题） |
| --- | --- | --- |
| F1 | `nonlinear_beam` 展开、几何精确梁单元、内力与应力输出、静平衡分步加载 | 小挠度悬臂 PL³/3EI（含剪切）误差 < 1%；端部力矩 M = πEI/L 卷成半圆，端点 (0, 2L/π)，误差 < 1%；大挠度弹性线 PL²/EI = 1：端点 w/L = 0.30172、u/L = 0.05643（Mattiasson 1981），误差 < 1%；整体刚体转动无内力 |
| F2 | 动力学：屈曲、离心刚化；HHT 建议；与线性柔性体对比 | 受压线性化：一阶弯曲频率平方随压力线性下降，外推到零得临界载荷，对欧拉公式误差 < 2%；旋转梁升速（Kane 1987）：大变形梁端部挠度有界、稳态 < 1 mm 级，线性模态柔性体（D6）发散 |
| F3 | FreeCAD：细长零件选“大变形梁”（截面由零件自动量出），变形和应力显示，帮助，计算报告事实 | 窗口走一遍；截面面积、惯性矩与解析值一致；帮助写清三种柔性怎么选 |

## 理由

- **为什么用离散 Cosserat**：
  - 节点就是构件，现有的约束、力元、积分器（HHT 分组差分，链只要 3 组）、输出全部直接复用。
  - 物理上就是几何精确梁的有限差分，每个量都有明确的力学含义，验收题都有解析解或经典数值。
- **没选的方案**：
  - ANCF（绝对节点坐标法）：要另一套坐标和质量阵，与现有刚体欧拉参数框架接不上；剪切闭锁要特殊处理。
  - 实体非线性有限元联合仿真（CalculiX 非线性）：重，而且绝大部分机器人场景的大变形件是细长件，梁够用。以后有需要另议。
  - 只改进现有 `beam` 力元：仍然要手工建一串构件，也没有截面内力。

## 影响

- `schema/mbd-model.schema.json`：
  - `flex` 加 `nonlinear_beam` 一支：几何、材料、截面、`elements`、`shear_factor`、`stiffness_damping_s`、`fiber_y_mm`、`fiber_z_mm`。
  - `analysis` 加 `load_steps`。
  - schema 改动单独成 PR（本 ADR 的 PR）。
- 线性柔性构件（`beam`、`modal`）不变。帮助里写清：
  - 小变形、高频、实体零件用模态柔性体；
  - 细长件、大变形、屈曲、旋转刚化用大变形梁。

## 补充一：F1 完成（2026-11-18）

- 代码：
  - `analysis/mbd/dae/nlbeam.py`：展开、几何精确梁单元。
  - `model.py`：先展开，再建系统，最后把单元加进力元。
  - `system.py`：`nlbeam` 力元；`load_scale` 只缩放重力和外加力、力矩。
  - `solve.py`：分步加载、静平衡牛顿法。
  - `run.py`：`flex[梁id]` 输出截面内力、节点位置、最大正应力。
  - `hht.py`：耦合关系认 `nlbeam`。
  - `advise.py`：大变形梁按梁处理，HHT，rtol 1e-7。
- 验收（`tests/test_mbd_nlbeam.py`，钢圆杆 φ20 × 1000 mm，EI = 1617.9 N·m²）：

  | 标准题 | 单元 | 结果 | 要求 |
  | --- | --- | --- | --- |
  | 小挠度，端部 1 N | 20 | 端部挠度差 0.06%；根部弯矩、最大应力差 1e-3 内 | < 1% |
  | 端部力矩 πEI/L，10 步加载 | 40 | 卷成半圆：端点 x = 9e-10 L，y 差 0.03%；各单元弯矩都等于 M | < 1% |
  | 弹性线 PL²/EI = 1，5 步加载 | 40 | w/L 差 0.01%，u/L 差 0.004%（对 Mattiasson 1981） | < 1% |
  | 整体刚体转动 + 平移 + 角速度（含阻尼） | — | 内力 < 1e-6 | 无内力 |
  | 力挂在节点之间 | — | 报错说明节点间距 | 报错 |

- 写回（施工中改的做法）：
  1. **节点 id 改为 `梁id__nK`**：原定 `梁id.nK`，但 schema 的 id 不允许“.”。
     schema 里的 `torque` 没有作用点，挂不到梁上，所以模型里可以直接引用节点 id，例如 `"body": "rod__n40"`。
  2. **静平衡用自己的牛顿法**（有大变形梁时）：
     - scipy 的 hybr（逐列差分、信赖域）在弹性线第一步就卡住（残差 32 N）。
     - 改成 [[∂(Φqᵀλ − Q)/∂q, Φqᵀ], [Φq, 0]] 的牛顿法，力的导数用 E2 的分组差分，不做线搜索。
       大变形的第一步常把残差先放大（约束先满足、力随后回来），随后二次收敛；线搜索会把这一步拒掉。
     - hybr 留作后备。
  3. **静平衡残差判据按力的量级**：原来力的残差一律要 ≤ 1e-6 N。大变形梁内力上万牛，舍入噪声就有 1e-5 N 级，改成 ≤ max(1e-6, 1e-8 × 最大力)。
     约束残差改成 ≤ 1e-9 m（原来 1e-6，收紧了）。
- 已知：半圆题（41 个节点，10 步加载）静平衡要 50 s，时间都在牛顿迭代里，F2 再看。

## 补充二：F2 完成（2026-11-18）

- **屈曲与几何刚度**（`test_buckling_load_from_frequency_vs_axial_force`）：
  - 题目：钢圆杆 φ20 × 1000 mm，两端铰支（面内），20 单元。
  - 做法：分别加压力 0.4 Pcr、拉力 0.2 Pcr、拉力 0.6 Pcr，先静平衡再线性化，取一阶弯曲频率。
  - 结果：f² 对轴力是直线（压力降、拉力升）。外推到 f = 0 得临界载荷，对欧拉公式 π²EI/L² 差 0.38%（要求 < 2%）；零轴力频率差 0.05%。
  - 对照：线性模态柔性体（D6）的频率不随轴力变（差 < 1e-6），算不出屈曲。
- **旋转梁升速**（Kane、Ryan、Banerjee 1987）：
  - 题目：L = 10 m，EI = 14000 N·m²，ρA = 1.2 kg/m；15 s 升到 6 rad/s 再匀速，仿真 20 s。
  - 大变形梁：梁端横向挠度（随转动坐标系）在 t ≈ 7 s 达到最大，升速结束后回到毫米级，并且保持住。

    | 单元数 | 最大挠度 | 15 s 后 | 用时 |
    | --- | --- | --- | --- |
    | 10 | −0.5752 m | < 5 mm | 210 s |
    | 20 | −0.5724 m（与 10 单元差 0.5%，网格已收敛） | < 5 mm | 366 s |

  - 线性模态柔性体（D6）：最大 −0.680 m，比大变形梁大 18%，随后也回到毫米级。
  - 写回：原定验收是“D6 发散”，实际没有发散。
    - Kane 的发散发生在“随轮毂转动的参考系 + 悬臂模态”的线性列式里；D6 是浮动参考系 + Craig-Bampton，整体转动由参考系承担，弹性坐标小。
    - D6 在这题里的误差是 18%，不是发散。验收改为“大变形梁网格收敛、升速后回到毫米级；与 D6 的差别如实记录”。
  - 单次要几分钟，不放进测试，做成验证脚本 `scripts/mbd_spinup_check.py`，结果记在这里。
- **成批计算**：
  - 改动：全部大变形梁单元在 `nlbeam.Batch` 里用 numpy 一次算完，与逐个单元一致（含阻尼、任意位形，`test_batch_equals_element_by_element`）。
  - 效果：半圆题静平衡 50 s → 17 s；升速题（10 单元）345 s → 210 s。剩下的时间主要在雅可比、约束和质量阵的逐构件计算，以后需要再提速。
- 帮助：`docs/mbd-help.md` 补充“什么时候必须用大变形梁”和“怎么求屈曲载荷”。

## 补充三：F3 的 schema 改动——指定必须是节点的点（2026-11-18）

- 问题：FreeCAD 里的细长零件，运动副多在孔中心，孔离杆端有一段距离。按均分节点，运动副点一般不在节点上（F1 的规则会报错）。
  把梁的起止点改到孔中心，又会丢掉两端伸出段的质量和柔性。
- 决定：`nonlinear_beam` 加可选 `nodes_at_mm`（地面系的点，最多 50 个）。展开时投影到梁轴上，并入节点表；相邻节点间距不等，各单元按自己的长度算刚度和质量。
  点离梁轴超过梁长的千分之一就报错；投影点和已有节点挨得很近（小于均分间距的 1/4）时，不另加节点，把那个节点挪到投影点上，免得出现极短单元。
- schema 改动单独成 PR（本 PR）；实现在 F3 的 PR 里。

## 补充四：F3 完成，ADR-0101 收尾（2026-11-18）

- `nlbeam.py`：`nodes_at_mm` 的实现。投影点离均分节点不到 1/4 间距就挪那个节点；但两端节点不挪（梁长不变），改在旁边加一个，这时会出现短单元。
  这一点修正补充三的说法：“不会出现极短单元”只对中间节点成立。
- `freecad_addon/fc/mbd_flex.py`：
  - `beam_from_part` 从零件量出梁的参数：
    - 梁轴取最小主惯量方向，长度取零件在梁轴上的投影范围。
    - 在 ¼、½、¾ 长度处各切一个截面，面积相差 > 2% 就报“不是等截面直杆”；长细比 L/√A < 8 就报“不够细长”。
    - 惯性矩由中间截面的面积惯性张量算，取主方向；扭转常数用圣维南近似。
    - 截面外缘距离由截面边界量出。
    - 运动副点进 `nodes_at_mm`。
  - `make_flexible` 认 `kind: "nonlinear_beam"`。说明里同时给出梁质量和实体质量，梁不计孔、倒角。
  - `BeamShow`：动画里画节点折线，颜色随最大应力变。
- 窗口：柔性零件下拉框里加“大变形梁：材料”。`Animator` 认大变形梁。
- 报告：`assist/mbd_report.py` 加大变形梁的最大正应力、轴力、两个弯矩，数字照样对回结果。
- 帮助：窗口操作、量截面的规则和近似。
- 验收：
  - `tests/test_fc_mbd_nlbeam.py`（FreeCAD）：
    - 矩形杆 300 × 10 × 6 任意摆放：长度、截面积、Iyy、Izz、外缘距离与解析值差 < 1e-6，端点、截面 y 轴对。
    - 短粗块、锥杆都报错。
    - 带孔摆杆：孔中心进 `nodes_at_mm`，自动建议 HHT，能算；动画折线与结果节点一致，复位后删掉。
  - `tests/test_fc_mbd_study.py`：窗口里选大变形梁。
  - `tests/test_mbd_nlbeam.py::test_nodes_at_points_nonuniform`：不等长单元。
    - 总质量守恒。
    - 中间点受力时，端部挠度对 Pa²(3L − a)/6EI，差 < 1%。
    - 点不在梁轴上时报错。
  - `tests/test_mbd_report.py`：大变形梁的数字进报告、可追溯。

**ADR-0101 收尾**：F1–F3 完成。
- 多体模块现在有三种柔性：模态梁、实体模态（小变形、高频、应力云图），以及大变形梁（大挠度、屈曲、旋转刚化）。
- 与 ADAMS 相比还没有的：
  - 实体零件的非线性大变形（ADAMS 要和 Marc 联合仿真）；
  - 变截面梁。
- 两者都不在本 ADR 范围内，需要时另议。
