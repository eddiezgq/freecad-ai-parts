# ADR-0077：机器人厂实验 29“一台机器人的售后追溯”

- 状态：已接受（2026-11-01 项目负责人确认问渠仓库第 68 轮细则 Q1、Q2）
- 日期：2026-11-01
- 补充：ADR-0075（现场的机器人）、ADR-0076（AI 巡检与助手）、ADR-0068（共用一份代码）

## 决策

1. 评分模块 `hub/lab29.py`：每个学生种一个场景（同一批问题谐波减速器装在 3 台机器人的 J2 上，1 台超限、2 台还没），六个任务自动评 60 分
   （找报警的机器人和关节、读出厂档案、判原因、定召回范围、派对症工单并做完、比较预防性更换与事后更换的花费），报告 40 分。
2. 只读 / 只用 `hub/rfield.py` 的现场机器人数据和接口；换件记录加上原关节的出厂背隙。场景和费用是示例值，不进零件库。
3. 共有路径，按 ADR-0068 逐字同步；本次顺带补上问渠第 66 轮已上线的共有代码（结构材料与强度、WQ-CR5 模型更新）。
