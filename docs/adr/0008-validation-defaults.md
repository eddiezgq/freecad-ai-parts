# ADR-0008：校验默认值——安全系数 1.2，惯量比告警阈值 10

- 状态：已接受
- 日期：2026-09-30

## 背景

连续扭矩校验需要安全系数，惯量比校验需要告警阈值。规格书中的额定值（尤其是谐波减速器效率）随工况变化，需要留出余量。

## 决策

- 连续扭矩校验（C4）默认安全系数 SF = 1.2，用户可在需求中修改
- 惯量比（C8）告警阈值默认 10，只告警不判失败；仅当需求给出负载惯量时计算

## 理由

1.2 是常见的工程起点，能吸收效率随工况下降等不确定性，又不至于过度放大选型。惯量比的合适上限与控制带宽要求有关，V1 只给出提示，由用户判断。

## 影响

- 需求 schema 包含 `safety_factor`（默认 1.2）与可选的 `load_inertia_kgm2`
- golden 用例须覆盖默认值与用户自定义值两种情况
