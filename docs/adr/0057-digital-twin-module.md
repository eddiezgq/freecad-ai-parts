# ADR-0057：数字孪生模块与寿命参数（M10 第五步）

- 状态：已接受（2026-10-06，按 ADR-0056 的第一批模块顺序）
- 日期：2026-10-06
- 补充：ADR-0056（本地分析模块）、ADR-0055（企业私有库）

## 背景

数字工厂的孪生（第 15 轮）是为 WQR-105 减速器写的：齿轮齿数、轴承位置、箱体散热面积、换油间隔都写死在代码里，其中
传动效率、换油间隔、“每高 10 ℃ 寿命减半”等是教学取值。本项目的孪生要面向企业用选型结果做出的设备：零件来自零件库
（公共库或企业库），参数都有出处。

要算寿命，零件库现在缺两样东西：

- 减速器的额定寿命：厂商样本按“额定寿命 × (额定转矩 / 平均转矩)³ × (额定输入转速 / 平均输入转速)”估算寿命
  （如谐波减速器波发生器轴承的 L10），零件库只有额定转矩，没有额定寿命和定额时的输入转速
- 轴承已有基本额定动载荷 C，可以按 ISO 281 算 L10

## 决策

1. **schema（单独 PR）**：减速器参数加两项，均为可选、非关键字段
   - `rated_life_h`：额定寿命（小时），condition 写明是 L10 还是 L50 以及适用的部件（如“波发生器轴承 L10”）
   - `rated_input_speed_rpm`：额定转矩与额定寿命对应的输入转速
   单位后缀 `_h`（小时）加入单位表
2. **数据**：不在本步补公共库的值；缺这两项时孪生显示“待确认”。企业可用“补数据”或“导入规格书”补
   （字段表取自 schema，新字段自动出现）
3. **孪生模块 `analysis/twin`**（纯 Python，不需要求解器）
   - 输入：BOM 中的零件（实例 → 组件，经零件库取参数）与运行记录（每天或每段：运行小时、减速器输出平均 / 最大扭矩、
     输出转速；轴承的当量径向载荷与转速）；记录可从 CSV 读入
   - 模型（都可手算核对）：
     - 减速器：L = L_r·(T_r/T_av)³·(n_r/n_av)，变工况按 Σ 小时 / Lᵢ 累加（与当量扭矩的三次方平均等价）
     - 轴承：ISO 281 L10 = (C/P)^p × 10⁶ 转，球轴承 p = 3、滚子轴承 p = 10/3（按 bearing_kind）
     - 过载：最大扭矩超过减速器启停允许峰值扭矩 → 报警；超过瞬间最大扭矩 → 严重
   - 输出：每个零件已用寿命的比例、按最近的消耗速度估算的剩余小时、报警（≥ 80% 警告，≥ 100% 严重）、
     缺参数的零件列为“待确认”
   - “假如”：负载、转速按比例变化后重算（寿命按公式变化，如降载 20% → 1/0.8³）
4. 数字工厂里依赖 WQR-105 结构的模型（箱体热平衡油温、换油）不搬：本项目的设备没有这些参数；以后有了对应的零件
   类别与参数再加
5. 现场数据接入（MQTT、传感器）放到 M10 第六步“本地工厂（Docker）”

## 后果

- 孪生只用零件库里有出处的参数；参数缺失不估，结果为待确认
- 公共库的减速器在补上额定寿命之前，孪生的减速器寿命都是待确认
