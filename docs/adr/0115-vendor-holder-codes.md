# ADR-0115：刀杆库收厂家代号的镗杆和螺纹刀片镗杆

- 状态：已接受（2026-11-22，属于 ADR-0106 Q4b）
- 日期：2026-11-22
- 补充：ADR-0112（刀杆库）、ADR-0114（内孔镗杆）

## 背景

内螺纹刀片（ADR-0113）要配螺纹镗杆才知道最小能进的孔。厂家样本里的螺纹镗杆（如泰珂洛 SIR0005H06、SNR0016M16、CNR0025R16）
有 DMIN、DCONMS、WF、LF、LH，但代号是厂家写法，不合 ISO 6261；装的是平装螺纹刀片，按刀片尺寸位（06、08、11、16、22、27）配，
不是 ISO 1832 的形状 + 尺寸。

## 决策

1. cam-holder/1 内孔镗杆可以用厂家代号 `vendor_code`（这时全长 `l1_mm` 必填，代号里读不出长度）；仍要 `bar_d_mm`、`min_bore_mm`。
2. 刀杆能装的刀片可以写螺纹刀片尺寸位 `insert.thread_size`（两位数字），与 `codes` + `size` 二选一。
3. cam-tool/1 的 holder 同样可以是厂家代号的镗杆（`vendor_code`、`bar_d_mm`、`l1_mm`）。
4. 实现（另一个 PR）：起草时内螺纹刀片按尺寸位和小径配螺纹镗杆；碰撞外形同 ADR-0114（圆杆按外接方柱）。

## 影响

- schema 改动单独成 PR（本 ADR）：两个 schema、测试夹具。
