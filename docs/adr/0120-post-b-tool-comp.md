# ADR-0120：后处理配置加 B 轴车铣中心的“沿刀轴刀长补偿”程序行

- 状态：已接受（2026-11-23，属于 ADR-0106 C4a）
- 日期：2026-11-23
- 补充：ADR-0109（可配置后处理）、ADR-0110（车铣动力刀）

## 背景

ADR-0106 C4a 做了 B 轴车铣中心：车刀、铣刀都装在 B 轴主轴上。车削按刀长把刀尖换成机床 X、Z 的位置写（不用刀补，各家通用）；
铣削用极坐标、圆柱插补（G12.1 / G7.1、TRANSMIT / TRACYL），插补里的 X、C 是刀尖相对工件的位置，刀长必须由数控系统沿刀轴补——
B 转到 90° 和 0° 时补的方向不同。各家开这种补偿的写法不一样（有的是专用 G 代码，有的靠参数、刀具数据），问渠不猜。
现在的 `millturn` 只有开 / 关动力刀、切入 / 切出 C 轴四项，写不下这一项，所以 C4a 里 B 轴机床上带铣削段的程序一律不出。

## 决定

`cam-post/1` 的 `millturn` 加一项 `b_tool_comp`：程序行数组（写法与 `live_on` 等相同，FANUC 写法不带括号、逗号），
B 定位之后、开动力刀之前写进程序。没写这一项，B 轴机床（机床文件里刀具一侧有摆动轴）上带铣削段的程序照旧不出，写明原因；
写了才出。其他机床不看这一项。

## 后果

- 机床说明书里查得到写法的企业自己填；示例配置不填（不编）。
- 仿真不管这几行（仿真按刀尖算），回读时跳过它们。
- 这一项只管“开”；关掉随换刀、回原点由数控系统处理——说明书要求另写关闭的，写进 `live_off`。
