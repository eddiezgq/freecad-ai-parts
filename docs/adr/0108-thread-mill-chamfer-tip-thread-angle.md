# ADR-0108：刀具库加螺纹铣刀、倒角刀刀尖直径、螺纹牙型角（cam-tool/1 补充）

- 状态：已接受（2026-11-19，属于 ADR-0106 Q3 已确认的施工细则：Q3b 螺纹铣、倒角，Q3a 锥管螺纹刀片核对）
- 日期：2026-11-19
- 补充：ADR-0105（cam-tool/1）、ADR-0106（问渠CAM 精品化 Q3）、ADR-0107

## 背景

Q3 施工中碰到三处 cam-tool/1 写不进去的刀具数据：

1. **螺纹铣刀**（Q3b 螺纹铣）：`kind` 里没有这一类。
2. **倒角刀刀尖小端直径**（Q3b 倒角、锪孔口）：倒角刀、中心钻刀尖多半有一小段平头。锪到多深才是图纸的孔口直径、倒角多宽，要用这个直径算。现在只能按尖点算，有平头的刀会锪浅。
3. **螺纹牙型角**（Q3a 锥管螺纹）：R 系列管螺纹要 55° 的刀片，普通螺纹和 NPT 是 60°。刀具库没有这一项，刀片按螺距挑出来以后，牙型对不对核对不了，现在只能报“未知”（ADR-0106 Q3a 完成记录）。

## 决策

cam-tool/1 只加可选内容，已有的刀具库文件照样有效：

- `kind` 加 `thread_mill`（螺纹铣刀），和其他回转刀具一样要写 `diameter_mm`、不能写 `insert`。
  多齿螺纹铣刀写 `pitch_mm`；单齿（单牙型）螺纹铣刀不写，任何螺距都能铣。
- 加 `tip_diameter_mm`：倒角刀、中心钻刀尖小端的直径，尖点写 0。不写就按尖点算，相关检查报“未知”。
- 加 `thread_angle_deg`：螺纹牙型角（普通螺纹 60、R 系列 55），丝锥、螺纹车刀片、螺纹铣刀都可以写。
  不写就核对不了，报“未知”，不当通过。

数值一律来自厂家样本；没有的不写（实施规则：不编数据）。

## 影响

- 校验：`tests/fixtures/cam-tool/` 加一个有效例子（螺纹铣刀多齿、单齿各一，带刀尖直径的倒角刀，带牙型角的丝锥和螺纹车刀片），
  三个无效例子（螺纹铣刀没写直径、刀尖直径为负、牙型角越界）。
- 实现另走代码 PR（ADR-0106 Q3b）：倒角、锪孔口按 `tip_diameter_mm` 算深度；螺纹铣按 `thread_mill`；
  车 R 系列锥管螺纹时按 `thread_angle_deg` 核对刀片，不对的报错误，没写的报未知。
