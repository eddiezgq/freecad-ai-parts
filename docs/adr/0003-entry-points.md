# ADR-0003：用户入口两者都要，先外部 MCP 客户端，后 FreeCAD 内置面板

- 状态：已接受
- 日期：2026-09-30

## 背景

用户可以通过 FreeCAD 内置对话面板，或外部 MCP 客户端（如 Claude Desktop）使用系统。

## 决策

两种入口都做，共用同一套 MCP 工具。先用外部客户端验证工具设计（M4a），工具稳定后再做 FreeCAD 内置对话面板（M4b）。

## 理由

- 外部客户端几乎零界面成本，能尽快验证工具粒度和返回格式是否合理
- 内置面板是最终用户体验，但在工具不稳定时开发，界面会跟着反复返工

## 影响

- M4 拆分为 M4a（MCP 工具）与 M4b（FreeCAD 插件与面板）
- MCP 工具必须与界面无关，内置面板只是另一个 MCP 客户端
