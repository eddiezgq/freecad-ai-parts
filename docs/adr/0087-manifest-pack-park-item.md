# ADR-0087：工厂清单的物料加 `pack`（按包装买）与 `park_item`（工业园对方物料号）

- 状态：已接受（2026-11-06 按项目负责人长期授权执行问渠第 106 轮细则 T-2、T-3 的建议）
- 日期：2026-11-06
- 补充：ADR-0064（工厂清单）、ADR-0068（共用一份代码）、ADR-0083（电路板厂）

## 背景

问渠第 103 轮的芯片封测厂按晶圆批卖芯片（一批约 34 000 只），第 106 轮电路板厂试产驱动板 B 版要向它买。
清单原来没有“最小起订量 / 整包”和“供应商物料号 + 单位换算”的写法，采购只能按缺省批量 10 取整、按同一个物料号送单。

## 决策

1. 清单 `items[]` 加两个可选字段：
   - `pack`：正整数，采购按它的整数倍取整（`hub/mrp.py` 的 `lot_size`）；
   - `park_item`：向工业园兄弟厂下单时对方的物料号；数量按 `pack` 换成对方件数、向上取整（`hub/park.py` 的 `to_peer`）；到货按这边的数量入库。
2. 校验（`factory/plant.py`）：`pack` 是正整数；写了 `park_item` 的物料，供应商要写 `park`、要同时写 `pack`。
3. 没写这两个字段的物料行为不变；不改 `schema/`（零件库的 JSON Schema）、`engine/`，不碰 `tests/golden/`。

## 后果

- 电路板厂清单 IC-ENCIF：`pack: 34000`、`park_item: WQ-ENCIF`。
- 测试 `factory/digital/tests/test_pack_park_item.py`。
