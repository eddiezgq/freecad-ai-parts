# ADR-0128：NUM Flexium 车铣（端面 G21、圆柱面 G22）与坐标位数

- 状态：已接受（2026-11-25，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”“我们是做工业级产品”，2026-11-25 “继续”）
- 日期：2026-11-25
- 补充：ADR-0127（NUM 基本写法）、ADR-0110 / ADR-0106 C2b（车铣中间格式：FANUC G12.1 / G7.1）

## 背景

ADR-0127 做了 NUM 车、铣，车铣留着没做。NUM《Flexium Programming Manual》M00018EN-03 §5.18 写了车床 C 轴的三种坐标：

| FANUC 写法（问渠CAM 车铣的中间写法） | NUM 写法（手册） | 差别 |
| --- | --- | --- |
| `G12.1` … `G13.1`（极坐标插补，端面）；块里 X 直径、C 是虚拟轴（mm） | `G21` … `G20`（§5.18.3 直角坐标编程：X、Y 换成 X、C）；块里 X、Y 是端面上的直角坐标 | X：NUM 参数 E11005 写明“直径编程只在 G20 下有效”，G21 里 X 是**半径**（§5.18.3 例：Ø30 上对边 20 的两个平面写 `G21 G01 G42 X10 Y11.18`，√(10² + 11.18²) = 15） |
| `G07.1 C半径` … `G07.1 C0`（圆柱插补）；块里 X 直径、C 角度（度）；进给按给定半径的展开面算 | `G22` … `G20`（§5.18.4 圆柱坐标编程：Y、Z 换成 Z、C）；Y 是展开长度，`Y = θ · X`（§5.18.4），X 是半径（同上，E11005） | NUM 没有“圆柱半径”参数：Y 按当前 X 半径展开，进给也按当前半径算（§5.18.4 “feed rate is limited by … the current value of the positioning radius”） |
| 每分进给 `G98`、回 `G99` | `G94` / `G95`（ADR-0127 已换） | — |
| 开动力刀、切 C 轴的 M 代码 | NUM 没有统一的 M 代码；选哪个主轴是 `M64`–`M65`（§5.5.7），动力刀、C 轴由机床厂定 | 与 FANUC 一样按配置 `millturn` 写（ADR-0110） |

另外查到 §5.1.4：µm 系统下**直线轴最多 3 位小数**（X+053），回转轴 4 位（C+034）；攻丝螺距 K 同样 K053。ADR-0127 的攻丝 K 写到 6 位小数，是错的，这次一并改。

## 决策

1. **端面（极坐标）**：`G12.1` → `G21`；块里每段 `X直径` → `X直径÷2`、`C毫米` → `Y毫米`，G00 / G01、Z、F 照写；`G13.1` → `G20`。
   这是逐点的线性换算，刀路与 FANUC 完全相同，进给意思也相同（都是端面上的合成进给）。
2. **圆柱面**：`G07.1 C半径` → `G22 (CYL R半径)`（半径写在注释里，回读用）；块里 `X直径` → `X直径÷2`（半径），`C角度` → `Y = 角度 × π ÷ 180 × 当前 X 半径`；`G07.1 C0` → `G20`。
   - 同一个 G01 段里 X 和 C 都变的**不出**（FANUC 在 X–C 上直线插补，NUM 在 X–Y 上，中间路径不同）；G00 不限（快移本来就不是直线插补）。
   - **进给换算**：FANUC 的 F 是给定半径 R 展开面上的进给，NUM 的 F 是当前半径 r 展开面上的。带 C 的 G01 段按
     `F_NUM = F × √(ΔZ² + (r·Δθ)²) ÷ √(ΔZ² + (R·Δθ)²)` 换（同一段用时相同）；不带 C 的段 F 不变。换出来的 F 与上一段不同就写上。
   - 进 G22 前 C 的位置要已知（前面一段写过 C），否则带 C 的 G01 段算不了进给，不出。
3. **坐标位数**（§5.1.4）：NUM 程序里直线轴字（X Y Z I J K U W，含攻丝 K）超过 3 位小数、C 超过 4 位的不出，写明章节。
   车铣块里 X÷2、Y 的换算按 3 位小数取整（≤ 0.5 µm）；回读按问渠CAM 一贯的刀路比对（容差 1e-3 mm）。攻丝螺距 K 取 3 位，乘回转速要能还原原来的 F，否则不出。
4. **配置**：NUM 家族收 `millturn`（`live_on`、`live_off`、`c_on`、`c_off`，按机床说明书填，例如 `M65` 选第二主轴 + `M03`）；`b_tool_comp`（B 轴）、`twin`、`channels` 仍不收。
   这些行里的 M 代码与换刀前后动作一样算“配置认的”，代码表放行。
5. **代码表**：车床加 `G20`、`G21`、`G22`（§5.18）；`G19` 仍不收（C 分度 + Y 轴铣还没做，点名“NUM 的 C 分度 + Y 轴铣还没做”）。

## 理由

- 直径 / 半径由手册参数说明 E11005 写死（直径只在 G20 下），并有 §5.18.3 的例题核对，不靠猜。
- NUM 的 G22 按当前半径展开，和 FANUC、西门子（TRACYL 给定直径）不同；只有把进给按长度比换过去，实际用时才和仿真一样。X、C 同时变的 G01 中间路径不一样，宁可不出。
- 位数是手册格式表的硬限制，超了机床报格式错，提前拦下。

## 施工细则（2026-11-25）

1. 本 ADR（不改 schema：`millturn` 已在 schema 里）。
2. `analysis/cam/num.py`：
   - `to_num`：车床加车铣状态（无 / 端面 / 圆柱）；记录当前 X（直径）、Z、C；按第 1、2 条换；攻丝 K 改 3 位小数。
   - `to_fanuc`：`G21` / `G22 (CYL R…)` / `G20` 换回 `G12.1` / `G07.1 C…` / `G13.1`、`G07.1 C0`；X×2、Y → C（端面原值，圆柱 Y ÷ r × 180 ÷ π）；圆柱块里的 F 按同一比例换回。
   - `check_codes`：`CODES_G` 车床加 20、21、22；位数检查（第 3 条）；G19 点名。
3. `postcfg.check`：NUM 收 `millturn`（不收 `b_tool_comp`）。
4. `postproc.render`：NUM 的代码表检查把 `millturn` 各行里的 M 代码也算上。
5. 标准题 `tests/test_cam_post_num.py` 加：
   - 车铣程序（外圆 + 端面槽 + 圆柱面槽，配置写 `M65 M03` 等）能出：有 `G21`、`G22 (CYL R25.0)`、`G20`，没有 G12.1 / G13.1 / G07.1 / G98 / G99；
     端面块 X 是半径、Y = 原 C；圆柱块 Y = 角度 × π ÷ 180 × r；回读与仿真刀路一致。
   - 进给换算：带 C 的 G01 段 F 按长度比（手算一题对照）。
   - 不出：G01 段 X、C 同变；进 G22 前 C 未知时带 C 的 G01；C 分度 + Y 轴铣（G19）；配置带 `b_tool_comp`。
   - 位数：坐标 4 位小数的配置不出、点名 §5.1.4；攻丝 K 3 位小数。
   - 记录写进 `assist/cam_verification_cases.json`（CAM-97 起）。
6. 帮助（中、英）NUM 一节加车铣；ADR-0127 “不做”里的车铣划掉、指向本 ADR；STATUS、ADR-0106 E3 记一笔。
7. 不做：C 分度 + Y 轴铣（G19；2026-11-26 已做，见 ADR-0132）、B 轴车铣、双主轴、多通道、车铣块里的圆弧（问渠CAM 本来就不写）。

## 实现记录（2026-11-25）

- `analysis/cam/num.py`：`to_num` / `to_fanuc` 加车铣状态（`_mt_to_num`、`_mt_to_fanuc`、`_cyl_feed`）；攻丝 K 改 3 位小数（`_f3`）；`check_codes` 车床认 G20–G22、查 §5.1.4 位数、G19 点名。
- `postcfg.check`：NUM 收 `millturn`，`b_tool_comp`、`twin`、`channels` 仍拒；`postproc.render`：`millturn` 各行的 M 代码算配置认的。
- 标准题 `tests/test_cam_post_num.py`：车铣能出（CAM-97）、圆柱面进给按半径换（CAM-98，手算 176、177.554）、不出的四种情况、位数。
- 回读：端面块逐行原样还原；圆柱面块 Y 只有 3 位小数，换回的角度与原角度差 ≤ 0.002°（刀尖位置差 < 1 µm），按刀路比对（容差 1e-3 mm）通过。
