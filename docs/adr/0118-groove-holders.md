# ADR-0118：刀杆库收切槽刀杆（可装刃宽、最大槽深）

- 状态：已接受（2026-11-22，属于 ADR-0106 Q4b）
- 日期：2026-11-22
- 补充：ADR-0112（刀杆库）、ADR-0115（厂家代号）

## 背景

Q4b 第十批收了京瓷外圆切槽刀片 GMM / GMG（ADR-0106）。切槽刀片装在切槽刀杆上（京瓷 KGM，样本 G056），刀杆决定两件事：

- 能装多宽的刀片（样本 CW min ~ CW max，如 KGMR2525M-3 装 3–4 mm）；
- 能切多深的槽（样本 CDX，刀杆让开工件的那一段，如 9 mm）。槽比 CDX 深，刀杆会撞到工件。

现在的 cam-holder/1 只认 ISO 1832 刀片（形状 + 尺寸位）和螺纹刀片尺寸位，也没有“最大槽深”；切槽刀杆代号是厂家写法（KGMR2525M-3），
截面是方柄，不是镗杆的圆杆。

## 决策

1. cam-holder/1 `use` 加 `groove`（外圆切槽刀杆）。这时必填：厂家代号 `vendor_code`、全长 `l1_mm`、刀杆高 `h_mm`、宽 `b_mm`、
   最大槽深 `max_depth_mm`（样本 CDX）、刀尖偏距 `f_mm`（样本 WF），能装的刀片写 `insert.groove_width_mm: {min, max}`（样本 CW min / max）。
2. `insert` 三选一：ISO 1832 `codes` + `size`、螺纹刀片 `thread_size`、切槽刃宽范围 `groove_width_mm`。
3. cam-tool/1 的 holder 可以是厂家代号的方柄刀杆：`vendor_code` + `h_mm` + `b_mm` + `l1_mm`，可带 `max_depth_mm`。
4. 实现（另一个 PR）：
   - 起草时切槽刀、切断刀按刃宽配刀杆（刃宽在 CW 范围内、手向对上、最大槽深够，截面优先 25×25）；
   - 碰撞外形同外圆刀杆（方柄从刀头到全长，刀头 LH 一段报“未知”）；
   - 计算时槽深（外径 − 槽底直径）/ 2 超过刀杆最大槽深报错，刀杆没写最大槽深的报 unknown；
   - 收京瓷 G056 的 KGM 外圆切槽刀杆。深槽刀杆 KGM-T（G057）的可切深度随工件直径变（G054 另有表），这次不收。

## 影响

- schema 改动单独成 PR（本 ADR）：两个 schema、测试夹具。
- 已有刀杆库、刀具库不受影响（新字段都只在 `use = groove` 或厂家方柄刀杆时用）。
