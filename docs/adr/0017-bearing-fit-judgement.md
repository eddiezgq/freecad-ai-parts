# ADR-0017：C2 对轴承端口的判定方式

- 状态：已接受（2026-10-01，随 PR #21 合并）
- 日期：2026-09-30

## 背景

ADR-0013 规定：一侧为轴承端口时，C2 不查 ISO 286 配合表，改查轴承配合推荐表。推荐表（`schema/rules/bearing-fits.json`）按内/外圈、圈上载荷是否旋转、载荷大小和轴径给出推荐公差带，但 V1 的需求里没有径向载荷，系统里也没有表达载荷方向的信息。

## 决策

1. **载荷是否旋转**由轴承端口的 `motion` 推断：内圈 `rotating` 视为“内圈旋转载荷”，外圈 `stationary` 视为“外圈静止载荷”。即假设载荷方向相对壳体固定，这是关节中最常见的情况
2. **载荷大小未知**：配合件的公差带只要落在该圈、该轴径范围内任一载荷等级（轻、中、重）的推荐集合中，即为 `pass`；不在其中为 `warn`
3. **轴径**取配合件端口的名义直径，按 (d_over_mm, d_upto_mm] 查表
4. **表未覆盖的轴承类型**（交叉滚子、圆锥滚子）或轴径超出表范围：C2 的公差部分为 `unknown`
5. 直径与形式的检查不变：名义直径必须相等，`feature`/`clamping` 按兼容矩阵判定

## 理由

在缺少载荷数据时，取各载荷等级推荐的并集能拦住明显错误（如用孔的配合等级或间隙过大的轴），又不会因为不知道载荷大小而误判；需求将来加入径向载荷后，可以收紧为按载荷等级判定。

## 影响

- 推荐表为草稿，合并前须人工核对
- 将来需求 schema 若增加径向载荷，本决定第 2 条应随之修订
