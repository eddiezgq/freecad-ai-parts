# ADR-0045：厂商目录不规定的端口

- 状态：已接受（2026-10-04，Claude 决定，项目负责人可推翻）
- 日期：2026-10-04
- 补充：ADR-0023（组装）、ADR-0041（生成的转接件）、ADR-0044

## 背景

为真实关节示例（#130）选定了一组零件：电机 SGM7J-02A、减速器 CSF-25-100-2UH、驱动器 SGD7S-1R6A。逐项排查组装缺项时发现，有些端口的规格在厂商目录中本来就不规定：

- **Harmonic Drive 整机型减速器（CSF-2UH）的电机侧安装法兰**：按客户所配的电机定制，目录只给输入孔，不给法兰孔位
- **驱动器的安装孔位**：按安装方式（底座安装、机架安装）选配，只画在外形图上

我们的端口 schema 把法兰的分度圆、孔数、孔的形式，以及安装面的孔位，都列为必填。照此规定，这类零件永远无法入库。另一条路是凭推测填上数，这又违反“不得编造参数值”的规则。

## 决策

1. **端口可以标 `configurable: true`**（`schema/common/port-base.schema.json`），表示厂商目录不规定、按配套件定制。
   - 标了的 `mechanical.flange`、`mechanical.mount_face` 端口，spec 的必填项不强制，可以不全或为空
   - 没标、或标为 false 时，要求不变
   - 端口类型、方向、运动方式、坐标系仍须给出
2. **校验结果**：引擎对缺数据的判断不变。法兰配合缺分度圆或孔数时为 `unknown`，不判通过。复核结论会把这些项列为待核对
3. **由谁来标**：只能由人在抽取任务中写明（`data/extract_jobs.yaml` 的 `configurable_ports`，附依据），程序和模型不得自行标注。组装时，标了的端口若没有任何规格，就按 configurable 输出，组件说明中写明依据
4. **与转接件的关系**：configurable 的电机法兰没有孔位，因此不生成转接板（ADR-0041）。复核结论中写明，要求按所配电机设计输入法兰

## 后果

- 整机型减速器、按安装方式选配孔位的驱动器可以入库。相关的配合校验为 `unknown`，在复核结论中如实列出
- 这次只放宽 `mechanical.flange` 与 `mechanical.mount_face` 两种端口；其他端口类型的必填项不变
- schema 改动单独成 PR（本 ADR），组装与任务配置的改动在下一个 PR
