# ADR-0011：校验规则数据表的格式与核对状态

- 状态：已接受（表内数值为草稿，待人工核对）
- 日期：2026-09-30

## 背景

C2、C3 校验需要三张表：ISO 286 配合表、轴孔形式与紧固方式兼容矩阵、ISO 273 间隙孔表。前两张出自标准，开发时未取得标准原文；第三张不出自任何标准。

## 决策

1. **格式**：每张表一个数据文件 `schema/rules/<表名>.json`，配一个同名 `.schema.json`。表头含版本、状态（`draft` / `verified`）、核对说明和来源清单；每一项带 `verified` 标记。状态为 `verified` 的表，每一项都必须已核对（测试强制）。
2. **ISO 273 间隙孔表**：M1.6–M30，精装、中等、粗装三个系列。数值取自两个公开二手来源，两者完全一致。C3 用中等系列。
3. **ISO 286 配合表**：15 个常用孔基制配对及其配合类别。配对在表内为 C2 `pass`，不在表内为 `warn`。两个二手来源对 H7/k6 归类不一致（一说过盈、一说过渡），表内按 ISO 286 偏差取过渡配合并注明；H7/js6、H7/m6 未见于二手来源，单独注明。
4. **兼容矩阵**：覆盖轴形式 × 孔形式 × 紧固方式全部 64 种组合，由两条规则组合生成（形状是否配合、紧固方式是否适用），取较严结果。这是工程判断，来源标为 `engineering_judgment`。
5. **核对要求**：三张表合并时状态为 `draft`。ISO 两张表须由人对照标准原文逐项核对后改为 `verified`；兼容矩阵须由有机械设计经验的人评审。M1 验收（issue #9）前完成。

## 理由

规则数据与代码分离，核对和修改不需要改引擎；逐项的 `verified` 标记让“尚未核对”在数据里可见，不会被误当作已确认的标准值。

## 影响

- 发现一个 schema 缺口：**滚动轴承内外圈的尺寸公差不属于 ISO 286 公差带**（由轴承精度等级规定，如 ISO 492），而 `cyl_female` / `cyl_male` 的 `fit` 只接受 ISO 286 代号。轴承端口如何表示 `fit`，须在品类 schema（issue #5）中解决，并另写 ADR。
