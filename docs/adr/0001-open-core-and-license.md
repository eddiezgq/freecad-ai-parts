# ADR-0001：开放核心模式，开源部分采用 Apache-2.0

- 状态：已接受
- 日期：2026-09-30

## 背景

项目需要在开源社区项目和商业产品之间做选择，这决定数据策略、厂商合作方式和许可证。

## 决策

采用开放核心（open core）模式：

- **开源**：schema、端口类型库、FreeCAD 插件、MCP 服务端，许可证为 Apache-2.0
- **商业**：经过校验、持续更新的厂商数据服务；企业功能（私有零件库、选型审计、ERP 对接）

## 理由

- FreeCAD 是开源生态，闭源插件难以被社区接受；开源才能获得使用者和贡献者
- 真正的壁垒是数据质量和厂商关系，不是代码
- 厂商有动力提供数据：被 AI 选中本身就是新的销售渠道
- Apache-2.0 对商业友好并带专利授权，企业和厂商更愿意采用；考虑过 LGPL-2.1（与 FreeCAD 一致），但部分企业对其有顾虑。两者都可用于 FreeCAD 插件

## 影响

- 仓库以 Apache-2.0 发布，附 NOTICE
- 商业数据服务与企业功能将来放在独立的私有仓库，通过公开的 schema 和接口对接
