# ADR-0134：MuJoCo 路线的设置加驱动侧惯量 armature（问渠 CAD 0.3.9）

- 状态：已接受（问渠 CAD 0.3.9 细则第三节 3，Eddie 2026-11-26 确认细则）
- 日期：2026-11-26

## 背景

《多体动力学》书第 40 章线索第 4 条：协作臂、SCARA 演练的选型需求只含连杆扭矩，电机转子与减速器输入侧的惯量
J_d = (J_m + J_in)·i² 只进了 C8（惯量比），没进动力学与 C4、C5。协作臂肩关节（SGM7J-04A-6 + CSF-32-100-2UH）
J_d = 2.176 kg·m²，是臂本身最大等效惯量的 33 %；“往上抬”工况计入后连续扭矩 76.9 → 82.0 N·m，C4 由通过变为不通过。
细则定的改法：选出组合后把 J_d 作为该关节的附加惯量（MuJoCo 的 armature）重算逆动力学，再校验 C4、C5。

`analysis.run("mbd", …)` 旧写法（MuJoCo 路线）的设置没有地方给关节附加惯量。

## 决策

旧写法的设置加**可选**键 `armature: {关节名: kg·m²（移动关节 kg）}`：`core.build` 写到 MuJoCo 关节的 `armature`，
即折算到关节上、只随该关节转动的惯量（质量矩阵对角元加上它，不受重力）。给定运动的驱动力矩、精确逆动力学（ADR 无，
线索第 19 条）、等效惯量都自动计入。不给时行为不变。

- 只是设置的一个键，不改 `schema/`（MuJoCo 路线的设置没有 JSON schema，说明在 `analysis/mbd/__init__.py` 文件头）。
- 值必须 ≥ 0；关节名不存在报“设置有误”。
- mbd-model/1（DAE 内核）不在本 ADR 范围：那边要加到 schema，留到第二组 B。

## 后果

- 演练（cobot_joint）选出组合后算 J_d，加到 armature 重算肩关节两个方向，再用同一组零件校验；样本缺转子或输入侧惯量时不估，
  照原样并标 unknown。
- 等效惯量 inertia_max_kgm2 会含 armature；C8 的惯量比原来另外加 J_d 的做法如果还在，就会重复计入——演练里改为用不含 J_d 的
  需求核 C8（见代码注释）。
