# ADR-0104：问渠CAM（WenQuest CAM）——车削、铣削、3+2 五轴、车铣复合到五轴联动

- 状态：已接受（2026-11-18 21:33 项目负责人“好”）
- 日期：2026-11-18
- 补充：ADR-0059（数控编程模块）、ADR-0096 / ADR-0102（问渠有限元、问渠多体动力学的产品化做法照它们）、
  ADR-0066（单机安装与授权）、ADR-0063（AI 两家切换）

## 背景

项目负责人 2026-11-18 定：

- 本会话先做 CAM；CAD、CAE 的培训课程和实际使用打磨由项目负责人在别的窗口做。
- 五轴和车铣复合必须做：中国的五轴机床、车铣中心已经很多，工厂和学校缺会编程的人。

现在有的：

1. **`analysis/cam`（ADR-0059）**，约 1,500 行：
   - 生成：阶梯轴车削、2.5 轴铣削（槽、型腔、外轮廓、孔），出 FANUC 风格 G 代码。
   - 检查：读任意 FANUC 风格程序，算加工时间，仿真切削，查快移撞料、过切 / 残留、超程、转速，按 Kienzle 公式算切削功率。
   - 机床参数由企业填，仓库只带两台示例机床（虚构）。
2. **FreeCAD 自带的 CAM 工作台**（LGPL）。按 FreeCAD 官方的 CAM 开发路线图：
   - 2.5 轴铣是它最强的部分（外轮廓、型腔、钻孔、自适应开粗、刻字）；三维曲面、等高线还是试验功能；
   - 车削还没有正式支持（不支持 G18）；
   - 连续 4 / 5 轴“目前不在范围内”；没有车铣复合，余料跟踪和碰撞避让还弱。
3. **问渠CAD 第 21 号补丁**：修过 CAM 区域偏置的一处错误。

所以：2.5 轴铣可以用 FreeCAD CAM 当底座；车削、车铣复合、3+2、五轴联动、整台机床的仿真、多数后处理要自己做。

## 决策

### 1. 名称与定位

- 名称：中文“问渠CAM”，英文“WenQuest CAM”。
- 用户：
  - 有数控车床、加工中心、五轴机床、车铣中心的中小机加工企业；
  - 职业院校和企业培训（数控车、加工中心、五轴编程、车铣复合）。
- 卖点：
  1. **AI 起草工艺，程序逐项核对，人确认**：装夹、工序、刀具、切削参数、加工策略。
  2. **整台机床仿真通过才出程序**：查刀具、刀柄、夹具、机床部件的碰撞，以及超程、奇异点、过切。
  3. **后处理在合作厂的实机上验证过**。
  4. **工艺卡、程序单、工时由程序填**，可以直接进数字工厂算成本。
- 先自己用、开培训课（同问渠有限元、问渠多体动力学，2026-11-18 项目负责人定），打磨后再卖。

### 2. 架构：同一份代码，加一个版本

- 都在本仓库：`analysis/cam/` 扩充，FreeCAD 里的界面在 `freecad_addon/`。
- 版本（edition）加 `cam`，授权功能 `cam_pro`；安装包、中英、报告、验证手册的做法照问渠有限元。
- 按职责分成几块：

| 块 | 内容 | 来源 |
| --- | --- | --- |
| 机床模型 | 每台机床的轴链（直线轴、回转轴、哪一侧是工作台、哪一侧是主轴头）、回转中心、行程、速度、部件外形 | 新做 |
| 运动学 | 正解、逆解（刀尖点 + 刀轴 → 各轴位置；两组解按行程和连续性选）、奇异点处理、RTCP 与非 RTCP | 新做 |
| 刀路 | 2.5 轴：调用 FreeCAD CAM；车削、车铣、3+2、五轴：自写 | 混合 |
| 仿真 | 材料去除：三向 dexel（numpy）；碰撞：机床部件、刀柄、夹具三角网格的包围盒树加 OCC 精确距离；不加新依赖 | 现有车铣仿真扩充 |
| 后处理 | 一个中间格式（刀位点 + 刀轴 + 工艺事件）→ 各系统的 G 代码；按系统分模板 | 新做 |
| 检查 | 现有的程序检查器扩到五轴：过切、碰撞、超程、奇异点、进给平顺、功率、时间 | 现有扩充 |
| AI 起草 | 读零件 STEP 和材料，起草装夹、工序、刀具、参数、策略；只能从企业刀具库里选刀，参数不能超出刀具样本给的范围 | 新做（模型网关） |
| 报告 | 工艺卡、程序单、刀具清单、装夹示意、工时，中英 | 照有限元报告 |

### 3. 四个阶段

| 阶段 | 内容 | 大约时间 | 验收 |
| --- | --- | --- | --- |
| C1 基础 | 车削（外圆、端面、切槽、螺纹、镗孔）；2.5 轴铣用 FreeCAD CAM；机床模型与整机仿真框架（三轴）；后处理 FANUC、西门子、广州数控（车）；AI 起草车、铣工艺；工艺卡 | 1–2 个月 | 标准题全过（第 6 节）；合作厂实机空走、首件试切各一件（车一件、铣一件） |
| C2 3+2 与车铣 | 3+2 定位（倾斜面坐标系：FANUC G68.2、西门子 CYCLE800、海德汉 PLANE）；车铣复合 C 轴 / Y 轴动力刀（极坐标插补 G12.1 / TRANSMIT，圆柱插补 G7.1 / TRACYL）；摇篮式 AC、摆头 BC 两种五轴机床模型；后处理加海德汉、华中数控 | 再 2–3 个月 | 运动学逆解往返误差 < 1e-9 mm；合作厂五轴机床、车铣中心各试切一件 |
| C3 五轴联动 | 侧刃铣（直纹面）、沿曲线加工、曲面多轴精加工；刀轴控制（前倾角、侧倾角、按碰撞自动避让倾斜）；RTCP（G43.4 / TRAORI / M128）与非 RTCP 输出；奇异点附近重新规划 | 再 3–6 个月 | NAS 979 圆锥台试件与 ISO 10791-7 的 S 形试件：仿真零过切、零碰撞；合作厂试切，量检测结果写进验证手册 |
| C4 B 轴车铣中心 | B 轴摆头车铣、双主轴、多通道同步（等待码、工件交接） | C3 之后另写细则 | — |

每个阶段一个或几个 PR；合作厂的实机验收没过，那个阶段不算完成。

### 4. 安全底线（写死在代码里）

1. 整台机床仿真没跑、或有一项“不通过”，**不输出程序**。
2. 程序头写明：机床型号、后处理版本、仿真指纹，以及“首件须空运行、单段试切确认”。
3. 后处理没在实机上验证过的系统，程序头写“未经实机验证”，界面上标黄。
4. 机床参数、刀具数据缺了就不写，检查结果为“未知”，不当成“通过”。

### 5. 免费与专业两档（授权功能 `cam_pro`）

| 免费版 | 专业版 |
| --- | --- |
| G 代码检查（时间、撞料、过切、超程、功率） | AI 起草工艺 |
| 车削、2.5 轴铣编程 | 3+2 定位、车铣复合、五轴联动 |
| 三轴整机仿真 | 五轴、车铣整机仿真 |
| FANUC 一种后处理 | 全部后处理 |
| | 工艺卡、程序单正式报告（中英） |

### 6. 验证手册（照问渠有限元的机制）

- 解析对照：
  - 车削和铣削的基本时间、切削功率与手算一致；
  - 极坐标、圆柱插补与笛卡尔刀路等价；
  - 运动学正解、逆解往返；
  - RTCP 与非 RTCP 两种输出的刀尖轨迹一致；
  - 材料去除体积与解析体积一致；
  - 已知会撞、会过切的算例必须报出来。
- 标准试件：NAS 979 圆锥台、ISO 10791-7 S 形试件，以及车铣复合的典型零件（法兰、带键槽的轴）；仿真结果与名义几何的偏差写进手册。
- 实机记录：合作厂试切件的检测结果（三坐标或量具），写明机床、系统、日期。

### 7. 数据规则（同零件库）

- 机床：企业自己填；仓库里的示例机床标明“示例（虚构）”。
- 刀具：企业刀具库；公共数据只取厂商公开样本，在 `data/sources.yaml` 登记出处，缺的不写。
- 切削参数：只用刀具样本给的范围和 Kienzle 表；AI 给的值超出范围就退回。
- 机床模型、刀具库的格式是新 schema，**单独 PR 加 ADR**（本 ADR 接受后立刻写）。

### 8. 不做的（本方案）

- 叶轮、叶盘专用模块；机器人加工；增材；三通道以上的复杂车铣中心；在线测量（探头）宏程序。
- 自己写几何内核：一律用 OCC（FreeCAD）。

### 9. 需要项目负责人做的

1. **找一到两家合作的机加工厂**（台州）：要有加工中心、一台五轴（摇篮式 AC 或摆头 BC）、一台车铣中心。用途是空走和试切验证，我提供程序和仿真记录。合作厂用的系统（FANUC、西门子、海德汉、广数、华中）决定后处理先做哪几种。
2. 合作厂一台机床的资料：型号、系统版本、行程、回转中心位置（厂家资料或合作厂测量），用来建第一台真实机床模型。
3. 出口管制：五轴相关的软件，发布前和其他产品一起核一次出口分类。

## 理由

- 中国的五轴机床、车铣中心多，编程人员缺。商业 CAM（Mastercam、NX、hyperMILL）贵、难学；开源的只有 2.5 轴。
  空白正好在“好学、带安全检查、价格低”的五轴和车铣编程上。
- 我们已有程序检查器、Kienzle 功率、零件库、数字工厂和 AI 核对的做法；问渠CAD 的 FreeCAD 修正也用得上。
- 先 3+2 和车铣，再联动：实际生产里大量五轴机床用的是 3+2 定位加工，难度低、风险小、马上有用。联动风险最高，放在仿真和后处理都实机验证过之后。
- 考虑过：
  - 直接扩 FreeCAD CAM 做五轴：官方路线图把连续多轴排除在外，上游框架没有机床运动学，改动大还要跟上游合并，不选；2.5 轴照用它。
  - 接 CAMotics 做仿真：它只有三轴、GPL，不选。

## 影响

- `analysis/cam/` 大幅扩充：机床模型、运动学、刀路、仿真、后处理、检查。
- 新 schema：机床模型、刀具库（各自单独 PR 加 ADR）。
- `freecad_addon/` 加问渠CAM 的窗口；安装包加 `cam` 版本。
- `docs/plan.md` 加 M43（问渠CAM）。

### C1 第 1 步：机床模型、运动学、刀具库（2026-11-19）

- `analysis/cam/machine_model.py`：读 cam-machine/1、按 schema 校验；旧格式（ADR-0059 的 machines.yaml）转新格式（数控系统写 `other`，旧格式没有的数不编）；
  给现有车削、2.5 轴铣、程序检查的旧字段视图。
- `analysis/cam/machines.py`：示例机床改为 `analysis/cam/machines/*.json`（车床、立加、摇篮 AC 五轴、车铣中心 C/Y，均虚构）；
  企业文件可以是旧格式 yaml、新格式 yaml、或一个放 JSON 的文件夹。旧视图只列两轴车床、三轴加工中心，转换后与原 `machines_example.yaml` 的数逐项一致；
  原文件删除。机床文件没写主电机功率或效率时，功率检查报“未知”。
  车铣中心示例的主轴端面基准点改到原点（X 直径编程时，X 指令值 = 刀尖直径），schema 用的样例不变。
- `analysis/cam/kinematics.py`：按 ADR-0105 的轴链约定（指数积）做正解；逆解先按刀轴方向解回转轴（Paden–Kahan 子问题，摇篮、摆头、一头一台三种都通），
  再按刀尖点解直线轴；两组解先筛行程，再取离上一点最近的；奇异点（刀轴与回转轴平行）回转轴保持上一点的值；连续回转轴取最近的整圈。
- `analysis/cam/tools.py`：读 cam-tool/1；切削参数按刀具样本范围核对（缺范围为“未知”）；FreeCAD CAM 刀具（.fctl / .fctb）导入，认不出的形状列出来不导入。
- 验收（`tests/test_cam_machine_kinematics.py`）：五种机床（摇篮 AC、摆头 BC、摆头 B 加转台 C、三轴立加、车床）各随机 200 个位姿往返，
  轴值回到原值（< 1e-7），刀尖误差 < 1e-9 mm；正解与手算对照 6 处；超程、达不到、奇异点、连续轴整圈、车铣中心径向刀各有用例。
- schema 补一处：数控系统型号 `controller.model` 改为选填（旧格式转换来的没有），在 schema PR 里改。

### C1 第 2 步：整机仿真框架（两轴车床、三轴加工中心）（2026-11-19）

- `analysis/cam/collide.py`：长方体（可斜放）、圆柱两种凸体，GJK 判碰，可带安全间隙；三角网格部件 C2 再加。
  与分离轴定理（精确判据）对照随机 3000 对长方体，结论全部一致。
- `analysis/cam/machine_sim.py`：按机床模型把机床动起来（轴位置由运动学逆解算，部件跟着它所在的轴链动），逐段采样查：
  1. 刀具刃部、刀杆、刀柄 ↔ 夹具、工作台等工件一侧和不动的部件；
  2. 主轴头等刀具一侧部件 ↔ 工件一侧部件、夹具、毛坯外形；
  3. 刀杆、刀柄 ↔ 剩下的材料（借现有铣削仿真的高度图，每段切削前查，`sim.simulate_mill` 加 `on_move` 钩子）；
  4. 机床走不到、超程。
  同一对东西相碰只报一条，写第一处的行号和共几行。刀长、刀柄外形、柄径没给，或车刀刀杆（cam-tool/1 还没有车刀刀杆外形）——报“未知”，不当“通过”。
  程序按的刀径与刀具库对应的刀不一样，报错。
- 指纹：机床、程序、刀具、毛坯、夹具、模块版本一起算 16 位，后处理写进程序头（第 4 步）。
- 接进 `analysis.cam.run`：设置给了 `machine_sim` 就跑；车削、铣削生成的程序整机仿真不通过就**不输出**（gcode 为空，检查里写原因）；
  检查已有程序的模式只报不扣。没给 `machine_sim` 的仍按原来的行为输出——安全底线第 1 条（没跑整机仿真不出程序）
  在第 4 步新后处理接上时强制执行，旧的 FANUC 风格输出到那时换掉。
- 验收（`tests/test_cam_machine_sim.py`）：干净程序通过且指纹稳定；压板挡路、刀切进工作台、刀太短 Z 到底够不着、深型腔刀柄碰侧壁、
  无刀柄短刀主轴头压到毛坯、检查模式只报不扣、车床刀尖碰卡爪、缺数据为“未知”、部件跟轴链的位姿与手算一致。
