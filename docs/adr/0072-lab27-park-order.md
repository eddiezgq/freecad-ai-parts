# ADR-0072：机器人厂实验 27“两厂之间的一张订单”

- 状态：已接受（2026-10-30 项目负责人确认问渠仓库第 57 轮细则 Q1、Q2）
- 日期：2026-10-30
- 补充：ADR-0068（数字工厂与问渠仓库共用一份代码）、ADR-0070（工厂供应商与两厂互发订单）

## 背景

ADR-0070 让机器人厂的 WQR-105 采购单送到减速器厂、接单生产、发货回传，机制已上线，但还没有让学生用起来的实验。
问渠第 57 轮加实验 27，改了两边共有的代码。

## 决策

1. **评分模块 `factory/digital/hub/lab27.py`**：六个任务自动评 60 分（接 2 台 AGV 算料、WQR-105 采购单送到减速器厂、
   到货检验入库、交期、安全库存与订货点 SS = z·σ_d·√L / ROP = d·L + SS、复盘牛鞭效应），报告 40 分。
   只读机器人厂自己的接单提议、请购、批次；不改两厂互发订单的机制。
2. 安全库存题的需求数据每个学生不同，是**示例值**，不是零件参数，不进零件库。
3. 页面 `Lab27.vue`、指导书和报告模板、帮助、测试 `test_lab27.py`；机器人厂演练 `plant_loop.py` 的 `--item` 可写“产品:数量”，加 `--lab27`。
4. 这些都在共有路径，按 ADR-0068 逐字同步。

## 影响

- 共有代码新增 `hub/lab27.py`、`web/src/pages/Lab27.vue`、`tests/test_lab27.py`、实验 27 指导书；改 `hub/app.py`、`labs_api.py`、
  `cae_api.py`、`course.py`、`cae/labdoc.py`、`web/src/main.js`、帮助机器人厂第 6、7 章、`tests/plant_loop.py`。
- 不改 `schema/`、`engine/`、零件数据。
