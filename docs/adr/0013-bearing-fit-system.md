# ADR-0013：圆柱端口增加公差体系，轴承用 ISO 492 精度等级

- 状态：已接受（2026-09-30 确认方案 A）
- 日期：2026-09-30

## 背景

滚动轴承内外圈的尺寸公差由轴承精度等级规定（ISO 492），不属于 ISO 286 公差带；而 ADR-0010 的圆柱端口 `fit` 只接受 ISO 286 代号，轴承端口无法如实表达。可选方案：A）端口增加公差体系字段；B）轴承端口不填公差，C2 对轴承只核对直径。

## 决策

采用方案 A：

- `mechanical.cyl_male`、`mechanical.cyl_female` 的 `spec` 增加可选字段 `fit_system`：`iso286`（缺省）或 `bearing`
- `fit_system` 为 `bearing` 时，`fit` 取轴承精度等级 `P0`、`P6`、`P5`、`P4`、`P2`（对应 ISO 492 的 Normal、6、5、4、2 级）；否则仍为 ISO 286 公差带
- C2：一侧为轴承端口时，不查 ISO 286 配合表，改查轴承配合推荐表（issue #14）：配合件的 ISO 286 公差带在推荐范围内为 `pass`，否则 `warn`

## 理由

如实表达轴承公差，使 C2 能真正校验轴承与轴、轴承座的配合；字段可选且缺省为 ISO 286，已有数据和样例不需要修改。

## 影响

- 品类 schema（issue #5）要求轴承的 `inner`、`outer` 端口 `fit_system` 为 `bearing`
- 新增一张需人工核对的规则表（issue #14）
