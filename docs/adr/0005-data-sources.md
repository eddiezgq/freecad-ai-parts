# ADR-0005：数据来源——参数入库、包络自生成、原厂模型只留链接

- 状态：已接受（2026-09-30 由 ADR-0015 补充：真实厂商数据须先取得书面授权）
- 日期：2026-09-30

## 背景

数据来源包括开源 CAD 库、公开标准和厂商产品目录。厂商 CAD 模型通常不允许再分发，各平台条款也各不相同。

## 决策

- **参数和元数据入库**：型号、尺寸、额定值、接口规格等事实性数据
- **包络几何自己生成**：按参数用 FreeCAD 脚本生成外形与安装接口
- **原厂模型只保留链接**：需要精确模型时引导用户到厂商下载
- **首批来源**：规格书规范、参数公开的厂商，国际与国产兼顾；候选如 Harmonic Drive、绿的谐波、安川、汇川
- **合规流程**：每个来源先在 `data/sources.yaml` 登记并核实使用条款，未核实不得入库；原始规格书不入 git
- **商业路线**：直接联系厂商申请数据授权，同时建立合作

## 理由

厂商零件被视为黑箱，只需端口、参数和包络，不需要精细几何；这样既规避模型授权问题，又天然适合 agent 读取。

## 影响

- M2 第一周先完成许可核查
- 每条参数记录来源文件、页码、抽取时间和置信度
- 使用条款的法律判断需请专业人士把关
