# ADR-0115：原创机器人案例——用我们的方法从一句需求设计整机、仿真、出结果（M44）

- 状态：已接受（2026-11-22 13:28，项目负责人：“好，继续”）
- 日期：2026-11-22
- 补充：ADR-0055（企业私有库）、ADR-0061（典型应用演练）、ADR-0097（装配体多体动力学）、ADR-0099（企业快速建库）、ADR-0100（AI 自主设计零件）

## 背景

项目负责人 2026-11-22 定：

- 一个一个往库里加零件没有意义；要跑通的是我们的设想——**用零件库和我们的方法快速搭出机器人、仿真、得到结果**；
- 案例要是**我们自己创造性的工作**，不照现有产品（UR5e、SCARA 一类）抄；
- 用几个典型的机器人案例来证明。

已有的演练（ADR-0061 的 `examples/apps/`）是照现有产品的参数、由脚本写死流程；AI 自主设计（ADR-0100）只做到单个零件。缺的是：
从一句需求出发，**AI 提出整机构型**，代码把构型变成可校核、可仿真的模型，一路走到结果。

## 决策

### 1. 三个案例（顺序：先 A，再 B，再 C）

需求数字是项目负责人确认的设计目标；构型由 AI 提、代码核，不预先指定。

| | A. 教学用桌面机械臂 | B. 缝纫车间裁片上下料机器人 | C. 小型酒店送物机器人 |
|---|---|---|---|
| 服务对象 | 问渠机器人学院（学生自己装拆、配课程与虚拟实验） | 台州缝纫机行业 | 小酒店 |
| 需求 | 5 轴；负载 0.5 kg；臂展 350 mm；末端重复定位 ±0.5 mm；同一种关节模组重复使用；全部自制件能在普通数控车铣上加工；整机外购件成本尽量低 | 从裁床逐片取裁片（单片几十克、最大 600×400 mm）放到平缝机工位；节拍 3 s/片；定位 ±1 mm；不损伤布料 | 走廊与电梯里送物；载重 20 kg；速度 1 m/s；过 15 mm 门槛；带升降储物仓（行程 300 mm）；连续工作 8 h |
| 要创造的地方 | 模块化关节（电机 + 减速 + 轴承 + 输出轴一体）、易加工的臂杆与支架 | 抓软布料的末端（真空或针刺，AI 提方案、代码比）；适合车间布局的轻型机构（悬挂龙门、并联或其他） | 底盘构型（差速 / 带摆臂悬挂）、门槛通过、升降机构 |
| 仿真 | 多体：典型搬运节拍下各关节力矩、速度；有限元：臂杆变形与一阶频率；末端偏移 | 多体：一个节拍的加减速、末端轨迹；有限元：横梁变形与频率；节拍是否达到 | 多体：起步、过门槛、急停、坡道；有限元：车架与升降机构；电机功率与续航所需电量 |

### 2. 每个案例走同一条路

| 步 | 谁做 | 内容 |
|---|---|---|
| 1. 需求 | 人写一段话 | 数字都在原话里；代码核对每个数的原话引用（同 ADR-0100） |
| 2. 构型 | AI 提 2–3 个、说理由 | 自由度、关节类型与排列、各杆长、传动方式、末端型式；写成结构化的“整机方案”（新数据格式，单独 PR + ADR） |
| 3. 构型初筛 | 代码 | 工作空间能否覆盖需求、奇异位置、粗估各关节载荷；不合格交回 AI，最多 4 轮（同 ADR-0100） |
| 4. 载荷 | 代码 | 多体动力学（`analysis/mbd`）按需求的典型动作算每个关节的力矩、速度曲线 |
| 5. 外购件 | 代码选、AI 只给偏好 | 从零件库选电机、减速器、驱动、轴承等，逐项校核（选型引擎 C1–C11）；**库里没有合适的，列出缺什么**，再从登记过、核过条款的公开产品目录**整本成批导入**（ADR-0099 通道 A），不手工一个一个加 |
| 6. 自制件 | AI 设计、代码校核（ADR-0100） | 关节轴、臂杆、支架、车架等；不合格交回 AI 改；通过后出模型 |
| 7. 整机 | 代码 | FreeCAD 里按接口装配、干涉检查；整机质量、重心 |
| 8. 仿真 | 代码 | 用真实装配体再跑多体动力学（ADR-0097）与有限元，和第 4 步的估算对照；差得多就回第 5、6 步 |
| 9. 结果 | 代码出、人确认 | 报告、三维模型、BOM；人确认后入企业库 |

AI 只提议、起草、解释；凡影响“能不能用”的判断由代码做；缺数据结论为“待确认”，不估。

### 3. 每个案例交付的结果

1. 整机方案：AI 提的几个构型、各自的理由、代码初筛结论、采用哪个；
2. 校核结论：每个数带来源（零件库资料页码、计算方法）；
3. 仿真数字：力矩、速度、变形、频率、节拍（或续航）；与需求逐条对照；
4. 三维模型（STEP、FreeCAD 文档）与 BOM；
5. 用时：从需求到结果，各步分别多久；哪些自动、哪些要人确认；
6. 卡在哪里、为什么（缺数据、缺功能），如实记，作为下一步的输入。

报告放 `examples/robots/<案例>/`（与 `examples/ai-design/` 同样：原话、结果、模型、BOM、README）；AI 调用用 CI 上的 Claude 录制，测试回放不调用真实模型。

### 4. 施工顺序（每步一个 PR，测试照旧全过）

1. **44.0 整机方案格式**（单独 PR + ADR）：构型、关节、杆件、传动、末端，与 `system.json` 和装配体多体动力学的输入对得上；
2. **44.1 构型初筛**：工作空间、奇异位置、粗载荷（解析 + 数值），标准题对照教材例题；
3. **44.2 构型循环**：需求 → AI 提构型 → 代码初筛 → 交回 AI（复用 ADR-0100 的循环、录制、回放）；
4. **44.3 案例 A 全流程**：载荷 → 选件（缺什么先列出，再整本导入公开目录）→ 关节轴与臂杆的 AI 设计 → 装配 → 仿真 → 报告；
5. **44.4 问渠 CAD 面板**“AI 设计整机”（在“AI 设计零件”面板之上加一层），项目负责人在问渠 CAD 里验收案例 A；
6. **44.5 案例 B**（新增：末端执行器的比较、软布料的抓取不做物理仿真，按吸附力或针刺力的公开数据核算，没有数据就标待确认）；
7. **44.6 案例 C**（新增：移动底盘的多体模型——轮地接触、门槛；电池按需求反算所需电量，不选具体电池型号时标待确认）。

### 5. 验收

- 案例 A：项目负责人在问渠 CAD 里从一句需求跑到结果（回放一次、真实 AI 一次）；整机方案、校核、仿真数字、模型、BOM 齐全；报告里各数可追溯；
- 案例 B、C：同样的六项结果；卡住的地方如实列出；
- 每个案例另附一页“和教材 / 公开资料的对照”：同类机器人的典型数字（负载自重比、节拍、续航）只作参照，不作为我们方案的依据。

## 理由

- 用原创机器人而不是照抄现有产品：才能检验“AI 提构型 + 代码校核”这条路本身，也才有我们自己的成果；
- 三个案例分别压在三个不同的难点上：A 是关节模组与串联臂（我们最成熟的一块，先跑通），B 是末端与软物料、车间节拍，C 是移动底盘与轮地接触；
- 外购件缺数据时整本导入公开目录：这正是“企业快速建库”要验证的能力，不再手工一个个加。

## 影响

- 新数据格式“整机方案”（schema 单独 PR）；新代码 `assist/robot_design.py`（构型循环）、`analysis/robot/`（工作空间、奇异、粗载荷）；
- 面板新增“AI 设计整机”；
- 问渠 CAD 0.4 改为本 ADR 的内容（原 0.4 的夹具设计、课程与虚拟实验顺延到 0.5），由问渠 CAD 那边改方案表。

- **44.1 构型初筛（2026-11-22）**：分析模块 `robot`（`analysis/robot/`）。`kinematics.py`：结构检查（schema 之外：引用、树、轴线、动作超行程、
  构型类型与轮子）、正运动学、位置雅可比、位置逆解（阻尼最小二乘、固定起点，可复现）；`screen()`：工作空间点可达、关节动作在行程内、
  直线动作沿途 20 段都有解且连续、奇异（位置雅可比秩亏才判，其余只报最小 / 最大奇异值之比）、末端负载的静力矩（下限，只计负载）。

- **44.3 案例 A 全流程之一：载荷 → 选件（2026-11-22）**：`analysis/robot/mjcf.py` 把整机方案变成多体动力学模型——杆件质量按截面 × 长度 × 密度
  （型材截面积要看样本，算不出就报错、不估），均布在本关节到下一关节之间；关节模组（电机 + 减速器）按所选零件的样本质量集中在关节处；
  末端负载在工具点；吊装把基座翻转 180°，墙装与移动底盘判不了。`assist/robot_build.py`：
  检验动作（需求没给速度，设计取值、写进报告的假设）——从水平伸直姿态出发，各转动关节同时转 90°、1.0 s（最高 120°/s），末端满载；
  多体动力学 → 同一模组组取组内各项最大值作一个选型需求 → 引擎选型，在不“不通过”、有样本质量的组合里取电机 + 减速器最轻的 →
  模组质量回代，重复到选型不再变。成本：零件库没有价格，“外购件成本尽量低”判待确认。
  标准题（`tests/test_robot_build.py`）：杆件质量公式、水平伸直两杆臂的肩、肘重力矩与手算一致、吊装力矩反号。
  案例 A 结果（`examples/robots/teaching-arm/out/build-result.json`）：3 轮收敛，五个关节都用 SGM7J-01A（100 W）+ CSF-17-100 + SGD7S-1R6A；
  最重的是肩 j2：均方根 11.1 N·m、峰值 15.9 N·m。自制铝管 0.64 kg，而五套电机 + 减速器 5.4 kg——**模组本身是负载（0.5 kg）的 10 倍多，
  肩部力矩大半来自扛着后面的模组**。这说明“只用一种模组”在这台小臂上代价很大：腕部两轴只要约 1 N·m，却装着和肩一样重的模组。
  构型循环里 AI 给过的方案 B（大小两种模组）同样算了一遍：只轻 0.2 kg——库里最轻的合法组合就是约 1 kg

- **案例 A 需求修改（项目负责人 2026-11-22 21:37“按建议”）**：照 ADR-0117 117.3 的结论走第一条路——速度放到 60°/s 一档、精度放宽到约 ±1 mm。
  需求原话改为“末端重复定位精度 ±1 mm；关节最高角速度 60°/s”（`requirement.txt`）。随之：设计条件加“关节最高角速度”（原话单位 °/s，
  在单位入口换成 rpm）；整机选件的检验动作按它定（最高 60°/s 即每 90° 用 2 s）；重复定位精度改在需求要够得着的点（臂展点等）上算，
  不再用水平伸直姿态（那个姿态在需求的工作范围之外，力臂偏大）。构型循环按新需求重新录制。
  重新录制（design-eval 45102421723，Claude）：1 轮通过，2 个构型，采用 AI 推荐的“五关节同模组竖直零位臂”（上臂 170、前臂 160 mm，6061-T6 铝管）。
  整机选件（`build-result.json`）：2 轮收敛，五个关节都用 Dynamixel XM540-W270（每个 0.165 kg，伺服链 0.98 kg），模组合计 0.83 kg；
  肩部峰值 4.4 N·m、均方根 3.3 N·m；重复定位在臂展点上最坏 ±0.84 mm，**满足 ±1 mm**；
  待确认只剩一项：肩部连续需求（含安全系数）是堵转力矩的 38%，厂商没给连续额定。成本仍判不了（库里没有价格）。
- **44.3 之二计划（2026-11-22 22:45，项目负责人“好，继续”之后写定）**：选了一体化模组以后，原计划的“关节空心轴”不再有——输出轴、轴承都在模组里。
  自制件变成**杆件（铝管）和连接模组与杆件的支架**。施工顺序：
  1. 杆件校核（不等别的）：每根铝管在动作过程中的最大弯矩取带动它的关节的峰值力矩，算弯曲应力（对材料屈服强度的安全系数）、
     末端由各杆弯曲累计的位移、整臂伸直时的一阶弯曲频率（标准题对照悬臂梁公式），不合格的交回 AI 改截面。
  2. 模组的机械接口：舵盘孔位、壳体安装孔只在 ROBOTIS 的图纸里（PDF / STEP），网站从我们这里下载不了；
     请项目负责人下载 XM540 的图纸 PDF 与 STEP（e-Manual 的 Drawings 一节），放进 `data/raw/robotis/`（不入库），
     由代码从 STEP 量出孔位与外形（ADR-0099 的 measured 做法），写进 31 个型号里同一壳体的那些（540 一组、430 一组）。
  3. 支架：AI 按接口与载荷设计（舵盘端、壳体端各一种，车铣能加工），代码校核（强度、装得上、不干涉）；不合格交回 AI。
  4. FreeCAD 装配：模组 + 支架 + 铝管按接口装起来，干涉检查，整机质量与重心。
  5. 用真实装配体再跑多体动力学，与 44.3 之一的估算对照；支架做有限元；出报告、三维模型、BOM。
- **44.3 之二第 1 步：杆件校核（2026-11-22）**：`analysis/robot/links.py`——各杆根部承受下游重量的弯矩与扭矩（水平伸直姿态），
  乘动载系数（多体动力学峰值 / 静重力矩，取最大，至少 1），当量应力对屈服强度、弯曲疲劳极限的安全系数与选件同一要求（1.2）比；
  末端下垂按各杆悬臂估算（关节模组刚度厂商没给，不计，是下限）。标准题：水平悬臂管的弯矩、应力、端部挠度与手算一致；竖直杆没有弯矩。
  与多体动力学互相核对：上臂根部弯矩 4.316 N·m = 肩部静重力矩 4.316 N·m。
  案例 A 结果：动载系数 1.03；最小安全系数是上臂 65（对弯曲疲劳），末端下垂（只计杆件）0.055 mm。
  **结论：AI 给的铝管强度上富余几十倍**，截面不是由强度定的，而是由能不能和模组、支架连起来定（模组宽 33.5 mm）；减薄的事放到第 3 步支架设计时一起定。

- **44.3 之二第 3 步之一：装不装得下（2026-11-22）**：`analysis/robot/fit.py`。一体化模组能固定的面（底面、侧面）都与输出轴平行，
  所以关节分两类：子杆垂直于轴的“侧摆”（U 形支架跨在前后舵盘上，底板离轴线 d），子杆沿轴的“轴转”（舵盘法兰）。
  查：① 侧摆的转角——U 底板随关节转，不能碰自己的壳体和下面的父杆（二维分离轴法，0.5° 一步），二分求满足行程的最小 d；
  ② 轴转若父杆也沿轴（共线），背面是会转的惰轮舵盘，装不上；③ 关节距放不放得下（近端 d + 远端轴线到壳体底面）。
  标准题：底板很远时最大转角由 d·sin φ = (b + w)/2 决定；底板进了壳体顶面伸直位就碰；d_min 单调。
  案例 A：j2、j3、j4 的 U 底板至少离轴线 47.8、51.4、47.8 mm；上臂、前臂长度够（余 77.5、63.8 mm）；
  **腕部 j5 是共线轴转，X540 装不上**——要交回 AI 改构型（让 j5 轴线偏开至少 44.75 mm，或腕部加长），这是下一步。
