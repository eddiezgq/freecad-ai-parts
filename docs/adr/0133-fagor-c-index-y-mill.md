# ADR-0133：发格 8060 / 8065 车铣——C 轴分度 + Y 轴铣（G19）

- 状态：已接受（2026-11-26，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”，2026-11-26 “好”继续 STATUS 下一步）
- 日期：2026-11-26
- 补充：ADR-0131（发格车铣端面 #FACE、圆柱面 #CYL，第 5 条把 G19 留着没做）、ADR-0106 C2b（C 分度 + Y 轴铣的中间写法）、ADR-0132（NUM 同一件事）

## 背景

问渠CAM 圆柱面上宽于刀径的平底槽用 C 轴分度 + Y 轴铣（ADR-0106 C2b），FANUC 中间写法是（`post.millturn_lines`）：

```
M05 / 夹 C 轴、开动力刀的配置行 / S转速
G00 C<角度>      分度（绝对角度，可以是负数，如 C-60.0）
G19              YZ 平面
G00 X<直径> Y.. Z..  /  G01 …   （X 直径、Y 切向、Z 轴向，只有直线段）
G00 Y0.0
G18
关动力刀、松 C 轴的配置行
```

ADR-0131 第 5 条发格代码表不收 G19，带这种铣削段的程序不出。查《CNCelite 8058/8060/8065/8070 Programming manual》（REF 2508）：

| 项 | 手册 | 与 FANUC 中间写法比 |
| --- | --- | --- |
| G19 | §4.2.1：“三面体”轴配置（铣床；带 Y 轴的车床）下 G19 是第二轴（横）、第三轴（纵）组成的主平面，第一轴垂直；通道轴序 X、Y、Z 时就是 Y–Z 平面、X 是刀轴 | 相同 |
| X 直径 | §3.4：G151 / G152 按轴（DIAMPROG）生效，与平面无关 | 分度铣在 G151 下（不在 #FACE / #CYL 块里），X 仍是直径，相同 |
| 主轴当 C 轴 | §18.1.1：用主轴做 C 轴要先 `#CAX`（独占一段），之后 C 按度数、当回转轴编；`#CAX OFF`（§18.1.2）回转速模式；M3 / M4 / M5 等于 `#CAX OFF` | **要加**：FANUC 由机床的 C 轴 M 代码切换，发格必须写 `#CAX` |
| C 绝对值 | §3.2.1：“普通”回转轴 G90 下**正负号是转的方向、绝对值是终点角**；“单向”轴按预设方向转到终点；“只定位”轴走最短路径；三种都显示在一圈的模内 | **不同**：FANUC `C-60.0` 是 −60°（= 300°）的位置；发格普通回转轴 `C-60.0` 是反转到 60°，差 120° |

## 决策

1. **代码表**：发格车床加 `G19`（§4.2）。
2. **#CAX**：`G00 C<角度>` 紧跟 `G19`（分度铣开头）→ 三段 `#CAX`、`G00 C<0–360>`、`G19`；分度铣结尾的 `G18` → `G18`、`#CAX OFF`。
   与 ADR-0131 车铣块同一顺序：夹 C 轴、开动力刀的配置行在 `#CAX` 前面（`#CAX` 只在主轴转着时把它停下，§18.1.1；之前已 `M05`）。
3. **分度角**：一律写成 0 ≤ C < 360 的正数（`C-60.0` → `C300.0`，`C360.0` → `C0.0`），4 位小数以内（§1.3.1）。
   普通回转轴按正号正转到这个角度，单向、只定位的轴按各自方向到同一个角度——三种轴终点都对；分度前刀已退到安全位，转的方向不影响零件。
   “类直线”回转轴（§3.2.1，带行程限位）不是主轴当 C 轴的情形，不考虑。
4. **只认这一种写法**：车铣块外、不是“`G00 C..` 后面紧跟 `G19`”的 C（例如 `G01 … C..`）不出；`#CAX` 后面不是分度铣开头的，回读报错。
5. **回读**：`#CAX` / `G00 C..` / `G19` → `G00 C..` / `G19`；`G18` / `#CAX OFF` → `G18`；`C300.0` 原样读回，与 `C-60.0` 在工件坐标里是同一个刀位（`millturn.index_to_work` 按 Rz(θ)），按刀路比对。
6. 不做：B 轴车铣、双主轴、多通道、车铣块里的圆弧；“平面”型轴配置（§4.1：G19 不换平面、只报警）的车床——带 Y 轴的车铣中心按“三面体”配置。

## 理由

- 平面选择、直径编程与 FANUC 一致，有章节可查；两处不同（主轴当 C 轴要 `#CAX`、回转轴绝对值的正负号）手册写明，按手册写就消除了。
- 负角度不换的话，`C-60` 在发格普通回转轴上停在 60°，槽铣到另一个位置——这是要拦的真错。

## 施工细则（2026-11-26）

1. 本 ADR（不改 schema）。
2. `analysis/cam/fagor.py`：`CODES_G` 加 `19`（§4.2）；`to_fagor` 车床车铣块外 `G00 C..` + `G19` → `#CAX` + 0–360 + `G19`，分度铣里的 `G18` 后加 `#CAX OFF`；车铣块外其他带 C 的段报错；

3. 标准题 `tests/test_cam_post_fagor.py`：

   - 90° 方向：`G00 C90.0` 原样。
   - 不出：车铣块外 `G01 … C..`。
