# ADR-0109：后处理配置文件格式 cam-post/1

- 状态：已接受（2026-11-19，属于 ADR-0106 Q5 已确认的计划：可配置后处理）
- 日期：2026-11-19
- 补充：ADR-0104（问渠CAM 安全底线）、ADR-0105（机床、刀具格式）、ADR-0106（Q5 施工细则）

## 背景

问渠CAM 的后处理（FANUC、西门子、广数）写死在代码里。车间要的写法各不相同：程序号位数、有没有顺序号、小数位、注释写不写中文、
换刀前要不要先回 Z 参考点、工序间要不要 M01、冷却用哪个 M 代码、钻孔用不用固定循环、要不要子程序。每家都改代码不可行。

## 决策

后处理配置写成 JSON 文件，格式 cam-post/1（`schema/cam-post.schema.json`）：

- 必需：`id`、`name`、`family`（fanuc / siemens / gsk / hnc / heidenhain，决定基本语法和回读规则）、`kinds`（lathe / mill）、`source`（配置从哪里来）。
- 可选开关：`program`（程序号位数、前后写不写 %、M30 还是 M02）、`sequence`（顺序号开关、起始、步长）、`decimals`（坐标、进给小数位）、
  `comments`（ascii / utf8 / none）、`tool_change`（换刀前后动作、工序间 M01）、`coolant`（flood / mist / through / off）、
  `cycles`（铣的钻孔循环、车的 G71 / G70 / G76）、`subprograms`（每道工序一个子程序）。不写的项按家族缺省（等于现在的输出）。
- `verified`：实机验证记录（日期、机床、谁确认）。没有这一项就是“未经实机验证”，程序头照写。
- 换刀前后动作只能是大写字母、数字、空格和 `. = + -`，写不进注释、宏变量或括号——配置文件只是开关，不是任意代码。

安全底线不在配置里，改不了：没有整机仿真或仿真不通过不出程序；程序写好后按同一套规则回读（顺序号、子程序、循环都展开），
与仿真刀路逐段比，对不上不出；没实机验证的程序头写“未经实机验证”。

## 影响

- 内置三份配置（FANUC、西门子、广数）等于现在的写法，例子程序一字不变；加华中 HNC-8。用户配置放 `用户目录\.freecad-ai-parts\posts\`。
- 测试：`tests/fixtures/cam-post/` 两个有效例子（最少、全写），四个无效例子（不认识的家族、验证记录缺机床、换刀动作有小写和注释、缺来源）。
- 实现另走代码 PR（ADR-0106 Q5a）。
