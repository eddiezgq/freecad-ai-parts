# ADR-0041：按两侧端口尺寸生成转接件（轴套与转接板）

- 状态：已接受（2026-10-02，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-02
- 补充：ADR-0007（转接件作为独立组件）、ADR-0029（链路模板与候选求解）

## 背景

真实电机与减速器很少能直接对接：

- 电机轴径和减速器输入孔径通常不同
- 电机法兰和减速器的电机安装面也不同

M1–M5 用的转接件是虚构的库存件，组件库里正好有尺寸对得上的轴套和转接板。真实数据里没有这样的库存件，转接件一般按两侧尺寸专门设计、加工。

如果没有转接件，候选求解会跳过几乎所有真实的电机 + 减速器组合（issue #129）。

## 决策

1. **由引擎生成**：`engine/adapters.py` 按电机与减速器的端口尺寸生成转接件
   - 实现为纯函数，不联网，不读数据库
   - `compose_chain(..., generate_adapters=True)` 时，组件库里找不到合适的轴套或转接板，就为这一对电机、减速器各生成一个
   - 组件库里有合适的库存件时，优先用库存件
2. **生成件的身份**：
   - id 为 `adapter.fap-generated.<规格>`，厂商记为 `freecad-ai-parts (generated)`，`license: open`（与本项目同为 Apache-2.0）
   - 每个参数 `method: computed`，`source.formula` 写明设计规则
   - `note` 注明“按两侧端口尺寸生成的设计件，须加工；加工前按图纸复核”
   - 生成件不进入组件库，每次求解时重新生成，同一输入结果相同
3. **轴套**（电机轴 → 减速器输入孔）：
   - 只在轴径小于孔径时生成
   - 内孔配电机轴：公差 H7；电机轴有键时内孔开键槽，键宽与电机相同，用键连接；光轴时用夹紧环
   - 外圆配减速器输入孔：公差 h6；减速器孔要求压装时改用 k6（过渡配合）；减速器孔有键时外圆开键槽，键宽与减速器相同
   - 长度取电机轴可用长度与减速器孔深中较小的一个，两者都没有时不生成
   - 最小壁厚为 1.5 mm，再加上键槽占用：内孔键槽按键宽的 0.45 倍，外圆键槽按键宽的 0.6 倍（近似 DIN 6885 的轮毂与轴键槽深度）。内外键槽错开 180°，只加较深的一个。壁厚不够时不生成，并说明原因
   - D 形、花键不生成
4. **转接板**（电机法兰 → 减速器电机安装面）：
   - 电机侧：
     - 分度圆、孔数、第一个孔的角度与电机法兰相同
     - 电机侧为通孔时，板上攻螺纹：取 ISO 273 中等系列间隙孔不大于该通孔的最大螺纹
     - 电机侧为螺纹孔时，板上开该螺纹的中等系列间隙孔
   - 减速器侧：规则相同
   - 止口：对方是凸止口，板上做凹止口（H7）；对方是凹止口，板上做凸止口（h7）；对方没有止口，板上也不做
   - 板厚：取 8 mm 和螺纹深度（1.5 倍螺纹直径）加 2 mm 中较大的一个，向上取整
   - 外形为正方形：边长取电机法兰边长、两侧分度圆加孔边距、止口加 6 mm 中最大的一个，向上取偶数
   - 两侧孔位会碰撞时，把减速器侧孔位转半个孔距；仍然碰撞时不生成
5. **质量**：轴套按钢（7850 kg/m³），转接板按铝合金（2700 kg/m³），用外形体积计算，偏保守
6. **生成件必须通过检查**：每个生成件都要通过 schema 校验，以及它所在连接的 C1–C3 检查（单测覆盖）。生成规则只决定转接件自身的尺寸，不改动电机或减速器的任何数据

## 理由

- 转接件本来就是关节设计中要自己画的零件。由引擎按规则生成、写明公式，比让 LLM 临时编尺寸可靠，也可复现
- 不改 schema：生成件用已有的 `computed` 方法和 `license: open` 就能表达
- 设计规则是本项目的设计约定，不是厂商数据；规则偏保守，并要求加工前复核

## 影响

- 新增 `engine/adapters.py`；`compose_chain` 增加 `generate_adapters` 参数，默认关闭，保持现有 golden 与样例结果不变
- MCP 工具与端到端演示在用真实组件库时开启（issue #130）
- BOM 中生成件标为“须加工”
