# ADR-0132：NUM Flexium 车铣——C 轴分度 + Y 轴铣（G19）

- 状态：已接受（2026-11-26，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”，2026-11-26 “好”继续 STATUS 下一步）
- 日期：2026-11-26
- 补充：ADR-0128（NUM 车铣端面 G21、圆柱面 G22，第 5、7 条把 G19 留着没做）、ADR-0106 C2b（C 分度 + Y 轴铣的中间写法）

## 背景

问渠CAM 圆柱面上宽于刀径的平底槽用 C 轴分度 + Y 轴铣（ADR-0106 C2b），FANUC 中间写法是：

```
G00 C<角度>      分度（绝对角度，可以是负数，如 C-60.0）
G19              YZ 平面
G00 X<直径> Y.. Z..  /  G01 …   （X 直径、Y 切向、Z 轴向，只有直线段）
G00 Y0.0
G18
```

ADR-0128 第 5 条 NUM 车床代码表不收 G19，带这种铣削段的程序不出。查 NUM《Flexium Programming Manual》M00018EN-03：

| 项 | 手册 | 与 FANUC 中间写法比 |
| --- | --- | --- |
| G19 | §5.4：G17 / G18 / G19 选平面，模态，互相取消；换平面要在 G40 下 | 相同 |
| G19 里的圆弧 | §5.7.5.1：G19 写 `Y.. Z.. J.. K..` | 相同（平底槽刀路本来只有直线段） |
| X 直径 | §5.18.1：G20 是缺省状态（被 G21 / G22 取消）；参数 E11005 写明直径编程只在 G20 下有效 | 分度铣在 G20 下（不在 G21 / G22 块里），X 仍是直径，相同 |
| C 绝对值 | §4.4.1：回转轴 G90 下写的值是 0–360° 的终点角，**正负号是转的方向**（`B+270` 与 `B-270` 到同一个角度）；§5.18.1：C 按 360° 取模 | **不同**：FANUC `C-60.0` 是 −60°（= 300°）的位置；NUM `C-60.0` 是反转到 60°，差 120° |

## 决策

1. **代码表**：NUM 车床加 `G19`（§5.4）。
2. **分度角**：车铣块（G21 / G22）外面的 `C` 一律换成 0 ≤ C < 360 的正数写法（`C-60.0` → `C300.0`，`C360.0` → `C0.0`），按 §4.4.1 正转到这个角度；4 位小数以内（§5.1.4）。
   分度时刀已退到安全位（问渠CAM 分度前先 G00 回换刀点），转的方向不影响零件。
3. **回读**：`to_fanuc` 原样读回 `C300.0`；`C300.0` 与 `C-60.0` 在工件坐标里是同一个刀位（`millturn.index_to_work` 按 Rz(θ)），按刀路比对。
4. 车铣块外、带 C 的不是 `G00` 段的（C 轴参与切削插补）不出：问渠CAM 只在分度和进 G22 前用 G00 写 C。
5. 不做：发格的 C 分度 + Y 轴铣（ADR-0131 仍不收 G19，另按发格手册做）、B 轴车铣、双主轴、多通道。

## 理由

- 平面选择、圆弧写法、直径编程在手册里与 FANUC 一致，有章节可查；唯一的差别是回转轴绝对值的正负号，手册 §4.4.1 写明、有例题，换成 0–360 的正数就消除了。
- 负角度不换的话，`C-60` 在 NUM 上停在 60°，槽铣到另一个位置——这是要拦的真错。

## 施工细则（2026-11-26）

1. 本 ADR（不改 schema）。
2. `analysis/cam/num.py`：`CODES_G_LATHE` 加 `19`（§5.4）；`to_num` 车床车铣块外的 `G00 … C..` 段 C 取模成 0–360；车铣块外带 C 的非 G00 段报错；`check_codes` 去掉“C 分度还没做”的点名。
3. 标准题 `tests/test_cam_post_num.py`：
   - Ø50 上 −60° 方向的平底槽（宽 12、深 3）：程序能出，有 `G00 C300.0`、`G19`、`G18`，没有 `C-`；去料与积分值差 < 1%；回读与仿真刀路一致。
   - 90° 方向：`G00 C90.0` 原样。
   - 不出：车铣块外 `G01 … C..`。
   - ADR-0128 的“G19 不出”一条改成能出（不是 golden）。
   - 记录写进 `assist/cam_verification_cases.json`（CAM-103）。
4. 帮助（中、英）NUM 车铣一句加分度铣；ADR-0128 “不做”里的 G19 指向本 ADR；ADR-0106 E3、STATUS 记一笔。
