# ADR-0113：刀具分内孔、外圆（internal、min_bore_mm）

- 状态：已接受（2026-11-22，属于 ADR-0106 Q4b）
- 日期：2026-11-22
- 补充：ADR-0105（刀具库）

## 背景

cam-tool/1 的车刀只按种类分（turn、groove、thread_turn、bore），分不出一把刀是车内孔还是车外圆。厂商样本里内、外螺纹刀片
（如泰珂洛 16IR15ISO 与 16ER15ISO）螺距相同、种类相同，起草工艺按螺距挑刀时可能把内螺纹刀片拿去车外螺纹。内孔刀还有“能进的最小孔径”，
孔比它小就进不去。

## 决策

1. 刀具加可选的 `internal`（布尔）：true = 内孔用；不写 = 外圆用（原有刀具不用改）。
2. 刀具加可选的 `min_bore_mm`：内孔刀能进的最小孔径（样本的 Dmin / DMIN）。
3. 实现（另一个 PR）：起草工艺时内孔工序（内螺纹、镗孔、内槽）只挑 `internal: true` 的刀，外圆工序不挑；
   `bore` 种类的刀没写 `internal` 时照旧当内孔刀（种类本身就是内孔）。计算时孔径小于刀的 `min_bore_mm` 报错。

## 影响

- schema 改动单独成 PR（本 ADR）：cam-tool 加两个可选字段、测试夹具。
