# ADR-0026：性能链校验（C4–C8）的实现约定

- 状态：已接受（2026-10-01，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-01

## 背景

实施细则第七节给出了公式 (1)–(6)，但没有说明系统缺少电机或减速器时怎么算，也没有说明效率给的是范围时取哪一端。实现 C4–C8（issue #50）前需要定下来。

## 决策

1. **组件缺席**
   - 系统没有减速器时按直驱处理：i = 1、η = 1，只校验电机侧
   - 系统没有电机时，只校验减速器侧
   - 两者都没有时，C4–C7 为“不适用”；C6 要求电机和减速器同时存在
2. **效率取值**：效率按范围给出时，折算到电机侧（公式 (1)(3)）用下限，过载保护（公式 (5)）用上限，两处都取对安全不利的一端
3. **需求缺项**
   - 需求没给峰值扭矩：C5 不适用
   - 需求没给负载惯量：C8 不适用（ADR-0016）
   - 安全系数默认 1.2，惯量比阈值默认 10（ADR-0008），需求中给出时以需求为准
4. **C7 平均输入转速限制**：该参数是选填，缺失时不做这一子项，不判 unknown；有值且超过时 warn
5. **C8 惯量**
   - 系统有减速器而它缺少输入侧惯量时判 unknown：该项在分子上，缺了会低估惯量比
   - 转接件（轴套等）的惯量 V1 忽略
6. **“≤ 限值”的判定**：测量值等于限值时通过，按相对误差 1e-12 处理浮点误差

## 理由

缺席时退化为直驱或只校验减速器侧，能让模板之外的系统也得到有意义的结果。效率取不利的一端，与 ADR-0025 的保守取数一致。

## 影响

链路模板（#53）始终包含电机和减速器；第 1 条主要用于人工搭建的系统。
