# ADR-0066：企业单机安装版与商业授权（M18）

- 状态：已接受（2026-10-08，项目负责人：“好的”；授权由 Claude 代定的三个选项见“决策 1”）
- 日期：2026-10-08
- 补充：ADR-0040（零件数据来源）、ADR-0056（分析模块）、ADR-0063（企业安装版）、ADR-0064（工厂清单）

## 背景

现在装 FreeCAD 工作台要先克隆仓库、自己装 FreeCAD、再跑 `freecad_addon/install.py`；生成的 `InitGui.py` 指回仓库目录，
FEA 依赖 gmsh、numpy、scipy，CalculiX、OpenFOAM 要自己装。企业设计员的电脑上做不到。
项目负责人还想向企业收费，并希望用技术手段防止企业把软件随意分发。

可以收费的前提和边界：

- 本仓库是 Apache-2.0，已经公开的代码不能收回，只能对**新增的**闭源部分、数据服务和支持收费。
- FreeCAD 是 LGPL，CalculiX、OpenFOAM、gmsh、ERPNext 是 GPL：可以随安装包分发（附许可证与源码获取方式），
  但不能对它们加锁或限制再分发。
- 厂商零件数据现在是 `license: params-only`（ADR-0040），多数厂商条款不允许商用。**收费的零件库必须先拿到厂商授权**
  （`data/sources.yaml` 里 `license: partner`），没拿到授权的来源不进收费零件库。

## 决策

1. **单机安装包**：Windows 优先（企业设计员主要用 Windows），之后再做 Linux。安装包**自带 FreeCAD 1.0.2**
   （与 `scripts/fetch_freecad.sh` 同版本），工作台装进 FreeCAD 的 `Mod` 目录、不依赖仓库；Python 依赖预装进 FreeCAD
   自带的 Python；**自带 CalculiX**；**CFD 不进安装包**，交给数字工厂服务器上的 cae 服务算（OpenFOAM 在 Windows 上
   太重），没连工厂时 CFD 显示“需要工厂服务器”。支持静默安装（企业 IT 批量部署）。安装包里有许可证与源码获取说明页。
   首次启动向导：填 AI 密钥（存本机用户配置，不进安装目录）、可选连接企业数字工厂。
2. **开源核心 + 闭源增值**：
   - 公开（Apache-2.0，免费）：工作台、选型与校验、公开零件库、教学数字工厂、单机安装包本身。
   - 收费：企业零件库订阅（厂商授权的数据，定期更新）、新增的企业高级功能、授权与席位管理、技术支持与定制。
   - 闭源模块放私有仓库（项目负责人创建，如 `eddiezgq/fap-enterprise`），用 Nuitka 编译成二进制模块发布，不发源码。
3. **授权文件**：JSON 加 Ed25519 签名，内容为企业名、到期日、席位数、功能清单、可选的机器指纹；公钥写进程序，
   私钥只在签发工具的环境变量里（不入任何仓库）。校验离线完成，不联网。到期后闭源功能停用，公开功能不受影响，
   已有设计文件照常打开。
4. **席位**：
   - 有数字工厂服务器的企业：**浮动席位**——授权文件装在服务器上，工作台启动时向工厂服务器租一个席位、定时续租，
     超过席位数就拒绝；断网有宽限期（7 天）。
   - 没有服务器的小企业：**单机绑定**——按机器指纹（主板、系统盘、网卡）签发，离线激活：程序生成激活码，
     我们签发授权文件发回。换电脑走解绑。
5. **零件库订阅**：按企业生成的零件库数据包带签名和客户水印（每条记录里不可见的客户标识），外泄能追到来源；
   授权里有该功能才加载。
6. **合同**：许可协议写明使用范围、不得转授与分发、审计条款。技术手段防的是随手拷贝，合同和水印管外泄追责。
7. 校验的结论只影响“能不能用闭源功能”，不影响 `engine/` 的选型校验结果；`engine/` 仍是纯函数。

## 后果

- 企业设计员一个安装包装好就能用，CI 在干净的 Windows 上验收
- 收入来自零件库订阅、高级功能和服务，不依赖锁住开源部分
- 要维护一个私有仓库和签发流程；授权私钥丢了要换公钥重发所有授权
- 收费零件库在拿到厂商授权前只能放我们自己有权发布的数据，这一项先做机制，数据随授权补
- 需要项目负责人做的事：创建私有仓库、生成并保管签名私钥、与厂商谈授权、拟许可协议
