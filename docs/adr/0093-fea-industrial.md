# ADR-0093：有限元模块做到接近商业可用——算例模型、可信度核查、装配与接触、非线性、动力学，AI 只起草不判定

- 状态：已接受（2026-11-13 22:42，项目负责人“好”：F1–F7 的顺序与代码归属照本 ADR）
- 日期：2026-11-13
- 补充：ADR-0056（本地运行的分析模块）、ADR-0059（第二批分析模块）、ADR-0060（计算内核并入 analysis/）

## 背景

项目负责人 2026-11-13 22:36：“开始完善我们的有限元模块，做 AI 重构，接近商业用，工业级”。

现在的 `analysis/fea`（搬自问渠数字工厂第 11 轮）：单个零件 STEP → Gmsh 二阶四面体 → CalculiX；线性静力、模态；
载荷只有固定、圆柱支承、面力、压力、扭矩；结果是最大 Von Mises（避开约束面）、位移、安全系数；标准题 4 道
（悬臂挠度、轴扭转、悬臂一阶频率、出错处理）。热、热—结构、疲劳在 `analysis/thermal`、`analysis/fatigue`。

和商业软件（ANSYS Mechanical、Abaqus、SolidWorks Simulation 这一档）比，缺的是：

| 方面 | 现在 | 商业软件的基本盘 |
|---|---|---|
| 算例怎么描述 | 一个 setup 字典，只够单零件 | 算例模型：几何（多体）、材料分配、连接、边界、载荷步、网格控制、结果请求，可存、可改、可复算 |
| 可信不可信 | 只报最大值 | 网格质量、反力平衡、网格收敛与误差估计、应力奇异点识别，结果附“可信度”结论 |
| 装配 | 不支持 | 绑定、接触（无摩擦 / 摩擦）、螺栓预紧 |
| 载荷边界 | 5 种 | 加上重力、离心、远端力 / 力矩、轴承载荷、强制位移、对称、弹性支承、温度场 |
| 非线性 | 不支持 | 材料弹塑性、大变形；线性屈曲 |
| 动力学 | 只有模态 | 预应力模态、谐响应、随机振动（PSD）、瞬态 |
| 规模 | 20 万单元、单线程网格 | 百万单元级、多线程 |
| 结果后处理 | Von Mises、位移 | 主应力、应力线性化（沿路径的膜 + 弯曲）、反力、安全系数分布、疲劳热点 |
| 验证 | 4 道题 | 公认考题（NAFEMS 线弹性、模态、接触、非线性各题）+ 解析解，每版回归 |

## 决策

1. **代码只有一份，在本仓库 `analysis/fea`**（Apache-2.0）；问渠数字工厂之后改为调用这一份（另开问渠的轮次，本 ADR 不动问渠）。
   FreeCAD 工作台、企业本地版、数字工厂都用同一套。
2. **分四层，层与层之间只传数据**：
   - **算例模型**（新 schema `schema/fea-study.schema.json`，单独的 PR 先行）：几何（一个或多个 STEP 体，带面 / 边 / 体的稳定编号）、
     材料分配、连接（绑定、接触、螺栓）、边界与载荷、分析步（静力、屈曲、模态、谐响应、随机、瞬态；可串联：预紧 → 工作载荷 → 预应力模态）、
     网格控制、结果请求、单位（只用标准单位，见 implementation-rules 第四节）。
   - **前处理**：Gmsh 网格（二阶四面体为主，薄件可选壳单元放后面），局部加密，网格质量报告（雅可比、长宽比、扭曲），
     网格收敛（自动加密两到三次，Richardson 外推，给“网格误差估计”）。
   - **求解适配**：CalculiX 为主（FreeCAD 自带，GPL 可执行程序以子进程调用，不链接）；接口留给 Code_Aster（以后，另立 ADR）。
     每次计算都在子进程里、有时限、可复现（单线程网格、固定随机种子）。
   - **后处理与可信度核查**（确定性代码，结论只有“通过 / 不通过 / 未知”）：反力与外载平衡（≤ 0.1 %）、网格质量、收敛误差、
     应力奇异点（随加密不收敛的点标出，不当设计依据）、材料数据是否齐全（缺就“未知”）。安全系数只在核查通过时给。
3. **AI 只起草，不判定**（与本项目总原则一致）：
   - 起草算例：从一句话 + 零件（面的类型、孔、轴承座、螺纹孔识别）提议约束、载荷、连接、网格控制；人在界面上确认后才算。
   - 解释结果、写报告草稿、指出可疑处（例如“最大应力在尖角上，随网格加密在长”）——这些说法都来自核查层的确定性结论，AI 不自己下结论。
   - AI 不改结果、不决定“合格”。测试不调用真实 LLM。
4. **验证体系**：`tests/fea_bench/` 放标准题，每题写明出处和参考值（NAFEMS 公开发表的参考值、教材解析解：Lamé 厚壁圆筒、
   Kirsch 圆孔板、悬臂梁、欧拉屈曲、平板固有频率、Hertz 接触等）；每题判据写明容差；新功能先有题再有代码。
   参考值查不到原文核对的不进测试（照 implementation-rules 第八节，来源登记）。
5. **分段**（每段一个 PR；schema 改动单独 PR 并附 ADR 补充）：

| 段 | 内容 | 验收 |
|---|---|---|
| F1 | 算例模型 schema；现有静力、模态改成从算例模型跑（旧 setup 自动转换，旧测试不改通过）；可信度核查层（反力平衡、网格质量、收敛与误差估计、奇异点） | 旧 4 题照过；新增 Lamé、Kirsch、NAFEMS LE1、LE10；奇异点题（L 形内角）判“不收敛” |
| F2 | 载荷边界补齐：重力、离心、远端力 / 力矩（分布耦合）、轴承载荷（余弦分布）、强制位移、对称、弹性支承、温度场（接 `analysis/thermal`） | 每种至少一道解析题；反力平衡全过 |
| F3 | 多体与连接：绑定、接触（无摩擦、摩擦，面对面）、螺栓预紧；分析步串联 | Hertz 接触、过盈配合（Lamé）、螺栓预紧力 |
| F4 | 非线性：弹塑性（材料曲线必须有出处）、大变形；线性屈曲 | 欧拉屈曲、薄壁圆筒、塑性铰（解析） |
| F5 | 动力学：预应力模态、谐响应、随机振动（PSD 输入 → RMS 应力）、瞬态 | 单自由度、悬臂梁谐响应解析解；NAFEMS 模态题 |
| F6 | AI 起草与报告：算例起草、结果解释、报告草稿（Word / PDF 由报告模板出），全部人确认 | 起草的算例都过 schema 校验；报告里每个数字来自结果文件（测试核对） |
| F7 | 规模与集成：百万单元级（求解器多线程、内存估计、超限先报）；FreeCAD 工作台面板；问渠数字工厂接入另开轮次 | 50 万单元算例本机跑通并记录时间、内存 |

## 理由

- 先把“结果可不可信”做成确定性的核查，再扩功能：商业软件真正值钱的是用户敢用结果；本项目的原则也是“影响能不能用的判断由确定性代码给出”。
- CalculiX 已能做接触、塑性、大变形、屈曲、谐响应、随机振动，缺的是前后处理和核查，不必换求解器。
- 算例模型先定 schema：以后 FreeCAD 面板、网页、AI 起草都写同一份数据，不各自拼 setup。

考虑过的替代方案：
- 换 Code_Aster 为主：功能更全，但 FreeCAD 不自带、安装重；先留接口。
- 直接让 AI 选约束和判结果：不做——会把不可复核的判断放进“能不能用”的结论里。

## 影响

- 新 schema 一份（单独 PR）；`analysis/fea` 结构重排，但 `run(setup)` 的旧写法保留兼容。
- 依赖不增加（gmsh、numpy、scipy、CalculiX）；报告导出复用现有 python-docx。
- 问渠数字工厂的 `cae/solve.py` 暂不动，F7 之后另开问渠的轮次改为调用本仓库。
- 计算时间：网格收敛要多算两到三遍，缺省只对最大应力处局部加密复算，时间约为单次的 2–3 倍，界面可关。

## 补充：算例模型第一版（F1，2026-11-13）

`schema/fea-study.schema.json`，`format` 为 `fea-study/1`：

- `bodies`：F1 只允许一个（`maxItems: 1`），每个写 `id`、`step_path`、`material`（材料库 id）。
- `supports`：`fixed`、`cyl_support`；`loads`：`force`（`vector_n`）、`pressure`（`value_mpa`）、`torque`（`value_nm` + `axis`）、`moment`（`vector_nm`）。
  每项都写 `body` 和 `faces`（面编号同 `analysis: faces` 的清单）。轴线写 `axis: {origin_mm, dir}`（旧 setup 的 `origin` 改名带单位）。
- `steps`：`static`、`modal`（`n_modes`）；有多个时依次算，同一份网格。
- `mesh`：`size_mm`、`refine_faces`、`max_elements`。
- `checks`：`convergence`（缺省开）、`levels`（3–4）、`refine_ratio`（1.3–2.0，缺省 1.6）、`tolerance_ratio`（GCI 上限，缺省 0.05）、
  `balance_tolerance_ratio`（反力平衡，缺省 0.001）。
- `provenance`：`drafted_by`（human / ai）、`confirmed_by_human`；AI 起草且未确认的算例不算（F1 就执行这条）。

旧的 `run(setup)` 写法（`step_path` + `loads` 混写支承和载荷）继续可用：内部转换成算例模型；为了不改旧测试与示例，旧写法的结果照旧给安全系数，
同时附可信度核查结果并注明“安全系数未经网格收敛核查”（旧写法缺省不做收敛）。新写法只在可信度核查结论为“通过”时给安全系数，
否则给 `safety_factor: null` 和原因。

## 补充：F1 施工记录（2026-11-13）

- 代码：`analysis/fea/study.py`（校验、旧写法转换、按算例计算）、`analysis/fea/trust.py`（核查，纯函数）；`solve.py` 加局部加密、网格质量、
  反力输出与平衡计算；`run()` 收到 `format: fea-study/1` 时走新写法。模块版本 1 → 2。
- **CalculiX 的反力**：`.frd` 里的 RF 是节点上的全部外力（支承反力 + 加在该节点上的载荷），整体坐标——受约束又受载的节点（例如压力面与约束面
  交界的一圈）要减去载荷才是反力。按这个算，悬臂、厚壁圆筒、圆孔板的合力、合力矩误差都在 10⁻⁶ 量级。
- **网格收敛**：在原网格最大应力处加一个加密球，逐层把局部尺寸缩小 1.6 倍；局部尺寸取最大应力节点周围单元的平均边长，相邻两层的实际比值不相等，
  观察阶按 Celik 等（2008）的迭代式求；来回振荡时按 Stern 等（2001）取半个变化幅度；各层几乎一样（相差不超过容差的 1/5）直接通过。
- 标准题（`tests/test_fea_bench.py`）：Lamé 厚壁圆筒（偏差 +0.5 %，核查通过）、Kirsch 圆孔板（3.05σ，对 3.0 偏 +1.8 %，核查通过，
  网格误差估计 0.4 %）、L 形凹角（越加密越大，判“疑似奇异点”，不给安全系数；位移收敛）、悬臂反力平衡、Richardson / GCI 公式题。
- **偏差**：NAFEMS LE1、LE10 挪到 F2——它们要对称面和强制位移边界，F1 还没有；参考值届时按原始出处核对后再进测试。
- **发现、留给 F2**：曲面上的压力按三角形角点所成平面的法向分配，厚壁圆筒内压的合力本应为 0，实际有 1.7 × 10⁻⁴ 倍总压力的轴向残量；
  F2 改为按二阶面的真实法向积分。

## 补充三：F2 施工记录（2026-11-14）

- 新边界与载荷全部按补充二实现；结果另加 `probes`（探针）和 `support_reactions`（各支承的反力与对原点的力矩：一个节点的某方向被几个支承共同限制时，
  这一方向的反力算给先写的那个）。
- **曲面上的面力改为在二阶曲面上 7 点高斯积分**（位置、法向逐点取），F1 发现的“曲面压力合力有残量”消失；平面上与原来逐位相同，旧测试照过。
- **反力平衡计入体力**：重力、离心的等效节点力按 C3D10 同样的 4 点积分算出，CalculiX 的 RF 在受约束节点上含体力份额，同样减掉；
  平衡判定的分母加下限（1 N、1 N × 模型尺寸），只有温度变化、强制位移时不会因为“全是 0”误判。
- **网格的三处稳健性修正**（这些在 F1 前就存在，改在共用的 `mesh()` 里，热分析、模态同样受益）：
  1. 不再在生成网格时开 gmsh 高阶优化：它在薄板网格上抛出 C++ 异常、整个进程直接退出（不是 Python 异常，接不住）。改为先生成一阶、再升二阶；
     升阶后有很扭曲的单元（最小缩放雅可比 < 0.1）时改用直边二阶单元，并在网格质量核查里判“未知”、提示加密。
  2. 曲面网格自检：带尺寸场时，个别曲面（椭圆柱面）上缺省算法会连出横跨整个面的三角形；边长超过 3 倍单元尺寸的面改用 MeshAdapt 重划。
  3. STEP 里有几块贴合的实体时先粘成共面共节点（`fragment`），否则各块互不相连。
- **收敛核查改为比较加密球内的最大应力**（三层都用同一个球；第 0 层取原网格在球内的最大值），不再比较全局最大值——全局最大可能跳到别处、
  把不同位置的数混在一起比。最细一层别处的应力比核查点还大（超过容差）时加一条“未知：那一处没有核查收敛”。
- 标准题（`tests/test_fea_f2.py`）：
  - NAFEMS LE1 椭圆膜：D 点 σyy = 92.76 MPa（参考 92.7，+0.06 %）；收敛核查通过（92.77，解析参考 92.658）。
  - NAFEMS LE10 厚板：D 点 σyy = −5.384 MPa（参考 −5.38，+0.07 %，4.1 万个单元）。
  - 自重悬臂、强制位移拉杆（σ 与反力精确到 10⁻⁴）、自由热膨胀（位移精确到 10⁻⁶、应力 ≈ 0）、旋转圆盘中心应力、弹性地基、远端载荷、轴承载荷合力。
- 参考值出处写在测试文件开头：NAFEMS TNSB Rev. 3（1990）的 LE1、LE10，几何与边界按 Ansys 验证手册、Abaqus 基准手册、COMSOL 模型说明、
  seamplex Fino 案例逐项核对过。

## 补充四：算例模型加 F3 的内容（2026-11-15）

项目负责人 11-15 12:26“好”：做 F3。`fea-study/1` 只加不改：

- `bodies` 最多 20 个，各自的 STEP、各自的材料；支承、载荷、连接里的面编号都是各自 STEP 里的编号（同 `analysis: faces` 单独列出的编号）。
- `connections`：
  - `bonded`（绑定）：`a`、`b` 两侧各为 `{body, faces}`，`a` 为从面；网格可以不一致（CalculiX `*TIE`）；`tolerance_mm` 缺省为单元尺寸的 1/10。
  - `contact`（接触）：面对面、非线性，`friction_coefficient` 缺省 0；罚刚度由程序按材料和网格定，不让用户填（填错最常见）。
  - `bolt_preload`（螺栓预紧）：在 `body` 上过 `point_mm`、垂直于 `axis_dir` 的截面施加 `force_n`（拉为正）。算两步：第一步只加预紧，
    第二步锁住截面长度、加其余全部载荷——即“预紧 → 工作载荷”的分析步串联。截面不用在 CAD 里切开：程序沿网格把螺栓分成截面两侧、
    复制截面上的节点，用约束方程连接两侧（法向的相对位移由一个参考节点控制，预紧力加在参考节点上）。
- 夹具：`invalid/two_bodies.json`（F1 只许一个实体）删掉，换成 `invalid/too_many_bodies.json`（超过 20 个）。
- 用户自定的多个分析步（不同步加不同载荷）这一版仍不开放：算例里的载荷都在最后一步一起加；只有螺栓预紧会自动多出前面一步。
