# ADR-0093：有限元模块做到接近商业可用——算例模型、可信度核查、装配与接触、非线性、动力学，AI 只起草不判定

- 状态：提议（2026-11-13，待项目负责人确认）
- 日期：2026-11-13
- 补充：ADR-0056（本地运行的分析模块）、ADR-0059（第二批分析模块）、ADR-0060（计算内核并入 analysis/）

## 背景

项目负责人 2026-11-13 22:36：“开始完善我们的有限元模块，做 AI 重构，接近商业用，工业级”。

现在的 `analysis/fea`（搬自问渠数字工厂第 11 轮）：单个零件 STEP → Gmsh 二阶四面体 → CalculiX；线性静力、模态；
载荷只有固定、圆柱支承、面力、压力、扭矩；结果是最大 Von Mises（避开约束面）、位移、安全系数；标准题 4 道
（悬臂挠度、轴扭转、悬臂一阶频率、出错处理）。热、热—结构、疲劳在 `analysis/thermal`、`analysis/fatigue`。

和商业软件（ANSYS Mechanical、Abaqus、SolidWorks Simulation 这一档）比，缺的是：

| 方面 | 现在 | 商业软件的基本盘 |
|---|---|---|
| 算例怎么描述 | 一个 setup 字典，只够单零件 | 算例模型：几何（多体）、材料分配、连接、边界、载荷步、网格控制、结果请求，可存、可改、可复算 |
| 可信不可信 | 只报最大值 | 网格质量、反力平衡、网格收敛与误差估计、应力奇异点识别，结果附“可信度”结论 |
| 装配 | 不支持 | 绑定、接触（无摩擦 / 摩擦）、螺栓预紧 |
| 载荷边界 | 5 种 | 加上重力、离心、远端力 / 力矩、轴承载荷、强制位移、对称、弹性支承、温度场 |
| 非线性 | 不支持 | 材料弹塑性、大变形；线性屈曲 |
| 动力学 | 只有模态 | 预应力模态、谐响应、随机振动（PSD）、瞬态 |
| 规模 | 20 万单元、单线程网格 | 百万单元级、多线程 |
| 结果后处理 | Von Mises、位移 | 主应力、应力线性化（沿路径的膜 + 弯曲）、反力、安全系数分布、疲劳热点 |
| 验证 | 4 道题 | 公认考题（NAFEMS 线弹性、模态、接触、非线性各题）+ 解析解，每版回归 |

## 决策

1. **代码只有一份，在本仓库 `analysis/fea`**（Apache-2.0）；问渠数字工厂之后改为调用这一份（另开问渠的轮次，本 ADR 不动问渠）。
   FreeCAD 工作台、企业本地版、数字工厂都用同一套。
2. **分四层，层与层之间只传数据**：
   - **算例模型**（新 schema `schema/fea-study.schema.json`，单独的 PR 先行）：几何（一个或多个 STEP 体，带面 / 边 / 体的稳定编号）、
     材料分配、连接（绑定、接触、螺栓）、边界与载荷、分析步（静力、屈曲、模态、谐响应、随机、瞬态；可串联：预紧 → 工作载荷 → 预应力模态）、
     网格控制、结果请求、单位（只用标准单位，见 implementation-rules 第四节）。
   - **前处理**：Gmsh 网格（二阶四面体为主，薄件可选壳单元放后面），局部加密，网格质量报告（雅可比、长宽比、扭曲），
     网格收敛（自动加密两到三次，Richardson 外推，给“网格误差估计”）。
   - **求解适配**：CalculiX 为主（FreeCAD 自带，GPL 可执行程序以子进程调用，不链接）；接口留给 Code_Aster（以后，另立 ADR）。
     每次计算都在子进程里、有时限、可复现（单线程网格、固定随机种子）。
   - **后处理与可信度核查**（确定性代码，结论只有“通过 / 不通过 / 未知”）：反力与外载平衡（≤ 0.1 %）、网格质量、收敛误差、
     应力奇异点（随加密不收敛的点标出，不当设计依据）、材料数据是否齐全（缺就“未知”）。安全系数只在核查通过时给。
3. **AI 只起草，不判定**（与本项目总原则一致）：
   - 起草算例：从一句话 + 零件（面的类型、孔、轴承座、螺纹孔识别）提议约束、载荷、连接、网格控制；人在界面上确认后才算。
   - 解释结果、写报告草稿、指出可疑处（例如“最大应力在尖角上，随网格加密在长”）——这些说法都来自核查层的确定性结论，AI 不自己下结论。
   - AI 不改结果、不决定“合格”。测试不调用真实 LLM。
4. **验证体系**：`tests/fea_bench/` 放标准题，每题写明出处和参考值（NAFEMS 公开发表的参考值、教材解析解：Lamé 厚壁圆筒、
   Kirsch 圆孔板、悬臂梁、欧拉屈曲、平板固有频率、Hertz 接触等）；每题判据写明容差；新功能先有题再有代码。
   参考值查不到原文核对的不进测试（照 implementation-rules 第八节，来源登记）。
5. **分段**（每段一个 PR；schema 改动单独 PR 并附 ADR 补充）：

| 段 | 内容 | 验收 |
|---|---|---|
| F1 | 算例模型 schema；现有静力、模态改成从算例模型跑（旧 setup 自动转换，旧测试不改通过）；可信度核查层（反力平衡、网格质量、收敛与误差估计、奇异点） | 旧 4 题照过；新增 Lamé、Kirsch、NAFEMS LE1、LE10；奇异点题（L 形内角）判“不收敛” |
| F2 | 载荷边界补齐：重力、离心、远端力 / 力矩（分布耦合）、轴承载荷（余弦分布）、强制位移、对称、弹性支承、温度场（接 `analysis/thermal`） | 每种至少一道解析题；反力平衡全过 |
| F3 | 多体与连接：绑定、接触（无摩擦、摩擦，面对面）、螺栓预紧；分析步串联 | Hertz 接触、过盈配合（Lamé）、螺栓预紧力 |
| F4 | 非线性：弹塑性（材料曲线必须有出处）、大变形；线性屈曲 | 欧拉屈曲、薄壁圆筒、塑性铰（解析） |
| F5 | 动力学：预应力模态、谐响应、随机振动（PSD 输入 → RMS 应力）、瞬态 | 单自由度、悬臂梁谐响应解析解；NAFEMS 模态题 |
| F6 | AI 起草与报告：算例起草、结果解释、报告草稿（Word / PDF 由报告模板出），全部人确认 | 起草的算例都过 schema 校验；报告里每个数字来自结果文件（测试核对） |
| F7 | 规模与集成：百万单元级（求解器多线程、内存估计、超限先报）；FreeCAD 工作台面板；问渠数字工厂接入另开轮次 | 50 万单元算例本机跑通并记录时间、内存 |

## 理由

- 先把“结果可不可信”做成确定性的核查，再扩功能：商业软件真正值钱的是用户敢用结果；本项目的原则也是“影响能不能用的判断由确定性代码给出”。
- CalculiX 已能做接触、塑性、大变形、屈曲、谐响应、随机振动，缺的是前后处理和核查，不必换求解器。
- 算例模型先定 schema：以后 FreeCAD 面板、网页、AI 起草都写同一份数据，不各自拼 setup。

考虑过的替代方案：
- 换 Code_Aster 为主：功能更全，但 FreeCAD 不自带、安装重；先留接口。
- 直接让 AI 选约束和判结果：不做——会把不可复核的判断放进“能不能用”的结论里。

## 影响

- 新 schema 一份（单独 PR）；`analysis/fea` 结构重排，但 `run(setup)` 的旧写法保留兼容。
- 依赖不增加（gmsh、numpy、scipy、CalculiX）；报告导出复用现有 python-docx。
- 问渠数字工厂的 `cae/solve.py` 暂不动，F7 之后另开问渠的轮次改为调用本仓库。
- 计算时间：网格收敛要多算两到三遍，缺省只对最大应力处局部加密复算，时间约为单次的 2–3 倍，界面可关。
