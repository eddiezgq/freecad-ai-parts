# ADR-0002：端口类型库用自定义轻量 JSON Schema，概念上对应 SysML v2

- 状态：已接受
- 日期：2026-09-30

## 背景

组件以"端口 + 参数 + 包络"的黑箱描述，端口类型库是自动匹配能否可靠的关键。需要决定是自定义格式还是直接采用 SysML v2 的语法。

## 决策

自定义一套简洁的 JSON Schema（Draft 2020-12）描述组件、端口、连接规则和系统；概念上一一对应 SysML v2（端口定义、端口用法、接口），并提供导出。不直接采用 SysML v2 的文本语法。

## 理由

- SysML v2 面向系统工程师，语法较重；LLM 从规格书抽取到其语法更容易出错
- JSON Schema 便于校验、便于 LLM 结构化输出、便于数据库存储
- 概念对齐保证将来能导出给系统工程工具，不被锁死

## 影响

- `schema/` 为全项目共同契约，M1 定稿，CI 自动校验
- 后续增加 SysML v2 导出（不在 V1 范围）
