# ADR-0135：运动副摩擦加导轨长度、销长度，反力矩换成两端接触力（问渠 CAD 0.4）

- 状态：已接受（问渠 CAD 0.4 细则第二节 3；Eddie 2026-11-26 22:15“可以一直做和验证，不要上线，直到我通知”）
- 日期：2026-11-26

## 背景

《多体动力学》书第 20 章线索第 28 条：mbd-model/1 的运动副摩擦（D2）正压力只取横向反力 |F⊥| + 预载，
不计垂直于运动方向的反力矩。真实的移动副靠导轨两端接触来承受这个力矩（抽屉效应），接触力 ≈ M/l，两端都有摩擦：

- 抽屉（1 kg、20 N 推力偏 100 mm、10 N 阻力、导轨长 100 mm）：μ = 0.25 应刚好推不动，问渠在 μ = 0–0.6 都算出 10 m/s²。
- 曲柄滑块（滑块长 40 mm）θ = 90°、μ = 0.5：驱动力矩应 11.33 N·m，问渠 9.01 N·m；μ = 0.9 时 99.6 对 16.1 N·m，自锁的 μ 由 0.96 变成 1.61。

转动副同理：销（轴承）有长度时，垂直于轴的弯矩由两端轴承承受。

## 决策

`joints[].friction` 加两个**可选**字段（单位 mm）：

| 字段 | 用于 | 含义 |
|---|---|---|
| `guide_length_mm` | 移动副 | 导轨接触长度 l |
| `pin_length_mm` | 转动副 | 销（轴承）长度 l |

给了时正压力取 N = |F⊥| + 2|M⊥|/l + 预载（与书第 20 章同一写法：两端接触力各 M/l，再加横向力；是偏安全的上界，
不细分两端力的方向）。其中 F⊥ 是反力垂直于运动副轴的分量，M⊥ 是反力矩垂直于轴的分量，力矩对运动副点（body_j 上）取。
沿轴的力矩（移动副的扭转）不计入，在报告局限里写明。

- 不给时行为与现在完全一样，报告局限写“移动副摩擦没计反力矩（没给 guide_length_mm）”。
- 移动副写了 `pin_length_mm`、转动副写了 `guide_length_mm`：报模型错误（写错了地方，不悄悄忽略）。
- 只加可选字段，mbd-model/1 版本号不变，旧模型照样能读能算。

## 后果

- 摩擦与反力仍按现有的不动点迭代耦合；收敛因子约 2μh/l，≥ 1 时是真正的自锁，靠静摩擦过渡区（stiction_speed）停在近零速度。
- 运动副点要放在导轨（销）中点，反力矩才对；建模说明和面板提示写明。
- 验证题（实现 PR 里做成回归测试）：书第 20 章抽屉 μ = 0.25 加速度 0（≤ 1e-3 m/s²）、μ = 0.1 时与 P/(1 − 2μh/l) 一致；
  曲柄滑块 μ = 0.5、θ = 90° 驱动力矩 11.33 N·m（1 % 以内）。
- 面板（建模面板运动副摩擦）加两个输入项。
