# ADR-0050：向厂商索取资料与授权

- 状态：已接受（2026-10-05 项目负责人同意）
- 日期：2026-10-05
- 补充：ADR-0040（公开目录数据）、ADR-0043（引用核对）、ADR-0044 第 4 条（人工确认）

## 背景

公开目录只能收参数和接口尺寸（ADR-0040），CAD 外形、选项说明、未公开的型号都拿不到；有的厂商网站也不提供可下载的规格书。项目负责人决定主动向厂商索取资料，并在后台每天少量进行。

本项目将归入问渠（WenQuest）的 AI 原生工程平台：课程与教学资源免费，工程选型平台将来收费。

## 决策

1. **渠道**
   - 以电子邮件为主，发往厂商官网公开的销售、市场或技术支持邮箱；不从第三方名录搜集个人邮箱
   - 采购网站（1688、阿里巴巴国际站等）的在线询盘不自动发送：平台规则禁止程序批量询盘，账号由项目负责人所有。Claude 只准备待发清单与话术，由项目负责人自己发
2. **发信身份**
   - 以“问渠 WenQuest”名义署名，网址 wenquestrobotics.com
   - 第一阶段从项目负责人的 Gmail 发出；问渠域名邮箱设好收信转发与 Gmail 代发后改用问渠地址
3. **如实介绍**
   - 说明问渠正在建设 AI 原生的工程选型平台，同时用于免费的教学资源；不冒充买家，不承诺采购量，不夸大机构规模
4. **请求内容**
   - 公开的规格书、外形图或 CAD
   - 书面同意：允许把产品参数与接口尺寸收入选型平台，包括将来收费的商业平台；如同意，是否允许提供 CAD 下载链接
   - 厂商可随时要求修改或撤下
5. **中立性**
   - 邮件写明：收录免费；选型排序只依据校核结果与公开规则，不受厂商影响；选型理由对用户公开
   - 不接受以付费、资料或其他条件换取排序或推荐
6. **频率**
   - 每天最多 5 封新邮件；每家只跟进一次，不早于首封后 7 天；对方表示不需要即停止，不再联系
   - 头两周只建草稿，由项目负责人审阅后发出；之后经项目负责人同意可改为自动发送
7. **记录**
   - `data/outreach/log.yaml`：厂商、公开邮箱、出处网址、发出日期、状态（draft / sent / replied / declined / granted / no_reply）、收到的资料、对应来源 id
   - 只记录官网公开的单位邮箱，不记录对方个人的其他信息
8. **入库**
   - 收到的文件放 `data/raw/`，不入 git
   - 对方书面同意后，在 `data/sources.yaml` 登记为 `license: partner`，`terms_note` 写明同意的范围、日期与邮件主题；未明确同意的只按 ADR-0040 的 `params-only` 规则使用其公开目录
   - 规格书照常逐份登记、抽取并逐项核对，不因来自厂商而放松
9. **每日后台任务**
   - 查回信并更新记录；需要入库的资料列出清单；按缺口挑选下一批厂商建草稿；当天结果写进记录

## 理由

- 邮件可以留下书面同意，比在线聊天更适合作为授权依据
- 采购网站的自动询盘有封号风险，且对方多转到即时通讯，后台任务无法可靠跟进
- 中立性从第一封信写明，将来收费时不被动；也符合问渠“选型理由公开可查”的方向
- 写明商业用途，避免授权范围只覆盖教学

替代方案：用个人名义发信（与平台归属不符）；只用公开目录（拿不到 CAD 和未公开的型号）。

## 影响

- 新增 `data/outreach/`、`docs/outreach/` 两处
- `sources.yaml` 的 `partner` 来源开始出现，入库流程不变
- 第一批厂商按关节模组四类的缺口选择；第一个产品范围定下后，按新品类的缺口选择
