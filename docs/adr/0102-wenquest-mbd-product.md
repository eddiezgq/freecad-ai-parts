# ADR-0102：问渠多体动力学（WenQuest MBD）——把多体动力学模块做成可单独安装、销售的产品

- 状态：已接受（2026-11-18 12:42 项目负责人“好”）
- 日期：2026-11-18
- 补充：ADR-0096（问渠有限元，产品化的做法照它）、ADR-0097（多体工业化 D1–D8）、ADR-0098（隐式积分 HHT）、
  ADR-0101（大变形梁）、ADR-0066（单机安装与授权）、ADR-0063（AI 两家切换）

## 背景

多体动力学模块已经做完三轮：ADR-0097（D1–D8）、ADR-0098（E1–E3）、ADR-0101（F1–F3），全部合进主线（最后是 PR #576）。
现在能做的：

- **模型**：刚体；柔性体三种——模态梁、实体模态（STEP 缩减，带应力云图）、大变形梁。
- **连接与力**：六种运动副、驱动；力元（弹簧阻尼、扭簧、衬套、梁、IMPACT、样条）；摩擦、间隙；接触（球、平面、圆柱、曲线、网格）、齿轮啮合。
- **控制**：执行器，PID、状态空间、FMU 联合仿真。
- **分析**：运动学、静平衡（含分步加载）、动力学（显式 DOP853、隐式 HHT，自动建议）；线性化与模态；参数扫描、试验设计、优化；
  疲劳载荷谱交给疲劳计算。
- **FreeCAD 里**：
  - 从 Assembly 装配体或 STEP 建模。STEP 导入时，程序从几何找候选运动副，AI 只在候选里挑。
  - 窗口里能设驱动、柔性零件、积分器；能看曲线、动画、变形与应力云图。
  - 能出计算报告，数字可追溯；AI 只写解释。
- **可信度**：每次计算都核查约束残差、自由度、能量漂移和稳定性。对照题有四十多个，对解析解或独立程序。

项目负责人问：“现在可以打包成问渠多体动力学软件了吧？”可以。核心功能齐了；问渠有限元（ADR-0096）已经把产品化要的
共用设施做好了：版本与授权、中英翻译机制、模型网关、验证手册机制、Windows 安装包与 CI 验收。

还差的，与问渠有限元第一版对照：

| 项目 | 问渠有限元 | 多体现在 |
| --- | --- | --- |
| AI 走模型网关（国内 DeepSeek、国外 Claude） | 有 | 有（窗口已用同一个客户端） |
| 正式报告（Word / PDF，带审核栏） | 有 | 只有 Markdown |
| 中英双语（界面、报告） | 有 | 只有中文 |
| 验证手册 | 有（42 题） | 对照题散在测试里 |
| 单独的安装包、免费 / 专业两档 | 有 | 没有 |
| 用户手册（Word / PDF）、入门例子、产品页、销售方案 | 有 | 只有一份 Markdown 帮助 |

## 决策

### 1. 名称与定位

- 名称：中文“问渠多体动力学”，英文“WenQuest MBD”。
- 用户：做机器人、自动化设备、机构的中小企业工程师。他们买不起 ADAMS、RecurDyn，又要算驱动力矩、反力、振动和柔性。
- 卖点：
  1. **装配体直接算**：FreeCAD 装配体或 STEP 进来，程序找运动副，AI 帮着挑，人确认。
  2. **刚柔一体**：小变形、实体应力云图、大变形梁都有，硬系统自动换隐式积分。
  3. **每次计算带可信度核查**，配验证手册，每个数字能追到测试。
  4. **报告数字由程序填**，带出处账和审核栏。
  5. **界面就是 FreeCAD**。

### 2. 与零件库、问渠有限元的关系：同一份代码，再加一个安装包版本

- 不另开仓库、不复制代码（ADR-0060“分析只留一份”）。
- 版本（edition）加一个 `mbd`：只装多体窗口（装配体多体动力学、多体研究）、疲劳交接、帮助与授权菜单。
  零件库面板、选型、数字工厂、有限元三个按钮都不装。
- **套装**：一个授权文件可以同时开 `fea_pro` 和 `mbd_pro`。
  - 第一版仍是两个安装包，各装各的。
  - 多体里实体柔性件要用的 gmsh 和 CalculiX，问渠多体动力学的安装包自带。
  - 合成一个“问渠仿真”安装包放第二版。

### 3. 免费与专业两档（授权功能 `mbd_pro`，机制同 ADR-0096 决策 3：第一版只靠签名授权，不编译）

| 免费版 | 专业版（`mbd_pro`） |
| --- | --- |
| 刚体，最多 15 个构件 | 构件数不限 |
| 六种运动副、驱动 | AI 帮着挑运动副（STEP 导入） |
| 弹簧阻尼、扭簧、衬套、恒力、函数力 | 柔性体三种（模态梁、实体模态与云图、大变形梁） |
| 运动学、静平衡、动力学（DOP853） | 接触、齿轮啮合、摩擦、间隙 |
| 曲线、动画、核查结论 | 控制器（PID、状态空间、FMU） |
| 简要结果页（不出正式报告） | HHT 隐式积分、线性化与模态 |
| | 参数研究、优化；疲劳交接 |
| | 正式报告（Word / PDF，AI 解释）；技术支持 |

- 免费版遇到专业版功能时，说明是哪一项、怎么开放；不改任何计算结果和核查结论（同 ADR-0096）。
- 15 个构件够算一般的连杆机构、单个机器人关节、缝纫机挑线机构，够用户先信结果。

### 4. 两个市场

照 ADR-0096 决策 4，不另定：

- 中国：中文、DeepSeek、台州公司销售、软件著作权登记。
- 美国与国际：英文、Claude、美国公司销售、出口管制核一次分类。
- 公制单位；模型和结果只在用户本机。

### 5. 施工顺序（每步一个或几个 PR）

1. **报告升级**：`assist/mbd_report.py` 改用问渠有限元的报告排版，出 Word / PDF：
   - 公司抬头、审核栏、结果指纹、出处账；
   - 曲线图、构件与运动副表、核查表；
   - 柔性体写应力，大变形梁写内力。

   验收：三个样例出 Word / PDF；报告里每个数字逐个对回结果。
2. **中英双语**：多体窗口、研究窗口、核查说明、报告并入 `assist/i18n` 的对照表。
   验收：同一计算出中英两份报告，数字和指纹完全相同；测试核对多体模块每句显示给人的中文都有英文。
3. **验证手册**：多体对照题接入 `tests/verification.record`，题目清单 `assist/mbd_verification_cases.json`，出中英两版 Word / PDF。
   - 约 30 题，分刚体运动学与动力学、力元与接触、控制、线性化、柔性（模态、实体、大变形）、隐式积分六类。
   - 升速旋转梁太慢，不进测试；手册里单列，数字取自验证脚本，写明这一点。

   验收：全部题目在注明的误差内；手册里的数字能追到测试。
4. **安装包与授权**：
   - `assist/mbd_edition.py`（或把 `fea_edition` 推广成通用的版本模块）：`pro_needs(模型)`、`gate()`。
   - 卡口：计算前、STEP 导入时的 AI、出正式报告。
   - `installer/windows/build.ps1 -Edition mbd`，用新的 `wenquest-mbd.iss`（新 AppId），产物 `WenQuest-MBD-Setup-<版本>.exe`。
   - 在干净的 Windows 上做 CI 验收：
     1. 装好；
     2. 免费版算曲柄滑块；
     3. 拒绝柔性体和正式报告；
     4. 导入测试授权；
     5. 算柔性摆、AI 回放挑运动副；
     6. 出中英报告。
5. **帮助与入门**：
   - 用户手册中英各一份：由 `docs/mbd-help.md` 扩成，Word / PDF，截图自动截。
   - 入门例子三个，`examples/wenquest-mbd/`：
     1. 免费版：曲柄滑块，算驱动力矩和反力；
     2. 专业版：机器人关节 STEP 导入，AI 挑运动副，PID 控制，出报告；
     3. 专业版：柔性连杆（大变形梁）屈曲与振动，出报告。
   - 产品页、销售方案（中美各一份，定价参照公开报价的同类软件，写明出处和日期），给项目负责人定。

### 6. 不做的（第一版）

- 不做网页版计算，不做托管 AI。
- 实体零件的非线性大变形、变截面梁不做（ADR-0101 收尾已写）。
- 英制单位、Linux 与 macOS 安装包放第二版（同问渠有限元）。

### 7. 需要项目负责人做的事

- 软件著作权登记：用台州公司名义，第 4 步之后，材料我们准备。
- 定价和许可协议：第 5 步给出方案后定。
- 可选：Windows 代码签名证书（问渠有限元同一张可以共用）。

## 理由

- 计算、核查、AI、FreeCAD 结合都有了，问渠有限元又已经把产品化的共用设施做好。做问渠多体动力学主要是报告、语言、验证、安装包，
  五步就能出第一版。
- 一份代码：多体、有限元、零件库的结果永远一致。
- 免费版能算大多数刚体机构，让用户先信结果；柔性、接触、控制、隐式积分、优化和正式报告是付费的理由。
- 考虑过：
  - 直接和问渠有限元合成一个产品：两个市场的用户不完全重合（结构工程师和机构 / 机器人工程师）。分开卖、给套装价更灵活；
    合并安装包放第二版。
  - 免费版不设构件上限：免费版就能覆盖多数机构，专业版少了一个付费理由，不选。
