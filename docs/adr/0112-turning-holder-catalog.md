# ADR-0112：车刀刀杆库（cam-holder/1）——起草时给车刀片配刀杆

- 状态：已接受（2026-11-22，属于 ADR-0106 Q4b）
- 日期：2026-11-22
- 补充：ADR-0105（刀具库）、ADR-0107（车刀刀杆碰撞）

## 背景

厂商车刀片样本（如泰珂洛 ISO-EcoTurn，ADR-0106 Q4b 第三批）只有刀片，没有刀杆；刀具库里的车刀没写刀杆时，整机仿真只查刀尖，刀杆会不会撞报“未知”。
同一厂家的综合样本另有刀杆表（代号、能装的刀片、h、b、l1、刀头长、刀尖偏距 f），但刀杆和刀片是多对多：一种刀杆能装同尺寸的各种刀片，
把刀杆写进每把刀（cam-tool/1 的 holder）会把刀具库撑成刀片数 × 刀杆数。

## 决策

1. 新格式 `cam-holder/1`（`schema/cam-holder.schema.json`）：刀杆目录，每个刀杆写 ISO 5608 代号（厂家后缀照抄）、用途（先只有外圆 `external`）、
   能装的刀片（ISO 1832 代号前两位，可多个；尺寸位 4 位，如 1204）、刀尖偏距 f（必填，没有 f 放不下刀杆）、h、b、l1、刀尖高 h1、刀头长、标准刀尖圆弧、出处。
   厂商刀杆库放 `analysis/cam/libraries/`，与刀具库一样只读。
2. `cam-tool/1` 的 holder 加可选的 `head_mm`（刀头长）：碰撞检查里刀头这一段报“未知”的范围按它算，没写时照旧按刀片刃长。
3. 实现（另一个 PR）：起草工艺时，车刀没写刀杆就从刀杆库里按刀片代号配一把（形状 + 法后角、尺寸位都对上，右手，外圆；按刀片形状挑主偏角：
   C、W 取 L 形 95°，D、V 取 J 形 93°，T 取 G 形 90°；刀杆截面优先 2525），写进这道工序的整机仿真设置（不改刀具库文件），工艺卡写明刀杆代号和“起草配的”。

## 影响

- schema 改动单独成 PR（本 ADR）：新 schema、cam-tool 的 head_mm、测试夹具。
