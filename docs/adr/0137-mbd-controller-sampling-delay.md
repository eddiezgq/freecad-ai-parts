# ADR-0137：控制器的采样、输出延迟与执行器滞后（问渠 CAD 0.4）

- 状态：已接受（问渠 CAD 0.4 细则第二节 6；Eddie 2026-11-26 22:15“可以一直做和验证，不要上线，直到我通知”）
- 日期：2026-11-26

## 背景

《多体动力学》书第 31 章线索第 44 条：FMU 控制器在采样时刻读测量、立即输出、零阶保持；连续 PID 没有采样。
真实控制器至少晚一拍。转台 PD（ωₙ = 600 rad/s、T_s = 1 ms、ωₙT_s = 0.6、ζ = 1）阶跃 10°：问渠稳定，
加一拍延迟后发散（书里 mini-mbd 最大 7.8e5°）。ζ = 1 时临界 ωₙT_s：无延迟 1.0、一拍 0.426、两拍 0.258。
在问渠里调稳的增益上机可能发散，报告却什么都不说。

## 决策

mbd-model/1 的 `controllers[]` 加**可选**字段：

| 控制器 | 字段 | 含义 |
|---|---|---|
| pid | `sample_time_s` | 给了就是数字 PID：只在采样时刻读测量、算输出，输出保持到下一拍；积分按矩形（e·T_s），微分按后向差分（有 rate_sensor 时直接用它） |
| pid | `delay_steps` | 输出延迟 n 拍（要同时给 sample_time_s，schema 用 dependentRequired 检查） |
| pid、fmu | `actuator_lag_s` | 执行器一阶滞后 τ_a：τ_a·ḟ = u − f，f 才是加到执行器上的力 / 力矩 |
| fmu | `delay_steps` | 同上 |

- 限幅沿用 PID 已有的 `output_min`、`output_max`（数字 PID 同样限幅，抗饱和用离散的反算法）；FMU 的限幅由 FMU 自己做。
- 都不给时与现在完全一样；报告写明“控制器没计计算延迟（delay_steps）”。
- 只加可选字段，mbd-model/1 版本号不变。

## 后果

- 实现：数字 PID 与 FMU 一样在积分器的采样时刻停下、更新输出；同一模型里所有采样控制器的周期要相同（不同时报模型错误，
  以后需要再放开）。执行器滞后是连续状态，随积分器一起积。
- 结果里报每个采样控制器的 T_s、延迟拍数；sensor 与 actuator 在同一运动副上的 PD / PID，按初始位形的等效惯量 J 估
  ωₙ = √(kp/J)、ζ = kd / (2√(kp·J))，给出 ωₙT_s 与“二阶对象 + 零阶保持 + n 拍延迟 + 执行器滞后”离散闭环的谱半径，
  ≥ 1 时提示“按采样和延迟会发散”。这是单关节的近似，多关节耦合时只作提示。
- 线性化（linear）不含采样与延迟，与现在对 FMU 的处理相同，报告写明。
- 验证题（实现 PR 里做成回归测试）：书第 31 章转台，延迟 0 拍稳定、1 拍发散；ζ = 1 时一拍延迟的临界 ωₙT_s = 0.426。
