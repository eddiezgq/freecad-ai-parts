# ADR-0071：机器人厂的整机运动学标定与实验 26

- 状态：已接受（2026-10-29 项目负责人确认问渠仓库第 55 轮细则 Q1–Q4）
- 日期：2026-10-29
- 补充：ADR-0068（数字工厂与问渠仓库共用一份代码）、ADR-0069（清单第 2 版与机器人厂）、ADR-0056（分析模块）

## 背景

机器人厂“整机标定”工位原来只按名义值加散布造两个测量值，背后没有机器人几何、没有测量和辨识。问渠第 55 轮把它做成真的标定，
改了两边共有的代码。

## 决策

1. **计算模块 `factory/digital/sim/calib.py`**（仿真车间和枢纽共用）：WQ-CR5 的名义标准 DH 参数（**示例值**，不照抄任何厂商）、
   每台 24 个参数偏差（零位含关节测试台测得的零位残差）、激光跟踪仪测量（示例噪声）与几何以外的误差、列归一化 + 奇异值分解的
   最小二乘迭代辨识、另取位姿验证、条件数。纯计算：不联网、不调 LLM、不读数据库；同一台机器人结果可复现。
2. **仿真**：关节零位残差按规格先进先出装进整机；整机标定工位的“标定后绝对定位误差”由标定算出，测量消息带零位、标定前误差、条件数。
3. **页面与实验**：机器人厂“整机标定”页可换位姿（数量、铺满 / 集中）重新辨识；实验 26 六个任务自动评 60 分；机器人的真实偏差只给老师看。
4. 这些都在共有路径，按 ADR-0068 逐字同步。

## 理由

- 标定是机器人制造里决定绝对精度的工序；把《机器人学》的 DH 参数、最小二乘辨识落到数字工厂里，数据有来历、可核对。
- 计算放在确定性代码里，带标准题（无噪声时位置完全复原、零位偏差辨识到噪声量级、位姿集中时条件数变大）。
- 这里的偏差、噪声都是教学示例，不是零件参数，不进零件库（本仓库“不编造参数”的规矩不受影响）。

## 影响

- 共有代码新增 `sim/calib.py`、`hub/lab26.py`、页面 `Calib.vue`、`Lab26.vue`、测试 `test_calib.py`，改 `sim/errors.py`、`sim/engine.py`、
  `hub/app.py`、机器人厂清单（cr_abs 名义值）等。
- 减速器厂、企业厂行为不变。
