# ADR-0024：轴承内圈端口不强制紧固方式

- 状态：已接受（2026-10-01，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-01
- 修订：ADR-0013、ADR-0017 中轴承内圈端口的必填字段

## 背景

`mechanical.cyl_female` 要求 `clamping`（紧固方式）。对减速器输入孔等，紧固方式是零件本身的设计，规格书上有。对滚动轴承内圈，紧固方式取决于装配设计（过盈配合、紧定套、锁紧螺母、锥孔……），轴承规格书上没有。

复核后组装组件（ADR-0023）时，为了通过 schema，只能给轴承内圈填一个 `press_fit`，这是编造数据（#30 评审）。

## 决策

1. `fit_system` 为 `bearing` 的 `mechanical.cyl_female` 端口，`clamping` 不再必填；其余（`iso286` 或未写 `fit_system`）仍必填
2. C2 对轴承端口：配合按轴承配合推荐表判定（ADR-0017 不变）；轴承一侧没有 `clamping` 时，`feature`/`clamping` 兼容检查对该连接为“不适用”（ADR-0016），不判 `unknown`，因为这一项本来就不由轴承决定
3. 轴承一侧写了 `clamping` 时，照常按兼容矩阵检查

## 理由

字段是否必填应取决于数据能否从零件资料中得到。轴承内圈的紧固方式属于装配设计，强制填写只会逼出编造值。

## 影响

- 只放宽 schema，已有数据仍然合法
- 组装（`ingest/assemble.py`）不再推导轴承内圈的 `press_fit`；模拟规格书答案同步去掉该隐含字段
- 实施细则 C2 一行补充说明；M3 引擎按本条实现
