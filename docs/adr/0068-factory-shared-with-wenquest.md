# ADR-0068：数字工厂与问渠仓库共用一份代码——企业功能挪进独有模块

- 状态：已接受（2026-10-09，项目负责人确认问渠仓库第 30 轮细则 Q1–Q4：“按建议”）
- 日期：2026-10-23
- 补充：ADR-0058（数字工厂搬入）、ADR-0061/0062（新产品进工厂）、ADR-0063（企业账号）、ADR-0064（工厂清单）、ADR-0065（网页帮助）、ADR-0066（席位）

## 背景

2026-10-06 本仓库从问渠仓库的提交 `8710ae0c` 整套搬入数字工厂（ADR-0058），约定之后不再同步。三天里两边各走了一大段：
问渠那边加了七个领域（客户与服务、安全环保、设备维护、人员、供应链、能源、经营与财务）、实验 16–23、两周情景与情景导演；
本仓库加了工厂清单、网页帮助、本地版、企业账号、CAD 发布、选型零件库、新产品进工厂、浮动席位。
再不合，以后每建一座新厂都要两边各做一遍，两边的修复也互相拿不到。

问渠仓库第 30 轮先把本仓库的工厂清单、网页帮助、本地版、AI 提供方切换合到那边（已上线），再整体同步回本仓库，作为 M19。

## 决策

1. **`factory/` 分三类**，清单写在 `factory/SYNC.md`（两边逐字相同）：
   - 两边共有（绝大部分）：内容逐字一致；
   - 只在本仓库（企业）：企业安装版 `enterprise/`、模型网关、企业账号、CAD 方案发布、选型零件库、新产品进工厂、浮动席位及其测试；
   - 只在问渠（教学、问渠线上）：服务器端说明文件、设计软件接口等。
   另有少数同名文件故意各自实现（部署、`docker-compose.yml`、本地版脚本、计算转接层 `cae/`），也列在清单里。
2. **企业功能只从独有模块挂上，不改共有文件**：
   - 枢纽：共有的 `hub/app.py` 只留一处口子——有 `hub/enterprise_api.py` 就调用 `mount(app, H, 枢纽模块)`；
     企业账号的登录、换角色、凭证检查，CAD 方案、零件库、新产品、席位的接口都在 `enterprise_api.py` 里挂上；
   - 共有代码里留几个空的扩展点，企业模块往里登记：提议执行完的回调（`hub/ai.py` 的 `ON_PROPOSAL_DONE`）、
     起草工艺规程时的装夹提示（`hub/process.py` 的 `PLAN_HINTS`）、新消息类型（`wqbus/envelope.py` 的 `register`）、
     桥接里的企业提议（共有的 `bridge/lib/erp.js` 有 `lib/erp_enterprise.js` 就加载）；
   - 问渠那边没有这些独有文件，扩展点是空的，行为不变。
3. **以问渠那边为教学主线**：七个领域、实验 15–23、两周情景、教学版帮助（每章动画、视频、当场动手、你来选）随共有代码进来；
   这些教学页面只在演示厂（减速器厂）显示，企业厂不显示（`plant.is_demo()`）。
4. **以后不再分叉**：教学功能在问渠仓库改，企业功能在本仓库改；共有部分谁改了，同一轮同步到另一边。
   比对脚本 `tools/factory_sync.py` 在问渠仓库，报告两边共有部分的差异，0 差异才算同步完。

## 理由

- 问渠那边功能多（七个领域、实验、情景），教学课程已建在上面；本仓库独有的是企业外壳，挪进独有模块改动面小。
- 考虑过 git 子模块、子树：两边的独有部分散在同一目录里（如 `hub/` 下的几个文件），子模块切不开；
  用清单加比对脚本，规矩简单、出了差异一眼看到。
- 企业功能挂到口子上而不是写进共有文件，共有文件才能逐字一致；问渠那边不用知道企业功能的细节。

## 影响

- 本仓库 `factory/` 多出七个领域、实验 16–23、情景导演等教学功能（演示厂才显示）；企业厂的页面、接口、行为不变
  （企业账号、CAD 发布、选型零件库、新产品、席位的测试全部照旧通过）。
- 共有文件以后不在本仓库单独改；要改先在问渠那边改（或两边同一轮改），再比对。
- 新产品下单时的算料：非演示产品下达全部自制件和产品本身；供应商没填交期时不估，标“交期待确认”（不编参数）。
- 本仓库的 CI 预算（ADR-0067）不变：改了 `factory/` 才跑数字工厂作业。
