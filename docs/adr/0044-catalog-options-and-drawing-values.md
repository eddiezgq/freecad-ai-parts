# ADR-0044：公差带推导、图纸标注与只印在图纸上的尺寸

- 状态：已接受。第 1、2 条 2026-10-03 由 Claude 决定；第 3、4 条 2026-10-04 经项目负责人同意
- 日期：2026-10-03
- 补充：ADR-0023（组装）、ADR-0040（公开目录数据）、ADR-0043（引用核对）

## 背景

真实抽取（#167）中，安川 SGM7J-01A 的外形尺寸已经齐全。第一次组装时，它卡在端口的 schema 必填项上：

- 轴的公差带 `fit`、轴端形式 `feature`
- 编码器类型
- 安装孔数

这些信息在目录里不是直接印出的一个数，而是以下几种形式：

- 公差：表格印的是偏差 `8 0 -0.009`，没有写 h6
- 孔数：印在图纸标注 `4 × LZ dia.` 里
- 轴端形式、编码器类型：由订货型号中的选项代码决定

驱动器的宽、高、深，以及部分减速器的尺寸，只印在外形图上。

## 决策

1. **公差带由偏差按 ISO 286 推导**
   - 轴、孔端口给出名义直径与上、下偏差时，按 ISO 286-2 反查常用公差带
     - 轴：g6、h5、h6、h7、js6、j6、k6、m6
     - 孔：H6、H7、H8、JS7
     - 尺寸范围 3–80 mm
   - 恰好对应一个公差带时，记为 `method: computed`，公式写明偏差与结果；复核状态随依据字段
   - 对应不上、或对应不止一个时不推导，不猜
   - 查表在 `ingest/iso286.py`，纯函数
2. **图纸标注“N × 孔径名”**
   - 孔数可取自图纸标注，要求同时满足：
     - 孔径名（如 LZ）是本页尺寸表的列名
     - 本页尺寸表列出了目标型号
     - 页面上只有一种这样的标注
   - 取用时注明“孔数取自图纸标注”
3. **由型号选项决定的端口属性**
   - 轴端形式、编码器等，按目录“型号说明”表中选项的含义取值
   - 轴端形式取外形尺寸表所列的选项（如 `01A□A2□` 中的 2）；编码器取型号说明表列出的第一个选项
   - 模型在 condition 中写明所选选项（如“轴端代码 2”），摘出说明该选项的那一行，逐字核对
   - 多型号目录的提示词版本 `catalog/3`
   - 组件型号暂用基本型号，所选选项见各参数的工况；拼出完整订货型号留到后续
4. **只印在图纸上的外形尺寸人工确认**
   - 引用核对通不过的读数，即使两个模型一致，也不自动入库
   - 汇总成清单，由项目负责人确认后写入 `data/review/confirmed.yaml`（文档、型号、字段、值、页码、确认人、日期）
   - 只能确认至少一次抽取在该页读到的数，不能凭空补数
   - 确认后的值记为已复核（`method: manual`），来源注明确认人与日期

## 后果

- 公差带与孔数不再是 SGM7J 系列组装的阻碍
- 第 3 条确认后，电机的编码器与轴端可以入库
- 第 4 条确认后，驱动器与部分减速器的外形需要一次人工确认，每个型号约 3 个数
