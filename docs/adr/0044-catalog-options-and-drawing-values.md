# ADR-0044：公差带推导、图纸标注与只印在图纸上的尺寸

- 状态：第 1、2 条已接受（2026-10-03，Claude 决定，项目负责人可推翻）；第 3、4 条为提议，等项目负责人确认
- 日期：2026-10-03
- 补充：ADR-0023（组装）、ADR-0040（公开目录数据）、ADR-0043（引用核对）

## 背景

真实抽取（#167）中，安川 SGM7J-01A 的外形尺寸已经齐全。第一次组装时，它卡在端口的 schema 必填项上：

- 轴的公差带 `fit`、轴端形式 `feature`
- 编码器类型
- 安装孔数

这些信息在目录里不是直接印出的一个数，而是以下几种形式：

- 公差：表格印的是偏差 `8 0 -0.009`，没有写 h6
- 孔数：印在图纸标注 `4 × LZ dia.` 里
- 轴端形式、编码器类型：由订货型号中的选项代码决定

驱动器的宽、高、深，以及部分减速器的尺寸，只印在外形图上。

## 决策

1. **公差带由偏差按 ISO 286 推导**
   - 轴、孔端口给出名义直径与上、下偏差时，按 ISO 286-2 反查常用公差带
     - 轴：g6、h5、h6、h7、js6、j6、k6、m6
     - 孔：H6、H7、H8、JS7
     - 尺寸范围 3–80 mm
   - 恰好对应一个公差带时，记为 `method: computed`，公式写明偏差与结果；复核状态随依据字段
   - 对应不上、或对应不止一个时不推导，不猜
   - 查表在 `ingest/iso286.py`，纯函数
2. **图纸标注“N × 孔径名”**
   - 孔数可取自图纸标注，要求同时满足：
     - 孔径名（如 LZ）是本页尺寸表的列名
     - 本页尺寸表列出了目标型号
     - 页面上只有一种这样的标注
   - 取用时注明“孔数取自图纸标注”
3. **（提议）按完整订货型号入库**
   - 轴端形式、编码器等由选项代码决定的端口属性，按目录“型号说明”表中选项代码的含义取值。模型摘出该行，逐字核对
   - 组件型号写到能确定这些属性的订货型号
   - 尺寸表注明了适用的选项（如 `01A□A2□`）时，以该选项为准
4. **（提议）只印在图纸上的外形尺寸人工确认**
   - 两个模型读数一致，也只列为“待人工确认”，不自动入库
   - 汇总成清单，由项目负责人确认后入库，复核人记为确认人

## 后果

- 公差带与孔数不再是 SGM7J 系列组装的阻碍
- 第 3 条确认后，电机的编码器与轴端可以入库
- 第 4 条确认后，驱动器与部分减速器的外形需要一次人工确认，每个型号约 3 个数
