# ADR-0052：换件建议（M8 第四步）

- 状态：已接受（2026-10-06，项目负责人授权 Claude 推进 FreeCAD 的 AI 原生重构）
- 日期：2026-10-06
- 补充：ADR-0048（共用工具与装配即校验）、ADR-0049（AI 改动先成提案）、ADR-0051（选型与 BOM 面板）

## 背景

前三步之后，人和 AI 可以在 FreeCAD 中选型、对接、看到逐项校验结论。但校验报出“不通过”或“待确认”时，下一步该换什么仍要人自己去库里翻，或者让 AI 凭对话猜。AI 原生的工具应当把“发现问题”直接接到“给出可行的改法”，而且改法本身由确定性代码算出，理由可查。

## 决策

1. **换件建议是确定性计算**（`freecad_addon/core/swap.py`，纯函数）
   - 输入：当前布局、要换的实例、需求（可无）、组件库
   - 候选：与该实例同品类的其他组件
   - 对每个候选，把该实例换成候选、连接关系不变，按校验窗口的同一规则（`live_check.check`）整体重新校验
   - 排序：整体结论（通过 > 注意 > 待确认 > 不通过）→ 待确认项数 → 质量（缺失排后）→ 组件 id
   - 每个候选给出：整体结论、与当前相比结论变化的校验项（如“C2：不通过 → 通过”）、质量
   - 不通过的候选不列出；当前组件本身不列出
2. **换上**：删除该实例，在原位姿放入新组件、同名实例，再按原顺序重建与它相关的机械连接；全部经 `place_component` / `connect_ports`
3. **人用**：校验窗口中选一个零件（在 3D 视图或按实例名），点“换件建议”，列出候选与变化；选一个点“换上”。人的换件直接生效，不成提案
4. **AI 用**：新增 MCP 工具 `suggest_replacements(instance, requirement?, top_n)`，读当前布局，返回同样的候选与变化。AI 换件仍按 ADR-0049 成为提案，由人接受或拒绝
5. **范围**：一次只换一个实例；不自动加转接件（需要时由选型面板整体重选）

## 理由

- 校验与换件用同一规则、同一函数，人看到的建议与 AI 拿到的一致，不存在 AI 自己“想”出来的改法
- 以整体重新校验为准，而不是只看单个连接，能同时考虑需求（扭矩、转速、供电）与所有接口
- 组件库当前规模下逐个重算的代价可以接受；库变大后可先按端口类型筛选

替代方案：只用 `find_compatible`（只看一个端口，忽略需求与其他连接）；让 LLM 直接提议（不可核查）。

## 影响

- 新增 `core/swap.py`、MCP 工具 `suggest_replacements`、校验窗口的“换件建议”区
- 计划与实施细则加第四步分项任务
