# ADR-0114：内孔镗杆（ISO 6261）进刀杆库和刀具的 holder

- 状态：已接受（2026-11-22，属于 ADR-0106 Q4b）
- 日期：2026-11-22
- 补充：ADR-0112（刀杆库）、ADR-0113（内孔刀）

## 背景

ADR-0112 的刀杆库只有外圆刀杆（ISO 5608 代号，方杆）。内孔车刀装在镗杆上：圆杆，代号按 ISO 6261（如 A25R-PCLNR12：A 带内冷钢杆、
杆径 25、长度字母 R、P 夹紧 C 形刀片 L 形 95°、右手、刀片 12），样本给杆径 DCON、能进的最小孔径 DMIN、刀尖到杆轴线 WF、全长 LF、刀头长 LH。
内螺纹刀片（ADR-0113）的最小孔径也取决于配的镗杆。

## 决策

1. cam-holder/1：`use` 加 `internal`；内孔镗杆写 `iso6261`（代号）、`bar_d_mm`（杆径）、`min_bore_mm`（最小孔径）、`f_mm`（刀尖到杆轴线）；
   外圆刀杆照旧要 `iso5608`。
2. cam-tool/1 的 holder 可以是内孔镗杆：`iso6261`、`bar_d_mm`、`min_bore_mm`（与 `iso5608`、`profile_mm` 三选一）。
3. 实现（另一个 PR）：起草时内孔刀没写刀杆，就按刀片代号和孔径配一把镗杆（最小孔径不大于孔径，杆径取能进的里面最粗的）；
   计算时孔比镗杆的最小孔径小报错；整机仿真把镗杆当圆杆（轴线离刀尖 f，杆径 bar_d）查与卡盘、刀塔等机床部件的碰撞，刀头一段照旧报“未知”。

## 影响

- schema 改动单独成 PR（本 ADR）：两个 schema、测试夹具。
