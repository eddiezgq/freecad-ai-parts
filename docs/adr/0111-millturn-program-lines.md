# ADR-0111：车铣程序行允许括号——写西门子的 SETMS(2)、SPOS[n]

- 状态：已接受（2026-11-20，属于 ADR-0106 C2b）
- 日期：2026-11-20
- 补充：ADR-0110（cam-post/1 的 `millturn`）

## 背景

ADR-0110 给后处理配置加了 `millturn`（开 / 关动力刀、切入 / 切出 C 轴的程序行），写法规则沿用 `tool_change`：只能大写字母、数字、空格和 `. = + -`。
西门子车铣中心上，动力刀常是第二根主轴，后处理要先切主主轴 `SETMS(2)`、完了 `SETMS`；主轴定位写 `SPOS[1]=0`。这些带圆括号、方括号，按 ADR-0110 的规则写不进去，
西门子的 TRANSMIT / TRACYL 后处理（ADR-0106 C2b）就只能用不带括号的机床专用 M 代码。

## 决策

1. cam-post/1 的 `millturn.live_on / live_off / c_on / c_off` 的程序行另可带 `( ) [ ] ,`；其余规则不变（大写、不许分号、不许小写）。
2. `tool_change` 的规则不变（FANUC 里圆括号是注释，换刀动作不需要）。
3. 实现（另一个 PR）：后处理照原样写这些行；回读时西门子的 `SETMS(...)`、`SPOS...` 行跳过（不影响刀路）；FANUC 系的配置里出现括号时
   按注释处理，后处理配置检查报“FANUC 写法的车铣程序行不该带括号”。

## 影响

- schema 改动单独成 PR（本 ADR）。
- 测试夹具：cam-post 加一个带 `SETMS(2)`、`SPOS[1]=0` 的有效例子、一个带分号注释的无效例子。
