# ADR-0100：零件库 + AI 自主设计（M42，先做平缝机上轴，机器人关节第二）

- 状态：已接受（2026-11-18 项目负责人确认：“好，继续”）
- 日期：2026-11-18
- 补充：ADR-0099（企业库与三条进料通道）、ADR-0056（分析模块）、ADR-0093 补充十一（AI 起草算例的分工）
- 来源：项目负责人 2026-11-17：“零件库加 AI 自主设计才是出路”；“先做缝纫机上轴，对照《机械设计》33.11 验收；机器人关节第二”

## 背景

- M41 做完后，企业库里有外购件（电机、驱动器、轴承、同步带……）和自制件（从模型量出的轴段、孔位、质量）。
- 现在 AI 能做的是“选”：从库里挑电机、减速器、驱动器并由代码校验（C1–C11）。自制件还得工程师自己设计。
- 《机械设计》33.11 用平缝机上轴 LS-101 讲了一根高速轻载轴的完整设计校核：曲柄滑块惯性力、旋转轴上一点的应力循环、
  两个台阶截面的无限寿命安全系数、梁单元临界转速、有限元固有频率核对、提速到 5 500 r/min 的评估。书里的结论和程序都有，
  正好拿来做对照。

## 决定

### 1. “AI 自主设计”在 M42 里指什么

给一段需求原话和企业库，AI 出一个完整的零件设计：自制件的结构和尺寸、配套选用的外购件（从库里选），代码校核每一项“能不能用”；
不合格时代码把校核结论（哪一项、差多少）交回 AI 改方案，直到全部通过，或说清楚为什么做不到（例如库里没有能用的轴承）。
最后生成三维模型、二维图、校核报告和 BOM，人确认后自制件进企业库。

### 2. 分工（与全仓库一致：凡影响“能不能用”的判断都由代码做）

| | AI | 代码 |
| --- | --- | --- |
| 需求 | 读原话，列出设计条件（转速、功率、机构参数、轴向位置、材料……），每个数字附原话引用 | 核对引用在原话里、单位按 pint 换算；原话没有的条件不补，进“待确认” |
| 结构 | 排结构：分几段、每段装什么（轴承、曲柄、凸轮、带轮……）、从哪头装 | 查装得进去（直径从装入端起单调、轴肩挡得住、轴承定位） |
| 选件 | 从企业库和公共库里选轴承、带轮、紧固件 | 配合尺寸一律从库里取（轴承内径、宽度、安装尺寸 da/ra；带轮孔径），不让 AI 给 |
| 尺寸 | 只提议自由尺寸（不受外购件约束的段的直径、长度）；圆角、退刀槽按规则表 | 规则表定标准系列、圆角、配合代号；缺数据的项是“待确认”，不是“通过” |
| 校核 | 读校核结论、改方案、写设计说明 | 强度（静强度、无限寿命安全系数）、刚度（轴承处转角、外伸端挠度）、临界转速、轴承寿命、键或紧定螺钉 |
| 输出 | — | FreeCAD 生成回转体与平面、键槽；用 41.4 的测量回读模型，与设计数据逐段核对；二维图、报告、BOM |

- AI 不给载荷数字：载荷由代码从设计条件算（平缝机：曲柄滑块往复惯性力与转矩，式 33.11.1、33.11.2；带的拉力；装在轴上的零件的质量取库里的 `mass_kg`）。
- 每一轮（AI 提议 → 代码校核）都留记录：提议原文、校核结论、AI 改了什么。最多 4 轮，还不通过就停下，列出卡住的项交给人。

### 3. 新代码

- `analysis/shaft/`（分析模块，ADR-0056 规矩）：阶梯轴的载荷 → 弯矩、转矩 → 截面应力（旋转轴上一点一转之内的应力循环，33.11.3 节的做法）
  → 无限寿命安全系数（应力集中系数用 33.5.4 节的有限元程序或规则表，尺寸系数、表面系数按材料库与规则表）；梁单元临界转速（带集中质量）；
  轴承处转角、外伸端挠度。标准题：与 33.11 的书中结论对照（见第 5 节），另加两道教材公式题（简支等直轴的临界转速解析解、
  对称循环纯弯的安全系数）。
- `engine/` 只加“装得进去”和配合尺寸取值这类确定性规则（纯函数，不联网、不调用 AI）。
- `assist/design.py`：需求原话 → AI 提议 → 核对 → 校核 → 回给 AI 的循环；提示词与录制照 `fea_draft` 的做法（在 CI 上用 Claude 录，
  DeepSeek 经网关自动切换，不单独验收）。
- `freecad_addon/`：问渠 CAD 里“AI 设计零件”面板：输入原话、看每一轮的方案和校核结论、确认后生成模型并入企业库。

### 4. 数据前提

- 轴承 6201 等要在库里有内径、外径、宽度、安装尺寸、额定动静载荷、极限转速：来自 M41 登记并核过条款的轴承目录（41.6）。
  目录条款不允许就缺数据，设计停在“轴承数据待确认”，不凭经验补。
- 曲柄、凸轮、偏心轮、带轮、手轮与电机转子的质量：取企业库（41.4 从模型量出的或规格书上的）；缺了就让人补，不估。
- 平缝机的机构参数（曲柄半径、连杆长、往复质量、平衡率、缝纫功率）与轴向位置（机头两侧轴承座的位置）写在需求原话里，
  用《缝纫机设计与制造》的示意数据，标注“示意数据”。

### 5. 验收（42 平缝机上轴；项目负责人在问渠 CAD 里看）

1. 分析模块先过标准题：用书里的 LS-101 几何与载荷，算出的截面 I、II 安全系数（5 000 与 5 500 r/min）和带集中质量的一阶临界转速，
   与 33.11 的书中结果相差 ≤ 2 %；两道解析解题相差 ≤ 0.5 %。
2. 给 AI 的需求原话只写条件（转速、电机、机构参数、轴向位置、材料、轴承型号可以不指定），不写 LS-101 的尺寸。AI 设计的上轴：
   - 全部校核通过（安全系数 ≥ 1.5、一阶临界转速 ≥ 1.3 倍最高转速、轴承寿命 ≥ 需求给的小时数），提速 5 500 r/min 也算一遍并给出结论；
   - 与书里的 LS-101 对照：结构同类（曲柄座 — 前轴承位 — 轴身 — 后轴承位 — 带轮段），轴颈直径与选的轴承内径一致；
     与 LS-101 不同的尺寸，设计说明里要讲出理由（校核结论支持）；
   - 生成的模型用 41.4 的测量回读，与设计数据逐段一致（直径 ±0.01 mm、长度 ±0.05 mm）；
   - 每个数字都能追到依据：原话引用、库里组件的字段、规则表条目、或校核计算；
   - 循环不超过 4 轮；记下用时。
3. 测试照旧全过（ruff、pytest；问渠 CAD 的 `tests-wqcad.ps1`）。

### 6. 机器人关节（第二）

平缝机上轴做完后，用同一套流程设计关节模组的输出轴或电机侧转接轴（库里已有电机、减速器、驱动器，C1–C11 现成），
验收对照 `examples/` 里的关节例子；方案到时另写施工记录，原则不变。

#### 6.1 42.5 方案（2026-11-18 项目负责人确认：“好，继续”）

**对象**：协作机器人肩关节 J2 的输出空心轴（对照《机械设计》33.10 的 RJ-201：Ø70 减速器法兰、两个 6010 装在连续的 Ø50 上、
中间隔套、外端花键传转矩给大臂法兰、最外端圆螺母压紧，Ø30 贯通内孔）。与平缝机上轴的根本不同：**按刚度设计、要最轻**——
J2 输出轴的扭转使末端偏移，系统分给它的预算 0.20 mm（峰值力矩下），强度远远富余（书中静强度安全系数几十）。

**分工照旧**（AI 提结构和自由尺寸、代码核对和算）。新增的部分：

| | 内容 |
| --- | --- |
| 数据 | NSK 目录同一份 Part C 里 60 系列内径 40–55 mm 的几款（6008–6011）补进公共库，带安装尺寸（ADR-0103 字段）；抽取与复核照 41.6。减速器 CSF 的输出法兰尺寸现在缺（完整度报告 C3 待确认）：从已登记的 Harmonic Drive 目录补；补不到，法兰外径按“轴承位 + 20 mm”的结构规则取，并在结论里标明依据 |
| 载荷 | 不再从原话读机构参数，由代码从机器人动力学算：`examples/apps/cobot_joint.py` 已有的 UR5e 一类参数化串联臂（负载、姿态、节拍写在原话里），得到 J2 一个节拍的驱动力矩 T(t)、大臂传来的力 F(t)；急停按减速器的瞬时允许最大转矩 |
| 分析模块 | `analysis/shaft` 加空心截面（内孔）、扭转角（各段串联，与书中式 33.10.2 同）与末端偏移 δ = θ·R；标准题：空心圆轴扭转角解析解、书中 RJ-201 的扭转角与五个方案的偏移（≤ 1 %） |
| 规则表 | 花键（GB/T 3478.1，模数 1.5，30° 平齿根：齿数、分度圆、大径、小径由轴承位直径定）、圆螺母螺纹（GB/T 812 细牙，比花键小径小的最大一档）、花键齿面挤压许用应力（60–100 MPa 取中值 80，书中 25 章）——写成数据文件，注明出处 |
| 校核项 | 刚度：1.2·δ ≤ 0.20 mm（手算留 1.2 倍给台阶法兰的局部变形，与书同）；强度：花键段与轴承位的静强度（正常、急停）、法兰台阶的无限寿命；花键挤压；轴承寿命 20 000 h（两班 5 年）；装配：两个轴承都从大臂一端装入（花键大径 < 轴承内径）；减速器 C1–C11 照旧 |
| 目标 | 全部通过后**再要最轻**：代码把质量和刚度余量交回 AI，AI 可再收一轮（只在全部通过的前提下）；最多 4 轮不变。这一条同样补给平缝机上轴（42.2 之三记的偏重 50 %） |
| 零件类型 | 面板的“零件类型”加“关节空心轴”；方案格式加内孔直径、隔套长、花键与螺纹段（尺寸由规则表算，AI 只选轴承位直径、内孔、材料） |

**验收**（对照 33.10）：AI 选出的轴承位 / 内孔与书中一致（Ø50 / Ø30、6010 一对），或者给出同样满足刚度、更轻的方案并由代码算出依据；
扭转角、末端偏移、质量与书中相差 ≤ 2 %；模型回读、工程图、BOM 照 42.3、42.4；在问渠 CAD 面板里跑通（回放与真实 AI 各一次）。

**施工顺序**：① 数据 PR（NSK 6008–6011）；② 分析模块空心轴与扭转刚度 + 标准题；③ 规则表 + 关节轴的校核；④ 载荷从动力学来；
⑤ 设计循环与“再要最轻”；⑥ 录制（CI 上 Claude）；⑦ 面板与问渠 CAD 验收。每步一个 PR，测试照旧全过。

## 理由

- 先做一根轴：结构简单、校核方法成熟、教材里有完整的对照答案，能把“AI 提议 → 代码校核 → 回给 AI 改”这条路完整走通；
  做通以后换别的零件（法兰、支架）主要是加校核规则。
- AI 不给尺寸里受外购件约束的部分、不给载荷：这两样 AI 给错了很难发现，代码取库、按公式算才可复现、可追溯。
- 校核放在分析模块：它是计算，不是选型规则；结果不写进零件参数（ADR-0056），只进设计报告。

## 影响

- 依赖 M41：企业库、轴承数据（41.6）、模型测量（41.4）。
- 不做：多个零件同时设计；齿轮、壳体、焊接件；拓扑优化出形状；AI 直接改 FreeCAD 模型（模型一律由代码按设计数据生成）。
- 问渠 CAD：面板随问渠 CAD 0.3c 交付；工作台的固定提交由问渠 CAD 那边改。

## 施工记录

- **42.1（2026-11-18）**：轴的分析模块 `analysis/shaft/`（登记为分析模块 `shaft`）。
  - 载荷：曲柄滑块（往复惯性力一、二阶 + 平衡块离心力；转矩波动级数到三阶，与 33.11 式 33.11.1、33.11.2 同）、空间固定的力、
    转矩负载（平均功率）；截面转矩取“离开动力一侧”的转矩负载之和。两支点简支，两平面弯矩按截面精确位置算。
  - 疲劳：旋转轴上 72 个圆周点、一转 720 个转角，取最危险点；Kσ = kσ/ε + 1/β − 1，ψσ = σ₋₁/σb，ψτ = τ₋₁/(σb/√3)，
    S = SσSτ/√(Sσ² + Sτ²)。修正系数（Marin 表面、尺寸，Neuber 缺口敏感）用 Shigley 的拟合式，写在 `analysis/shaft/factors.yaml`
    并注明出处；与书中 33.11 的 q、ε、β 逐位相同。
  - 临界转速：Euler 梁单元（≤ 2 mm）+ 集中质量，广义特征值；挠度与支点转角用同一刚度阵；支反力给最大、平均、均方根（轴承寿命用）。
  - 理论应力集中系数 `analysis/shaft/kt.py`：阶梯圆杆纯弯、纯扭的有限元（Gmsh 二阶四面体 + CalculiX，远端载荷，圆角弧上 31 个探针取主应力），
    圆角附近 r/5。台阶 Ø10→Ø12、r 0.5：α_σ = 2.079、α_τ = 1.522（书中 2.041、1.493，差 1.9 %）；再加密到 r/8 为 2.094、1.525，
    随加密略增，偏安全。Ø12→Ø16：2.361、1.656（书中 2.331、1.607）。每对约 40 秒，按 (d, D, r) 缓存。
  - 标准题（`tests/test_analysis_shaft.py`）：用书中的 kt，截面 I、II 在 5 000 与 5 500 r/min 的安全系数与 33.11 相差 ≤ 1.1 %
    （书里截面 I 的弯矩取在 0.495 mm 网格上的 z = 21.78，本模块按 z = 22 精确算）；一阶、二阶临界转速差 0.97 %
    （书里 E 取 206 GPa，材料库 45-QT 为 210 GPa，√(210/206)）；Sτ 相同到 1e-4。三道解析解：简支等直轴一阶临界转速（≤ 0.5 %）、
    中点固定力 + 稳定转矩的安全系数（1e-4）、中点集中力的挠度与支点转角（1e-6）。用本模块自己算的 kt，四个安全系数比书低 1.4–2.4 %。
