# ADR-0090：工厂清单加“计量室抽检”（sampling）一节

- 状态：已接受
- 日期：2026-11-10

## 背景

问渠缝纫机厂的工艺方案（问渠第 137 轮）规定三坐标、圆度仪、粗糙度仪等计量设备对铸件、机壳、轴、针杆、旋梭、偏心做首件和抽检。这些抽检不是每件都走的工序，写进工艺路线会让 ERPNext 为每件建作业卡，也会撞上“一种物料一张检验模板”的限制（ADR-0064 的清单第 2 版）。

## 决策

清单第 2 版可选加 `sampling` 一节，每条：`item`、`after`（该物料工艺路线里的工序）、`unit`（计量设备）、`every`（每几件抽 1 件，整数 ≥ 1）、`minutes`（每次检测分钟）、`chars`（同 `measurements` 的特性：code、name、unit、nominal、lo、hi、sigma）。规则：每张工单首件必抽，以后每 N 件抽 1 件。

- 校验：物料、工序在该物料路线里、设备存在、N 和分钟合法、特性字段齐全、同一物料内特性代号不与 `measurements` 和其他抽检重复。
- 仿真：被抽到的零件过 `minutes` 分钟由计量设备发 `quality.measurement`（带 `sample: true`），零件照常往下走；抽检用独立的随机数流。
- 桥接：`sample: true` 的测量不在 ERPNext 建检验单。
- Excel 模板加“计量室抽检”表，可空。

## 理由

抽检按检验计划执行，与工艺路线分开，符合工厂实际；不改 ERPNext 数据，已部署的工厂不用重建。替代方案“在路线里加抽检工序”要求每件都走，与抽检的意思不符。

## 影响

没有 `sampling` 一节的清单行为不变（全部原有测试不改）。质量页的特性列表多出抽检特性。
