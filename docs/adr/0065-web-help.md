# ADR-0065：网页版帮助——教学版与企业版（M17）

- 状态：已接受（2026-10-08，项目负责人：“可以。用网页版就是要其动画，视频以及和其他模块的互动性，还有视觉冲击力。”“不要配音”）
- 日期：2026-10-08
- 补充：ADR-0063（企业安装版）、ADR-0064（工厂清单）

## 背景

数字工厂的说明只有一份 70 行的 Markdown（`factory/digital/帮助_数字工厂使用说明.md`），网页里没有帮助入口；
企业版（M15、M16）的安装、工厂清单、账号、AI 设置只在仓库文档里。要两份帮助：教学用（学生、老师）与企业用
（管理员、各岗位）。做成网页版是为了动画、视频、和其他模块的互动，以及视觉冲击力，不是把说明书搬上网页。

## 决策

1. **位置**：工作台里的“帮助”页（`/help`），左栏“资源”下有入口。教学版、企业版可切换；演示工厂缺省打开教学版，
   企业工厂（ADR-0064）缺省打开企业版。登录页也有入口（企业版的“上线与部署”在登录前就要看）。
2. **内容**：每版一组 Markdown（`web/src/help/teach/*.md`、`web/src/help/enterprise/*.md`），一节一个文件；
   网页负责呈现。Markdown 里用几种自定义块把动画、视频、互动嵌进来：
   - `goto`：“带我去做”——打开对应页面，按步骤高亮要点的地方（页面元素用 `data-help` 标记），一步一步引导；
   - `anim`：机制动画（SVG + CSS），如全流程、工单流转、MRP 展开、异常追因链、AI 只起草由人确认、命令行安装；
   - `video`：操作视频；
   - `live`：本厂此刻的数据（设备状态、指标、在制工单），讲解对着自己的工厂；
   - `ask`：就这一节问 AI 工厂助手。
   演示工厂与企业工厂的示例随工厂清单换（厂名、设备、工序）。
3. **视觉**：首屏是实时 3D 车间（复用 `workshop3d.js`）加全流程动画；按工作台现有配色，支持深色、浅色。
4. **视频**：不人工录屏。脚本驱动真实系统（演示工厂）自动操作并录制，字幕直接叠在画面上，**不配音**。
   界面改了重录即可。首批约 12 段，每段 30–90 秒：教学版 8 段（登录选角色、接单与 MRP、派工报工、3D 车间、
   FreeCAD 发布到工厂、异常追因与推演、8D、AI 助手），企业版 4 段（Excel 清单导入、开账号分角色、新产品进工厂、
   备份与升级）；企业版的命令行安装用终端动画（`anim`）。
   视频不入仓库：CI 录好后发布为 GitHub Release 附件，工厂镜像构建时取来放进镜像；没有视频时帮助照常可用，
   视频位置显示“带我去做”。
5. **只写现有功能**；没做的不写。帮助里的数字示例取自系统（`live`）或标明是示例。

## 后果

- 帮助能“看、动、做”：读一节就能跳到页面照着做，并看到本厂此刻的数据
- 帮助内容与界面一起演进：视频可以重录，“带我去做”的高亮点在页面上有标记，页面改了测试能发现标记丢失
- 镜像变大（视频约 20–40 MB）

## 补充（2026-10-08，M17 第 4 项实施时）

- 企业版视频调整为 3 段：开账号分角色、新产品进工厂、AI 设置与运行记录。Excel 清单导入和备份升级都是命令行操作，
  已用终端动画演示（逐字打出命令，输出与脚本实际一致），不再另录视频。
- 教学版视频在 CI 的本地版作业（演示工厂）里录；企业版视频在企业安装作业（示例缝纫机厂、企业账号）里录。
  合并到 main 后两份视频包上传到 Release `help-videos`；工厂镜像构建时取最新的一份（同一次提交里可能晚一个版本）。
