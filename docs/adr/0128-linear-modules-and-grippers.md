# ADR-0128：直线模组与抓手进零件库

- 状态：已接受（2026-11-25 09:19，随 ADR-0115 44.5 计划批准，项目负责人：“好”）
- 日期：2026-11-25
- 补充：ADR-0115（原创机器人案例，44.5.2）、ADR-0117（一体化关节模组，同样的做法）、ADR-0040（公开目录数据）、ADR-0099（品类）

## 背景：案例 B 跑出来的缺口

案例 B（缝纫车间裁片上下料）的构型初筛（44.5.1）采用了台面上的 X–Z 两轴龙门、真空吸盘：
X 轴皮带直线 1600 mm 行程，节拍里末端最高 2.5 m/s、12.5 m/s²；抓取力至少 4.46 N。零件库里只有转动件（伺服电机、减速器、驱动器、轴承、
一体化关节模组），**没有直线模组，也没有抓手**，选件做不下去。

先看了两家公开目录，按它们实际给的数定字段（2026-11-25）：

- 上银（HIWIN）单轴机器人目录：滚珠丝杠型（KK、SK…）给导程、速度、重复定位精度、行程、允许静力矩（俯仰 / 偏摆 / 滚转）、质量；
  同步带型（KA…B、KS…B）给带轮周长、最高线速度（1800 mm/s）、额定推力、重复定位精度、有效行程、水平最大负载、动态力与力矩、按行程的质量；
  垂直负载只说“请洽厂商”。
- 施迈茨（Schmalz）针刺抓手数据表（SNG-M 等）：针数、针径、针的行程、刺入角、工作气压、质量、适用材料（复合材料织物、无纺布、泡沫等）；
  **不给保持力**。

## 决策

1. **新品类 `linear_module`（直线模组）**：驱动方式（滚珠丝杠 / 同步带 / 直线电机 / 齿轮齿条）、有效行程、每转行程（导程或带轮周长）、
   最高速度、最大加速度（给了才写）、额定推力、重复定位精度、水平与垂直最大负载（分开写，只给水平的不折算垂直）、
   滑台允许力矩（滚转、俯仰、偏摆，静态或动态写在条件里）、本体质量、滑台质量（给了才写）。
   行程两种给法：厂商按行程分型号的，每个行程一条（`stroke_mm`，质量是这个行程下的）；行程订货时任选的（费斯托 EGC），一个尺寸一条——
   写最大行程 `max_stroke_mm`、行程 0 mm 的基本质量 `mass_kg` 和每加 10 mm 的增重 `mass_per_10mm_stroke_kg`，选定行程后的质量由选型代码算。
   推力分额定 `rated_thrust_n` 与最大 `max_thrust_n`；滑台允许的侧向力、法向力（`force_lateral_n`、`force_normal_n`）给了才写。
2. **新品类 `gripper`（抓手）**：型式（真空吸盘 / 面状真空 / 针刺 / 夹爪 / 其他）、保持力（厂商给了才写，条件写真空度、气压）、吸盘直径、
   针数、针径、针行程、刺入角、工作气压（范围）、质量、适用材料（厂商原话）。
   **没给保持力就不写**，抓取力的校核判待确认，不按针数估；适用材料只摘给人看，代码不据此判伤不伤布料。
3. 两个品类的接口（电机法兰、滑台与底座孔位、气源接口）多只在图纸里：端口查得到才写，可以一个都没有；整机装配时这些接口判待确认。
4. **直线速度的标准单位定为 m/s**（字段后缀 `_m_s`，与已有的加速度 `_m_s2` 一致）；换算只在 `ingest/` 用 pint 做，`ingest/units.py` 加后缀在导入那一步（实现代码，另一个 PR）。
5. 价格：两家目录都没有，成本仍判不了。
6. 抽取结果的品类（`schema/extraction.schema.json` 的 category）同时加这两个，导入走已有的云端下载、抽取、复核流程（`real-data.yml`）。
7. **来源改用费斯托（Festo）做直线模组（2026-11-25 补，偏差记录）**：再查时发现上银美国官网的目录页没有同步带型目录（KA、KS 只在经销商转载里），使用条款页本环境打不开；同步带型最高 1.8 m/s 也不够案例 B 用。费斯托公开目录 EGC-TB-KF（同步带）给最高速度 3–5 m/s、最大加速度 50 m/s²、重复定位精度、最大推力、行程、三向许用力矩、本体与滑台质量，字段齐、速度够；EGC-BS-KF（滚珠丝杠）作 Z 轴。抓手仍用施迈茨。上银留作后备。

## 后果

- 案例 B 的 X 轴：上银同步带型最高 1.8 m/s，比构型要的 2.5 m/s 低；费斯托 EGC-TB-KF 70 以上最高 5 m/s，够用——推力、加速度和力矩在 44.5.4 选型时核。
- 案例 C（送物机器人）的升降仓也会用到直线模组。
