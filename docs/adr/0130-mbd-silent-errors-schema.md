# ADR-0130：多体模型加恢复系数、抗积分饱和跟踪时间、过死点走法（问渠 CAD 0.3.8）

- 状态：已接受（问渠 CAD 0.3.8 细则第一组，Eddie 2026-11-25 确认细则）
- 日期：2026-11-25

## 背景

《多体动力学》书交给问渠的线索里，有 14 条“静默出错”（结果错了却照常报完成），问渠 CAD 0.3.8 细则逐条修。其中三条要让使用者在模型里能改，
而 `mbd-model.schema.json` 相关对象都是 `additionalProperties: false`，所以先改 schema：

1. **第 31 条 接触阻尼**：接触对只有常值阻尼 `damping_n_s_per_mm`，阻尼在 `penetration_mm` 内由 0 升起，低速碰撞穿透不到，阻尼几乎为零。
   同一参数 0.01 m/s 落下 e = 0.998、10 m/s 时 0.842，1 kg 撞 1 kg 时 0.948；弹跳球过了 Zeno 时刻还在跳。使用者没法直接给恢复系数。
2. **第 46 条 PID 抗积分饱和**：0.3.8 的代码 PR 已把“条件积分”改成反算法（ż = e + (u − u_raw)/(ki·T_t)），T_t 先用缺省 0.05 s；
   跟踪时间要能按控制器调。
3. **第 13 条 过死点**：0.3.8 的代码 PR 让运动学分析缺省按速度外推越过死点（原动件推着越过），原来“倒回”的走法要保留成选项。

## 决策

都是**可选字段**，不给时行为见各条；旧模型不用改。

1. `contacts[]` 加：
   - `restitution`（0–1）：给了就按恢复系数算阻尼——Carvalho–Martins / Gonthier 律 c = k·δ^e · 8(1 − e_r)/(5·e_r·v⁻)
     （v⁻ 是本次碰撞开始时的法向速度），各速度、各质量比下实际恢复系数都等于给定值；`damping_n_s_per_mm` 不再用；
   - `min_impact_speed_mm_s`：给了 `restitution` 时，碰撞速度低于它按完全非弹性处理（落下的零件能停住），缺省 1 mm/s。
   - 不给 `restitution`：照原来的常值阻尼，结果的局限说明写明“实际恢复系数随速度、质量变”。
2. `controllers[]` 的 PID 加 `antiwindup_tracking_s`（T_t），缺省 0.05 s。
3. `analysis` 加 `dead_point`：`continue`（缺省）或 `reverse`。

## 不放进 schema 的

- **第 38 条 带传动**的初拉力、摩擦系数、带的抗拉刚度：带传动在常用机构库（MuJoCo 路线，`analysis/mbd/mechanisms.py` 的参数表）里，
  参数不经这个 schema。按“不编造参数”的规矩不设缺省：不给时打滑核查判 unknown，并在结果里写明。

## 理由

- 恢复系数是工程上能查到、能测的量，常值阻尼的数值使用者很难给对；书里 Exudyn 的同类模型（Carvalho–Martins）实测各速度 e = 0.800。
- T_t 与 ADAMS、Simulink 的做法一致；缺省 0.05 s 与书里验证题相同。
- 过死点的两种走法都有用：机构设计多数要“推着越过”（缝纫机、内燃机），找极限位置时要“倒回”。
