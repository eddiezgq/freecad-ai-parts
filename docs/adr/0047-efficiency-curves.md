# ADR-0047：只以曲线给出的效率按环境温度查表

- 状态：已接受（2026-10-05，项目负责人决定）
- 日期：2026-10-05
- 修订：ADR-0046 第 3 条（只以曲线给出的参数不录入）
- 补充：ADR-0040、ADR-0044

## 背景

Harmonic Drive 整机型减速器的效率只以曲线给出（目录第 134–135 页）：

- 效率随环境温度（-10–40 °C）和输入转速（500、1000、2000、3500 rpm）变化
- 以速比 80、100 为例，读数从约 33% 到约 85%

ADR-0046 第 3 条规定不按曲线估读，扭矩三项（C4–C6）因此一直是 unknown。真实关节方案无法判定可用，M6 验收（#131）无法完成。

项目负责人决定：按需求给出的环境温度查曲线；需求没给温度时，取最坏情况。

## 决策

1. **需求加环境温度**
   - `schema/requirement.schema.json` 增加可选字段 `ambient_temp_c`
2. **减速器加效率曲线**
   - `schema/categories/reducer.schema.json` 增加参数 `efficiency_curve`
   - 内容是在图的网格温度上读出的点：环境温度、输入转速、效率
   - 带来源、工况、获取方式、复核状态，与其他参数相同
   - 它不是参数值对象：`schema/component.schema.json` 对参数表的通用约束（每个参数都是参数值）为它单独放开，格式由品类 schema 约束
3. **读图规则**
   - 只在图的网格温度上读（如 -10、0、10、20、30、40 °C），每条转速曲线都读
   - 读数向下取整到整数百分比
   - 按 ADR-0044 第 4 条记为人工录入，注明图号与页码
4. **查表规则**（引擎，纯函数）
   - 所需输入转速 = 输出转速 × 减速比
   - 取图上不低于所需输入转速的最低一条转速曲线；所需转速高于图上最高转速时为 unknown
   - 需求给了环境温度：在相邻两个网格温度之间线性插值；超出图的温度范围时为 unknown
   - 需求没给环境温度：取这条曲线上的最低值
   - 组件同时有 `efficiency_ratio` 时，优先用 `efficiency_ratio`
   - 校验说明中写明效率的取法：温度、转速曲线、查得的值
5. **已知简化**
   - 负载低于额定扭矩时，效率还要乘补偿系数 Ke（目录第 134 页，图 134-1），这次不计
   - 补偿系数小于 1，不计它会高估效率。这一点在 C4–C6 的说明中注明

## 后果

- 扭矩三项可以判定；真实样例写明环境温度（室内 25 °C）
- 需求没写温度时按 -10 °C 曲线计算，结果偏保守，可能判为不通过
- schema 改动单独成 PR（本 ADR）；引擎、录入与数据在后续 PR
