# ADR-0127：NUM Flexium / Flexium+ 家族的基本写法

- 状态：已接受（2026-11-25，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”“我们是做工业级产品”）
- 日期：2026-11-25
- 补充：ADR-0124（写法差别）、ADR-0125（手册代码表）、ADR-0126（发格，同一做法）

## 背景

NUM（瑞士）在官网公开了编程手册：**《Flexium Programming Manual》M00018EN-03**
（num.com/fileadmin/documents/Manuals/Flexium/M00018EN-03_Flexium_Programming_manual.pdf，555 页，英文，2026-11-25 下载；下面的“§”指这本手册的章节）。
逐条核对后，NUM 和 FANUC 有不少**同一个代码、意思不同**，原样给 NUM 会出事：

| FANUC 写法（问渠CAM 的基本写法） | 在 NUM 上的意思（手册） | 后果 |
| --- | --- | --- |
| `G21`（公制） | NUM 的 `G21` 是**直角坐标编程**、`G20` 是极坐标；公制是 `G71`，英制 `G70`（§5.1.1） | 单位没切 |
| `G49`（取消长度补偿） | NUM 的 `G49` 是**删除样条曲线**（§5.1.1） | — |
| `G43 Z H`（长度补偿） | NUM 的 `G43` 是**圆柱刀三维刀补**（§5.1.1）；长度补偿随刀补号 `D` 生效，下一次刀轴方向移动时补上（§5.11.3、§5.11.3.1） | 报错或走错 |
| `G28`（回参考点） | NUM 没有 G28；按测量原点编程用 `G52`（§5.1.1，测量原点 OM） | 报错 |
| `G50 S`（车，限速） | NUM 限速是 `G92 S`（§5.5.4），`G92` 后面必须紧跟 S，否则当成坐标预置 | 不限速 |
| `G96 S M03`（车，恒线速） | NUM 的 `G96` 要主轴**已经在转**，还要给出当前直径 `X`（同段或前面，§5.5.3，否则报错 28） | 报错 |
| `G98` / `G99`（车，每分 / 每转进给） | NUM 的 `G98` 是 C 轴插补起始 X，没有 `G99`；每分 / 每转是 `G94` / `G95`（§5.1.1） | 进给单位不对 |
| `G32 Z F`（车螺纹） | NUM 单段车螺纹是 `G38 X Z K螺距`（§5.13.2）；`G33` 是螺纹**复合循环** | — |
| `M29 S` + `G98 G84 X Y Z R F`（刚性攻丝） | NUM 没有 M29；刚性攻丝是 `G84 Z终点 K螺距`（K 表示刚性攻丝，§5.12.7）；`R` 在 NUM 不是退回平面（ER / EH 才是） | 程序跳走或走错 |
| `G02` / `G03` 的 `I J K` | NUM 在 G90 下 I J K 是**圆心的绝对坐标**（相对程序原点），G91 下才相对起点（§5.7.3） | 圆心完全错位 |
| `G04 X` / `G04 P`（暂停） | NUM 是 `G04 F秒`（§5.19.1） | — |
| `M30`（程序结束） | NUM 手册 M 代码表里没有 M30，程序结束是 `M02`（§3.3.1、§5.1.2） | — |
| `O1001`（程序号） | NUM 程序以 `%` 开头，`%1001 (注释)`；9000 以上的号可能被 NUM / 机床厂占用（§3.3.3） | — |
| 车床直径编程 | NUM 直径 / 半径编程是**机床参数**，不是 G 代码（§5.2） | 要按机床设好 |

冷却：NUM 手册 M 代码表里有 `M08`（冷却 1 开）、`M07`（冷却 2 开）、`M09`（关）（§5.1.2），和 FANUC 的意思相同，照写。

## 决策

1. **新增 `num` 家族**（`schema/cam-post.schema.json` 的 `family` 加 `num`，这一步单独一个 PR）。做法与发格（ADR-0126）相同：
   问渠CAM 先按 FANUC 写法写好（同一套刀路、同一套整机仿真），再按固定的对照表逐行换成 NUM 写法；回读时按同一张表**换回** FANUC 写法，
   交给 `sim.parse` 与仿真逐点比，一致才出（ADR-0104 安全底线）。换不回来的行一律报错不出。
2. 对照表（每条写手册章节，`analysis/cam/num.py`）：
   - 程序头：去掉 `%` 行；`O1001 (…)` → `%1001 (…)`（§3.3.3，程序号和注释同一行）；程序号 ≥ 9000 报错（§3.3.3 留给 NUM / 机床厂）。
     车床在程序头下面加一行注释 `(NUM: X IN DIAMETER, MANUAL 5.2.1)`，提醒机床要设成直径编程（§5.2 是机床参数，程序里改不了）。
   - 第一行模态：`G21` → `G71`；`G49` 去掉；车床 `G99` → `G95`、`G98` → `G94`。
   - 车：
     - `T0101` → `T1 D1 M06`（§3.2.1.1、§5.11.1 车床例 `T05 M06`；NUM 刀补号可以和刀号不同，`T0102` → `T1 D2 M06`）；
     - `G50 S` → `G92 S`（§5.5.4）；
     - `G96 S… M03` → 两行：`G97 S转速 M03`（先让主轴转起来）、`G96 X直径 S线速`（§5.5.3；X 取紧接着那一段移动的 X，
       转速 = 线速 × 1000 ÷ (π × 直径)，不超过前面 G92 的限速，取整；手册例 N130 `G97 S900 M40 M03` / N150 `G96 X22 S100`）；
       后面那一段没有 X、或直径为 0 的，报错不出；
     - `G99` / `G98` → `G95` / `G94`；`G32 … F` → `G38 … K`（§5.13.2；G38 段里不许有 M 代码，有就报错）。
   - 铣：
     - `T1 M06` → `T1 D1 M06`（§3.2.1.1 例 `N20 T01 D01 M06`）；换刀后第一次 Z 移动 `G43 Z… H01` → `Z…`（去掉 G43、H；H 号必须等于刀号，否则报错）；
     - `G91 G28 Z0.0` → `G00 G52 Z0`（按测量原点回 Z 零点，与西门子 `G0 SUPA Z0`、发格 `#MCS Z0` 同一约定：机床 Z 零点在上方；§5.1.1、§5.11.1
       “换刀前编一个安全位置……或用 G52 按测量原点”）；
     - 刚性攻丝 `M29 S` / `G98 G84 X Y Z R F` / `G80` → `G00 X Y`、`G00 Z R`、`S转速 G84 Z终点 K螺距`、`G80`、`G00 Z初始平面`
       （§5.12.1：不写 ER 时用前一个 Z 当接近 / 退回平面；§5.12.7 例 N50 `G00 Xa Ya Za` / N60 `G84 Zb K..`；螺距 = F ÷ S，换回去要能逐字还原 F，否则报错）。
       刀路与 FANUC 的 G98 G84 相同（快移到孔上、快移到 R、攻进去、退到 R、快移回初始平面）。
   - 程序结束：`M30` → `M02`（配置 `program.end` 缺省 `M02`，由 `postcfg.finish` 换）。
3. **手册代码表**：NUM 程序里出现的每个 G、M 代码都要在手册 §5.1.1、§5.1.2 的表里、且是本表用到的
   （G00 G01 G17 G18 G38 G40 G52 G54 G71 G80 G84 G90 G92 G94 G95 G96 G97；M00 M01 M02 M03 M04 M05 M06 M07 M08 M09 M19）；
   `G92` 只收 `G92 S`；`G02` / `G03` 不收（问渠CAM 不写圆弧指令，而 NUM 的 I J K 意思不同，见上表）；`G04` 不收（参数写法不同）；
   配置里换刀前后动作写的 M 代码（用户按机床说明书填）也认。表外的不出、点名。
4. **配置限制**（`postcfg.check`）：NUM 家族不收 `dialect`（写法已按手册固定）；`cycles.turn`、`cycles.drill` 必须关
   （NUM 的 G70 / G71 是英制 / 公制，钻孔、车削固定循环的参数另有一套：ER、EH、EF……）；`subprograms` 必须关（NUM 子程序是 `G77 H`，§5.1.1，还没做）；
   车铣、双主轴、多通道不做（程序里出现 G12.1、G13.1、G07.1 等按代码表拒出，写明“NUM 车铣还没做”）。冷却可以开（M08 / M09 在手册表里）。
5. 内置配置 `analysis/cam/posts/num-flexium.json`：车、铣；`source` 写手册名、编号和章节；`verified` false；核对级别 L1（自己回读）+ L2（LinuxCNC 回读 FANUC 原文）。
6. 程序比对（`progdiff`）认 NUM：`G52`、`G38`、`T数 D数 M06`、或第一行模态是 `G71 G17` / `G71 G18`（且不是发格）任一出现就是 NUM。

## 理由

- 与发格同一个思路：写法差别全部可逆、回读一致才出；NUM 的同名异义代码比发格还多（G21、G43、G49、G98、I J K），只能整张表换、不能在 FANUC 上打补丁。
- 恒线速要“主轴已转 + 当前直径”，手册例子就是 `G97 S M03` 再 `G96 X S`，照手册写；转速按同一公式算，不另编。
- 直径编程是机床参数，程序里改不了，只能写在程序头提醒、写进帮助。

## 施工细则（2026-11-25）

1. 本 ADR + `schema/cam-post.schema.json` 的 `family` 加 `num`（单独一个 PR，ADR 先合）。
2. `analysis/cam/num.py`：`CODES_G`、`CODES_M`（带章节）、`to_num(text, lathe)`、`to_fanuc(text, lathe)`、`check_codes(text, lathe, extra_m)`；`NumError`。
   回读时保留行尾的 `(#Ln)` 行号标记。
3. `postcfg`：`DEFAULTS["num"]`（同 FANUC，循环关、不写 %、结束 M02）；`check()` 加第 4 条的限制。
4. `postproc.render`：NUM 按 FANUC 写好、`finish`（按 FANUC 家族加工）后 `num.to_num`，再查代码表；`to_fanuc`：NUM 先 `num.to_fanuc`。
5. `progdiff`：认 NUM。
6. 内置配置 `num-flexium.json`；标准题 `tests/test_cam_post_num.py`：
   - 车（外圆、切槽、车螺纹）、铣（开槽、钻孔、攻丝）能出，程序里没有 G21 / G49 / G50 / G99 / M29 / G28 / G43 / G32 / M30，
     有 G71、G92 S、G95、`T1 D1 M06`、`G97 S… M03` + `G96 X… S…`、`G38 … K`、`G00 G52 Z0`、`G84 Z… K…`、M02；
   - 回读一致；车削、铣削程序时间与 FANUC 相同（冷却照开）；
   - 往返：`to_fanuc(to_num(x)) == x`（FANUC 原文逐行一致）；恒线速的转速按公式、受限速；
   - 车铣零件出不了、点名“NUM 车铣还没做”；表外代码不出、点名；程序号 ≥ 9000 不出；
   - 配置限制（dialect、循环、子程序、车铣）各一条，写明原因；
   - L2：换回的 FANUC 程序交 LinuxCNC rs274 解释器能读（有 rs274 才跑）。
   - 记录写进 `assist/cam_verification_cases.json`，目录 CAM-94 起。
7. 帮助（中、英）加“NUM Flexium”一节；STATUS、ADR-0106 E3 记一笔。
8. 不做：车铣、双主轴、多通道、五轴、NUM 固定循环（G81–G89 的 ER / EH 写法、G63–G66 车削循环）、子程序、圆弧指令、L3（NUM 的模拟软件另找）。
