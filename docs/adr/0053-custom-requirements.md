# ADR-0053：可配置接口的定制要求（M8 第五步）

- 状态：已接受（2026-10-06，项目负责人授权 Claude 推进 FreeCAD 的 AI 原生重构）
- 日期：2026-10-06
- 补充：ADR-0045（厂商目录不规定的端口）、ADR-0046（真实关节样例）、ADR-0051（BOM 面板）

## 背景

真实关节样例中唯一待确认的校验是 C3：Harmonic Drive CSF-2UH 整机型的电机法兰按所配电机定制，目录不规定孔位（ADR-0045）。这不是数据缺失，而是订货时要告诉厂商“按哪台电机做法兰”。用户需要的是一份能直接用于询价、订货的说明，而现在只看到“待确认”。

## 决策

1. **定制要求由确定性代码从对接的另一侧端口整理**（`engine/custom.py`，纯函数）
   - 对系统中每个连接：一侧端口标了 `configurable: true`、另一侧端口有规格时，生成一条定制要求
   - 内容：哪个组件的哪个端口，要按哪个组件的哪个端口定制；对方端口的各项规格（值、出处页码），以及对方缺失、需要另行确认的项
   - 法兰列出：分度圆、孔数、孔的形式、通孔直径或螺纹、止口直径与形式；安装面列出其规格中已有的项
   - 只照录对方的数据，不推导本侧的孔径、螺纹或公差，不补缺失值
2. **不改校验结论**：C3 仍为待确认（ADR-0046 第 7 条的验收口径不变）。定制要求是对“待确认”的处理办法，不是判定
3. **输出**
   - BOM JSON 增加 `custom_requirements` 列表；BOM CSV 的列不变
   - BOM 面板在清单下方列出定制要求
   - 校验窗口在相关校验项后提示“定制要求见 BOM”
4. **AI**：`export_system` 的 bom_json 已包含该列表，AI 回答订货问题时以它为准

## 理由

- 把“待确认”变成可执行的下一步，符合“负担在 AI，不在用户”，同时不放松校验
- 只照录有出处的数据，订货说明的每个数都能追到规格书页码
- 本侧的配合尺寸（螺纹规格、止口公差）由厂商按其设计规范决定，我们不代替厂商设计

## 影响

- 新增 `engine/custom.py`；`engine/export.py` 的 bom_json 加字段，示例 `examples/joint-real/bom.json` 随之重新生成
- BOM 面板、校验窗口显示定制要求
