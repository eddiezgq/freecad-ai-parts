# ADR-0022：公差偏差的符号约定

- 状态：已接受（2026-10-01，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-01
- 修订：ADR-0010 中参数值“公差”写法的跨字段约束

## 背景

`schema/common/param-value.schema.json` 的说明要求 `tol_lower ≤ 0 ≤ tol_upper`。真实公差常有两侧同号的偏差：

- g6 轴 φ14：上偏差 −0.006、下偏差 −0.017
- F7 孔 φ14：上偏差 +0.034、下偏差 +0.016

按原约定这些值无法表示，LLM 抽取（#29）时会把正确的值判为错误（issue #42）。

## 决策

1. 公差写法的跨字段约束改为：`tol_lower ≤ tol_upper`。两者都是带符号的偏差，单位与名义值相同；不再要求下偏差 ≤ 0 ≤ 上偏差
2. 只给一侧偏差时（只有 `tol_upper` 或只有 `tol_lower`），不做符号约束
3. 由代码校验（schema 不表达跨字段数值关系，与 ADR-0010 一致）：LLM 抽取核对时执行；M3 引擎校验时执行

## 理由

偏差带符号就足以表达任意公差带，`tol_lower ≤ tol_upper` 是唯一必需的一致性条件。原约定把“名义值落在公差带内”误当成了普遍规律，只对对称公差和基准偏差为 0 的公差成立。

## 影响

- 只改 schema 的说明文字，不改结构，已有数据与样例不受影响
- 随后的实现 PR 放宽 `ingest/llm_extract.py` 的检查，并补两侧同号公差的测试
