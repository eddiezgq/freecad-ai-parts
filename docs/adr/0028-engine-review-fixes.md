# ADR-0028：校验引擎独立评审后的规则修订

- 状态：已接受（2026-10-01，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-01
- 修订：ADR-0025 第 2 条（取数）、ADR-0026 第 2 条（效率取值）；补充 C2、C3 规则

## 背景

C1–C11 全部实现后做了一次独立评审（M3 #52 之前）。评审发现几种情况下，本应为 fail、warn 或 unknown 的结果会显示成 pass 或 not_applicable：
- 同品类有多个实例
- 需求侧参数给的是范围
- 压装配合间隙配合
- 系统中没有任何适用项

## 决策

1. **取数按“对安全不利的一端”**，替代 ADR-0025 第 2 条中“范围一律取下限”
   - 能力侧取下端：电机额定扭矩与峰值扭矩（公式 (1)(3)）、减速器各项额定、驱动器电流、轴承极限转速、电机转子惯量
   - 需求侧取上端：电机所需电流（C9）、公式 (5) 中的电机峰值扭矩、减速器输入侧惯量（公式 (6)）
   - 减速比与效率：公式 (1)(3)(6) 取下端，公式 (5) 与转速换算取上端
   - 公差写法按名义值加上、下偏差得到两端，没写偏差的一侧按名义值；只给一端的范围，缺的那端视为缺失
2. **同品类多实例**：电机、减速器、驱动器在一个系统中各至多一个（V1 一个关节）。超出时，依赖它们的校验（C2、C3 的连接检查，C4–C10）判 unknown 并说明原因，不得判为不适用
3. **压装须过盈或过渡配合**：孔的紧固方式为 `press_fit`，且 ISO 286 配合类别为间隙配合时，C2 判 fail。轴承一侧的配合仍按 ADR-0017、ADR-0024 处理
4. **没有任何适用项**时整体结论为 unknown，不得呈现为通过
5. **缺少应有的连接**（ADR-0020）
   - C2、C3 查找电机到减速器的路径时，只走通过 C1 的连接
   - 接错（C1 不通过）与缺失同样判 fail，与 C9、C10（ADR-0027）一致
6. **缺数据即 unknown 的补充**
   - 止口：写了止口形式或直径任一项，就视为有止口，缺的另一项判 unknown
   - 组件缺少 C9、C10 需要的标准端口时判 unknown
7. **可换轴套**：轴径与孔径不等，但轴径在孔的 `accepted_diameter_range_mm` 内时判 warn，须选配轴套
8. **轴承配合查表的直径**取配合件端口的名义直径（ADR-0017 第 3 条，原实现取的是轴承端口）
9. **“须相等”类的判定不输出余量**，只有“不大于限值”类的判定输出测量值、限值与余量
10. **golden 运行器从严**：预期中出现未知的校验项、不合法的状态值或不支持的 `others` 写法，都报为不一致，防止拼写错误被静默放过

## 理由

范围数据在真实规格书中很常见。一律取下限会让需求侧的校验偏乐观，与“保守取数”的本意相反。另外三处（多实例、全部不适用、压装）都会把不能用的方案显示为能用，属于必须堵住的漏洞。

## 影响

- 现有 golden 用例结果不变（18/18 与预期一致）
- 第 3、7 条是新增规则，需要的话可由人调整
