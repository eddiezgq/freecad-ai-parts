## 背景

2026-11-18 项目负责人定：“我们要出就是精品，没有进度要求”；“对照商业版，好好先把短板补齐，好好看看界面合适否”。

## 一、逐项对照

“商业版常见水平”取上面几家的共同水平（Fusion 基础版大体是下限，NX、hyperMILL 是上限）。

### 6. 我们已有、商业版少见的（保留并做深）

- AI 起草工艺，程序逐项核对，超出刀具样本范围的不采用；
- 安全底线写死：整机仿真不通过不出程序；程序回读与仿真刀路逐段比对；程序头带仿真指纹；
- 中英对照，验证手册（每个数来自自动测试）；
- 价格与教学：免费版能学完车削和三轴编程。

## 二、界面审查

现在的面板是“一张长表单从上填到下”，像网页表单，不像工程软件。看商业 CAM 的共同做法，问题有六个：

1. **没有加工树**：工序不是文档里的对象，不能选中、改、复制、调顺序、单独算。
2. **零件只能读或手填**：不能在三维视图里点选面、边、孔。
3. **一个工序的参数没有地方改**：只有表格里的 vc、f、ap；进退刀、安全高度、余量、分层都看不到。
4. **结果只在文字里**：没有回放，不能单步看刀具怎么走、在哪一行撞。
5. **程序看不到**：存成文件才看得到程序，不能对照刀路看是哪一行。
6. **刀具、机床只是文件**：没有管理窗口，看不到刀的样子、机床的样子。

目标界面（照 FreeCAD CAM 与商业 CAM 的共同习惯，用 FreeCAD 自己的模型树和任务面板，学过任何一家 CAM 的人都能上手）：

- **模型树里的加工树**：作业 → 装夹（机床、毛坯、坐标系、夹具）→ 工序（刀具、参数、刀路），每个都是文档对象，存在 FCStd 里；右键：编辑、复制、上移下移、单独计算、隐藏刀路。
- **工序的任务面板**：分页签——几何（在视图里点选）、刀具（从刀具库选，显示外形）、切削参数（显示样本范围，超出变红）、高度与进退刀、分层与余量；改完当场重算该工序。
- **回放条**（视图下方）：播放 / 暂停 / 单步 / 速度 / 时间轴；当前程序行高亮；碰撞、过切处在时间轴和视图里标红，点一下跳过去。
- **程序窗口**：正式程序与刀路联动——点程序行，视图里刀具跳到那里；点刀路，程序跳到那一行。
- **刀具库窗口、机床窗口**：建刀、改刀，显示外形；机床显示三维模型，可点动各轴，行程到头变红。
- **检查清单**：按装夹、工序归类，点一条跳到对应工序和程序行。
- AI 起草放在作业的右键菜单里：起草出来的工序就是加工树里的对象，人逐个确认（确认前标“草稿”）。

### Q1 界面骨架：施工细则（2026-11-19）

**数据放在文档里**（`freecad_addon/fc/cam_objects.py`，FeaturePython，存进 FCStd，FreeCAD CAM 的 Job / Operation 也是这么做的）：

### Q2 仿真与回放：施工细则（2026-11-19）

**决定**
- 铣削的三维材料去除用**三向 dexel**（沿 X、Y、Z 三组平行射线，每根射线存材料区间），新模块 `analysis/cam/dexel.py`，纯 numpy。
  刀具按回转体处理（平底、球头、牛鼻、钻头），刀轴方向任意，所以 3+2、五轴的去除也能算。
  三轴竖直刀具的现有高度图仿真（`simulate_mill`）**保留不动**：它对三轴是精确的、快，已有的检查和指纹不变；
  加一道对照题：三轴程序的 dexel 结果与高度图结果在网格精度内一致。dexel 用在：五轴 / 3+2 的去除与过切、回放画面、色差图。
- 车削的半径网格对回转体是精确的，保留；车铣（C2）再接 dexel。
- 机床部件支持**三角网格**（STL，ASCII / 二进制都读）：`collide.Mesh`，三角形包围盒树粗筛，再逐个三角形用现有 GJK 精判；
  机床文件里部件写 `{"type": "mesh", "file": "xxx.stl"}`（相对机床文件所在目录）。
- 车刀刀杆按 **ISO 5608 代号**生成外形（例如 `PCLNR 2525 M 12`）：刀杆高 h、宽 b、全长 l1 都来自代号（长度字母按 ISO 5608 表）；
  刀尖到刀杆侧面的偏距 f 各家不同，来自刀具数据 `holder.f_mm`，没有就**刀头一段报“未知”**（不编数值），刀杆柄部照查。

  内孔刀方位 2）。精车刀路做刀尖圆弧补偿（在问渠CAM 里算好，不靠 G41/G42，任何系统都一样）：
  外圆、端面上假想刀尖与实际接触点重合，路径不变；倒角、锥面、圆弧上按 rε 偏置。不补偿时倒角会残留，仿真能查出来。

  并每隔若干段存一份材料状态，拖动时间轴时从最近一份往后补算。界面 `freecad_addon/gui/cam_replay.py`：视图下方停靠一条回放条
  （播放 / 暂停 / 单步前后 / 速度 / 时间轴，时间轴上事件标红，点一下跳过去），旁边程序窗口（正式程序，当前行高亮；点行跳到那一段，点视图里的刀路跳到那一行）；
  视图里刀具（刀柄 + 刀具外形）随回放移动，铣削的在制毛坯按 Z 向 dexel 画成网格面，车削的按半径网格旋成回转面。

  在公差内的是绿；在视图里给在制毛坯表面上色，旁边一条色标。结论进检查清单（过切 = 错误，残留超过精加工余量 = 提示）。

### Q3c 三维曲面：评估报告与完成记录（2026-11-19）

**怎么评**：FreeCAD 1.0.2 自带的 3D Surface（平行，OCL 投影）、Waterline（等高，OCL）出 R3 球头刀刀路，行距 2、等高层距 0.5；
高度图仿真加了球头刀，按刀路算出加工后的表面，与零件模型（弦高 0.002 三角化后按竖直方向取顶面）逐格比，网格 0.05，只看零件中间一块。
理论残留高度见 `freecad_addon/fc/cam_surface_eval.py`；数据由 `scripts/cam_surface_eval.py` 生成，存 `docs/verification/cam/surface-eval.json`。

| 零件 | 刀路 | 采样 | 量出残留（最大） | 理论 | 过切 |
| --- | --- | --- | --- | --- | --- |
| 平面 | 平行 | 0.05 | 0.163 | 0.172 | 0 |
| 斜面 20°（沿行距方向） | 平行 | 0.05 | 0.202 | 0.208 | 0.0005 |
| 斜面 20° | 等高 | 0.25 | 0.180 | 0.096 | 0 |
| 斜面 20° | 等高 | 0.10 | 0.124 | 0.096 | 0 |
| 斜面 20° | 等高 | 0.05 | 0.107 | 0.096 | 0 |
| 球冠顶部（坡度 ≤ 6°） | 平行 | 0.05 | 0.162 | ≤ 0.174 | 0.003 |
| 球冠侧面（坡度约 23°） | 等高 | 0.05 | 0.077 | 0.078 | 0.004 |
| 自由曲面 | 平行 | 0.05 | 0.173 | —（平面 0.172） | 0.002 |
| 自由曲面 | 等高 | 0.05 | 3.06 | — | 0.005 |

（量出的残留比理论小一点：网格 0.05，残留顶点落在两个格心之间。过切 ≤ 0.005，是三角化与网格的误差量级。）

**结论：够用，接进来。**
1. 平行精铣（3D Surface）各种曲面都与理论一致、不过切，直接用。
2. 等高精铣（Waterline）要两个设置：多层模式（缺省的单层模式只出 3 段，等于没加工）；采样间距要小——等高线位置按采样间距取整，
   残留约多出 采样 × tan θ（0.25 时 20° 斜面上残留 0.18，近一倍）。问渠固定用 0.05。
3. 等高不管平缓的地方（自由曲面上留了 3 mm），只用于陡面；平缓的地方用平行。问渠不自动替人判断，两种都放在“新建工序”里。
4. 慢：球冠侧面等高刀路 5 万多段，FreeCAD 算 3 分多钟；三维比对、回放都按段走，回放检查点原来每 20 段存一份毛坯，
   十几万段的曲面程序会耗尽内存——已改为最多 60 份。

**做了什么**：加工树加“曲面平行精铣”“曲面等高精铣”（新建工序；最大的球头刀，行距按目标残留高度 0.01 算 s = 2√(2Rh − h²)，
等高层距取 s·sin45°，采样 0.05）；高度图仿真支持球头刀；评估模块与报告；标准题：球头刀平面残留（CAM-47），FreeCAD 测试对理论值（平行平面、平行斜面、等高斜面）。

**与细则的偏差**：自写曲面刀路不需要另开一段（FreeCAD 的够用）。曲面零件的规则起草不自动加曲面工序（看不出哪些面要精铣、用哪种），由人在“新建工序”里加。
曲面开粗用已有的自适应开粗 / 型腔分层；残料清角对曲面不适用（只认型腔底面）。

2. 直线 `L X+.. Y+.. Z+.. R0 F..`，快移 `FMAX`（只管本段）；换刀 `TOOL CALL 号 Z S转速`（刀长补偿由刀具表自动生效，不写 G43）；
   `M3`、`M8` 跟在第一段移动上；工序结束 `L Z+安全高度 R0 FMAX M9`、`M5`；程序结束 `M140 MB MAX`（沿刀具轴退到行程尽头）、`M30`。
3. 钻孔：配置 `cycles.drill` 关（缺省）时与其他系统一样展开成直线段；打开时写 `CYCL DEF 200 DRILLING`（Q200 安全距离 2、Q201 深度、
   Q206 进给、Q202 每次进给深度（一次钻到底时等于孔深）、Q203 表面坐标 = R 平面 − 2、Q204 第二安全距离 = 安全高度 − Q203），
   每个孔 `L X Y R0 FMAX M99` 调用。攻丝一律 `CYCL DEF 207 RIGID TAPPING`（Q239 螺距），同样 `M99` 调用。
4. 配置开关：小数位、注释（ascii / utf8 / none）、冷却（flood / mist / off）、选择停（`M1`）、程序结束 M30 / M02、钻孔循环、
   子程序（每道工序一个 `LBL 号` … `LBL 0`，主程序 `CALL LBL 号`，标签放在 `M30` 之后、`END PGM` 之前）都管用；
   换刀前后动作只认对话格式回读认得的写法（`M140 MB MAX`、单独的 M 代码、`L … R0 FMAX` 直线），认不得的配置拒收、写明原因；
   `sequence`、`program.percent`、车削项对海德汉没有意义，打开就拒收。
5. 安全底线照旧：回读时把对话格式换回 ISO（`L` → G00 / G01，`TOOL CALL` → T M06 S，`CYCL DEF 200` + `M99` → G98 G81 / G83，
   `CYCL DEF 207` + `M99` → M29 + G98 G84，`CALL LBL` 展开，`M140 MB MAX` → G91 G28 Z0），与整机仿真刀路逐段比，对不上不出；
   换刀前后动作也换成 ISO 进整机仿真。程序头写“未经实机验证”。
6. 不做的（写明原因）：`CC` / `C` 圆弧——刀路中间格式里没有圆弧（FreeCAD 的圆弧在进中间格式前已按弦高 ≤ 0.002 mm 拆成直线），
   其他系统同样只写直线；以后中间格式加了圆弧，各家一起加。`CYCL DEF 203`——我们没有断屑、递减进给这些动作，200 就够。
   钻孔循环的“提前停止距离”由数控系统定，仿真按退到上次深度上方 0.5 mm 算，首件单段确认（加提示）。

**交付物**：`analysis/cam/klartext.py`（写好后按配置加工、回读换回 ISO、换刀动作检查）、内置配置 `posts/heidenhain.json`、
postproc 写海德汉铣、标准题（每个开关一题 + 内置配置一题 + 不合格配置一题）、验证手册加一题、帮助文件加一节。

**验收**：铣的标准程序（开槽、钻孔含啄钻、攻丝）在每个开关下都能出正式程序，回读与整机仿真刀路逐段一致，程序时间与 FANUC 一样
（换刀前后动作带移动的除外）；不合格配置不列出、写明原因；全部已有测试照过。

### Q4b 第三批：车刀片（泰珂洛 ISO-EcoTurn）：施工细则与记录（2026-11-22）

### C2b 西门子 TRANSMIT / TRACYL：进度记录（2026-11-20）

### C2b 车铣作业的界面：施工细则（2026-11-20）

目标：车削作业选的是车铣中心时，在加工树里加动力刀工序，一键算出“车 + 铣”整个程序。先做最常见的两种，别的明说不做。

1. **作业**：车削作业的机床下拉里选车铣中心（kind = mill_turn）时，右键装夹多两种工序：“端面铣（动力刀）”“圆柱面键槽（动力刀）”；
   车床（kind = lathe）上不出现。
2. **端面铣**：点零件右端面上的平面（法向 +Z、不是整圈的回转面），工序在端面坐标里按铣削的现成办法起草刀路（型腔、外形、钻孔，同 `cam_doc.mill_plan`，
   毛坯 = 车完的外形），刀路点 (x, y, z) 换成极坐标插补程序：X = 2x（直径）、C = y、Z = z。只做右端面（第一次装夹）。
3. **圆柱面键槽**：点键槽底面（平面，法向径向）。槽宽 = 刀径的直槽：沿 Z 的直线，C 取底面法向的角度、X = 2 × 底面到轴线的距离；槽宽大于刀径的不做
   （平底宽槽要 Y 轴铣，不是圆柱插补），报“请用刀径等于槽宽的键槽铣刀”。
4. **计算**：有动力刀工序时，先按现有车削算出该装夹的车削刀路，再把动力刀工序接在车削之后，整段按 `mode: millturn` 算（车完的外形上铣、动力刀整机仿真、
   按后处理配置出程序）；没有动力刀工序时照旧走车削。调头装夹（左端）不加动力刀工序。
5. **卡片与回放**：工艺卡里动力刀工序写“动力刀 T、插补方式、转速、进给”；回放先放车削，铣削段先只在程序里看（三维回放的铣削段另做）。
6. **验收**：带键槽和端面槽的示例轴，从建作业到出 FANUC、西门子两份程序全程在 FreeCAD 里走通；去料体积与解析值差 < 2%；帮助（中英）补一节。

**C3a 骨架：刀位 → 逆解 → 程序 → 回读仿真**（本段）
1. 刀路中间格式：铣削工序可带 `simul5: true`（五轴联动，和 `frame` 互斥），它的 G01 走刀点都带刀轴 `axis`（工件坐标单位向量，从刀尖指向主轴）。
2. 直纹面侧刃铣的刀位（`analysis/cam/fiveaxis.py`，C3b 的刀路要用、C3a 的标准题也要用）：直纹面由底边、顶边两条等点数折线给出，
   刀轴沿直纹线，刀尖在底边沿曲面法向往外偏一个刀具半径（平底刀侧刃贴曲面），可再往下多伸一点（`below`）。
3. 逆解成串：沿刀路逐点逆解，回转轴取离上一点最近的解（不绕远、不跳 360°）；找出三类问题——
   超行程（错误）；相邻两点回转轴突变（大于 `flip_deg`，缺省 30°，多半是过奇异点或换了一组解，报错并给行号）；
   刀轴离第一根回转轴不到 `singular_deg`（缺省 1°）的“奇异点附近”（第二根回转轴转多少都对，提示）。
   线性化：相邻两点刀轴夹角大于 `max_angle`（缺省 1°）时插点。
4. 后处理：用刀尖跟随（RTCP），程序写刀尖的工件坐标 + 回转轴角度——
   FANUC / 华中 `G43.4 H..` … `G49`；西门子 `TRAORI` … `TRAFOOF`；海德汉 `M128` … `M129`（`L X Y Z A/B C`）；广数没有，拒出。
   机床没开 RTCP（`features.rtcp`）报错不出程序。非 RTCP 输出（逐点按刀长、工件在台上的位置算机床轴位置，老机床才用）挪到 C3c。
   进给照写刀尖的每分进给 F；回转轴角速度超过机床能力（轴的 `rapid`，度/分）的段提示“会降速”。
5. 回读与仿真：`sim.parse` 认上面三种 RTCP 写法（回转轴角度按机床运动学换成刀轴），每段走刀带起点刀轴 `axis` 和终点刀轴 `axis_b`；
   材料去除走三向 dexel（刀轴在一段里变时按 2° 拆）；整机仿真按每个采样点的刀轴逆解（刀轴在段里按球面插值）。程序时间按刀尖路程。
6. 标准题：
   - NAS 979 圆锥台（半锥角 15°、底 Ø150、高 15 的圆锥面侧刃一圈）：刀位离理论锥面 < 0.001 mm；
     AC、BC 两台机床的 FANUC、西门子、海德汉程序回读后刀尖、刀轴与刀位逐点一致（< 0.01 mm、< 0.01°）；
     dexel 去料后锥面里面不少料（不过切）、锥面外一个刀径的带里不剩料（都差一个网格以内）；
   - 回转轴不绕远：刀轴转一圈时 C 连续走 360°，不出现 +180° → −180° 的跳变；
   - 刀轴经过 C 轴方向（竖直）时报“奇异点附近”；故意让刀轴走过奇异点、C 跳 180° 时报“回转轴突变”；
   - 三轴机床、广数系统遇五轴联动程序报错；回转轴超程报错。

**C3b 刀路**：直纹面侧刃铣（从 FreeCAD 选直纹面）、沿曲线加工（刀轴取曲面法向）、曲面多轴精加工（三轴刀路 + 前倾角 / 侧倾角）。
**C3c 刀轴控制**：按碰撞自动避让倾斜（刀柄、刀杆、机床部件），奇异点附近重新规划刀轴；非 RTCP 输出。
**C3d 界面**：FreeCAD 里的五轴联动工序、刀轴预览、回放。
**C3e 验收**：ISO 10791-7 S 形试件仿真零过切零碰撞；NAS 979、S 形试件对方实机试切（等对方，同 Q5c）。

### C3c 刀轴控制：施工细则（2026-11-23）

分两次交：C3c-1 刀轴控制（本节 1–3），C3c-2 非 RTCP 输出（本节 4）。只动球头刀精加工、沿曲线这类“刀轴可以改而切出来的形状不变”的刀路；
侧刃铣的刀轴由曲面定，改不了，只报问题。

1. **奇异点让开**（`fiveaxis.avoid_pole`）：找出机床的“极轴”（工件一侧最外的回转轴、或刀具一侧最里的回转轴的方向，AC / BC 都是 Z），
   刀轴离极轴不到 `min_deg`（缺省 3°）的点，把刀轴往一个固定的侧向推到 `min_deg`；从 `min_deg` 到 2·`min_deg` 之间逐渐减到 0，刀轴连续。
   侧向缺省取这段刀路刀轴水平分量的平均方向（都没有就取工件 +X）。球头刀改刀轴后按同一个球心重算刀尖（与曲面仍相切）。
2. **之字形不甩刀轴**：`ball_surface` 可给 `lead_dir`（固定方向）：前倾往这个方向倒，不跟走刀方向；之字形来回走刀轴不变向，可以 `direct` 直接连行。
3. **按碰撞加大倾角**（`fiveaxis.avoid_collision`）：刀具除刀刃外的部分（刀杆、刀柄，按离刀尖的高度分段的圆柱）与零件之间留 `clearance`（缺省 1 mm）；
   零件给成三角面（FreeCAD 网格）或距离函数。碰了就把刀轴绕球心往侧倾方向加大倾角，每次 2°，到 `max_tilt`（缺省 45°）还碰就报错；倾角沿刀路平滑（相邻点差不超过 2°）。
4. **非 RTCP 输出**（C3c-2）：机床没开刀尖跟随时，程序写逐点逆解出来的机床轴位置（按刀长、工件零点在机床坐标里的位置算），刀尖在两点间按机床直线插补走弯，
   超过弦差（缺省 0.01 mm）插点；程序头写明刀长与工件零点，换刀长、换装夹要重出程序；回读按机床正解换回工件坐标。
**标准题**：球冠擦奇异点（前倾 10°、±20°，C3b 记的那个）让开后不再突变、出程序、dexel 不过切；之字形固定方向前倾直连不突变；
深腔里的球冠（四周有壁）刀杆碰壁时自动加大倾角，碰撞查得过；非 RTCP 程序回读与刀位一致（C3c-2）。

### C3c-1 刀轴控制：完成记录（2026-11-23）

### C3d 五轴联动的界面：施工细则（2026-11-23）

1. 工序种类（铣削作业、机床要有回转轴）：`swarf5` 五轴侧刃铣（点一个或几个直纹面）、`surface5` 五轴曲面精加工（点一个曲面，球头刀）、
   `curve5` 五轴沿曲线（点一条或几条边，法向取边两侧面里朝上的那个）。菜单“新建工序”里三条命令，跟动力刀工序一样先在三维视图里点面 / 边再点命令。
2. 工序参数（属性编辑器里改，改完右键“重算刀路”）：前倾角、侧倾角（度）、固定前倾方向（空 = 跟走刀方向；`x` / `y` = 往工件 +X / +Y 倒，之字形用）、
   侧刃铣往下多伸（mm）、沿曲线进给深度（mm）、行距（占刀径比例，曲面精加工）、让开奇异点（度，0 = 不让）、按碰撞加大倾角（开 / 关）。
3. 选刀：侧刃铣挑刃长够直纹线长的平底刀里最粗的；曲面精加工、沿曲线挑球头刀里最粗的（不超过 Ø10）；参数取刀具样本的中间值。
4. 重算刀路：从面 / 边取几何（`cam_5axis`），算刀位（`fiveaxis`），让开奇异点、按碰撞加大倾角（零件按 FreeCAD 网格算距离，刀杆、刀柄按刀具库的刃长、

### C3e S 形试件仿真：完成记录（2026-11-23）

- 查出来的问题：扭曲直纹面上圆柱侧刃只能沿一条直纹线贴住，法向沿直纹线在转（这件转约 20°），两端会啃进曲面。原来按底边那点的法向偏刀，
  这件过切 0.44 mm——C3a 的圆锥台是可展面（法向沿直纹线不变），没暴露出来。
- 改法（`fiveaxis`）：① `swarf` 缺省按直纹线中间高度的法向偏刀（`at=0.5`），两端各啃一半，过切降到 0.12 mm；给了面法向时只用它定刀具在哪一侧；
  ② `swarf_check` 按全部刀位量曲面上每点的过切、剩料；③ `swarf_clear` 把啃进去的刀位沿法向推出来，直到过切 ≤ 0.001 mm——过切换成剩料，这件剩料最多 0.15 mm。
  FreeCAD 的五轴侧刃铣工序重算刀路时自动做 ②③，剩料 ≥ 0.01 mm 时工序理由里写“面是扭曲的直纹面……最多剩料 x mm”（留给清根或球头多轴精加工）。
- 结果：折线曲面上过切 ≤ 0.001 mm；拿 4 倍密的真曲面再量，过切 ≤ 0.01 mm（输入折线本身的弦差）、剩料 ≤ 0.15 mm；
  摇篮 AC（FANUC / 西门子 / 海德汉）、摆头 BC（FANUC / 华中）都出程序，整机仿真通过，没有回转轴突变、奇异点提示，回转轴每段最多转 4°；
  dexel（网格 0.25）壁里 0.3 mm 处都有料、壁外 0.5–9 mm 都没料。
- 偏离计划：加了 ①②③（第 3 条做题时查出来的）。剩料 0.15 mm 是圆柱刀做扭曲直纹面本身的偏差，要更小得改刀轴（离开直纹线优化摆角），不在本段，
  需要时另开。
- 标准题：`tests/test_cam_fiveaxis_c3e.py`（核对手册 CAM-65 至 CAM-67）。

### C4b 双主轴（工件交接）：施工细则（2026-11-24）

现在车两端是“右端一次装夹、调头再装一次”，两个程序，中间人工调头。双主轴车铣中心上改成一个程序：主主轴车右端 → 副主轴过来夹住已车好的右端 →
切断 → 副主轴带着工件退回来车左端（背面加工）。

1. **机床文件**（schema，ADR-0121）：加 `sub_spindle`：转速、功率（与 `spindle` 同）、副主轴沿 Z 移动的轴（`axis`，机床文件 `axes` 里的直线轴，例如 W）、
   副主轴自己的 C 轴（`c_axis`，可不写）、该轴在零位时卡爪端面的 Z（`face_z_mm`）、能夹的长度范围（`grip_mm` [最短, 最长]）。
   这几根轴只带副主轴一侧（夹头部件 `attached_to` 它们），主主轴上的工件不跟着动。
2. **后处理配置**（schema，ADR-0121）：加 `twin`：主副主轴同步转 / 停同步（`sync_on`、`sync_off`）、副主轴卡盘夹紧 / 松开（`sub_clamp`、`sub_unclamp`）、
   切到副主轴编程 / 切回主主轴（`sub_select`、`main_select`）、副主轴一侧的工件坐标（`sub_offset`，例如 G55）。各家写法不同（M 代码、SETMS(2) 等），按说明书填；
   六项缺一项，双主轴程序不出，写明缺哪项。
3. **工艺**：机床有 `sub_spindle` 且零件两端都要车（原来要调头）时：夹持位置、夹持长度与调头装夹的规则相同（夹在最大直径段上），
   夹持长度取 `grip_mm` 范围内、不超过最大直径段可夹长度的最大值；不够最短夹持长度、或副主轴移到夹持位置超出 W 行程 → 报错，不出程序。
   棒料要切断（`parting`）；不切断的毛坯（单件）副主轴接不了 → 照旧两次装夹。
4. **程序**（一个程序）：右端各工序 → `sync_on`、主轴转速 → W 快移到夹持位置前 2 mm、进给到夹持位置 → `sub_clamp` → 切断（原切断工序） → W 退回 →
   `sync_off` → `sub_select`、`sub_offset` → 左端各工序 → `main_select` → 结束。左端各工序不用固定循环，按副主轴一侧的坐标写（Z 方向与主主轴相反，
   程序 Z = −z′，z′ 是调头后的零件坐标；不用镜像指令——各家都能这样写）。FANUC、西门子出；其他系统不出双主轴程序。
5. **仿真与回读**：两段刀路分别按原来的两次装夹仿真（左端毛坯就是右端车完、切断后的样子）；回读认 `sub_select` 到 `main_select` 之间按副主轴坐标换回 z′，
   两段都与仿真刀路一致才出。整机仿真：W 带副主轴夹头，查切断、背面加工时刀与副主轴夹头、工件的碰撞；W 的移动查行程。

### C4c 多通道（两个刀架同时干）：施工细则（2026-11-24）

双主轴车铣中心常配上下两个刀架（两个通道、两条程序）：通道 1 在主主轴上车第 n+1 件的右端，同时通道 2 在副主轴上车第 n 件的背面；
两边都干完才交接（等待点），节拍 = 两边较长的那段 + 交接时间。

1. **机床文件**（schema，ADR-0123）：加 `channels`：每个通道写编号、这个刀架的直线轴（`axes`，例如 ["X2", "Z2"]）、刀具朝向与基准点（`tool`，同顶层 `tool`）、
   换刀点（`lathe_home_mm`）、干哪个主轴（`spindle`：main / sub）。不写 `channels` 就是单通道（现状）。刀架 2 的部件 `attached_to` 它自己的轴。
2. **后处理配置**（schema，ADR-0123）：加 `channels`：等待指令的写法（`wait`，带 `{n}` 的模板，例如 FANUC `M{n}`、西门子 `WAITM({n},1,2)`）、
   等待号从几开始（`wait_first`）、每个通道程序开头的行（`heads`，可不写）。没写 `channels` 的配置不出多通道程序。
3. **分工**：双主轴（C4b）+ 两个通道：通道 1 干主主轴一侧（右端各工序、切断），通道 2 干副主轴一侧（背面各工序）。
   一个循环：两边同时干 → 等待 1 → 交接（接料、切断、退回，通道 1 写，通道 2 等） → 等待 2 → 下一循环。第一件开机时通道 2 空等。
4. **程序**：两条程序（通道 1、通道 2），等待号按 `wait_first` 起依次编，两条里成对出现；各自回读、与各自的仿真刀路一致才出。
5. **时间线与互碰**：两个通道各自按 `sim.timing` 算每段的起止时间，等待点对齐；同时干的那段按 0.05 s 一步取两边刀架的位置，
   查刀架 1（刀、刀杆、跟着 X1/Z1 的部件）与刀架 2 互碰，以及刀架 2 与主主轴卡盘、刀架 1 与副主轴卡盘。
6. **节拍报告**：每个通道的切削、快移、等待时间，循环节拍；单通道做同一个零件的节拍对比。
7. 示例机床 EX-MT-TT（虚构）：EX-MT-TS 加下刀架（X2 朝 −X、Z2）和刀架 2 部件。分两个 PR：本 PR schema + 细则；C4c-2 实现。

**标准题**：EX-MT-TT 上 C4b 的零件：两条程序等待号成对、顺序对；节拍 = max(右端, 背面) + 交接，手算核对；比单通道节拍短；
把刀架 2 的换刀点挪到主主轴卡盘前 → 时间线查出刀架互碰；`channels` 缺写法不出、写明原因。
