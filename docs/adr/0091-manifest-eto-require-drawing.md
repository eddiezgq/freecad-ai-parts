# ADR-0091：工厂清单 `eto` 加 `require_drawing`（按单设计发布前本单新件要有批准的图纸）

- 状态：已接受（2026-11-11，项目负责人确认问渠第 150 轮细则第七节第 4 条）
- 日期：2026-11-11
- 补充：ADR-0090（工厂清单加 `eto` 一节）、ADR-0068（共用一份代码）

## 背景

问渠第 150 轮 150d 把按单设计和“设计发布与审批”（`/design`）接起来：作业设计发布前，本单新件（编号以作业号开头的自制件、外购件）
要在“设计发布与审批”里有一次已批准、带图纸的提交；发布记录写下各件的图纸版本，作业单显示按哪张图做。
项目负责人定的是默认开、演示工厂也开，但要能按工厂关掉（有的工厂按物料清单和工艺就能做，不出图）。

## 决策

1. `eto` 一节加可选字段：

   | 字段 | 类型 | 用途 | 没写时 |
   | --- | --- | --- | --- |
   | `require_drawing` | true / false | 设计发布前本单新件（自制件、外购件；原材料不要）是否必须有批准的图纸 | true |

2. 校验在 `factory/plant.py` 的 `_validate_eto`：写了就必须是布尔值。
3. 关掉时，缺图纸只提醒、不挡发布；图纸有的照样记进发布记录和指纹。
4. 不改 `schema/`、`engine/`，不碰 `tests/golden/`。

## 后果

- 演示减速器厂清单不写这一项，按默认开。
- 测试：`factory/digital/tests/test_eto_design.py::test_require_drawing_switch`。
- 代码同步（`hub/eto_design.py`、`hub/app.py`、页面、测试）另提 PR，按 `factory/SYNC.md` 比对。
