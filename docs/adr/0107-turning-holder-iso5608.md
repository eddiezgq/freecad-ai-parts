# ADR-0107：刀具库加车刀刀杆的 ISO 5608 代号（cam-tool/1 补充）

- 状态：已接受（2026-11-19，属于 ADR-0106 Q2 已确认的施工细则第 3 项）
- 日期：2026-11-19
- 补充：ADR-0105（cam-tool/1）、ADR-0106（问渠CAM 精品化 Q2）

## 背景

整机仿真查车刀时只查刀尖圆弧，刀杆外形没有数据，结论是“未知”（ADR-0104 C1 记录）。cam-tool/1 的 `holder` 只有铣刀刀柄用的回转轮廓 `profile_mm`，车刀刀杆不是回转体，写不进去。

## 决策

`holder` 加两个字段（都可选），`profile_mm` 与 `iso5608` 至少写一个：

- `iso5608`：车刀刀杆 ISO 5608 代号，例如 `PCLNR 2525 M 12`。刀杆高 h、宽 b 来自第 6–9 位数字，全长 l1 来自长度字母（ISO 5608 的长度表），
  刀片大小来自最后两位。空格可写可不写。
- `f_mm`：刀尖到刀杆基准侧面的距离（厂家样本的 f）。ISO 5608 不规定这个值，各家不同；没有就不写，
  整机仿真里刀头一段（刀尖到刀杆柄部之间）报“未知”，柄部照查——不编数值。

## 影响

- 只加可选字段，已有刀具库文件照样有效。
- `analysis/cam/holders.py`（ADR-0106 Q2 第 3 步）按这两个字段生成刀杆外形，进整机仿真。
- 测试：`tests/fixtures/cam-tool/` 加两个有效、两个无效例子。
