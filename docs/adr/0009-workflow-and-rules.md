# ADR-0009：开发流程——main 受保护，全部改动走 PR；实施细则入库

- 状态：已接受
- 日期：2026-09-30

## 背景

V1 以一名兼职开发者加 AI 编码助手推进，需要一个能评审 AI 改动、保持实现与方案一致的流程。

## 决策

- `main` 为受保护分支，所有改动（包括开发者本人的改动）通过 PR 合并，CI 全绿方可合并
- 实施细则定稿为 `docs/implementation-rules.md`；其中 AI 编码助手规则同时写入仓库根目录 `CLAUDE.md`
- M1 提前至 2026-10-05 开工，多出的 1 周转为缓冲，V1 完成日期不变

## 理由

PR 是逐行评审 AI 改动的入口；把规则写进仓库，每个 AI 会话都会自动读取并遵守。

## 影响

- GitHub 免费账户的私有仓库不能强制分支保护规则；在仓库公开或升级为付费计划之前，“不直接推送 `main`”按约定执行
- 计划调整后：M1 10/5–10/25，M2 10/26–11/22，M3 11/23–12/13，缓冲 12/14–2027/1/3，其后不变
