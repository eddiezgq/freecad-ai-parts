# ADR-0079：实验 30“一台轮式人形从订单到交付”

- 状态：已接受（2026-11-02 项目负责人确认问渠仓库第 74 轮细则 Q1、Q2）
- 日期：2026-11-02
- 补充：ADR-0078（轮式人形 WQ-H1）、ADR-0068（共用一份代码）

## 决策

1. 机器人厂加实验 30（`hub/lab30.py`、页面 `Lab30.vue`、接口 `/api/lab30`），六个任务自动评 60 分：接单算料（含底盘在这张单里自己造）、按层下达、
   两种整机抢一个工位、人形判定、入库开票、成本。
2. 任务 3 的答案当场由平台数据算：两种整机工艺路线共用的设备 ∩ 技能矩阵里只有一个人会的设备；对策按这一周该设备负荷与班次、会的人数判。
3. `hub/lab24.py` 的订单、测量、成本函数加产品参数供实验 30 复用，实验 24 行为不变。
4. 共有路径，按 ADR-0068 逐字同步；顺带同步问渠第 71 轮之后别处对共有代码的修改。

## 影响

- 新增 `hub/lab30.py`、`tests/test_lab30.py`、`web/src/pages/Lab30.vue`、指导书；改 `hub/app.py`、`hub/labs_api.py`、`hub/course.py`、`hub/cae_api.py`、`cae/labdoc.py`、
  `hub/lab24.py`、`tests/plant_loop.py`、`tests/test_lab24_25.py`、帮助机器人厂第 6、12 章。
- 不改 `schema/`、`engine/`、零件数据，不碰 `tests/golden/`。
