项目负责人 2026-11-17 00:12 问“我们的多体动力学模块和 ADAMS 主要差距是什么”，00:27：“当然要追上，分步骤实施”。

现在的 `analysis/mbd`（搬自问渠数字工厂第 12 轮）：底层 MuJoCo；模型只有 10 个参数化机构、参数化串联臂、手写 MJCF；

## 决策

1. **代码只有一份，在本仓库 `analysis/mbd`**（Apache-2.0）。FreeCAD 工作台、网页、问渠数字工厂都调它。现有 `run(setup)` 旧写法与
   “动力学 → 选型”保留兼容，旧标准题不改照过。
2. **自写精确求解器，MuJoCo 保留**：
   - 新内核 `analysis/mbd/dae/`（只用 numpy、scipy，纯计算、不联网）：每个构件 7 个坐标（位置 + 欧拉参数），运动副、驱动是代数约束；
     运动学用牛顿迭代解约束；动力学用坐标分块（独立坐标积分、带误差控制的隐式积分器，非独立坐标每步牛顿迭代回到约束面，
     分块病态时自动换分块）；静平衡用带约束的牛顿法；线性化在独立坐标上求刚度、阻尼、质量矩阵再解特征值。约束满足到 1e-10 级。
   - MuJoCo 留作“快速 / 机器人 / 多接触”后端；同一模型两个后端都能跑时，测试里互相核对。
3. **模型先定 schema**：新 `schema/mbd-model.schema.json`（单独 PR）：单位、构件（质量惯量，或几何 + 材料算）、标记点、运动副、
   驱动、力元、接触、测量、分析（运动学 / 动力学 / 静平衡 / 线性化，可串联：静平衡 → 动力学）、结果请求。
   函数表达式用受限的表达式语言（ADAMS 函数的常用子集：time、STEP、STEP5、IMPACT、HAVSIN、SIN、样条插值、测量量 DX / VX / WZ…），
   自写解析器，不用 eval。
4. **确定性核查**（结论只有通过 / 不通过 / 未知）：约束残差、能量守恒（无耗散时）、自由度数与冗余约束检查（Grübler 与雅可比秩）、
   积分误差（换容差复算比较）、驱动力矩与虚功原理对照。结果附核查结论；核查不过的不出“可用于选型”的需求。
5. **AI 只起草，不判定**：从 FreeCAD 装配、一句话或图纸起草运动副、驱动、力元，人确认后才算；结果解释的说法都来自核查层。测试不调用真实 LLM。
6. **验证体系**：`tests/mbd_bench/` 放标准题，每题写明出处与参考值（IFToMM 基准库公开的参考解、Hairer–Wanner 测试集的 Andrews 挤压机构、
   教材解析解），容差写明；参考值没对过原文的不进测试（implementation-rules 第八节，来源登记）。
7. **分段**（每段一个或几个 PR；schema 改动单独 PR 并在本 ADR 写补充）：

| 段 | 内容 | 验收 |
|---|---|---|
| D1 | 模型 schema；精确求解器内核：刚体，固定、转动、移动、圆柱、球、万向副，关节驱动（位移函数），重力、恒定 / 函数力；运动学、动力学、静平衡；约束残差、能量、自由度核查；旧 MuJoCo 接口照旧 | 单摆周期、双摆能量守恒、曲柄滑块与四杆解析、Andrews 挤压机构（参考解）、静平衡解析题；与 MuJoCo 互证 |
| D2 | 力元与函数：弹簧阻尼（移动 / 转动）、衬套、梁、单分量力、运动副摩擦（库仑 + 粘滑过渡、随反力）、间隙；函数表达式全集；测量量与结果请求 | 弹簧质量解析、阻尼衰减、斜面滑块摩擦、粘滑临界 |
| D3 | 接触：球、圆柱、平面、凸轮轮廓曲线、齿轮啮合、网格；IMPACT / Hertz 接触力与摩擦；分离与冲击 | 落球恢复系数、凸轮从动件跳动临界转速（解析）、齿轮传动比与啮合力 |
| D4 | 线性化：固有频率、振型、模态能量；准静态分析 | 多自由度弹簧质量、双摆小角度频率解析；与 `analysis/fea` 模态互证 |
| D5 | 从 FreeCAD 装配建模：Assembly 工作台的运动副 → 模型，质量惯量由实体 + 材料算；STEP 装配导入 + AI 起草运动副（人确认）；工作台面板：动画、曲线、核查结论 | 一个平缝机挑线机构、一个机械臂从装配建模，结果与手写模型一致 |
| D6 | 柔性体：CalculiX 模态缩减（Craig-Bampton）→ 柔性构件，变形与应力回放 | IFToMM 柔性曲柄滑块、柔性悬臂摆（解析） |
| D7 | 控制与优化：控制器（PID、状态空间、FMU 联合仿真）、参数扫描、试验设计、优化（接 `analysis/optimize`）、载荷谱给 `analysis/fatigue` | 闭环位置控制阶跃响应解析题；优化找到已知最优 |
| D8 | 规模与集成：几十个构件、长时间、性能（稀疏雅可比）；网页与问渠数字工厂接入另开问渠轮次；帮助；AI 起草与报告 | 50 个构件的链条 / 履带本机跑通并记录时间；报告里每个数来自结果文件 |

## 理由

- ADAMS 值钱的是“约束满足、误差可控、分析种类全、能从装配直接建”。MuJoCo 是为机器人实时仿真设计的软约束引擎，闭环机构有约束偏差、
  不给误差控制，做不到 ADAMS 的精度，所以要自写 DAE 内核；它在多接触、机器人上快，保留当第二后端并用来互证。
- 先模型 schema 再求解器：以后 FreeCAD 面板、网页、AI 起草都写同一份模型，不各拼各的 setup（同 ADR-0093 的做法）。
- 坐标分块法（Wehage–Haug）配 scipy 的隐式积分器：约束精确满足、误差受控、只靠 numpy / scipy，不引入 GPL 求解器。

考虑过的替代方案：
- 接开源多体求解器（Project Chrono 等）：功能多，但依赖重、Windows 安装麻烦、许可证与本仓库打包方式要另评估；内核自写可控，先不接。
- 只在 MuJoCo 上加功能：精度天花板在那里，追不上。

## 影响

- 新 schema 一份（单独 PR）；`analysis/mbd` 增加 `dae/` 子包，旧接口保留。
- 依赖不增加（numpy、scipy 已有；mujoco 照旧可选）。
- 问渠数字工厂的多体页面之后另开问渠轮次改为调用新内核。

## 补充一：模型 schema 第一版（D1，2026-11-17）

`schema/mbd-model.schema.json`（format = `mbd-model/1`）：

- 单位：长度 mm、质量 kg、惯量 kg·m²、时间 s、角度 °、力 N、力矩 N·m、刚度 N/mm、阻尼 N·s/mm；字段名带单位后缀。求解器内部用 SI，换算只在模型读入处。
- 位置、方向都写装配好时（t = 0）在地面坐标系里的值；构件坐标系 t = 0 时与地面同向、原点在质心（以后 D5 从装配建模时加构件姿态字段）。
  惯性张量对质心、沿地面轴；ixy、ixz、iyz 写张量的非对角元本身（= −∫xy dm 等）。
- 运动副：fixed、revolute、translational、cylindrical、spherical、universal；一律用“中心点 + 轴”描述，程序在两个构件上各建标记点坐标系。
- 驱动：运动副相对位移的函数（rotation 是 °、translation 是 mm，t = 0 记为 0），或匀速简写（rpm、mm/s）。
- 力元：力（作用点、地面或构件坐标系）、力矩、点对点弹簧阻尼；分量可以是数或函数表达式。
- 分析：kinematic（自由度为 0 时，逆动力学出驱动力矩与反力）、dynamic、static、static_then_dynamic；积分器 DOP853 / Radau / BDF，容差可写。
- 测量：构件上一点的位置、速度、加速度；运动副反力、驱动力矩、能量总是输出。
- 地面构件 id 固定为 `ground`，其他构件不能用这个 id。

## 补充二：D1 完成（2026-11-17）

- 求解器 `analysis/mbd/dae/`：`expr.py`（受限表达式语言，二阶射流给精确时间导数）、`system.py`（绝对坐标 + 欧拉参数，
  A(p) 用齐次二次式 (e0² − eᵀe)I + 2(eeᵀ + e0ẽ)，B 矩阵就是它的精确导数；约束值、ν、γ 用射流算，雅可比解析写出）、
  `model.py`（模型 → 内核，单位换算只在这里）、`solve.py`（冗余约束用带主元 QR 识别并删除；运动学、静平衡、
  动力学：坐标分块 + scipy 积分器，非独立坐标每次求值牛顿迭代到 1e-14，分块条件数超过起始的 10 倍就停下换分块）、`run.py`（结果与核查）。
- 对外：`analysis.run("mbd", {"model": <mbd-model/1>})`，不需要 MuJoCo（模块按设置声明依赖：`needs(setup)`）；旧写法照旧走 MuJoCo。
- 核查：约束残差（含删掉的冗余约束，≤ 1e-8）、保守系统能量相对漂移（≤ 1e-6）、自由度与冗余约束数（报出删掉了哪几条）。
- 标准题（`tests/test_mbd_dae.py`，18 项全过）：
  - Andrews 挤压机构（Test Set for IVP Solvers II.13）：7 个构件、10 个转动副按空间写法，程序删掉 9 条冗余约束，
    t = 0.03 s 七个角与参考解相对误差 < 1e-6（实测约 7e-9）；
  - 物理摆大摆角（90°）周期与椭圆积分解相对误差 < 1e-5；双摆能量漂移 < 1e-8，并与 MuJoCo（RK4、5e-5 s）0.6 s 后角度差 < 1e-3 rad；
  - 曲柄滑块位置与几何解 < 1e-10 m，驱动功率 = 动能变化率 + 克服外力的功率（相对 1e-3）；四杆摇杆角与几何解 < 1e-9 rad；
    万向节输出转速比的最大、最小值 1/cos β、cos β（相对 1e-4）；
  - 静平衡：弹簧质量 mg/k、侧向力单摆 atan(F/mg)；
  - 雅可比与射流方向导数一致到 1e-12，γ 与有限差分一致；表达式导数与差分一致，非法表达式（含 `__import__`）全部拒绝。
- 速度：纯 Python，Andrews 0.03 s（30 个输出点）约 16 s；性能放 D8（稀疏雅可比、向量化）。

## 补充三：D2 的模型字段（2026-11-17）

`schema/mbd-model.schema.json` 加（都可选，D1 的模型照旧有效）：

- 运动副 `friction`（转动副、移动副）：μ(v) 按速度光滑过渡——|v| ≤ v_s 时 μ = STEP(|v|, 0, 0, v_s, μs)，v_s < |v| < v_t 时
  μ = STEP(|v|, v_s, μs, v_t, μd)，以后为 μd；摩擦力 = μ·(反力 + 预载)，方向与相对速度相反；转动副乘销半径成摩擦力矩。
  反力取运动副约束力里垂直于运动方向的部分（转动副：径向力；移动副：横向力），与加速度互相依赖，求解时按不动点迭代。
- 转动副 `clearance`：径向间隙 c、接触刚度 k、指数 e、阻尼 c_d、阻尼满值压入深度 d；径向理想约束换成接触力
  F = max(0, k·δ^e + STEP(δ, 0, 0, d, c_d)·δ̇)，δ = 径向偏心 − c；两轴平行、轴向位置仍是约束。
- 力元：`rotational_spring_damper`（扭簧扭转阻尼）、`bushing`（六向线性衬套）、`beam`（直梁，欧拉–伯努利，可选剪切变形，阻尼 = 系数 × 刚度）。
- `measures`：运动副转角 / 角速度 / 位移 / 速度、两点距离 / 距离变化率；结果里输出，力元表达式里用 id 当变量。驱动的函数不能用测量量（只能是时间的函数）。
- `splines` 与表达式函数 `SPLINE(id, x)`（三次、Akima、线性）；表达式函数 `IMPACT(x, ẋ, x1, k, e, cmax, d)`：
  x < x1 时 max(0, k(x1 − x)^e − STEP(x, x1 − d, cmax, x1, 0)·ẋ)，否则 0（本模块的定义；与 ADAMS 同名函数的写法一致性在 D3 用公开算例核对）。

## 补充四：D2 完成（2026-11-17）

- 代码：`expr.py` 加 IMPACT、SPLINE、测量量变量；`system.py` 加扭簧、衬套、梁、转动副间隙接触力、运动副摩擦、测量量；
  `model.py` 把补充三的字段换成 SI 送进内核；`solve.accel` 对摩擦做不动点迭代（反力 → 摩擦 → 反力，收敛到相对 1e-12，最多 30 次）；
  `run.py` 输出 `measures`，有摩擦、衬套、梁、间隙或扭转阻尼时不判能量守恒（标 unknown）。
- 偏差（写回）：静平衡不计摩擦（速度为 0，摩擦按光滑模型为 0；"卡住不动"的静摩擦请用动力学看）；间隙副与摩擦不能同时加（放到 D3 接触里）；
  梁、衬套的势能不进能量账，所以有它们时不判能量守恒。
- 标准题（`tests/test_mbd_dae_d2.py`，15 项全过）：
  - 有阻尼弹簧质量与闭式解差 < 1e-6 mm；力的表达式用测量量 −1·x 等效 1 N/mm 弹簧，位移、速度与闭式解一致；
  - 30° 斜面滑块末速度与 g(sinθ − μd cosθ)t 相对 < 2e-4；10° 斜面（tanθ < μs）不滑（速度始终 < 静摩擦速度阈值）；
  - 转动副销轴摩擦让飞轮匀减速，末角速度与 ω0 − μmgR/I·t 相对 < 1e-6；
  - 衬套静变形 F/k（相对 1e-6）；悬臂梁端部挠度 PL³/3EI、转角 PL²/2EI、扭转角 TL/GJ（相对 1e-3，几何非线性带来的差远小于此）；
  - 扭簧振动频率 √(k/I)，能量守恒判通过；转动副间隙在重力下停在 c + (mg/k)^(1/e)（相对 1e-3）；
  - IMPACT 数值和导数、SPLINE 与 scipy 三次样条值及一、二阶导数一致；驱动函数里用测量量会被拒绝；schema 的 D2 全量样例能跑通。

## 补充五：D3 接触的做法与字段（2026-11-17）

字段（`schema/mbd-model.schema.json`，都可选）：

- `geometries`：挂在构件上的接触几何，坐标写装配位置下的地面坐标（mm）。
  - `sphere` 球；`plane` 平面（实体在法向反侧；可给 `half_size_mm` 成有限矩形）；`cylinder` 实心圆柱（侧面和两端圆边）；
  - `curve` 平面轮廓曲线（凸轮）：平面坐标系里的点，周期三次样条或折线，材料在曲线围成的一侧；
  - `mesh` 三角网格（凸体，法向朝外），与球、平面接触。
- `contacts`：接触对。法向力 F = max(0, k·δ^e + STEP(δ, 0, 0, d, c)·δ̇)（与 IMPACT 同形，e 缺省 1.5 即 Hertz），
  摩擦按切向滑动速度在 μs、μd 之间光滑过渡（同运动副摩擦），作用在两接触点中点、沿公法线和滑动反向。
- 力元 `gear_mesh`：两个轴线平行、同一支承构件的转动副之间的直齿外啮合。啮合线位移
  δ = remainder(r_b1·θ1 + r_b2·θ2, p_b)（r_b 基圆半径，p_b 基节，按齿距周期所以转角绕圈不出跳变），
  侧隙 b 内无力，之外 F = k·(|δ| − b/2) + c·δ̇，作用在节点、沿啮合线（两轮的力矩和轴承力都对）。中心距与 m(z1 + z2)/2 差超过 0.1% 报错。

支持的几何配对（其余配对报“暂不支持”，不静默跳过）：球–球、球–平面、球–圆柱、圆柱–平面、曲线–平面、曲线–球、曲线–圆柱（滚子，轴线垂直曲线平面）、
网格–平面、网格–球。曲线距离用密采样找初值再牛顿迭代到 1e-12 mm。

标准题（`tests/test_mbd_dae_d3.py`）：
- 落球无阻尼 Hertz 碰撞：最大压入 (5mv²/4k)^(2/5)、接触时间 2.9432·δmax/v、回弹速度 = 来时速度（Johnson《Contact Mechanics》第 11 章）；有阻尼时回弹变小、单调；
- 球在平地上带初速无转动滑出：先滑后纯滚，最终速度 5/7·v0（理论力学）；斜面纯滚 a = 5/7·g·sinθ；
- 偏心圆凸轮 + 平底从动件 + 拉簧：接触力 N = mg + F_mid + (k_s·e − m·e·ω²)·cos ωt，转速低于 ω_c = √((mg + F_mid + k_s·e)/(m·e)) 时从动件跟随 R + e·cos ωt，高于时在顶点脱离；

- 立方体网格静置平面：每角压入 (mg/4k)^(1/e)。

偏差（写回）：间隙副摩擦、内啮合 / 齿条、斜齿、网格–网格接触、凹网格不在 D3，放 D8 前按需求再开；接触几何不从 FreeCAD 实体自动取（D5 做）。

## 补充七：D4 线性化的做法与字段（2026-11-17）

字段：`analysis.type` 加 `linear`（在初始状态、含初速度处线性化）和 `static_then_linear`（先静平衡再线性化）；
`analysis.modes` 输出前几阶模态；`analysis.plant` 导出状态空间模型（inputs：作用在构件上的地面系方向力 / 力矩，u 单位 N 或 N·m；
outputs：measures 的 id）。

做法：在工作点按坐标分块取独立坐标 z（与动力学同一套 QR 选主元），状态 x = [z, ż]，
ẋ = f(x, u) 由精确的约束动力学（牛顿解非独立坐标到 1e-14、速度约束、加速度方程）给出，A = ∂f/∂x 用中心差分（步长 1e-6·max(1, |x|)），
B 由加速度方程对输入广义力的线性关系直接解出（精确），C 对测量量中心差分，D = 0。特征值 λ 给固有频率 |λ|/2π、阻尼比 −Re λ/|λ|；
振型从 z 映回全部坐标（dq = [I; −Φ_qD⁻¹Φ_qI]dz），按构件给出质心位移（mm）和转角（deg），最大分量归一为 1。
特征值与所选坐标无关，所以欧拉参数作独立坐标不影响频率。

标准题（`tests/test_mbd_dae_d4.py`）：有阻尼弹簧质量 λ = −ζωn ± iωn√(1−ζ²)；单摆 √(g/L)；双摆 ω² = (g/L)(2 ∓ √2)；
两自由度弹簧链 ω² = (3 ∓ √5)/2·k/m；悬臂梁端部质量 √(3EI/(mL³))；衬套支承自由体六阶 √(K/m)、√(Kr/I)；
状态空间直流增益 −CA⁻¹B = 1/k；先静平衡再线性化的偏置单摆。有摩擦、接触、间隙、齿轮侧隙的模型线性化时给出提示（非光滑力只在工作点附近成立）。

## 补充十三：D6 柔性体的做法（2026-11-17）

D6 分两段：**D6a**（本段）柔性构件的求解与梁柔性体；**D6b** 从 CalculiX 实体模型做 Craig-Bampton 缩减（`modal` 数据）和应力回放。

字段：`bodies[].flex`（`beam` 或 `modal`）；有 flex 时不写 mass_kg、cm_mm、inertia_kg_m2（由节点质量算）。运动副中心要与界面节点重合，程序自动对上。

做法（浮动参考系 + 模态坐标，ADAMS Flex 同类）：
- 坐标：刚体部分不变（每个构件 r、欧拉参数 p），所有柔性构件的模态坐标 η 依次接在后面（不改动现有下标）。
  构件参考系原点在未变形时的质心、t = 0 与地面同向。节点位置 r + A(p)(x₀ + Φ_t η)，节点小转角 Φ_r η。
- 质量阵、二次速度力、重力全由集中质量节点逐点累加（节点平动质量 + 对角转动惯量），对这套离散模型是精确的：
  速度 v = (ṙ, ω̄, η̇) 下 M_rr = mI、M_rω = −A·S̃(η)、M_rf = A·Σmᵢ Φᵢ、M_ωω = J(η)、M_ωf = Σ(mᵢ x̃ᵢ Φᵢ + Jᵢ Φ_rᵢ)、M_ff；
  二次速度项逐节点 A[ω×(ω×xᵢ) + 2ω×Φᵢη̇] 与 ω×Jᵢ(ω + Φ_rᵢ η̇)；再用 T = diag(I, 2G(p), I) 换到 (ṙ, ṗ, η̇)（Ġṗ = 0）。
  弹性力 −Kη、模态阻尼 −2ζω η̇。
- 模态：Craig-Bampton（界面节点 6 个约束模态 + 若干固定界面模态）→ 缩减阵上再做一次特征分解得到正交模态，**去掉 6 个刚体模态**
  （否则与参考系运动重复、质量阵奇异）；集中质量下剩下的模态与刚体运动质量正交，Σmᵢ Φᵢ = 0，耦合项小、条件好。
- 约束：界面节点上的点 s(η) = x₀ + Φ_t η、方向 a(η) = a₀ + (Φ_r η) × a₀；射流里 η 与 r、p 同样按 (值, 速度, 0) 展开，
  雅可比对 η 的列为 A·Φ_t、−A·ã₀·Φ_r。线性化（D4）的扰动坐标加上 δη。
- D6a 的限制：力元、接触、测量量不能挂在柔性构件上（报错，请挂在界面节点相连的刚体上）；结果输出参考系运动、各界面节点位置、模态坐标。

标准题（`tests/test_mbd_flex.py`）：自由–自由梁频率（βL = 4.730、7.853）、Σmᵢ Φᵢ = 0；铰支–自由梁经线性化的频率（βL = 3.927、7.069，含刚体转动的零频）；
重力下悬臂梁端部挠度 qL⁴/8EI、转角 qL³/6EI；无阻尼柔性摆大摆角能量守恒；很硬的柔性体退化成刚体；
柔性曲柄滑块（IFToMM 柔性曲柄滑块同类）与“很多刚体 + D2 梁元件”的链式模型对比连杆中点横向变形。

## 补充十七：D7 分两段；D7a 控制器的做法与字段（2026-11-17）

D7 分两段：**D7a** 执行器与控制器（本段）；**D7b** 参数扫描、试验设计、优化（新 schema `mbd-study/1`）与载荷谱给疲劳。

字段：力元 `actuator`（沿运动副轴的力 / 力矩，值由控制器给）；顶层 `controllers`：
- `pid`：e = 设定（时间表达式）− 测量量；u = kp·e + ki∫e + kd·de/dt；给了 `rate_sensor`（如 joint_speed）就用 kd·(设定变化率 − 它)，
  否则误差过一阶滤波再微分（`derivative_filter_s`，缺省 1 ms）；`output_min/max` 限幅，饱和且误差同向时停积分。
- `state_space`：ẋ = Ax + Bu、y = Cx + Du；u 来自测量量或时间表达式，y 送执行器。
- `fmu`：FMI 2.0 / 3.0 联合仿真（fmpy），按 `sample_time_s` 采样、零阶保持；可设结构参数和参数。
  本机实测参考 FMU（Modelica Reference-FMUs v0.0.38 的 FMI 3.0 StateSpace）可用；测试件随仓库放（BSD-2 许可一并放）。
- 单位：测量量是对外单位（deg、mm、deg/s…），增益按“输出单位 / 测量单位”给。

做法：连续控制器的状态（PID 的积分、滤波，状态空间的 x）接在积分器状态后面一起积分，误差控制同样管它们；
每次求右端先算测量量，再算各执行器的值，执行器的力在广义力里出现。FMU 不进积分器：积分分段停在采样时刻，
在采样时刻送入测量量、`doStep`、取输出并保持到下一拍。静平衡、运动学、线性化时控制器不参与（执行器为 0；
线性化导出的是被控对象，给控制设计用，闭环线性化放 D8）。

标准题（`tests/test_mbd_control.py`）：转台 PD 位置闭环阶跃响应与二阶系统解析解（ωn = √(kp/J)、ζ = kd/(2√(kp·J))）；
加恒定扰动力矩时 PID 稳态误差为 0、PD 稳态误差 = T/kp；同一 PD 用状态空间控制器写结果相同；
限幅时初始段角加速度 = u_max/J；FMU（参考 StateSpace，D = [kp, −kd]）采样 1 kHz 时与连续 PD 一致到采样误差量级。
