# ADR-0126：发格（Fagor）8060 / 8065 家族的基本写法

- 状态：已接受（2026-11-24，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”“我们是做工业级产品”）
- 日期：2026-11-24
- 补充：ADR-0124（写法差别）、ADR-0125（手册代码表）

## 背景

ADR-0124 把 `fagor` 家族留到“官方编程手册到了再做”。2026-11-24 用公司资料邮箱在发格官网资料门户（fagorautomation.com，需注册登录）下到
**《CNCelite 8058/8060/8065/8070 Programming manual》**（`man_elite_58_60_65_70_prg.pdf`，530 页，英文；下面的“§”指这本手册的章节）。
逐条核对后，发格和 FANUC 有几处**同一个代码、意思不同**，原样给发格会出事：

| FANUC 写法（问渠CAM 的基本写法） | 在发格上的意思（手册） | 后果 |
| --- | --- | --- |
| `G21`（公制） | 发格公制是 `G71`；`G70` 是英制（§1.5、§3.1） | — |
| `G71` / `G70`（车削复合循环） | 公制 / 英制（§3.1） | 循环当成单位切换 |
| `G50 S`（限速） | 发格限速是 `G192 S`（§7.2.1）；`G50` 是半圆角过渡（§11.1） | 不限速 |
| `G92`（坐标预置）、`G98` / `G99`（每分 / 每转进给，车） | `G92` 同为坐标预置；`G98` / `G99` 是铣床固定循环的退回平面（§1.5）；每分 / 每转进给是 `G94` / `G95`（§6.2） | 进给单位不对 |
| `M29 S`（刚性攻丝方式） | `M29` 是**子程序结束**（§1.6） | 程序跳走 |
| `G91 G28 Z0`（回参考点） | 发格没有 G28；回机床坐标用 `#MCS`（§5.1） | 报错 |
| `G43 Z H`（长度补偿） | 发格没有 G43；长度补偿随刀补号 `D` 生效，下一次纵向移动时补上（§13.2） | 报错 |
| `T0101`（车，刀号 + 刀补） | `T` 选刀，`D` 选这把刀的刀补（每把刀最多 8 组，§6.13、§6.15）；转塔换刀不写 M06（§6.13） | — |
| `G32 Z F`（车螺纹） | 发格车螺纹 `G33 Z K螺距`（§10.1） | — |
| `G84` 攻丝循环 | 发格铣床的 G84 参数另有一套（固定循环另一本手册）；刚性攻丝用 `G63`：`G63 Z终点 S转速` 攻进去，`G63 Z退回点 S-转速` 反转退出（§10.3） | — |
| `M08` / `M09` 冷却 | 手册 M 代码表（§1.6）里没有冷却，冷却的 M 代码由机床厂定 | 不能替机床厂写 |

## 决策

1. **`fagor` 家族可以用了**，基本写法按上面的手册逐条做。问渠CAM 先按 FANUC 写法写好（同一套刀路、同一套整机仿真），
   再按固定的对照表逐行换成发格写法；回读时按同一张表**换回** FANUC 写法，交给 `sim.parse` 与仿真逐点比，一致才出（ADR-0104 安全底线）。
   换不回来的行（表外的写法）一律报错不出。
2. 对照表（每条写手册章节，`analysis/cam/fagor.py`）：
   - 程序头：去掉 `%` 行；`O1001 (…)` → `%1001` 一行 + 原注释另起一行（§1.2.1：`%` 加程序名，最多 14 个字符）；注释用圆括号（§1.9）。
   - `G21` → `G71`；车床第一行加 `G151`（直径编程，§3.4）。
   - 车：`G99` → `G95`、`G98` → `G94`；`G50 S` → `G192 S`；`T0101` → `T1 D1`；`G32 … F` → `G33 … K`。
   - 铣：`T1 M06` → `T1 D1 M6`（§6.13 例）；`G43 Z… H01` → `Z…`（去掉 G43、H，长度补偿由 D1 生效）；`G49` 去掉；
     `G91 G28 Z0.0` → `#MCS Z0`（回机床 Z 零点，与西门子 `G0 SUPA Z0` 同一约定：机床 Z 零点在上方的参考点）。
   - 攻丝：`M29 S` / `G98 G84 X Y Z R F` / `G80` → `G00 X Y`、`G00 Z R`、`G63 Z终点 F进给 S转速`、`G63 Z R S-转速`、`G00 Z初始平面`、`S转速 M03`
     （M03 取消 G63、主轴回正转，§10.3）。刀路与 FANUC 的 G98 G84 相同（快移到孔上、快移到 R、攻进去、退到 R、快移回初始平面）。
3. **手册代码表**：发格程序里出现的每个 G、M 代码都要在手册 §1.5、§1.6 的表里、且是本表用到的（G00 G01 G02 G03 G17 G18 G33 G40 G54 G63 G71 G80 G90 G94 G95 G96 G97
   G151 G192；M00 M01 M02 M03 M04 M05 M06 M19 M30）；车床不收 G02 / G03（直径编程下圆心 I 按半径还是直径，这本手册没写明，不猜）；
   暂停 G04 的参数写法与 FANUC 不同（§12.1），不收；配置里换刀前后动作写的 M 代码（用户按机床说明书填）也认。表外的不出、点名。
4. **配置限制**（`postcfg.check`）：发格家族不收 `dialect`（写法已经按手册固定）；`cycles.turn`、`cycles.drill` 必须关（发格的 G70 / G71 是单位，
   钻孔、车削固定循环的参数另有一套）；`subprograms` 必须关（发格子程序是 `%L` / `#CALL`，§16，还没做）；`coolant` 只能 `off`
   （冷却 M 代码按机床说明书写进换刀后动作）。
5. 车铣（`#CAX` / `#FACE` / `#CYL`，§18.1）、双主轴、多通道（`#EXEC`，§17）、五轴倾斜面（`#CS`，§19）**这一步不做**：程序里出现 G12.1、G07.1、G68.2 等
   就按代码表拒出，写明“发格车铣还没做”。
6. 内置配置 `analysis/cam/posts/fagor-8065.json`：车、铣；`source` 写手册名和章节；`verified` false；核对级别 L1（自己回读）。
   发格官方的 8065 模拟软件（门户里有，Windows）是 L3，另做，装软件时另请同意。
7. 程序比对（`progdiff`）认发格：`#MCS`、`G151`、`G192`、`T数 D数 M6` 任一出现就是发格（`%` 开头不再一律当华中）。

## 理由

- 一张固定对照表 + 换回去再比，和 ADR-0124 的写法差别是同一个思路：写法差别全部可逆、回读一致才出。
- 冷却不替机床厂写：手册没有就不编（工业级标准、ADR-0040）。
- G28 → `#MCS Z0` 沿用西门子 `SUPA Z0` 已经用了的约定，不新造。

## 施工细则（2026-11-24）

1. 本 ADR（这一步，先写）。
2. `analysis/cam/fagor.py`：`CODES_G`、`CODES_M`（带章节）、`to_fagor(text, lathe, extra_m)`、`to_fanuc(text, lathe)`、`check_codes`；
   `FagorError`。回读时保留行尾的 `(#Ln)` 行号标记。
3. `postcfg`：`DEFAULTS["fagor"]`（同 FANUC，循环关、冷却关、不写 %）；`check()` 去掉 fagor 的拦截、加第 4 条的限制；大隈仍拦着。
4. `postproc.render`：发格按 FANUC 写好、`finish`（按 FANUC 家族加工）后 `fagor.to_fagor`，再查代码表；`to_fanuc`：发格先 `fagor.to_fanuc`。
5. `progdiff`：认发格。
6. 内置配置 `fagor-8065.json`；标准题 `tests/test_cam_post_fagor.py`：
   - 车（外圆、切槽、车螺纹）、铣（开槽、钻孔、攻丝）能出，程序里没有 G21 / G50 / G99 / M29 / G28 / G43 / M08，有 G71、G192、G95、`T1 D1`、`G33 … K`、`#MCS Z0`、`G63`；
   - 回读一致（对照表换回去，与仿真比）；车削程序时间与 FANUC 相同；
   - 往返：`to_fanuc(to_fagor(x)) == x`（FANUC 原文逐行一致）；
   - 车铣零件出不了、点名“发格车铣还没做”；表外代码（如配置里写 G28）不出、点名；
   - 配置限制（dialect、循环、子程序、冷却）各一条，写明原因。
   - 记录写进 `assist/cam_verification_cases.json`，目录 CAM-89 ~ CAM-91。
7. 帮助（中、英）加“发格 8060 / 8065”一节；状态页、ADR-0106 E3 记一笔。
8. 不做：车铣、双主轴、多通道、五轴、发格固定循环、子程序、L3 模拟软件核对（另起）。
