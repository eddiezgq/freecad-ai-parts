# ADR-0098：多体动力学隐式积分器（HHT-I3）

- 状态：已接受
- 日期：2026-11-17

## 背景

ADR-0097 的求解器（D1–D8）用坐标分块 + 显式积分（DOP853）。对“硬”的系统很慢：

- 梁元件链：50 mm 段的轴向频率约 10⁵ rad/s，显式积分步长被压到 1e-6 s 量级，0.1 s 仿真要十万次右端，几分钟。
- 柔性体高阶模态、硬接触、硬衬套也一样。
- 隐式积分（scipy 的 BDF、Radau）用数值雅可比，而且是在独立坐标上，每步要 2 × 自由度次右端，更慢。

ADAMS 的缺省积分器是 GSTIFF（BDF）；新版的主力是 HHT（Negrut 等 2007，“HHT method for index-3 DAEs of multibody
dynamics”，就是 MSC 给 ADAMS 做的）。这是 ADR-0097 收尾时写明的两个剩余差距之一（另一个是大变形，以后另立 ADR）。

## 决策

在 `analysis/mbd/dae/` 加 **HHT-I3 积分器**，与现有显式积分并列，按模型选：`analysis.integrator: "HHT"`（现有字段加一个取值；缺省仍是 DOP853）。

1. **方程**：直接在全部坐标上解指标 3 的 DAE，不分块：
   - 第 n+1 步未知量是加速度 q̈ 和乘子 λ。
   - 位置、速度按 Newmark 公式由 q̈ 给出：q = qₙ + h q̇ₙ + h²[(½ − β) q̈ₙ + β q̈]，q̇ = q̇ₙ + h[(1 − γ) q̈ₙ + γ q̈]。
   - 动力方程按 HHT 加权：M q̈ /(1+α) + (Φqᵀλ − Q) − α/(1+α)(Φqᵀλ − Q)ₙ = 0（补充一更正了符号）。
   - 约束在位置层满足：Φ(q)/(β h²) = 0。
   - 参数：α ∈ [−⅓, 0]，缺省 −0.1；γ = ½ − α，β = (1 − α)²/4。
   - α = 0 是梯形法，不耗散。α < 0 时高频（数值上的硬模态）被阻尼掉，低频几乎不受影响（二阶精度）。
   - 欧拉参数归一行、柔性模态坐标都照旧在坐标里，和显式积分用同一个 `System`。
2. **牛顿迭代矩阵**：

   ```
   [ M/(1+α) + β h² (Mq̈ + Φqᵀλ − Q)_q − γ h Q_q̇    Φqᵀ ]
   [ Φq                                              0   ]
   ```

   - Φq 用现有的解析雅可比。
   - Q_q、Q_q̇（力元刚度、阻尼）：E1 用差分；E2 按构件间的耦合关系分组差分。
   - 只在收敛变慢时重算、重分解（和 D8a 的简化牛顿同一个规则）。
   - 坐标多时用稀疏 LU。
3. **步长控制**：用局部截断误差估计（Zienkiewicz–Xie 估计 h²|β − ⅙| |q̈ − q̈ₙ|）对照 rtol/atol 调步长。
   遇到下面三种情况，这一步作废，步长减半重来：
   - 牛顿不收敛；
   - 误差超限；
   - 接触、齿轮的力出了 NaN。

   输出时刻一定落在步上，不插值。
4. **速度**：每步之后把 q̇ 投影到速度约束（Φq q̇ = ν），按质量阵度量取最小改变。指标 3 格式本身速度约束不精确，投影后核查照常。
5. **其他**：
   - 摩擦：反力用上一次牛顿迭代的 λ，迭代收敛时两者一致。
   - 控制器状态：每步用梯形法随步推进。
   - FMU：采样时刻落在步上。
   - 输出、核查（约束残差、能量漂移等）、`run.py` 的结果格式全部不变。

## 分步

| 步 | 内容 | 验收 |
| --- | --- | --- |
| E1 | HHT-I3 积分器：差分力雅可比、步长控制、速度投影；摩擦、控制器、FMU 接上 | 现有动力学样例用 HHT 算，与 DOP853 结果一致（位置差小于 1e-4 的相对量）；α = 0 时保守系统能量漂移 < 1e-4；单摆周期对椭圆积分解；硬梁链比 DOP853 快 10 倍以上 |
| E2 | 力雅可比提速：按耦合关系分组差分（列着色），弹簧、衬套、梁、柔性体的刚度、阻尼给解析式 | 解析与差分雅可比一致；ADR-0097 补充二十一放弃的“柔性曲柄滑块 vs 刚体段 + 梁元件链”对比做出来（两者曲柄力矩差 < 2%）；50 节梁链 0.1 s 在 30 s 内 |
| E3 | 收尾：FreeCAD 窗口里可选积分器、帮助、模型自动建议（有硬力元时提示用 HHT） | 窗口走一遍；帮助写清两种积分器怎么选 |

## 理由

- **为什么选 HHT-I3**：
  - 它就是 ADAMS 现在用的方法，有公开论文可以逐式对照。
  - 二阶精度，高频耗散可调。
  - 直接在指标 3 上解，不用坐标分块，换分块的麻烦（D1 起的“分块病态就换”）在这条路上没有。
- **没选的方案**：
  - GSTIFF（变阶 BDF）：工业里用得最久，但在指标 3 上要特殊处理速度和加速度误差（ADAMS 有 SI2 等变体）。
    实现量比 HHT 大，阻尼也不可调。
  - scipy 的 BDF、Radau 放在独立坐标上：已试过，见 ADR-0097 补充二十一，数值雅可比在独立坐标上太贵。
  - 广义 α 法（Chung–Hulbert）：和 HHT 同族，参数多一个，好处有限；以后需要时只改系数。

## 影响

- `schema/mbd-model.schema.json`：`analysis.integrator` 的取值加 `"HHT"`，`analysis` 加 `hht_alpha`（−⅓ ~ 0）。schema 改动单独成 PR（本 ADR 的 PR）。
- 显式积分保持缺省，已有模型、golden 结果不受影响。
- 大变形（几何非线性柔性体）是另一个差距，不在本 ADR，以后另立。

## 补充一：E1 完成（2026-11-17）

- 代码：
  - `analysis/mbd/dae/hht.py`：积分器本体。
  - `run.py`：`integrator: "HHT"` 时走它。缺省容差放宽到 rtol 1e-6、atol 1e-9（二阶格式），`hht_alpha` 缺省 −0.1。
  - 结果的 `solver` 里多记：步数、拒绝步数（分牛顿不收敛和误差超限）、雅可比次数、牛顿次数、最小和最大步长。
- 写回（施工中发现、改了做法）：
  1. **方程符号**：决策第 1 条 fₙ 项的符号原写成 +，应为 −（Negrut 2007 式），已更正。
  2. **容差的权**：欧拉参数量级是 1，权按 atol + rtol 算，不按 rtol·|q|。原做法下转角接近 0 时要求修正量到 1e-9 以下，牛顿永远收不住。
  3. **牛顿收敛判据**：第一次修正多在硬方向，第二次多在软方向，两者的比值不代表收敛速率。
     速率从第 3 次迭代起才算，并照 SUNDIALS 的做法：修正量 ≤ ⅓ 个容差单位就算收敛，修正量到舍入误差一级也算收敛。
     用了 4 次以上迭代，下一步就换新的雅可比。
  4. **约束残差**：收敛时要求 Φ ≤ min(1e-9, 0.01·atol)。
     残差留大了，下一步会被当成加速度修掉（a ≈ Φ/(βh²)），误差估计被带偏，步长越缩越小（落球、方块接触样例曾缩到 1e-12 s）。
  5. **不留碎步**：离输出点或采样点不到 1.25 步就一步走到；不到 2 步就两步平分。
     否则会出现 1e-8 s 的碎步，把后面的步长拖小（3000 个输出点的单摆曾因此慢了 7 倍）。
  6. **控制器状态**：原定随步显式推进，改成梯形法隐式推进，与力学牛顿交替求解。PID 的导数滤波（1 ms）是快状态，显式推不稳。
     执行器输出随 q 的变化也计入了差分雅可比。
- 验收（`tests/test_mbd_hht.py`，8 项全过）：

  | 项目 | 要求 | 结果 |
  | --- | --- | --- |
  | 大摆角单摆（缺省容差） | 与 DOP853 差 ≤ 2e-4 × 运动幅度 | 1.1e-4 |
  | 力元样例 | 与 DOP853 一致 | 一致 |
  | 接触样例（rtol 1e-8） | 差 ≤ 5e-4 × 运动幅度 | 2.3e-4 |
  | PID 转台（rtol 1e-8） | 差 ≤ 5e-4 × 转角 | 1.7e-4 |
  | 连续 PD | 对二阶系统解析解 | 差 < 1e-4 × 阶跃量 |
  | FMU | 采样时刻都落在步上 | 误差 < 1% |
  | α = 0 | 能量漂移 < 1e-4 | 通过 |
  | α = −0.1 | 低频耗散 < 2e-3 | 通过 |
  | 60° 物理摆周期 | 对椭圆积分解，相对差 1e-4 内 | 通过 |
  | 硬系统：柔性摆（D6 样例） | 比 DOP853 快 10 倍以上，差 ≤ 1e-4 | 41.6 s → 1.8 s（23 倍） |

  其他计时：接触样例 13.8 s → 2.9 s；5 段钢梁元件链摆 0.01 s 只要 0.3 s（2 次雅可比），DOP853 同一题 25 分钟没算完（超时停掉）。
- 偏差（写明）：
  - 原定“全部样例与 DOP853 差 < 1e-4”只在光滑系统、缺省容差下成立。
  - 带冲击接触、阶跃设定值、输出限幅的样例输入不光滑，二阶格式要把 rtol 收紧到 1e-8，才能到 2e-4 一级。
  - 帮助里写明：硬系统用 HHT；有冲击、限幅的，HHT 要收紧容差，或者仍用 DOP853。
- 下一步 E2：差分雅可比按耦合关系分组（现在每列一次，n 个坐标要 2n 次力计算），弹簧、衬套、梁、柔性体给解析刚度，
  然后做补充二十一（ADR-0097）放弃的“柔性曲柄滑块 vs 梁元件链”对比。

## 补充二：E2 完成（2026-11-18）

- **分组差分**（`hht.py`：`coupling`、`color_groups`、`grouped_fd`）：
  - 先由运动副行和力元列出谁的坐标会影响谁的力（含约束力 Φqᵀλ）。
  - 函数力用了测量量、执行器由控制器驱动时，与测量量涉及的构件全算耦合；不认识的力元退回逐列。
  - 构件按“闭邻域互不相交”着色（距离 2），同色构件一起扰动，每一行由唯一的构件认领。
  - 链只要 3 组：50 节链一次雅可比用 1 + 2 × 3 × 7 = 43 次力计算（逐列要 701 次）。
  - 全部样例上与逐列差分一致（1e-12）。
- **解析刚度没做**（写回决策第 2 条）：分组差分已经把 50 段梁链 0.1 s 压到 15 s（目标 30 s），解析式暂不需要。以后某类力元成瓶颈再补。
- **补充二十一（ADR-0097）放弃的对比做出来了**：
  - 题目：钢连杆 φ10 × 300 mm 的曲柄滑块，连杆用两种建模——柔性构件（梁有限元 20 单元，Craig-Bampton）和 20 段刚体 + 梁元件链。
    起动 0.02 s 内升到 2000 rpm。
  - 一阶弯曲频率 223.5 / 223.2 Hz。
  - 0.04–0.08 s 的曲柄力矩最大差 0.8%（要求 < 2%）。
  - 柔性与刚性连杆差 1.7%：这根杆一阶频率是转频的 6.7 倍，柔性影响本来就小。
- **施工中发现并处理**：
  1. **梁元件、衬套的阻尼力有错**（D2 起就有），已修正。
     - 变形速度原来用 Aᵢᵀ(Vⱼ − Vᵢ)，少了 −ωᵢ × (Pⱼ − Pᵢ)：两构件一起整体转动、没有变形，也会出阻尼力。i 是地面时不受影响，所以 D2 的样例没暴露出来。
     - 新增回归测试 `test_beam_and_bushing_no_force_under_rigid_rotation`。
  2. **梁元件 `damping_ratio` 的含义**：它是刚度比例阻尼系数（C = cr·K，单位 s，同 ADAMS BEAM 的 CRATIO），不是阻尼比。
     - 按阻尼比填 0.02，对轴向（10⁵ rad/s 级）是上千倍的过阻尼。
     - 帮助里写明换算：cr = 2ζ/ω。
  3. **刚度比例阻尼大的链对速度误差敏感**：rtol 1e-5 时力矩差 14%，1e-7 时 0.8%。帮助里写明：梁元件链用 HHT 时容差收紧到 1e-7。
  4. **细长杆受压失稳是真的**：第一次选的铝杆 φ6、3000 rpm，滑块惯性压力约 4900 N，是欧拉临界载荷（约 480 N）的 10 倍。
     梁元件链（几何非线性）真的屈曲、发散；柔性构件（线性小变形）算不出屈曲。验收题改用不失稳的杆。
     这是“柔性构件是线性小变形”的局限，帮助里已写，大变形另立 ADR。
- 验收：
  - `tests/test_mbd_hht_jac.py`：分组 = 逐列（7 个样例）、链 3 组、不认识的力元退回、柔性曲柄滑块对比、50 段梁链计时。
  - `test_mbd_dae_d2.py`：新回归测试。

## 补充三：E3 完成，ADR-0098 收尾（2026-11-18）

- `analysis/mbd/dae/advise.py`：按模型内容建议积分器和容差（纯规则），规则来自补充一、二的实测：
  - 没有柔性构件、梁元件：DOP853。
  - 有柔性构件：HHT，rtol 1e-6。
  - 有梁元件：HHT，rtol 1e-7。
  - HHT 加上接触或控制器限幅：rtol 1e-8。
  - 不是动力学分析，不给建议。
  - `apply` 只在模型没写积分器时填，用户写了就不动。
- FreeCAD 窗口加“积分器”下拉（自动 / DOP853 / HHT）：
  - 自动时，在柔性零件缩减之后再建议（缩减后才知道有柔性构件）。
  - 状态栏写明用了哪个积分器、理由。
- 帮助：`docs/mbd-help.md` 的“积分器怎么选”补上窗口操作和自动规则。
- 验收：
  - `tests/test_mbd_advise.py`：普通机构 → DOP853；柔性 → HHT 1e-6；梁 → HHT 1e-7；加接触 → 1e-8；运动学不建议；用户选了不覆盖。
  - `tests/test_fc_mbd_study.py`（xvfb）：窗口里自动建议写进状态栏；手选 HHT 时，设置里带上 `integrator`。

**ADR-0098 收尾**：
- E1–E3 完成。硬系统的速度差距补上了：
  - 柔性摆快 23 倍；
  - 5 段梁链从“25 分钟算不完”到 0.3 s；
  - 50 段梁链 0.1 s 只要 15 s。
- 与 ADAMS 剩下的主要差距是柔性体的大变形（几何非线性），E2 的屈曲例子就是证据。另立 ADR。
