# ADR-0098：多体动力学隐式积分器（HHT-I3）

- 状态：已接受
- 日期：2026-11-17

## 背景

ADR-0097 的求解器（D1–D8）用坐标分块 + 显式积分（DOP853）。对“硬”的系统很慢：

- 梁元件链：50 mm 段的轴向频率约 10⁵ rad/s，显式积分步长被压到 1e-6 s 量级，0.1 s 仿真要十万次右端，几分钟。
- 柔性体高阶模态、硬接触、硬衬套也一样。
- 隐式积分（scipy 的 BDF、Radau）用数值雅可比，而且是在独立坐标上，每步要 2 × 自由度次右端，更慢。

ADAMS 的缺省积分器是 GSTIFF（BDF）；新版的主力是 HHT（Negrut 等 2007，“HHT method for index-3 DAEs of multibody
dynamics”，就是 MSC 给 ADAMS 做的）。这是 ADR-0097 收尾时写明的两个剩余差距之一（另一个是大变形，以后另立 ADR）。

## 决策

在 `analysis/mbd/dae/` 加 **HHT-I3 积分器**，与现有显式积分并列，按模型选：`analysis.integrator: "HHT"`（现有字段加一个取值；缺省仍是 DOP853）。

1. **方程**：直接在全部坐标上解指标 3 的 DAE，不分块：
   - 第 n+1 步未知量是加速度 q̈ 和乘子 λ。
   - 位置、速度按 Newmark 公式由 q̈ 给出：q = qₙ + h q̇ₙ + h²[(½ − β) q̈ₙ + β q̈]，q̇ = q̇ₙ + h[(1 − γ) q̈ₙ + γ q̈]。
   - 动力方程按 HHT 加权：M q̈ /(1+α) + (Φqᵀλ − Q) + α/(1+α)(Φqᵀλ − Q)ₙ = 0。
   - 约束在位置层满足：Φ(q)/(β h²) = 0。
   - 参数：α ∈ [−⅓, 0]，缺省 −0.1；γ = ½ − α，β = (1 − α)²/4。
   - α = 0 是梯形法，不耗散。α < 0 时高频（数值上的硬模态）被阻尼掉，低频几乎不受影响（二阶精度）。
   - 欧拉参数归一行、柔性模态坐标都照旧在坐标里，和显式积分用同一个 `System`。
2. **牛顿迭代矩阵**：

   ```
   [ M/(1+α) + β h² (Mq̈ + Φqᵀλ − Q)_q − γ h Q_q̇    Φqᵀ ]
   [ Φq                                              0   ]
   ```

   - Φq 用现有的解析雅可比。
   - Q_q、Q_q̇（力元刚度、阻尼）：E1 用差分；E2 按构件间的耦合关系分组差分。
   - 只在收敛变慢时重算、重分解（和 D8a 的简化牛顿同一个规则）。
   - 坐标多时用稀疏 LU。
3. **步长控制**：用局部截断误差估计（Zienkiewicz–Xie 估计 h²|β − ⅙| |q̈ − q̈ₙ|）对照 rtol/atol 调步长。
   遇到下面三种情况，这一步作废，步长减半重来：
   - 牛顿不收敛；
   - 误差超限；
   - 接触、齿轮的力出了 NaN。

   输出时刻一定落在步上，不插值。
4. **速度**：每步之后把 q̇ 投影到速度约束（Φq q̇ = ν），按质量阵度量取最小改变。指标 3 格式本身速度约束不精确，投影后核查照常。
5. **其他**：
   - 摩擦：反力用上一次牛顿迭代的 λ，迭代收敛时两者一致。
   - 控制器状态：每步用梯形法随步推进。
   - FMU：采样时刻落在步上。
   - 输出、核查（约束残差、能量漂移等）、`run.py` 的结果格式全部不变。

## 分步

| 步 | 内容 | 验收 |
| --- | --- | --- |
| E1 | HHT-I3 积分器：差分力雅可比、步长控制、速度投影；摩擦、控制器、FMU 接上 | 现有动力学样例用 HHT 算，与 DOP853 结果一致（位置差小于 1e-4 的相对量）；α = 0 时保守系统能量漂移 < 1e-4；单摆周期对椭圆积分解；硬梁链比 DOP853 快 10 倍以上 |
| E2 | 力雅可比提速：按耦合关系分组差分（列着色），弹簧、衬套、梁、柔性体的刚度、阻尼给解析式 | 解析与差分雅可比一致；ADR-0097 补充二十一放弃的“柔性曲柄滑块 vs 刚体段 + 梁元件链”对比做出来（两者曲柄力矩差 < 2%）；50 节梁链 0.1 s 在 30 s 内 |
| E3 | 收尾：FreeCAD 窗口里可选积分器、帮助、模型自动建议（有硬力元时提示用 HHT） | 窗口走一遍；帮助写清两种积分器怎么选 |

## 理由

- **为什么选 HHT-I3**：
  - 它就是 ADAMS 现在用的方法，有公开论文可以逐式对照。
  - 二阶精度，高频耗散可调。
  - 直接在指标 3 上解，不用坐标分块，换分块的麻烦（D1 起的“分块病态就换”）在这条路上没有。
- **没选的方案**：
  - GSTIFF（变阶 BDF）：工业里用得最久，但在指标 3 上要特殊处理速度和加速度误差（ADAMS 有 SI2 等变体）。
    实现量比 HHT 大，阻尼也不可调。
  - scipy 的 BDF、Radau 放在独立坐标上：已试过，见 ADR-0097 补充二十一，数值雅可比在独立坐标上太贵。
  - 广义 α 法（Chung–Hulbert）：和 HHT 同族，参数多一个，好处有限；以后需要时只改系数。

## 影响

- `schema/mbd-model.schema.json`：`analysis.integrator` 的取值加 `"HHT"`，`analysis` 加 `hht_alpha`（−⅓ ~ 0）。schema 改动单独成 PR（本 ADR 的 PR）。
- 显式积分保持缺省，已有模型、golden 结果不受影响。
- 大变形（几何非线性柔性体）是另一个差距，不在本 ADR，以后另立。
