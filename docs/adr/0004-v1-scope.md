# ADR-0004：V1 只做 4 类核心链路，每类 30–50 个型号，只做静态匹配

- 状态：已接受
- 日期：2026-09-30

## 背景

领域先从机器人切入（航空只做标准件，汽车后置）。V1 需要一个能端到端演示的最小范围。

## 决策

- **品类**：伺服电机、减速器（谐波/行星）、驱动器、轴承
- **数量**：每类 30–50 个型号，覆盖 3–5 家厂商
- **编码器**：作为电机的一个端口处理，不单列品类
- **紧固件**：按 ISO/DIN 标准参数化生成，不计入厂商数据
- **校验深度**：只做静态匹配（接口尺寸、扭矩/转速链、电气与协议一致性）；schema 预留动态参数字段
- **不在 V1**：动态仿真、航空/汽车品类、多用户协作、ERP 对接

## 理由

V1 的成败取决于端口标注质量而不是数量；这个范围足够演示选型、校验和替代。动态仿真复杂度高一个数量级，放到 V1 之后。

## 影响

M1 的端口类型只需覆盖：轴、孔、法兰、安装面、电源、总线/编码器信号。
