# ADR-0007：减速器只收录整机型；新增 adapter 组件类型

- 状态：已接受
- 日期：2026-09-30

## 背景

谐波减速器既有带壳体和输出轴承的整机型（unit），也有需要用户自行设计壳体与轴承的零件型（component set）。不同品牌的电机与减速器之间常需要轴套或适配法兰转接。

## 决策

- V1 的减速器只收录整机型，不收录零件型
- 新增 `adapter` 组件品类（`sleeve` 轴套、`flange_plate` 适配法兰），用独立组件表达品牌之间的转接，不在端口定义里写条件分支

## 理由

- 零件型需要描述波发生器、柔轮、刚轮之间的装配关系，端口会复杂一个量级；整机型的输入孔、电机法兰、输出法兰和安装面足以覆盖 V1 演示
- 转接件作为组件，可以被检索、校验、计入 BOM，与真实采购一致

## 影响

- 品类从 4 类核心链路扩展为 4 类 + `adapter`；`adapter` 的收录数量与链路模板中的用法在 M1、M3 中细化
