# ADR-0129：发格车铣（#CAX、#FACE、#CYL）

- 状态：已接受（2026-11-25，属于 ADR-0106 E3；项目负责人 2026-11-24 定“适配所有主流数控系统”，2026-11-25 “继续”）
- 日期：2026-11-25
- 补充：ADR-0126（发格基本写法）、ADR-0110 / ADR-0106 C2b（车铣中间格式：FANUC G12.1 / G7.1）、ADR-0128（NUM 车铣，同一思路）

## 背景

ADR-0126 做了发格车、铣，车铣没做。《CNCelite 8058/8060/8065/8070 Programming manual》第 18.1 节写了车床 C 轴：

| FANUC 写法（问渠CAM 车铣的中间写法） | 发格写法（手册） | 说明 |
| --- | --- | --- |
| 切 C 轴（配置 `c_on`） | `#CAX`（§18.1.1，主轴当 C 轴；独占一段） | 用主轴做 C 轴必须先 `#CAX`（§18.1.3、§18.1.5）；`M3 / M4 / M5` 会撤掉 C 轴（§18.1.1） |
| `G12.1` … `G13.1`（极坐标插补；X 直径、C 虚拟轴 mm） | `#FACE [X,C,Q0]` … `#FACE OFF`（§18.1.3、§18.1.4） | C 按 mm 编，系统换算角度（§18.1.3 例：X–C 平面上的 R15 圆弧）；`Q0` 让 C 0° 作平面原点（不写 Q 时以当前位置为 C0） |
| `G07.1 C半径` … `G07.1 C0`（圆柱插补；X 直径、C 角度，F 在给定半径上） | `#CYL [Z,C,X半径,Q0]` … `#CYL OFF`（§18.1.5、§18.1.6） | “激活后系统切到半径编程和 G94”，C 按 mm（给定半径上的展开长度）编（§18.1.5）——F 也在给定半径上，与 FANUC 相同 |
| 直径编程 | `G151` 直径 / `G152` 半径（§3.4），程序可随时切换、独占一段 | #FACE 一节没写 X 是直径还是半径，所以程序里明写 `G152` |

## 决策

1. `G12.1` → 三段：`G152`、`#CAX`、`#FACE [X,C,Q0]`；块里每段 `X直径` → `X直径÷2`（半径），C（mm）、Z、F、G00 / G01 照写；`G13.1` → `#FACE OFF`、`#CAX OFF`、`G151`。
2. `G07.1 C半径` → 三段：`G152`、`#CAX`、`#CYL [Z,C,X半径,Q0]`；块里 `X直径` → `X直径÷2`，`C角度` → `C = 角度 × π ÷ 180 × 半径`（mm），Z、F 照写（F 本来就在给定半径上）；
   `G07.1 C0` → `#CYL OFF`、`#CAX OFF`、`G151`。G152 在 #CYL 下与手册“自动切半径”一致，写出来是为了读程序的人一眼看懂。
3. 坐标位数按手册 §1.3.1（毫米 ±5.4：5 位整数、4 位小数）：换算出的值取 4 位小数；发格程序里坐标超过 4 位小数的不出。
4. 配置：发格家族收 `millturn`（`live_on`、`live_off`、`c_on`、`c_off`，按机床说明书填，例如夹紧 C 轴的 M 代码；`#CAX` 由后处理写，不用填）；
   `b_tool_comp`、`twin`、`channels` 仍不收。这些行里的 M 代码算配置认的。
5. 代码表加 `G152`（§3.4）；`#CAX`、`#CAX OFF`、`#FACE`、`#FACE OFF`、`#CYL`、`#CYL OFF` 只认上面这几种写法。`G19`（C 分度 + Y 轴铣）仍不收，点名“还没做”。
6. 回读：上面几组换回 FANUC 写法；圆柱块 C（mm）÷ 半径换回角度（4 位小数取整引起的误差 < 0.0001 mm），按刀路比对。

## 理由

- 手册写清了 #CAX、#FACE、#CYL 的用法；唯一没写的是 #FACE 下 X 的单位，用 G152 明写半径把歧义去掉，比猜强。
- 发格 #CYL 带半径参数、F 按该半径，与 FANUC G7.1 意思相同，不用像 NUM 那样换进给。
- `Q0` 固定平面原点，与 FANUC 按 C 轴零点算一致；不写 Q 会随 C 的当前位置漂。

## 施工细则（2026-11-25）

1. 本 ADR（不改 schema）。
2. `analysis/cam/fagor.py`：`to_fagor` / `to_fanuc` 加车铣状态；`CODES_G` 加 152；`check_codes` 查 4 位小数、G19 点名、`#` 指令只认上面几种。
3. `postcfg.check`：发格收 `millturn`（不收 `b_tool_comp`）；`postproc.render`：`millturn` 各行的 M 代码算配置认的。
4. 标准题 `tests/test_cam_post_fagor.py`：
   - 车铣程序（外圆 + 端面槽 + 圆柱面槽）能出：有 `G152`、`#CAX`、`#FACE [X,C,Q0]`、`#FACE OFF`、`#CYL [Z,C,X25.0,Q0]`、`#CYL OFF`、`#CAX OFF`、`G151`；
     没有 G12.1 / G13.1 / G07.1；端面块 X 是半径、C 原值；圆柱块 C = 角度 × π ÷ 180 × 25（手算一题）；回读与仿真刀路一致。
   - 不出：C 分度 + Y 轴铣（G19）；配置带 `b_tool_comp`；内置配置没写车铣行（同 FANUC：带铣削段的车铣程序不出）；坐标 5 位小数。
   - 记录写进 `assist/cam_verification_cases.json`（接着现有编号）。
5. 帮助（中、英）发格一节加车铣；ADR-0126 “不做”里的车铣指向本 ADR；STATUS、ADR-0106 E3 记一笔。
6. 不做：C 分度 + Y 轴铣、B 轴车铣、双主轴、多通道、车铣块里的圆弧。
