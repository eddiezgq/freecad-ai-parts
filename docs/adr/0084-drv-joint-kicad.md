# ADR-0084：关节驱动板 DRV-JOINT 的 KiCad 设计、可制造性检查与功能测试台（电子 E4）

- 状态：已接受（2026-11-05 项目负责人确认问渠第 88 轮细则 Q1–Q5）
- 日期：2026-11-05
- 补充：ADR-0068（共用一份代码）、ADR-0081～0083（电子 E1～E3）

## 决策

1. `factory/designs/`：驱动板 DRV-JOINT 的设计描述（器件、数值、引脚网络、摆放、功率铺铜）由脚本生成 KiCad 7 原理图与 PCB，开源 Freerouting 自动布线，
   KiCad 设计规则检查与导出（Gerber、钻孔、BOM、贴片坐标、STEP、GLB、各层 SVG）。**示例设计，未经硬件验证，不能直接投产。**
2. 要确切引脚的芯片用 KiCad 官方符号库里有的器件做“示例选型”（引脚取自官方库，不编参数）；电阻电容数值由电路公式算，与电路分析例题同一组数。
3. 可制造性检查按一份示例板厂工艺能力：线宽线距、孔与孔环、阻焊桥、元件到板边、元件间距、极性元件方向、ICT 测试点覆盖率、大电流功率路径（IPC-2221）。
4. 驱动板器件外形取自 KiCad 官方三维模型库 7.0.11 的 19 个 STEP（CC-BY-SA 4.0 附例外，`factory/designs/3dmodels/LICENSE.md`）；
   来源在 `data/sources.yaml` 登记（kicad-libraries，条款已核实）。
5. 电路板厂清单的驱动板物料清单按设计的数量写；新增“功能测试台”（复现每块板的测试画面、学生复测，复测记录单独存表，不改原始测量值）。
6. 工具链（KiCad、Freerouting）只作工具用，不改代码、不随产品分发；不改 `schema/`、`engine/`，不碰 `tests/golden/`。
