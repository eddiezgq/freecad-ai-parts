# ADR-0121：机床文件加副主轴、后处理配置加双主轴交接的程序行

- 状态：已接受（2026-11-24，属于 ADR-0106 C4b）
- 日期：2026-11-24
- 补充：ADR-0109（可配置后处理）、ADR-0110（车铣动力刀）、ADR-0120

## 背景

ADR-0106 C4b 做双主轴车铣中心：副主轴夹住主主轴上车好的一端，切断后带着工件车另一端，一个程序做完，不用人工调头。
机床文件现在只有一个主轴（`spindle`），写不下副主轴的位置、移动的轴和夹持长度；后处理配置写不下主副主轴同步、副主轴卡盘夹紧松开、
切换编程主轴这些动作——各家写法不同（FANUC 多是 M 代码，西门子 SETMS(2) 等），问渠不猜。

## 决策

1. `cam-machine/1` 加可选的 `sub_spindle`：`max_rpm`（必填）、`power_kw`、`efficiency`、`torque_n_m`（与 `spindle` 同）；
   `axis`（必填，副主轴沿 Z 移动的直线轴 id，须在 `axes` 里）；`c_axis`（副主轴的 C 轴 id，可不写）；
   `face_z_mm`（必填，`axis` 在零位时副主轴卡爪端面的机床 Z）；`grip_mm`（必填，[最短, 最长] 夹持长度，mm）。
   `axis`、`c_axis` 只带副主轴一侧的部件，主主轴上的工件不跟着动。
2. `cam-post/1` 加可选的 `twin`：`sync_on`、`sync_off`、`sub_clamp`、`sub_unclamp`、`sub_select`、`main_select`、`sub_offset`，
   都是程序行数组（写法同 `millturn`）。缺一项双主轴程序不出，写明缺哪项。示例配置不填。

## 理由

副主轴的几何（夹爪端面、行程、夹持长度）是算夹持位置、查行程和碰撞必需的，属于机床；交接动作的写法属于数控系统，放后处理配置，
与 ADR-0110 的动力刀 M 代码同一个做法。考虑过把副主轴写成 `spindles` 列表，但现有机床文件、代码都按单个 `spindle` 读，
加一个可选的 `sub_spindle` 不影响已有文件。

## 影响

- 已有机床文件、后处理配置不用改；没有 `sub_spindle` 的机床结果不变。
- 实现见 ADR-0106 C4b（两个 PR）。
