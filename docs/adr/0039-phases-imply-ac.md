# ADR-0039：需求解析中单相、三相供电推出交流

- 状态：已接受（2026-10-01，项目负责人授权先按最优方案决定，可推翻）
- 日期：2026-10-01
- 补充：ADR-0037

## 背景

示例需求“220 V 单相供电”第一次真实解析（claude-sonnet-5-5）时：

- LLM 报了电压与相数，没有报供电类型，并在 `unclear` 中说明“原话未明确说明交流 / 直流，未报告”。这符合提示词“只报告原话明确说出的指标”
- 需求 schema 要求供电的类型、电压、相数三项齐全，于是核对代码按“供电信息不全”整体不采用，并追问用户
- 结果是一句话里已经写清的供电条件被丢掉了，C9 无法校验

## 决策

- 相数为 1 或 3、原话没有说供电类型时，供电类型记为交流
- 在 `defaults` 中注明“单相 / 三相供电，按定义为交流”；依据沿用相数的原文引用
- 原话明说直流、又说单相或三相时，属于矛盾，仍不采用并追问（已有规则）
- 与已有的“直流 → 相数记 0”是同一类定义性推导；其他字段仍然“没说就不写”

## 理由

- 单相、三相是交流供电的概念，直流没有相数，这是定义而不是猜测
- 不应当要求 LLM 报原话中没写的词。推导放在确定性代码里，并在结果中写明，可追溯
- 追问用户“交流还是直流”对说了“单相”的用户是多余的

## 影响

- `engine/requirement_parse.py` 增加这条推导和单测
- 示例句子的真实录制回放后，结果与 `examples/joint2-requirement.json` 一致
