# ADR-0110：车铣复合的动力刀——机床文件的动力刀方向、后处理配置的动力刀与 C 轴 M 代码

- 状态：已接受（2026-11-20，属于 ADR-0106 C2b 第 4 步）
- 日期：2026-11-20
- 补充：ADR-0105（机床格式 cam-machine/1）、ADR-0109（后处理配置 cam-post/1）、ADR-0106（C2b 施工细则）

## 背景

车铣中心（示例 EX-MT-CY）上，车刀与动力刀装在同一个刀塔上，动力刀有两种朝向：**轴向**（刀轴沿 Z，铣端面、端面钻孔，配极坐标插补 G12.1）
和**径向**（刀轴沿 X，铣圆柱面、径向钻孔，配圆柱插补 G7.1）。cam-machine/1 的 `tool` 只有一个方向（铣床主轴），整机仿真按这一个方向逆解，
算不了轴向动力刀；后处理也不知道各家车铣中心开动力刀、切 C 轴的 M 代码（FANUC 只规定 G12.1、G7.1，动力刀与 C 轴的 M 代码由机床厂定）。

## 决策

1. **cam-machine/1 加可选 `live_tools`**：`{"axial": {direction, gauge_point_mm}, "radial": {direction, gauge_point_mm}}`，意义与 `tool` 相同
   （零位时从刀尖指向刀座的单位向量、刀长基准点的机床坐标）。车铣中心的整机仿真按工序用的动力刀朝向逆解；没写的朝向，那种铣削段整机仿真报“未知”。
2. **cam-post/1 加可选 `millturn`**：`{"live_on": [...], "live_off": [...], "c_on": [...], "c_off": [...]}`，每项是程序行（写法规则同 `tool_change`：
   只能大写字母、数字、空格和 `. = + -`）。动力刀转速由后处理写在 `live_on` 之后（`S` 字）。
   配置里没写 `millturn` 时，带铣削段的车铣程序**不出正式程序**，写明“后处理配置没写动力刀、C 轴的 M 代码（按机床说明书填）”——不猜 M 代码。
3. 内置配置不写 `millturn`（各厂不同）；示例机床 EX-MT-CY 加 `live_tools`（虚构，标示例）。

## 影响

- schema 改动单独成 PR（本 ADR）；实现走 ADR-0106 C2b 第 4 步。
- 测试夹具：cam-machine 加一个带 `live_tools` 的有效例子、一个方向缺一维的无效例子；cam-post 加一个带 `millturn` 的有效例子、一个动作带小写的无效例子。
