# ADR-0069：工厂清单第 2 版（产品、物料清单、库存、测量特性）与机器人厂

- 状态：已接受（2026-10-24 项目负责人确认问渠仓库第 45 轮细则 Q1–Q4、2026-10-26 确认第 47 轮 Q1–Q4）
- 日期：2026-10-27
- 补充：ADR-0064（工厂清单）、ADR-0068（数字工厂与问渠仓库共用一份代码）

## 背景

ADR-0064 的工厂清单只描述车间（公司、工作站、设备、工序、平面、班次、指标、客户、供应商）。按清单起的厂没有产品：
示例缝纫机厂起得来却接不了单，产品只能从设计经“转为生产物料”进来。问渠仓库第 45 轮要按一份清单建数字工业园的第二座厂——
机器人厂（六轴协作机器人、搬运 AGV、三种关节模组；AGV 的驱动单元用减速器厂的 WQR-105），第 47 轮在它上面做了实验 24、25。
这些都改了两边共有的代码（ADR-0068），本仓库要同步过来。

## 决策

1. **清单第 2 版**：可选的产品六节——物料（`items`，类别 原材料 / 外购件 / 自制件 / 部件 / 成品）、工艺路线（`routings`）、
   多层物料清单（`boms`）、可接单的成品与售价（`products`）、期初与安全库存（`stock`）、测量特性（`measurements`：在哪个物料、
   哪道工序测，名义、上下限、过程散布 σ）、首页关键物料（`key_materials`）。第 1 版清单照读；Excel 模板加六张表。
   没写产品的企业厂行为不变，产品仍从设计经“转为生产物料”进来。
2. **写了产品的厂**：导入脚本建物料、工艺路线、BOM、期初库存（按类别进库）；算料按多层 BOM 展开并给出领料仓库
   （自制件 / 部件从半成品库、外购件从外购件库、原材料从原材料库）；测量特性在那道工序合成测量值（名义 + 慢漂移 + 正态散布），
   桥接在那道工序的作业卡上建质量检验单，质检门只设在写了测量特性的工序；清单里的成品不设序列号（序列号追溯是演示厂的）；
   教学模式订单做完自动开销售发票。
3. **机器人厂**是一份清单 `factory/plants/wenquest-robot.yaml`：外购件型号只取零件库里有的（谐波减速器 CSF-32/25/17、
   轴承、激光雷达 TiM781、减速器 WQR-105），没有的标“型号待确认”、不写参数；售价、工时、公差、散布都标“示例”。
   它的实验 24、25（订单到交付、关节背隙异常的分层追因与 8D）只在这座厂显示；三种隐藏问题与措施只在这座厂的 8D 清单里。
4. **共有代码的其他改动**：按清单起的厂，同一道工序有几台设备时轮流派工（演示厂不变）；多层标准成本 `mrp.std_rollup`；
   质量页按装配工位、批次分层；帮助加“机器人厂”一册（只在机器人厂显示）。
5. 这些都在共有路径里，按 ADR-0068 逐字同步；本仓库独有的企业模块不用改。

## 理由

- 新厂只交一份清单、不改代码，是 ADR-0064 的初衷；第 1 版缺产品，工厂接不了单，第 2 版补齐。
- 产品数据写进清单而不是代码，企业厂可以先在清单里写几种现有产品试运行，再从设计接入新产品。
- 不编参数：库里没有的外购件不写型号参数；工厂行为数字（价格、工时、散布）标“示例”，与本仓库“不编造参数”的规矩一致。

## 影响

- 共有代码约 50 个文件随问渠第 45、47 轮更新（`factory/factory/plant.py`、`data.py`、`seed.py`、`hub/mrp.py`、`sim/engine.py`、
  `sim/errors.py`、桥接、质量页、帮助等），新加机器人厂清单、实验 24/25 与测试。
- 企业厂（没写产品的清单）行为不变：本仓库现有测试不改断言通过。
- 本仓库的 `factory/deploy` 是各自实现的，问渠那边的班级工厂“清单”字段不随同步过来。
