# ADR-0020：缺少连接、包络尺寸、轴承转速三条校验规则

- 状态：已接受（2026-10-01，项目负责人授权按最优方案决定）
- 日期：2026-10-01

## 背景

编写 golden 用例时留下三条须在 M3 前明确的规则（`tests/golden/README.md`）。M3 实现校验时需要确定的口径。

## 决策

1. **缺少应有的连接判为 `fail`，不判 `unknown`**
   - `unknown` 只表示“数据缺失”；缺少连接是方案本身不完整，属于设计错误
   - 系统中同时有驱动器和电机时，必须有动力连接（C9）和编码器连接（C10）；同时有电机和减速器时，必须有轴—孔连接（C2）和法兰连接（C3），中间可经转接件
   - 某类组件不在系统中时，相关校验为 `not_applicable`（ADR-0016）；方案应包含哪些组件，由链路模板（`compose_chain`）负责，不在单项校验中判断
2. **系统包络外径按外接圆计算**
   - 圆柱段取直径，长方体段取截面对角线 √(宽² + 高²)；系统外径取所有组件各段中的最大值
   - 理由：关节外壳通常为圆形，方形截面须按对角线才能装进圆形外壳，按边长计会漏判
   - **包络长度**依赖组件沿轴向的实际布置，M3 无法可靠计算；需求给出长度上限时，C11 长度部分为 `not_applicable`，原因写明“须 FreeCAD 布局后计算”，在 M4b 布局完成后再判定
3. **V1 中轴承的转速取关节输出转速**
   - V1 没有连杆、壳体品类，系统中的轴承视为支撑关节输出侧，转速等于需求的输出转速；C11 轴承部分在系统含轴承时适用：输出转速 ≤ 轴承极限转速
   - 轴承端口有连接时，C2 照常按轴承配合推荐表判定（ADR-0017）；无连接时 C2 对该轴承为 `not_applicable`

## 理由

三条都选择“宁可多报、不可漏判”的口径，并把无法可靠计算的部分明确标为不适用、写明原因，而不是给出看似确定的结果。

## 影响

- golden 用例 `invalid/c1-swapped-wiring` 中 C9、C10 目前为 `any`；按本决定应为 `fail`。golden 用例只能由人修改，是否更新由项目负责人决定
- 实施细则第七节 C9、C10、C11 的判定条件已同步
