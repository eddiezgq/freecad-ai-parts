# 多体动力学使用说明

本仓库自带的多体动力学求解器（ADR-0097），能力对标 ADAMS 的常用部分：刚体与柔性体、运动副与驱动、力元与接触、
摩擦与间隙、控制器与 FMU 联合仿真、线性化与模态、参数研究与优化，以及在 FreeCAD 里看动画、变形和应力云图、出计算报告。

## 问渠多体动力学安装包：免费版与专业版

单独安装的“问渠多体动力学”（Windows 安装包 `WenQuest-MBD-Setup-<版本>.exe`，ADR-0102）自带 FreeCAD、CalculiX 和 Gmsh，
装好后打开 FreeCAD，在工作台列表里选“问渠多体动力学”（第一次启动会自动选好）。菜单“问渠多体动力学”里有：
装配体多体动力学（窗口，见下）、授权…、设置 AI 密钥…、关于。零件库工作台全功能版不分档，下面的限制只对问渠多体动力学版。

| 免费版 | 专业版（授权文件里有 `mbd_pro`） |
| --- | --- |
| 最多 15 个刚性构件 | 构件数不限 |
| 六种运动副、驱动；程序按几何起草运动副 | AI 帮着挑运动副（导入 STEP 时勾“用 AI 起草”） |
| 弹簧阻尼、扭簧、衬套、恒力、函数力 | 柔性体（模态梁、实体模态与应力云图、大变形梁）；梁元件、齿轮啮合、执行器 |
| 运动学、静平衡、动力学（DOP853 等） | 接触、摩擦、间隙；控制器（PID、状态空间、FMU） |
| 曲线、动画、核查结论 | HHT 隐式积分；线性化与模态 |
| | 正式报告（Word / PDF，AI 解释） |

- 免费版用到专业版功能时，窗口状态栏写明是哪一项、怎么开放，不改任何计算结果和核查结论。
- 参数研究、优化、疲劳交接目前只能写模型文件用 Python 调用（见下文），窗口里还没有入口；以后加进窗口时算专业版功能。
- 买专业版：菜单“授权…”里复制本机激活码发给我们，收到授权文件后点“导入授权文件…”。一个授权文件可以同时开问渠有限元（`fea_pro`）
  和问渠多体动力学（`mbd_pro`）。
- AI 密钥：“设置 AI 密钥…”。中国用 DeepSeek，其他地方用 Claude；密钥只存在本机。调用 AI 时只发零件名称、体积、候选运动副清单，
  或计算结果的摘要，不发模型文件。

## 两种用法

| 用法 | 适合 | 入口 |
| --- | --- | --- |
| FreeCAD 窗口 | 有装配体（或 STEP），想点几下就看到结果 | FreeCAD 里 AI Parts 工作台，菜单 AI Parts →“装配体多体动力学” |
| 模型文件 | 要精确控制、批量计算、参数研究、接到别的程序 | 写 `mbd-model/1` 的 JSON（`schema/mbd-model.schema.json`），`analysis.mbd.dae.run.run_model` |

## FreeCAD 窗口：一步一步

1. **装配体**：点“用当前文档的装配体”，或“导入 STEP 并起草运动副…”。导入 STEP 时程序从几何里找候选运动副（同轴孔、
   贴合平面等），列在表里，“几何证据”一栏写着凭什么；勾掉不对的，选机架，点“确认，建成装配体”。勾“用 AI 起草”时 AI
   只在候选里挑，不会自己编运动副。
2. **材料**：每个零件要有材料（FreeCAD 零件属性 ShapeMaterial），没有就算不了——窗口会逐条列出缺什么，程序不估密度。
3. **驱动与分析**：给要驱动的运动副选“匀速”（rpm 或 mm/s）或“位移函数”（time 为时间，单位 s）；选分析类型、时长、输出点数。
4. **柔性零件**（可选）：在“按柔性体算”一栏给零件选材料（材料库里有弹性模量、泊松比、密度的才列出来）。程序把零件导出 STEP，
   在挂在它上面的运动副处放界面（孔：取整圈孔壁；面上的点：取周围一小片），用 gmsh 划网格、CalculiX 缩减成模态柔性体，
   带应力振型。要几十秒到几分钟。“变形放大倍数”只放大显示，应力不放大。
   细长的等截面直杆（连杆、轴、弹簧片）可以在下拉框里选“大变形梁：材料”。程序会自动量出梁轴、长度、截面积、两个惯性矩和截面外缘距离，
   运动副所在的点自动设成节点。量的时候在杆长四分之一、中间、四分之三三处各切一刀，截面积相差超过 2% 就报“不是等截面直杆”；
   长度与 √截面积 之比小于 8，就报“不够细长”。扭转常数按圣维南近似 J ≈ A⁴/(4π²Iₚ) 算（圆截面精确，方截面偏大约 8%）。
   梁的质量按“截面积 × 长度”算，不计孔和倒角，状态栏会同时列出实体零件的质量供对比。动画里这根杆画成节点连成的折线，颜色随最大应力变。
5. **计算**：点“计算”，在后台算，不卡界面。
6. **结果**：看核查结论（约束残差、能量守恒等，每条写通过 / 不通过 / 不判）、选曲线、模态表；拖滑块或点“播放”看动画。
   柔性零件在动画里画成网格，颜色是 von Mises 应力（蓝低红高，色标上限是整段时间的最大值，写在网格对象的 StressMaxMPa 属性里）。
   点“复位”零件回原位、云图网格删掉。
7. **报告**：点“写计算报告…”，选文件夹。得到正式报告 `report.docx`（装了 LibreOffice 时另有 `report.pdf`），还有 `model.json`、`result.json`、
   `report.ledger.json`（出处账）和 `report.record.json`（改版记录）。报告共八节：结论摘要、模型（构件、运动副）、可信度核查、
   结果（曲线、固有频率）、AI 解释、局限、审核清单、可追溯信息（模型指纹、结果指纹、代码版本、改版记录）。
   编制、审核、批准三栏留给人签字。
   报告语言同界面语言（FreeCAD 设成英文就出英文报告，数字与中文版完全相同）；环境变量 `FAP_LANG=zh` 或 `en` 可另指定。
   勾了“用 AI 起草”时 AI 写解释段落，但数字一律由程序填：AI 段落里自己写了数字、写“合格 / 安全”之类判断，或引用不存在的量，
   那一段就退回不用（窗口状态栏会说退回了几段）。报告页眉写着“草稿，须工程师审核”，合格与否由工程师对照要求判。

## 模型文件里能写什么（摘要）

| 内容 | 字段 | 说明 |
| --- | --- | --- |
| 构件 | `bodies` | 刚体给质量、质心、惯量；柔性体给 `flex`（`beam` 梁或 `modal` 实体，实体由 `analysis/mbd/flexsolid.reduce_step` 生成） |
| 运动副 | `joints` | 固定、转动、移动、圆柱、球、万向；可加摩擦，转动副可加间隙 |
| 驱动 | `motions` | 匀速或位移函数 |
| 力元 | `forces` | 力与力矩（恒定或函数，函数里可用 IMPACT、SPLINE）、弹簧阻尼、扭簧、衬套、梁、齿轮啮合 `gear_mesh`、执行器 `actuator` |
| 接触 | `geometries`、`contacts` | 球、平面、圆柱、曲线、网格；IMPACT 型法向力 + 光滑摩擦 |
| 控制 | `controllers` | PID、状态空间、FMU（FMI 2.0 / 3.0 Co-Simulation） |
| 测量与输出 | `measures`、`requests` | 测量量供控制器和研究用；输出点给位置速度 |
| 分析 | `analysis` | 运动学、动力学、静平衡、先静后动、线性化、先静平衡再线性化；动力学可选积分器（见下） |

参数研究另写 `mbd-study/1`（`schema/mbd-study.schema.json`）：变量（模型里的 JSON 指针）、方法（网格、拉丁超立方、优化）、
指标（最大、最小、均方根、积分平方误差、固有频率等）、目标与约束。疲劳：`analysis/mbd/loads.fatigue` 把结果里的一条载荷
时间序列接到疲劳计算。

## 大变形梁（细长件）

柔性构件 `flex` 有三种：

| 种类 | 适合 | 局限 |
| --- | --- | --- |
| `beam`（模态梁） | 小变形、看振动 | 线性：不会屈曲，没有离心刚化 |
| `modal`（实体模态，由 STEP 缩减） | 实体零件的小变形、应力云图 | 线性 |
| `nonlinear_beam`（大变形梁，ADR-0101） | 细长件大挠度、卷曲、受压屈曲、旋转刚化 | 只能是直梁，截面不变 |

大变形梁写法：给起点、终点、截面 y 轴、材料（E、G、密度）、截面（面积、两个惯性矩、扭转常数）、单元数（缺省 20）。
程序会把它拆成 单元数 + 1 个节点（id 为 `梁id__n0`、`梁id__n1`……）。运动副、力写 `"body": 梁id`，加上作用点，
就挂到最近的节点上；点离节点太远会报错，并告诉你节点间距。纯力矩（`torque` 没有作用点）直接写节点 id，例如 `"body": "rod__n20"`。

结果在 `flex[梁id]` 里：每帧、每个单元的轴力、剪力、扭矩、弯矩，节点位置；给了截面外缘距离 `fiber_y_mm`、`fiber_z_mm` 时，还有最大正应力。

大变形的静力题（卷曲、弹性线）一步解不出来，在 `analysis` 里写 `load_steps`（比如 5～10），力分几步加。
阻尼用 `stiffness_damping_s`（刚度比例阻尼系数，单位 s，换算同梁元件：2ζ/ω）。动力学会自动建议用 HHT。

什么时候必须用大变形梁、不能用模态柔性体：
- **轴力影响刚度**：受压会让弯曲频率下降，到临界载荷就屈曲；受拉会让频率上升。模态柔性体的频率不随轴力变，算不出这些。
- **离心刚化**：高速旋转的细长件。
- **大挠度、卷曲**。

想求屈曲载荷：做几次“先静平衡再线性化”，每次轴力不同，把一阶频率的平方对轴力连成直线，直线与零频率的交点就是临界载荷。

## 积分器怎么选

动力学分析的 `analysis.integrator`：

| 积分器 | 适合 | 说明 |
| --- | --- | --- |
| `DOP853`（缺省） | 一般机构、有冲击接触、阶跃输入、输出限幅 | 显式高阶，精度高；遇到硬的东西步长会被压得很小 |
| `HHT` | 硬系统：梁元件链、柔性体高阶模态、硬衬套、硬接触 | 隐式（ADAMS 现用的方法，ADR-0098），步长不受硬模态限制，柔性摆快 20 倍以上；`hht_alpha`（−⅓ ~ 0，缺省 −0.1）越负，高频数值耗散越大，0 不耗散 |
| `Radau`、`BDF` | 很少用 | scipy 的隐式积分，在独立坐标上用数值雅可比，一般比 HHT 慢 |

FreeCAD 窗口里“积分器”缺省是**自动**：
- 没有柔性零件、梁元件，用 DOP853。
- 有柔性零件，用 HHT，rtol 1e-6。
- 有梁元件，用 HHT，rtol 1e-7。
- 用 HHT 时如果还有接触或控制器限幅，rtol 再收紧到 1e-8。

计算完，状态栏会写用了哪个积分器、为什么。也可以手选 DOP853 或 HHT。模型文件里没写 `integrator` 时，
`analysis.mbd.dae.advise.apply(model)` 按同样的规则填上。

HHT 的缺省容差是 rtol 1e-6、atol 1e-9，光滑系统的位置精度约 1e-4（相对运动幅度）。有冲击接触、阶跃设定值、输出限幅时，
把 rtol 收紧到 1e-8，或者仍用 DOP853。梁元件链用 HHT 时容差收紧到 1e-7（刚度比例阻尼对速度误差很敏感）。

梁元件（`forces` 里的 `beam`）的 `damping_ratio` 是**刚度比例阻尼系数**（阻尼阵 C = cr·K，单位 s，同 ADAMS 的 CRATIO），
不是阻尼比；想要某阶频率 ω（rad/s）上的阻尼比 ζ，填 cr = 2ζ/ω。柔性构件（`flex`）的 `damping_ratio` 才是模态阻尼比。

细长杆受压超过欧拉临界载荷会屈曲：梁元件链能算出来（几何非线性），柔性构件（线性小变形）算不出，选模型时注意。结果的 `solver` 里记着步数、拒绝步数、雅可比次数，可以看算得顺不顺。

## 结果可信吗

- 每次计算都带核查：约束残差、自由度、（无耗散时）能量漂移、（线性化时）稳定性；删去的冗余约束列出来；不通过的照实写出来。
- 验证手册（`docs/verification/mbd/`，中英两版 PDF）：44 道标准题，对照解析解、教材公式、文献基准解或独立程序——单摆、
  Andrews 挤压机构、曲柄滑块、赫兹碰撞、齿轮侧隙、转子涡动、悬臂梁（同一网格 CalculiX 直接静力）、弹性线、屈曲载荷等。
  手册里每个数字都是运行 `tests/test_mbd_*.py` 时算出来的；自己重新生成：`python -m assist.mbd_verification --out 目录`。
- 缺数据就报错，不估：材料没有密度、柔性材料缺弹性模量、FMU 缺变量等。

## 局限

- 柔性体是线性小变形（浮动坐标系 + 模态）；大变形、塑性不算。
- 应力云图只画实体柔性体的表面；梁柔性体不画云图。
- 硬系统用 HHT 积分器（见上）；HHT 的力雅可比目前用逐列差分，坐标很多（几百个）时每次雅可比要几秒，ADR-0098 E2 再提速。
